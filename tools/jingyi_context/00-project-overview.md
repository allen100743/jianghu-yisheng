# 專案概覽 — 靜怡必讀

## 遊戲基本定位

**名稱**：江湖一生（暫定）
**類型**：武俠沙盒生涯 RPG（PC Steam，明朝洪武年間）
**核心體驗**：玩一個武俠角色從出生到死亡的完整一生，選擇有代價，時間不可逆

## 四個設計支柱（所有 UX 決策的最高依據）

| 支柱 | 意義 | UX 含義 |
|------|------|---------|
| **這是我的一生** | 一局 = 角色完整生命，有生老病死 | 每個介面要強化「我正在活這個角色」的感受 |
| **選擇有代價** | 每個決定有真實後果，無法撤回 | 關鍵選擇前：給「夠多資訊做決定，但看不到全部後果」 |
| **江湖有人** | NPC 有自己的記憶、目標、恩怨 | NPC 狀態和關係的可感知性要靠環境和行為，不靠數值 |
| **時間可見** | 角色和世界隨時間真實變化 | 時間流逝要有視覺錨點，老化和世界變化要可察覺 |

## 目標玩家心理

- **不是戰鬥爽快黨**：他們要的是「這個世界對我的選擇有記憶」
- **不是任務清單黨**：他們要的是「這一生走過的路有意義」
- **是沉浸敘事黨**：玩家要感覺自己「活在江湖裡」，不是「在操作 UI」

## 技術限制（影響 UX 設計範圍）

- 平台：PC Steam（鍵鼠主要，手把部分支援）
- Solo 開發：每個 UX 方案必須有 MVP 版本，不能依賴大量美術資源才能驗證
- 引擎：Godot 4.6 + GDScript
- 製作人不做過場動畫和 cutscene：UX 設計要考慮無過場的情況
