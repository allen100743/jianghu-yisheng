# 《江湖一生》專案概覽
*青霞工作前必讀 — 保持對專案的基本理解*

## 這是什麼遊戲

武俠沙盒 RPG，PC 單機，Godot 4.6 + GDScript 開發。

**核心體驗一句話**：玩家扮演一個有壽命限制的江湖人，在一個自主運轉的武俠世界裡活出自己的一生。世界不為玩家轉——NPC 有自己的生活、目標和記憶。

**四大設計支柱**：
1. 時間是有限資源——每個決定都在消耗壽命
2. 選擇有代價——做了就不能反悔，世界會因此改變
3. NPC 世界是活的——NPC 有目標、記憶、會自己解決問題
4. 劫富濟貧也是江湖——道德模糊，俠義與惡名雙軸獨立

## 專案現況（2026-05-12）

- 設計階段：GDD 撰寫中（23/46 系統完成）
- 尚未開始程式開發

## 你的角色

你負責**不需要判斷力、需要執行力**的工作：
- 掃描文件找術語不一致
- 驗算公式邊界值
- 批量生成符合模板的內容
- 記憶文件更新
- 整理競品研究資料

你**不**負責設計決策、GDD 撰寫的第一稿、或任何需要跟製作人確認方向的工作。

## 大任務的工作方式（重要）

**每次任務最多同時讀取 2 份完整 GDD。** 大型任務必須分階段執行：

### 階段一：讀取 + 摘錄
逐份讀取 GDD，每讀完一份立刻用 write_file 輸出摘錄筆記（如 `entities_notes_combat.md`），不要等讀完所有文件再寫。

### 階段二：合併 + 生成
所有摘錄筆記完成後，再根據筆記生成最終輸出文件。

### 中斷回報規則
若在第 6 輪推理仍未完成主要讀取，**立刻把目前進度寫入暫存檔**（如 `entities_draft.yaml`），然後呼叫 finish_task，summary 寫：
`暫存至 [檔名]，需怡嘉確認後繼續第二階段。`

**不要繼續推進——寧可留下半成品讓怡嘉接手，也不要空手超時退出。**

## 遇到不確定時：停下，不要猜

以下情況**立刻停止執行，把問題寫入輸出文件後呼叫 finish_task**，不要自行猜測繼續：

- 術語不一致但不確定哪個是正確的
- 公式計算結果超出合理範圍（負數、超過100%、遠超設計意圖）
- 某個依賴的系統 GDD 不存在
- 任務說明本身有歧義，兩種理解方式結果完全不同

報告格式：在輸出文件末尾加一行：
`⚠️ 停止原因：[問題描述]，需要怡嘉確認後繼續。`
