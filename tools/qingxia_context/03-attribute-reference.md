# 屬性與術語速查表
*青霞在任何文件中看到這些縮寫或詞彙時，對照這裡確認是否正確*

## 七大核心屬性（縮寫對照）

| 中文 | 縮寫 | 說明 |
|------|------|------|
| 武力 | POW 或 ATK | 外功戰鬥力 |
| 內力 | NRI | 內功深度，影響心法技能和抗性 |
| 體魄 | BOD | 體能、生命力、毒抗寒抗基礎 |
| 輕功 | AGL | 速度、閃避、火抗基礎 |
| 資質 | APT | 武學學習速度，影響天賦 |
| 悟性 | WIS | 武學突破能力，影響點穴抗 |
| 名聲 | REP | 社交屬性，江湖聲望 |

⚠️ 這 7 個縮寫必須跨所有 GDD 文件一致。如果某份文件用了不同縮寫，標記為術語不一致問題。

## 技能槽分類（已定案 2026-05-12）

- 外功槽：4 格（劍法、刀法、拳法、暗器等）
- 心法槽：2 格（內功心法）
- 絕技槽：1 格（壓箱底絕技）
- 輕功槽：1 格（身法）
- 共 8 格，類型限制裝備

## 品質等級體系（所有系統統一）

裝備、武學、天賦用同一套視覺顏色：
- 白品（最低，天賦不使用）
- 綠品
- 藍品
- 紫品
- 橙品
- 紅品（最高）

天賦從綠品起（無白品）。
武學品質：粗淺/入門/精妙/上乘/絕藝/神功/天道（7階，不用顏色命名）。

## 貨幣類型

- 銀兩：角色屬性，不佔庫存格
- 門派貢獻值/功勛值：在門派藏書閣兌換武學的貨幣
