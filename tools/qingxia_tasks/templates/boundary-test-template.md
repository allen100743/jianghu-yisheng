# 公式邊界壓力測試模板
*品霖完成任何公式章節後，青霞用此模板驗算*

> ⚠️ **只測試 entities.yaml 中標記 [LOCKED] 的公式。**
> [UNLOCKED] 公式尚未定稿，測出異常無法判斷是公式錯還是輸入錯，不要浪費算力驗算。

---

## 使用方式

1. 複製此模板，另存為 `tools/qingxia_tasks/boundary-test-[系統名稱].md`
2. 填入「系統名稱」和「公式來源」欄位
3. 逐條驗算每個公式的邊界值，將結果填入表格
4. 若計算結果異常，在「⚠️ 異常紀錄」區記錄並停止

## 合理性判斷標準

結果為「異常」的條件（任一滿足即標 ⚠️）：

- 輸出為**負數**（除非公式設計上允許負值）
- 輸出**超過設計文件明確標注的上限**
- 輸出出現 **NaN / Infinity / 除以零**
- 輸出結果超出直覺合理範圍（如「攻擊力 0 的玩家造成 500 傷害」）
- 門檻邊緣行為**與文件描述矛盾**（如文件說 0.3 觸發效果，但 0.299 就觸發了）
