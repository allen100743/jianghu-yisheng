# 江湖一生 — 設定/輸入系統 GDD
*策劃：陳品霖 | 版本：v1.0 | 審核：怡嘉 | 狀態：已審核 | 2026-05-12*
*系統編號：#40 | 層級：技術基礎*
*設計方法：情境先行 — 14情境→規格*
*依賴系統：平台 SDK（Steam）、音訊引擎、硬體抽象層*

---

## 1. 概述

設定/輸入系統是玩家與遊戲之間的摩擦消除器。它讓玩家在進入遊戲世界的第一秒，就能將遊戲改造為自己身體與習慣的延伸。核心原則：模組化、預設覆蓋、所見即所得、**輔助功能優先**。不追求功能堆疊，追求每一個設定在真實玩家情境下都有人用。

---

## 2. 玩家體驗

- **首次啟動** — 遊戲自動偵測硬體，設定解析度與畫質；出現簡潔對話框詢問「需要啟用輔助功能嗎？」，選是直接跳轉對應頁面
- **日常使用** — ESC 開設定，所有改動即時生效，無需重啟
- **極端情境** — 色弱玩家、左撇子、深夜玩家、Steam Deck 用戶，都能在 1 分鐘內找到並完成需要的設定

**刻意不追求：**
- 不是功能展示（沒有用不到的選項）
- 不是「最先進的引擎功能」秀場

---

## 3. 詳細規則

### 3.1 控制設定（Controls）— MVP

**三層優先架構（高→低）：**
1. 全域方案（玩家個人化配置）
2. 裝置方案（偵測到特定裝置自動切換）
3. 預設方案（遊戲內建配置）

**功能清單（MVP）：**

| 功能 | 說明 |
|------|------|
| 完全自由重映射 | 所有動作可綁定至鍵盤/滑鼠（含側鍵）/手把 |
| 左撇子模式 | 一鍵互換滑鼠左右鍵，同時提供 WASD→IJKL 或 8456 數字區快速遷移 |
| 搖桿 Y 軸反轉 | 移動軸與視角軸分開設定，互不影響 |
| 搖桿靈敏度/死區 | 各軸獨立數值 |

**V2 追加：**
- 滑鼠/搖桿加速曲線（線性/平滑/高精度/自訂）

### 3.2 輔助功能（Accessibility）— MVP 最高優先

獨立頁籤，狀態在存檔之上全域生效。

**視覺輔助（MVP）：**

| 功能 | 說明 |
|------|------|
| 色彩輔助模式 | 紅色盲/綠色盲/藍色盲色板校正；可手動微調關鍵 UI 元素和物件輪廓的色相/飽和度/亮度 |
| 字幕系統 | 大小滑桿（小/正常/大/特大）+ 背景透明度 + 說話者名稱 |

**視覺輔助（V2）：**
- 高對比度模式（增強敵我、互動物件、地形邊緣對比）

**聽覺輔助（MVP）：**

| 功能 | 說明 |
|------|------|
| 單聲道合併 | 合併左右聲道 |

**聽覺輔助（V2）：**
- 視覺化音效提示（腳步/攻擊方向 → 螢幕邊緣方向指示器）

**運動輔助（MVP）：**

| 功能 | 說明 |
|------|------|
| 按住取代連點 | 所有需要連點的 QTE 可設定為長按 |
| 閒置自動暫停 | 停止輸入超過 N 秒後暫停世界；可選「僅選單關閉時」或「任何時候」|

**運動輔助（V2）：**
- 粘滯按鍵（組合鍵改為依序按下）
- 鏡頭晃動/搖擺獨立滑桿（0 = 完全關閉）

### 3.3 音訊設定（Audio）— MVP

| 功能 | 說明 |
|------|------|
| 分軌控制 | 主音量/音樂/環境音效/腳步聲/語音，全部獨立滑桿 |
| 串流主模式 | 一個總開關：啟用時版權音樂替換為免版稅曲目，或選「關閉所有音樂僅留環境音效」|

**V2 追加：**
- 動態範圍模式（劇院/深夜壓縮/耳機）

### 3.4 影像設定（Video）— MVP

| 功能 | 說明 |
|------|------|
| 基礎 | 解析度、螢幕比例、視窗模式、垂直同步、幀率上限（30/60/120/144/無限制）|
| 省電模式 Preset | 30fps 鎖定 + 低解析度渲染（Steam Deck 情境）|
| 競技模式 Preset | 全畫質最低 + FOV 最大 + 關閉動態模糊/景深 |

**V2 追加：**
- FOV 滑桿、渲染解析度比例、動態解析度、反鋸齒模式
- 螢幕校正精靈（亮度/對比/HDR，含測試圖案）

### 3.5 遊戲性設定（Gameplay）

| 功能 | 階段 | 說明 |
|------|------|------|
| 血腥效果過濾 | MVP | 開/關/僅限效果；可設定家長密碼鎖定 |
| 教學提示 | MVP | 開/關/僅限新功能 |
| 自動存檔頻率 | V2 | 調整自動存檔間隔 |

## 4. 公式

### 4.1 最終音量計算

```
最終音量 = 主音量 × 分軌音量
範圍：[0.0, 1.0]
```

**串流主模式邏輯：**
```
if Streamer_Mode_On:
  if Music_Replace_Mode = "SafeTrack": 版權音樂 → 免版稅替代曲目
  if Music_Replace_Mode = "Off":       Music_Volume = 0
```

### 4.2 輸入優先級覆蓋

```
Active_Binding = Device_Override ?? Global_Remapping ?? Default_Binding
```

（`??` = 若左側為 null 則取右側）

## 5. 邊界條件

| 情境 | 處理方式 |
|------|---------|
| 最小可運行視窗 | 384×216，低於此不允許設定 |
| 按鍵衝突 | 允許衝突，但顯示紅色驚嘆號警告，不強制阻止（尊重玩家習慣）|
| 執行中更換/斷開設備 | 自動切換至下一個可用設備配置，彈出短暫提示 |
| 設定檔損壞 | 設定檔獨立於遊戲存檔；損壞時讀取預設值，遊戲本身不受影響 |
| w1+w2+w3 ≠ 1.0 | 系統自動標準化三個係數 |

## 6. 系統依賴

### 本系統依賴的系統

| 系統 | 說明 | MVP/V2 |
|------|------|--------|
| 平台 SDK（Steam）| Steam Input API（手把重映射、Deck 驗證）| MVP |
| Godot InputMap | 按鍵重映射的底層實作 | MVP |
| 音訊引擎 | 多軌即時混音、音軌切換 | MVP |
| 顯示管理器 | 解析度/視窗模式切換、HDR 支援 | MVP |

### 本系統對外廣播的事件

| 事件 | 觸發時機 |
|------|---------|
| `settings_changed(category, key, value)` | 任何設定值改變 |
| `input_device_changed(device_type)` | 輸入裝置切換 |
| `colorblind_mode_changed(mode)` | 色彩輔助模式切換（渲染層需響應）|

## 7. 可調參數

**外部化至：`assets/data/settings/defaults.json`**

| 參數 | 預設值 | 說明 |
|-----|--------|------|
| `default_fov` | 75 | 預設 FOV（度）|
| `battery_saver_fps` | 30 | 省電模式幀率上限 |
| `auto_pause_idle_seconds` | 30 | 閒置自動暫停等待秒數 |
| `subtitle_default_size` | 2（正常）| 字幕預設大小（0=小/1=正常/2=大/3=特大）|
| `audio_bus_count` | 5 | 可獨立控制的音軌數（主/音樂/環境/腳步/語音）|

## 8. 驗收標準

| 編號 | 驗收項目 | 預期結果 | 阻斷 |
|-----|---------|---------|-----|
| AC1 | 滑鼠側鍵重映射 | 將動作綁定至滑鼠側鍵，功能正常觸發 | 是 |
| AC2 | 色盲模式 | 開啟任一色盲模式，UI 和場景色彩正確改變，可手動微調色相 | 是 |
| AC3 | 串流主模式 | 啟動後，版權音樂消失或被替換；環境音效正常 | 是 |
| AC4 | 分軌音量獨立 | 主音量=5%，腳步聲=80%，腳步聲能蓋過環境音 | 是 |
| AC5 | 競技模式 Preset | 選擇後，所有畫質選項自動設為最低，FOV 最大 | 是 |
| AC6 | 設定即時生效 | 任何設定更動無需重啟，即時反映在遊戲畫面/音效中 | 是 |
| AC7 | 按鍵衝突警告 | 兩個動作映射到同一鍵時，顯示紅色警告，但不阻止保存 | 是 |
| AC8 | 搖桿 Y 軸反轉分離 | 移動 Y 軸反轉與視角 Y 軸反轉獨立設定，互不影響 | 否（V2）|
| AC9 | 省電模式 | 選擇後幀率鎖定 30fps，畫質降低，Steam Deck 上電量消耗明顯降低 | 否（V2）|
