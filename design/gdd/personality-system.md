# 性格特質系統 GDD
*策劃：陳品霖 | 審核：怡嘉 | 製作人拍板：2026-05-11 | 狀態：✅ 已核准*

## 1. 概述

性格特質系統定義了角色的初始行為傾向與道德羅盤。玩家在角色創建時從八種性格中選擇一種，每種性格以三級光譜（-1 / 0 / +1）呈現，代表該性格的純粹程度。性格將直接影響角色的初始屬性、NPC對他的第一印象，以及遊戲中可觸發的特殊對話選項，是玩家定義「我是誰」的第一步。

## 2. 玩家體驗

- **角色扮演的起點**：玩家在創角時所做的第一個有意義的選擇，就是在定義「我這一生要成為什麼樣的人」。這不是一個無關痛癢的開場選項，而是會持續影響整個遊戲歷程的核心設定。
- **選擇有代價的初體驗**：玩家會立刻感受到「豪爽」帶來的好處（酒樓老闆好感+15）和代價（官府NPC好感-10）。這為整個遊戲的「選擇有代價」核心支柱立下明確的基調。
- **鼓勵重複遊玩**：不同的性格會開啟完全不同的對話路線和事件觸發條件，強烈鼓勵玩家嘗試不同性格，體驗不同的江湖人生。

## 3. 詳細規則

### 3.1 性格光譜（Severity 連續值模型）

每個性格由一個 `severity` 值（0.0 ~ 1.0）定義，代表該性格的純粹程度。`severity` 在角色創建時由玩家選擇（度數）決定，遊戲過程中可透過重大事件（如背叛、救贖）小幅變動。

### 3.2 初始屬性影響（修飾詞疊加）

性格的 `severity` 值會作為一個乘法修飾詞，影響角色的初始屬性。公式如下：

`最終初始屬性 = 基礎初始屬性 × (1 + 性格修飾詞)`

| 性格 | degree | 影響屬性 | 修飾詞值 | 數值範例 (基礎武力=20) |
| :--- | :--- | :--- | :--- | :--- |
| 豪爽 | +1 | 武力 | +0.15 | 20 × 1.15 = 23 |
| 陰沉 | +1 | 悟性 | +0.15 | 基礎悟性=15，最終=17 |
| 莽撞 | +1 | 武力 | +0.20 (更高風險) | 20 × 1.20 = 24 |
| 謹慎 | +1 | 輕功 | +0.10 | 基礎輕功=20，最終=22 |
| 正直 | +1 | 體魄 | +0.10 | 基礎體魄=40，最終=44 |
| 狡猾 | +1 | 悟性 | +0.10 | 15 × 1.10 = 16 |
| 冷酷 | +1 | 武力 | +0.10 | 20 × 1.10 = 22 |
| 俠義 | +1 | 體魄 | +0.15 | 40 × 1.15 = 46 |

**Trade-off 設計：** 每個性格在提供一個屬性加成的同時，也會對另一個屬性造成減益。

| 性格 | degree | 減益屬性 | 修飾詞值 | 範例 (基礎內力=15) |
| :--- | :--- | :--- | :--- | :--- |
| 豪爽 | +1 | 悟性 | -0.10 | 15 × 0.90 = 13 |
| 陰沉 | +1 | 體魄 | -0.10 | 40 × 0.90 = 36 |
| 莽撞 | +1 | 悟性 | -0.15 | 15 × 0.85 = 12 |
| 謹慎 | +1 | 武力 | -0.10 | 20 × 0.90 = 18 |
| 正直 | +1 | 悟性 | -0.10 | 15 × 0.90 = 13 |
| 狡猾 | +1 | 武力 | -0.10 | 20 × 0.90 = 18 |
| 冷酷 | +1 | 名聲 | -0.15 (初始惡名) | 初始名聲=10，最終=8 |
| 俠義 | +1 | 輕功 | -0.10 | 20 × 0.90 = 18 |

### 3.3 NPC初始好感度影響

> **沙盒設計原則：性格對NPC的好感修正在「第一次實際遭遇該NPC」時套用，而非角色創建時。**
> 角色出生時不與任何NPC建立關係。NPC關係從0開始，於玩家首次遭遇時計算：
> `初始好感 = 0 + 出身背景修正(NPC類型) + 性格修正(NPC類型) + 當前名聲修正`
> 兩個修正值同時套用，不分先後順序。

性格會對特定類型的NPC產生初始好感度修正。這是加法修飾詞。

`NPC初始好感 = 基礎好感 + 性格好感修正`

| 性格 | degree | 好感修正對象 | 修正值 | 說明 |
| :--- | :--- | :--- | :--- | :--- |
| 豪爽 | +1 | 酒樓老闆、江湖幫眾 | +15 | 酒肉朋友多 |
| | | 官府衙役、錦衣衛 | -10 | 不拘禮法，易被官府側目 |
| 陰沉 | +1 | 情報販子、邪派中人 | +10 | 同類相吸 |
| | | 正道俠士、村莊百姓 | -15 | 感覺心機重，難以信任 |
| 莽撞 | +1 | 鏢師、傭兵頭領 | +10 | 欣賞其膽識 |
| | | 掌櫃、書生 | -15 | 覺得粗魯無禮 |
| 謹慎 | +1 | 商人、掌櫃 | +15 | 穩重可靠，是好客戶 |
| | | 江湖豪傑、綠林好漢 | -10 | 覺得是膽小鬼 |
| 正直 | +1 | 名門正派、清官 | +20 | 品性相投 |
| | | 黑道、貪官污吏 | -20 | 眼中釘 |
| 狡猾 | +1 | 黑市商人、騙子 | +15 | 欣賞其手腕 |
| | | 正直俠士 | -20 | 鄙視其為人 |
| 冷酷 | +1 | 殺手組織、邪派首領 | +10 | 認為是可造之材 |
| | | 一般百姓、善人 | -25 | 感到畏懼和厭惡 |
| 俠義 | +1 | 百姓、弱勢門派 | +20 | 視為救星 |
| | | 為富不仁者、惡霸 | -20 | 視為仇敵 |

### 3.4 對話選項觸發

遊戲中的對話節點會檢查玩家的性格 `severity`。如果 `severity` 高於某個閾值（例如 0.6），則會解鎖該性格專屬的對話選項。

- **功能**：這些選項通常能帶來獨特的解決問題方式、獲取情報的路徑，或觸發隱藏事件。
- **風險**：選擇性格選項可能會強化該性格（`severity` 小幅增加），或帶來預料之外的後果。
- **MVP 範圍**：每個性格至少設計 3 個專屬對話選項，分佈在遊戲早期（前兩小時）和中期。

## 4. 公式

### 4.1 性格 severity 與度數的轉換

```
severity = (degree + 1) * 0.4 + 0.1
```
- 當 degree = -1：`severity = 0 + 0.1 = 0.1` [需測試] 0.1 是否過低，導致效果不明顯。
- 當 degree = 0：`severity = 0.4 + 0.1 = 0.5`
- 當 degree = +1：`severity = 0.8 + 0.1 = 0.9` [需測試] 0.9 是否會讓角色極端化得太快。

### 4.2 屬性修飾詞計算

```
最終屬性 = 基礎屬性 × (1 + Σ性格加成修飾詞) × Π(1 + 其他乘法修飾詞)
```

- **範例**：
    - 角色選擇「莽撞 +1」。
    - 基礎武力 = 20。
    - 性格加成修飾詞列表：`{武力: +0.20, 悟性: -0.15}`。
    - 最終武力 = `20 × (1 + 0.20) = 24`。
    - 最終悟性（假設基礎悟性=15）= `15 × (1 - 0.15) = 12.75`，取整為 `13`。

### 4.3 NPC好感度修正計算

```
最終初始好感 = 基礎初始好感 + Σ性格好感修正值
```

- **範例**：
    - 角色選擇「俠義 +1」。
    - 遇到一個村莊百姓（基礎好感 = 25）。
    - 性格好感修正列表：`{百姓、弱勢門派: +20}`。
    - 最終初始好感 = `25 + 20 = 45`。

## 5. 邊界條件

- **多性格疊加**：角色一生只能選擇一個主要性格。遊戲中無法透過任何方式獲得第二個性格。
- **性格變更**：角色性格的 `severity` 可在遊戲中變動，但**無法改變性格類型**（例如，從「豪爽」變成「陰沉」）。變動範圍僅限於同一性格光譜內（-1 ~ +1 之間）。
- **NPC好感度上限**：性格帶來的好感度修正，受 NPC 好感度系統的上下限約束（例如，好感度範圍為 -100 ~ 100）。修正值不能超出此範圍。
- **對話選項衝突**：當玩家同時滿足多個性格的對話選項觸發條件時（理論上不可能，因只有一個性格），系統優先顯示 `severity` 值更高的性格選項。若 `severity` 相同，則按預設的系統優先級顯示。
- **創角後悔**：角色創建完成後，性格即鎖定。遊戲中不提供重新選擇的機會，以符合「選擇有代價」的原則。

## 6. 系統依賴

### 依賴其他系統
- **角色創建系統**：性格選擇是角色創建流程的一部分。
- **NPC人際關係系統**：需要讀取 NPC 的類型標籤（如「酒樓老闆」、「正道俠士」），才能應用好感度修正。
- **對話系統**：需要一個機制來檢查玩家的性格 `severity` 值，並動態加載對應的對話選項。

### 被其他系統依賴
- **世界感知系統**：角色的性格可能會影響其行為所產生的「江湖傳聞」的內容和傳播速度（V2 功能）。例如，一個「冷酷 +1」的角色行俠仗義，傳聞會更讓人難以置信，傳播速度可能減慢。

## 7. 可調參數（Tuning Knobs）

所有數值皆應外部化到設定檔（如 `character_traits.ini` 或 `trait_modifiers.json`）。

| 參數名稱 | 安全調整範圍 | 說明與影響 |
| :--- | :--- | :--- |
| `severity_base` | 0.05 ~ 0.2 | 公式 `severity = (degree + 1) * 0.4 + X` 中的常數 `X`。值越高，所有性格的基礎純粹度越高，極端性格的影響力會更強。 |
| `屬性加成修飾詞` | 0.05 ~ 0.30 | 控制性格對屬性的增益幅度。數值越高，性格對戰鬥風格的影響越大。 |
| `屬性減益修飾詞` | -0.05 ~ -0.20 | 控制性格對屬性的減益幅度。數值越低（負越多），選擇的代價越明顯。 |
| `NPC好感修正值` | -30 ~ +30 | 控制性格對社交的影響力。絕對值越大，性格對社交的決定性越強。 |
| `對話選項觸發閾值` | 0.4 ~ 0.7 | 控制性格對話選項出現的難易度。閾值越低，角色越容易展現性格。 |

## 8. 驗收標準（Acceptance Criteria）

- [ ] 角色創建介面中，八種性格及其三級光譜（-1/0/+1）可正常選擇與顯示。
- [ ] 選擇性格後，角色面板的初始屬性會根據公式正確計算並顯示。
- [ ] 選擇性格後，與不同類型 NPC 首次對話時，其好感度顯示正確的修正值。
- [ ] 當角色 `severity` 值達到觸發閾值時，對話中會出現對應的性格選項。
- [ ] 遊戲中所有因性格觸發的對話選項，其文字描述與角色性格設定一致。
- [ ] 所有數值（修飾詞、好感度、閾值）皆可從外部設定檔讀取，修改後重啟遊戲即生效。
- [ ] QA 人員可根據本文件，針對每一種性格的每一個度數，設計測試案例並驗證通過。

品霖筆記：
製作人，這個系統的設計完全遵循了「選擇有代價」和「資料驅動」的原則。我特別注意了以下幾點：

1.  **RimWorld 風格**：每個性格都是一個連續的光譜，而不是離散的標籤，這為未來的擴展（如事件影響性格偏移）留下了空間。
2.  **HOI4 修飾詞架構**：屬性和好感度計算都採用了清晰的修飾詞疊加，易於理解和調整。
3.  **數值具體化**：所有影響都給出了具體的百分比或數值，避免了模糊描述。
4.  **Trade-off 明確**：每個性格都有明確的優點和缺點，沒有「純優點」的選項。

關於標注 `[需測試]` 的 `severity` 公式，我的測試方向是：建立一個快速原型，讓測試人員分別選擇 `severity_base = 0.1` 和 `0.2` 的設定進行遊戲，並反饋「角色性格鮮明度」和「選擇的代入感」。我們需要找到一個平衡點，讓性格有影響力，但又不至於讓角色變成一個扁平的刻板印象。
