## 1. 武學分類體系

### 設計核心原則

武學不只是戰鬥工具，更是玩家的**社交名片**與**故事觸發器**。
玩家學了華山劍法，江湖上就會有人因此尊重他，也有人因此想挑戰他。

### 五大武學類別

| 大類 | 核心屬性 | 戰鬥定位 | 風格描述 |
|------|---------|---------|---------|
| **外功** | 武力 | 主要傷害輸出 | 刀、劍、拳、掌、棍等直接打擊技。講究招式凌厲，一力降十會。 |
| **內功** | 內力 | 核心能力、續航、特殊效果 | 心法、吐納、運功。決定內力總量、恢復速度及驅動高階招式的能力。 |
| **輕功** | 輕功 | 機動、先手、規避 | 身法、步法、提縱術。影響閃避、先手順序及地圖探索效率。 |
| **奇術** | 悟性 | 控制、輔助、環境互動 | 暗器、點穴、毒術、機關術、醫術。非正面戰鬥，但能創造戰機。 |
| **絕學** | 多項高門檻 | 終極招式、逆轉戰局 | 門派鎮派之寶、失傳秘典。學習條件極苛刻，威力巨大，使用有高代價。 |

### 屬性成長對應

| 練武行動 | 主要成長屬性 | 次要成長屬性 |
|---------|------------|------------|
| 練習外功 | 武力 | 體魄 |
| 修習內功 | 內力 | 體魄 |
| 鍛鍊輕功 | 輕功 | 體魄 |
| 鑽研奇術 | 悟性 | 資質 |
| 參悟絕學 | 資質、悟性 | 對應絕學所需屬性 |

**設計意圖：** 體魄是唯一在所有練武行動中都有次要成長的屬性，呼應「體魄決定壽命」的核心設計。練武本身就是在鍛鍊身體。

## 2. 武學學習機制

### 2.1 獲取途徑

| 途徑 | 說明 | 風險/代價 |
|------|------|----------|
| **師父傳授** | 加入門派或拜師後，消耗時間和門派貢獻學習 | 需忠於門派，叛門可能廢武功 |
| **自行摸索** | 從秘笈、殘卷、壁畫中參悟 | 耗時長、可能走火入魔（減壽/扣屬性） |
| **奪取** | 擊敗或殺死特定NPC獲得 | 與該NPC及其關係網全面敵對，名聲大幅下降 |
| **購買** | 在拍賣會或黑市用銀兩交換 | 花費巨大，高階武學有「身份權限」限制 |
| **門派藏書閣兌換** | 進入門派藏書閣，以門派貢獻值（功勛值）+ 身份等級兌換武學 | 需累積貢獻值，且身份等級決定可查閱品質上限 |
| **交換** | 以物易物或以「人情」交換 | 需要深厚的關係資本 |
| **自創** | 悟性和資質達極高水準，消耗大量時間自創武功 | 成功機率低，但創造出的武學完全契合自身 |

**P0 MVP優先實裝：** 師父傳授、自行摸索（秘笈系統）、購買、門派藏書閣兌換
**P1 正式版補完：** 奪取、交換
**P2 後續版本：** 自創

#### 2.1a 門派藏書閣兌換（商店邏輯）

- 進入門派藏書閣 → 顯示可兌換武學清單（按身份等級篩選，玩家只看得到自己等級有權查閱的武學）
- 兌換條件：**門派貢獻值（功勛值）** + **身份等級**
- 身份等級決定可查閱的武學品質上限
- 門派貢獻值是類似銀兩的門派貨幣，透過完成師門差事獲得，不可跨門派使用
- **普通弟子**只能兌換粗淺（灰）/ 入門（白）武學；**精英弟子**可兌換精妙（綠）；**長老以上**可兌換上乘（藍）及絕藝（紫）以上武學
- 兌換後武學進入庫存，以秘笈形式存在，需另行學習才能熟練使用

### 2.2 屬性門檻

每門武學有最低屬性要求。

| 門檻類型 | 說明 | 範例 |
|---------|------|------|
| **單一屬性門檻** | 某個屬性達到特定值 | 「武力≥30」才能學太祖長拳 |
| **複合屬性門檻** | 多個屬性同時達到要求 | 「武力≥50、內力≥30」才能學華山劍法 |
| **隱藏門檻** | 需要特定稱號或事件觸發 | 「一代宗師」才能參悟絕學 |

**屬性不足的後果：**
- 有師父教：不能學，師父說「你底子還不夠」
- 自行摸索：可以強行參悟，但觸發「走火入魔」事件 → 屬性暫時或永久受損
- 奪取/購買：拿到秘笈也看不懂，無法裝備

### 2.3 熟練度系統（五階）

| 階段 | 名稱 | 效果倍率 | 提升方式 |
|------|------|---------|---------|
| 1 | 入門 | 基礎效果 × 1.0 | 學會即達成 |
| 2 | 熟練 | × 1.2 | 戰鬥使用5次，或練習10天 |
| 3 | 小成 | × 1.4 | 戰鬥使用20次，或練習30天 |
| 4 | 大成 | × 1.7 | 戰鬥使用50次，或練習60天，或「頓悟」事件 |
| 5 | 圓滿 | × 2.0，解鎖隱藏效果 | 達「大成」後，在特定情境（如生死關頭）觸發「天人合一」事件 |

**設計意圖：** 一個把「太祖長拳」練到圓滿的江湖老手，比剛學會「獨孤九劍」的新手更具威脅。這讓低品質武學在後期仍有價值。

> **系統邊界：武學熟練度和天賦效果各自獨立計算。**
> - 武學系統負責：熟練度進階條件、「天人合一」觸發條件、突破所需時間（閉關天數）
> - 天賦系統負責：天賦效果修飾詞（包含「武道通神：閉關時間+50%」）
> - 天賦「武道通神」的「閉關時間+50%」作為修飾詞疊加至武學系統的突破時間計算上，公式為：
>   `實際閉關天數 = 基礎閉關天數 × (1 + 武道通神修飾詞)`
> - 「天人合一」戰鬥觸發機制**不受閉關時間影響**（因為它是戰鬥中自然觸發的感悟事件，不是主動閉關行為）

**品質對熟練度上限的影響（參考龍胤）：**

| 武學品質 | 熟練度上限 | 說明 |
|---------|----------|------|
| 凡品（灰） | 熟練（2階） | 練到頂也就那樣 |
| 精良（白） | 小成（3階） | 有一定潛力 |
| 利器（綠） | 大成（4階） | 可練到相當火候 |
| 寶器（藍） | 大成（4階） | 同上 |
| 神兵（紫） | 圓滿（5階） | 可達最高境界 |
| 絕世（金） | 圓滿（5階） | 同上 |
| 天工（紅） | 圓滿（5階）+ 特殊效果 | 傳說級 |

**P0 MVP：** 熟練度系統完整實裝（五階），品質對上限的影響先以簡單的條件判斷實現。

## 4. 武學組合與流派

### 4.1 同一流派加成

當玩家同時裝備同一流派的**多門武學**時，啟動流派加成。

**範例：華山劍派**

| 流派 | 核心 | 組成武學 | 裝備2件效果 | 裝備3件效果 |
|------|------|---------|------------|------------|
| 華山劍派 | 輕靈、迅捷、後發先至 | 華山劍法（外功）+ 養吾劍氣（內功）+ 雲梯縱（輕功） | 劍法招式速度+15% | 施展劍法時有機率觸發「無招勝有招」，無視對手部分防禦 |

**設計原則：**
- 流派加成是**錦上添花**，不是核心強度來源
- 鼓勵玩家深度投入一個門派，但不強迫
- 加成效果與流派特色一致（華山快、武當柔、少林剛）

### 4.2 跨流派組合技

玩家自行探索發現的隱藏效果，帶有強烈驚喜感。

| 組合 | 觸發條件 | 效果 |
|------|---------|------|
| 狂風刀法（外功）+ 梯雲縱（輕功） | 兩門武學皆達「小成」以上 | 「天外飛仙」：一次高額單體傷害，無法被格擋 |
| 龜息功（內功）+ 點穴手（奇術） | 兩門武學皆達「大成」 | 「龜息點穴」：大幅降低存在感，點穴成功率提升 |
| 辟邪劍法（外功）+ 葵花寶典（內功） | 兩門武學皆達「圓滿」 | 「劍氣縱橫」：範圍攻擊，附帶流血效果 |

**設計意圖：** 組合技是給探索型玩家的獎勵，不是強制所有玩家都要找的。發現組合技時，系統給予明確提示（如「你隱約覺得這兩門武功之間存在某種聯繫……」）。

**P0 MVP：** 流派加成實裝（簡化版，2件即可），組合技暫不實裝
**P1 正式版：** 組合技系統

## 6. 武學與NPC的互動

### 核心設計原則：武學是社會標籤

你學了什麼武功，江湖上的人就會據此判斷你是誰、值不值得尊重、該不該殺。

### 6.1 門派歸屬識別

| 情境 | NPC反應 |
|------|--------|
| 施展某門派獨門武學 | 同門或友好門派NPC增加好感，可能提供更高階武學或任務 |
| 在敵對門派面前施展其獨門武學 | 被視為挑釁，好感大幅下降或直接觸發戰鬥 |
| 施展失傳或罕見武學 | 引起江湖人士注意，名聲傳播速度加快，可能引來覬覦者 |

### 6.2 特定NPC反應類型

| NPC類型 | 對武學的反應 |
|---------|------------|
| **武痴** | 見到精妙武學會主動上前切磋，無論勝負都可能結為好友 |
| **仇家** | 見到玩家使用殺害其親友的武學，觸發「血海深仇」事件 |
| **名門正派** | 玩家使用邪派武學（如「奪命十三劍」），被列入「誅邪令」 |
| **朝廷鷹犬** | 玩家使用驚世駭俗的武學，增加被監視或通緝的風險 |

### 6.3 武學與世界感知連動

玩家在公開場合施展高品質或稀有武學時：
1. 事件成為「江湖傳聞」進入世界感知系統傳播
2. 直接影響名聲值（正邪兩面）
3. 吸引特定類型NPC前來拜訪或挑戰

**範例：**
> 玩家在蘇州城用「奪命十三劍」擊敗了當地惡霸。
> - 消息以「蘇州城出現神秘劍客，用的竟是傳說中的奪命十三劍」傳開
> - 華山派弟子對你態度複雜（此劍法曾殺害華山前輩）
> - 三天後，一位自稱「修羅門使者」的NPC找上門，邀請你加入

### 6.4 武學衝突事件

| 事件 | 觸發條件 | 後果 |
|------|---------|------|
| **清理門戶** | 使用叛門前所學的獨門武學 | 原門派派出追殺小隊 |
| **以彼之道還施彼身** | 用某門派的武學擊殺該門派弟子 | 該門派視你為死敵 |
| **武學傳承** | 將高品質武學傳授給特定NPC | 建立深厚關係，可能觸發後續事件 |

## 7. 數值設計（初步）

### 7.1 武學傷害公式（草案）

```
基礎傷害 = 武力 × 武學基礎係數 × 熟練度倍率
```

| 武學品質 | 基礎係數範圍 |
|---------|------------|
| 粗淺（灰） | 0.5 - 0.8 |
| 入門（白） | 0.8 - 1.2 |
| 精妙（綠） | 1.2 - 1.8 |
| 上乘（藍） | 1.8 - 2.5 |
| 絕藝（紫） | 2.5 - 3.5 |
| 神功（金） | 3.5 - 5.0 |
| 天道（紅） | 5.0+ |

### 7.2 熟練度消耗公式（草案）

```
每日練功消耗體力 = 20 + (武學品質階級 × 5)
```

- 體力每日恢復：基礎恢復量 = 體魄 × 0.5
- 體力不足時練功效率下降，嚴重時可能受傷

### 7.3 學習時間公式（草案）

```
學習天數 = 基礎天數 × (1 - 資質/1000)
```

| 品質 | 基礎天數 |
|------|---------|
| 粗淺（灰） | 3天 |
| 入門（白） | 7天 |
| 精妙（綠） | 15天 |
| 上乘（藍） | 30天 |
| 絕藝（紫） | 60天 |
| 神功（金） | 120天 |
| 天道（紅） | 180天 |

**範例：** 資質500的玩家學「精妙」武學 → 15 × (1 - 500/1000) = 7.5天

## 2. 玩家體驗（Player Fantasy）

（補齊缺失章節）

- **「這招是我的」**：玩家學了一門武學，練到圓滿，它就成了這個角色的標誌。其他人一看這招式，就知道是你。武學是角色身份的一部分。
- **「為了這本秘笈值了」**：千里尋訪、以命換來的一本神功秘笈，翻開時的期待感——這和打怪刷寶的爽感同出一源，只是更深沉。
- **「我比昨天強」**：熟練度從入門到圓滿，每一個階段的突破都有可感知的差異。同一招打出去的效果不同，是最直接的成長感。
- **「這個流派就是我」**：專精一個門派的玩家，不只是數值更強，而是整個江湖都用這個流派來認識你。「華山弟子」不是標籤，是你的江湖身份。

## 5. 邊界條件（Edge Cases）

（補齊缺失章節）

| 情境 | 處理方式 |
|------|---------|
| 屬性不足強行摸索秘笈 | 觸發「走火入魔」事件，套用傷勢系統的內傷效果，severity 依失敗程度決定 |
| 武學熟練度滿後繼續練習 | 不再獲得熟練度，但可觸發「頓悟」事件（機率觸發，提供其他收益）|
| 已達品質上限仍試圖突破 | 系統提示「此武學已臻極限，需更高品質的同類武學引路」|
| 武學秘笈丟失/被搶 | 熟練度已練成的部分保留；未學的內容隨秘笈消失 |
| 叛門後使用原門派武學 | 廣播事件給 NPC 行為系統，具體後果（追殺/降好感）由該系統處理 |
| 同時裝備超過技能槽上限的武學 | 超出部分不生效，系統提示玩家管理已裝備武學。技能槽共8格：外功槽4格、心法槽2格、絕技槽1格、輕功槽1格。同類型武學只能裝入對應槽位。 |
| 「嫁衣神功」傳功後原角色的狀態 | 傳功者內力歸零，屬性受損；接受者獲得對應加成。詳細規則見任務/事件系統 |

## 8. 驗收標準（Acceptance Criteria）

（補齊缺失章節）

| # | 驗收項目 | 預期結果 |
|---|---------|---------|
| AC1 | 五大武學類別正確分類顯示 | 武學詳情頁顯示正確類別標籤 |

| AC5 | 品質上限限制熟練度進階 | 凡品武學在熟練（2階）後無法繼續升階，系統提示正確 |
| AC6 | 學習天數公式計算正確 | 資質500，精妙武學：`15×(1-0.5)=7.5天`，顯示8天 |

| AC9 | 戰鬥使用次數計入熟練度 | 戰鬥使用5次後，入門→熟練提示觸發 |
