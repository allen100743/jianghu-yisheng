## 1. 概述（Overview）

戰鬥系統是《江湖一生》中玩家驗證自身成長、解決衝突的核心機制，但不是遊戲的唯一重心——它是江湖生活的一部分。

**設計核心原則（來自 core-gdd.md Ch10）：**
- 打贏之後發生的事，和怎麼打贏一樣重要
- 戰鬥是故事的一部分，不是故事的全部

**技術規格（已定案）：**
- 視角：橫版側視，動作感強，招式清晰可見
- 制式：即時制（非回合制）
- 場景：獨立戰鬥場景，從大地圖切入，打完切回

---

## 2. 玩家體驗（Player Fantasy）

**目標體驗：暗黑破壞神的打怪刷寶感**

| 階段 | 時數 | 核心感受 |
|------|------|---------|
| 新手期 | 0–10h | 戰鬥是生存壓力，每場都關係存活 |
| 成長期 | 10–50h | 之前打不過的敵人現在輕鬆取勝，成長感清晰 |
| 高手期 | 50h+ | 戰鬥是風格展現，追求打得漂亮、以寡敵眾 |

**鋸齒狀體驗曲線（核心設計）：**
```
爽（輕鬆）→ 遇牆（挑戰）→ 追求成長 → 突破 → 爽 → 更高的牆 → ……
```
- 牆要可見：輸了要知道為什麼輸
- 缺口要可填：知道去哪補（找更好的武學/裝備/隊友）
- 突破要有爽感：前面打不過的，現在輕鬆解決

## 3. 詳細規則（Detailed Rules）

### 3.1 大地圖遭遇機制（龍胤立志傳風格）

**設計原則：玩家看得見、有反應時間、有選擇權。嚴禁踩地雷式隨機觸發。**

大地圖行走時，NPC 可見於地圖上。玩家走近時出現**互動介面**，由玩家決定如何應對：

| NPC 類型 | 互動結果 |
|---------|---------|
| 中立 / 友善 NPC | 出現對話選項，玩家可選擇對話、交易、或離開 |
| 敵對 NPC（強盜/仇敵）| 出現互動介面後直接進入戰鬥，或玩家可嘗試逃跑 |
| 事件點 NPC | 特定顏色標記（傳聞點），玩家主動走近觸發探索/戰鬥 |

玩家在進入戰鬥前始終有**至少一次選擇機會**，除非被伏擊（特定劇情觸發）。

### 3.1d 戰鬥狀態（讀取傷勢系統 #43）

戰鬥狀態**不是獨立定義**，而是傷勢與狀態效果系統（#43）在戰鬥中的行為表現。系統讀取 #43 的 severity 值，決定單位可執行的行為：

| 底層狀態效果（#43）| 戰鬥中的行為限制 |
|-----------------|--------------|
| 外傷（手臂）| 武學技能無法釋放，普攻傷害降低 |
| 外傷（腿部）| 移動速度大幅降低，閃避無效 |
| 中毒（麻痹型）| 無法移動，可被攻擊，等同定身 |
| 中毒（暈眩型）| 完全無法行動，持續至 severity 降低 |
| 冰凍效果 | 無法移動，受到傷害+易傷加成 |
| 中陷阱（事件觸發）| 套用對應狀態效果，由事件系統傳遞 |
| 恐懼效果 | 優先觸發逃跑行為 |

severity ≥ 0.6 的狀態效果在戰鬥中通常會明顯限制行為；severity ≥ 0.9 接近無法戰鬥。詳細閾值見 status-effects-system.md。

### 3.2 戰鬥流程

1. **觸發**：玩家或 NPC 發起攻擊，或事件觸發 → 進入獨立戰鬥場景
2. **場景切入**：根據地點類型（野外/城鎮/門派/室內）載入對應背景
3. **先手判定**：所有參戰單位依輕功屬性決定出手順序。實作方式：以進場動畫時間差呈現——輕功較高者動畫播完更快，率先可以行動。非回合制跳號，而是視覺上的快慢差異。
4. **戰鬥進行**：即時制，玩家可隨時按 `Space` 暫停下達指令
5. **勝利條件**：消滅所有敵方，或敵方投降/逃離
6. **失敗條件**：玩家角色 HP 歸零（MVP：直接 Game Over；V2：重傷瀕死機制）
7. **結算**：掉寶、傷勢狀態更新、廣播戰鬥事件至各系統

### 3.5 自動戰鬥 + 速度控制

**四種模板（戰鬥外或暫停時選擇）：**

| 模板 | 行為風格 | 適合場景 |
|------|---------|---------|
| 激進 | 優先最大傷害，不保留資源 | 碾壓戰、刷怪 |
| 穩健 | 攻守平衡，保留部分 MP/SP | 強度相當的戰鬥 |
| 保守 | 優先生存，頻繁閃避格擋 | 挑戰高難度 |
| 輔助 | 優先增益/治療，保持距離 | 有隊友時補位 |

**速度控制：**
- `1x`：正常速度
- `1.5x`：加速
- `2x`：最大加速

速度控制在自動戰鬥時可用，手動戰鬥建議保持 1x。

**切換邏輯：** 自動戰鬥中，任何手動操作（移動/攻擊/技能）立即切換回手動。

### 3.6 傷害計算

**流程：** 命中判定 → 閃避判定 → 格擋判定 → 基礎傷害 → 最終傷害

**命中：** 基礎命中率 100%，目標閃避中則降低

**閃避率：**
```
閃避率% = 輕功 / (輕功 + 500) × 100
```

**格擋減免：**
```
格擋減免% = 50 + (體魄 / 1000) × 30
```

**傷害公式：**
```
基礎傷害 = Skill_Power × (1 + ATK / 500) × (1 + Mastery_Bonus)
最終傷害 = floor(基礎傷害 × (1 - 減傷%) × (1 + 增傷%))
```

**熟練度加成：** 入門 0% / 熟練 20% / 小成 40% / 大成 70% / 圓滿 100%

**減傷%疊加規則：** 多個減傷來源（格擋、裝備詞條、狀態效果）採**乘法疊加**，非相加：
```
總減傷係數 = (1 - 減傷A%) × (1 - 減傷B%) × ...
最終傷害 = floor(基礎傷害 × 總減傷係數 × (1 + 增傷%))
```
**最低傷害下限：最終傷害不得低於基礎傷害的15%**（防止多層減傷疊加至免傷）。

**增傷%來源說明：** 增傷%是最終傷害乘數，所有來源疊加計算。來源包括：
- 裝備詞條（如「破甲增傷+15%」）
- 狀態效果（如「易傷」標記令目標受傷+20%）
- 武學屬性相生加成（如剛內功+剛外功組合：傷害+15%，見3.9節）
- 技能自身加成

**範例：** ATK=200，技能威力=50，小成（40%），目標減傷10%，自身增傷5%
```
基礎傷害 = 50 × 1.4 × 1.4 = 98
最終傷害 = floor(98 × 0.9 × 1.05) = 92
```

### 3.7 掉寶系統（核心回饋循環）

**目標感受：暗黑破壞神——殺怪有掉落，好東西是情緒高點。**

**設計原則：**
- 每個敵人死亡**必有掉落**（哪怕只是幾兩銀子）
- 掉寶視覺：物品從敵人身上散出，玩家走過去拾取
- 掉寶品質與敵人難度正相關

**掉落類型：**

| 類型 | 說明 | 情緒價值 |
|------|------|---------|
| 金錢 | 銅錢/銀兩，最常見 | 低，但積少成多 |
| 材料 | 藥材/礦石/皮革，用於製作 | 中 |
| 裝備 | 有詞條的武器/防具，品質隨機 | 高，好詞條是驚喜 |
| 武學殘篇 | 收集後合成完整秘笈 | 最高，驅動繼續探索 |

**品質分級：** 灰/綠/藍/紫/橙/紅，對應六色系統

**鋸齒體驗連結：** 打不過的敵人掉更好的東西 → 玩家有動力去追求成長突破，突破後回去刷 → 閉環。

### 3.8 可破壞環境（V2）

### 3.8a 地形規則（製作人確認版）

**基本規則：**
- 戰鬥場景為**純平面 2D**，無高低差、無平台跳躍、無懸崖內部地形
- 障礙物**要有但要少**——參考鬼谷八荒標準，不讓玩家感覺被卡死
- 場景邊界是戰鬥的自然邊界，無法離開戰場

**特殊地形格（狀態效果 × 圖資源包裝）：**

視覺資源決定效果，底層掛 #43 傷勢系統。玩家看到圖就知道效果，不需要說明書：

| 地形視覺 | 觸發條件 | 套用的狀態效果（#43）|
|---------|---------|-------------------|
| 泥濘/沼澤 | 單位站在上面 | 移動速度 -50%（外傷腿部包裝）|
| 冰面 | 單位站在上面 | 移動慣性增大，難以急停/轉向 |
| 火焰地面 | 單位站在上面 | 灼燒 DoT，severity 每秒+0.05 |
| 毒霧/藥粉地面 | 單位站在上面 | 中毒，severity 每秒+0.03 |

特殊地形**不強制出現**——由場景設計師根據地點類型（山林/雪地/廚房/煉丹房等）決定是否配置。

### 3.11 死亡規則

**玩家角色：**
- **MVP**：HP 歸零 → Game Over，載入存檔
- **V2**：HP 歸零 → 重傷瀕死狀態，可被道具或隊友救回（HP 上限暫時降低作為代價）

**NPC：**
- 有名有姓 NPC 死亡 → 廣播 `combat_npc_killed` 事件，由關係/事件系統處理後果
- 雜兵/野怪 → 消失，掉落戰利品

## 4. 公式（Formulas）

### 4.1 基礎資源公式

| 資源 | 公式 |
|------|------|
| HP | `體魄 × 5 + 50` |
| MP | `內力 × 3 + 20` |
| SP | `體魄 × 2 + 輕功` |
| 閃避率% | `輕功 / (輕功 + 500) × 100` |
| MP恢復/秒 | `max(1, floor(內力 / 100))` |
| SP恢復/秒 | `max(1, floor(體魄 / 50))` |

### 4.2 傷害公式

```
基礎傷害 = Skill_Power × (1 + ATK/500) × (1 + Mastery_Bonus)
最終傷害 = floor(基礎傷害 × (1 - 減傷%) × (1 + 增傷%))
格擋減免% = 50 + (體魄/1000) × 30
```

**最大傷害倍率分析（設計邊界）：**

| 情境 | ATK | Mastery_Bonus | 基礎傷害倍率 |
|------|-----|---------------|------------|
| 普通玩家中期 | 200 | 0.4（小成）| 1.4 × 1.4 = **1.96×** |
| 強力玩家後期 | 500 | 1.0（圓滿）| 2.0 × 2.0 = **4.0×** |
| 極限屬性（理論）| 800 | 1.0（圓滿）| 2.6 × 2.0 = **5.2×** |

> ATK 實際上限待 `core-gdd.md` 第14章定義後補充。
> 設計意圖：極限傷害含增傷加成不超過 **6× Skill_Power**，超過需設定 cap。（V2補入）

**Skill_Power 絕技錨點（100–300）：**

| 武學類型 | Skill_Power 範圍 | 設計定位 |
|---------|----------------|---------|
| 普通外功招式 | 30–60 | 每次可用，高頻出招 |
| 強化外功 | 60–120 | 有冷卻，拳腳精華 |
| 心法爆發 | 80–150 | 消耗高，強力輸出 |
| 絕技 | 200–300 | 壓箱底，每戰限用 |

**絕技秒殺設計意圖（重要）：** Skill_Power 上限 300 配合圓滿熟練度（+100%）與後期ATK（500），基礎傷害約 1200，可秒殺中期玩家（HP ≈ 975）。**這是設計意圖，不是缺陷。** 「絕技」的敘事承諾是江湖高手一招定勝負——武俠美學的核心之一。平衡由以下機制承擔：閃避率（輕功投資）、格擋機制（體魄投資）、絕技 MP 消耗上限、絕技槽只有1格。開發者不應以「防止秒殺」為由調低 Skill_Power 上限，如需調整應先分析上述平衡機制的充足性。

### 4.3 特殊地形效果公式

```
地形狀態 severity 增長/秒（站在上面時）：
火焰地面：灼燒 severity += 0.05/秒
毒霧地面：中毒 severity += 0.03/秒
（詳細閾值效果見 status-effects-system.md）
```

> 墜落傷害公式已移除——地形確認為純平面，無懸崖高低差。

## 5. 邊界條件（Edge Cases）

| 情境 | 處理方式 |
|------|---------|
| 友方與玩家同時打最後一擊 | 歸屬造成最後一擊者；任務物品歸擊殺者 |
| 敵人逃跑 | 全員逃離視為勝利；逃跑的敵人保留殘血，可能觸發後續事件 |
| 戰鬥中使用道具 | 短暫施法動作（無法移動/攻擊），道具生效 |
| SP/MP 不足 | 技能按鍵變灰，自動戰鬥改為普通攻擊 |
| 戰鬥中存檔 | 禁止，只能在非戰鬥狀態存檔 |
| 環境擊殺（墜落/火焰）| 戰利品自動結算入背包，不需手動拾取 |
| 多單位同時攻擊同一目標 | 各自獨立計算，依序應用，無傷害合併機制 |
| 劇情 NPC 被玩家意外殺死 | 相關任務鏈永久關閉或觸發替代任務，遊戲不崩潰 |

**劇情 NPC 死亡保護設計（三層機制）：**

| 層次 | 觸發條件 | 機制 |
|------|---------|------|
| **第一層：衝突預警** | 玩家將要攻擊劇情 NPC | UI 出現「此人與進行中任務相關，繼續攻擊可能影響任務」警告（僅顯示，不強制阻止） |
| **第二層：無敵保護** | 核心劇情 NPC（手動標記 `is_core_story_npc = true`）| 受到致死傷害時 HP 不歸零，鎖定在 1。廣播 `combat_npc_critical(npc_id)` 事件供敘事系統處理 |
| **第三層：後果廣播** | 普通劇情 NPC（`is_story_npc = true`，但非 core）死亡 | 廣播 `combat_npc_killed(attacker, victim, method, is_story_npc=true)`，接收方處理：任務系統進入 INVALIDATED（不廣播失敗後果）、NPC關係系統觸發門派仇恨、世界感知系統觸發名聲懲罰 |

**事件流對齊說明：** 戰鬥系統廣播 `combat_npc_killed`（含 `is_story_npc` 參數），任務系統、NPC關係系統、世界感知系統各自獨立監聽並處理，互不干擾。任務系統識別劇情NPC死亡後進入 INVALIDATED 狀態（而非 FAILED），保留武俠「人生無常」的設計意圖（見 task-system.md 第5邊界條件說明）。

## 7. 可調參數（Tuning Knobs）

| 參數 | 當前值 | 安全範圍 | 影響 |
|------|-------|---------|------|
| HP 係數 | 體魄×5 | ×3～×7 | 影響戰鬥時長與致命感 |
| 閃避公式分母 | 500 | 300～800 | 輕功的閃避成長曲線 |
| 武力傷害係數 | 1/500 | 1/300～1/800 | 武力對傷害的影響強度 |
| 格擋基礎減傷 | 50% | 30%～70% | 坦克流派的強度 |
| MP 恢復係數 | 內力/100 | 內力/50～內力/150 | 技能使用頻率 |
| 相生效果加成 | 視類型 | ±10%調整 | 屬性專精的回報 [需測試] |
| 速度控制上限 | 2x | 2x～4x | 刷怪效率 |
| 掉寶必有底線 | 最低銅錢 | 可調整 | 確保每場戰鬥有回報感 |

## 8. 驗收標準（Acceptance Criteria）

| # | 驗收項目 | 預期結果 |
|---|---------|---------|
| AC1 | 大地圖走近敵對 NPC，出現互動介面 | 玩家有選擇機會，不會直接跳入戰鬥 |
