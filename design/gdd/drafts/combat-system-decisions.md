# 戰鬥系統設計規格（製作人確認版）
*2026-05-12 | 競品研究完成後確認*

## 已確認的核心設計方向

### 大地圖遭遇機制（龍胤風格，這是最重要的改動）
- 大地圖上可見敵對/中立NPC，玩家走近觸發**互動介面**
- 玩家有選擇權：對話、逃離、或開打
- 惡意NPC（強盜/仇敵）→ 互動後必然進入戰鬥（或直接跳過互動）
- **嚴禁「踩地雷」式隨機觸發** — 這是鬼谷八荒的痛點，我們不重蹈

### 戰鬥制式
- **即時制**（不是龍胤的回合格子制）
- 獨立戰鬥場景（切入打完切回大地圖）
- 橫版側視（已在core-gdd.md定案）

### 自動戰鬥（標配，不是選配）
- 四模板：激進/穩健/保守/輔助（已在core-gdd.md定案）
- 速度控制：**1x / 1.5x / 2x**（core-gdd.md已定，品霖v1漏掉了）
- 任何時候可切換手動

### 可破壞環境（新增）
- 鬼谷八荒和龍胤都有，江湖一生也加
- 戰鬥場景中的物件（木箱、石柱、擺設）可被打爛
- 部分地格有特殊效果（滑油、高台、水坑等）
- MVP只做基礎破壞效果，V2再加地格特效

### 掉寶系統（核心回饋，目標感：暗黑破壞神）
- 每場戰鬥必有掉落（金錢/材料/裝備/武學殘篇）
- 好東西掉落是情緒高點，這是玩家繼續戰鬥的動力
- 掉寶視覺要有爽感（撒出來讓玩家撿）
- 掉寶品質與敵人難度正相關

### 鋸齒狀成長（core-gdd.md已定，需要在GDD中突出）
- 爽（輕鬆）→ 遇牆 → 追求成長 → 突破 → 爽 → 更高的牆
- 之前打不過的敵人，現在輕鬆解決 = 最強成長感

## 品霖v1草稿已有但需保留的部分
- HP/MP/SP 三資源系統
- 傷害計算公式（ATK/DEF/熟練度加成）
- 邊界條件（無法存檔/SP不足等）
- 驗收標準框架

## 品霖v1草稿需要修改的部分
- 速度控制1x/1.5x/2x要加回來（漏掉了）
- 大地圖遭遇機制要明確寫出（龍胤風格）
- 掉寶系統要獨立成一個設計章節（不只是「有機率掉落」）
- 可破壞環境要加入詳細規則
- 鋸齒狀體驗曲線要在GDD中有對應的設計說明
