## 江湖一生 — 數值設計框架（修訂版 v1.1）

**策劃：陳品霖 | 日期：2026-05-12 | 狀態：待審核**

### 1. 屬性清單（7核心屬性）

**設計思路**：7屬性涵蓋戰力、生存、社交、成長四面向。數值規模放大至0-1000區間，提供細膩的成長感，避免數值過早觸頂。

| 屬性 | 作用 | 初始值範圍 | 成長上限 | 影響面向 |
|---|---|---|---|---|
| **武力** | 物理攻擊力、外功招式威力 | 10-30 | 1000 | 戰鬥（傷害）、部分裝備門檻、NPC畏懼度 |
| **內力** | 內功強度、特殊招式消耗、內傷抗性 | 5-20 | 1000 | 戰鬥（內功傷害/防禦）、輕功持續時間、運功療傷效果 |
| **體魄** | 生命上限、負重、疲勞抗性、壽命基礎 | 30-50 | 800 | **壽命公式核心**、戰鬥生存、疾病免疫力、重傷恢復速度 |
| **輕功** | 移動速度、閃避率、跳躍高度、探索效率 | 10-25 | 900 | 戰鬥（閃避/先手）、地圖移動速度、偷竊/逃脫成功率 |
| **資質** | 學習武學的速度上限、突破瓶頸機率 | 15-35 | 700 | 武學熟練度增長倍率、悟得高階武功前置、**境界稱號評分係數** |
| **悟性** | 戰鬥中觸發「悟道」機率、自創武功靈感、破解機關 | 10-20 | 600 | 戰鬥特殊事件、非戰鬥解謎、高階武學參悟前置 |
| **名聲** | 社會影響力、NPC初始好感度、世界感知傳播速度 | 0-10 | 1000 | **世界感知公式核心**、門派加入門檻、任務獲取機率、仇人數量 |

**公式範例**：
- `生命值 = 體魄 × 5 + 50` (體魄50時 = 300 HP)
- `物理傷害 = 武力 × (1 + 武學熟練度加成%)` (武力300，熟練度+50%時，傷害450)
- `閃避率 = 輕功 / (輕功 + 500) × 100%` (輕功500時，閃避率約50%)

### 2. 境界稱號門檻

**設計思路**：綜合評分放大至龍胤立志傳規模（0-5000區間），確保從「江湖新丁」到「一代宗師」有充分的成長空間與成就感。門檻設計讓玩家在每個階段都能感受到明確的「牆」。

**綜合評分公式**：
```
綜合評分 = (武力 × 1.0) + (內力 × 1.2) + (體魄 × 0.8) + (輕功 × 0.9) + (資質 × 1.5) + (悟性 × 1.1) + (名聲 × 0.5)
```
*（係數反映屬性對整體江湖地位的影響力，資質與內力權重略高）*

**四階門檻**：

| 稱號 | 綜合評分門檻 | 對應屬性（舉例） | NPC反應 |
|---|---|---|---|
| 江湖新丁 | 0 - 500 | 武力50，內力30，體魄60，資質40 | 漠視、輕視、可隨意欺負 |
| 小有名氣 | 501 - 1500 | 武力200，內力150，體魄120，資質100 | 尊重、願意交易、開始有人挑戰 |
| 武林高手 | 1501 - 3500 | 武力500，內力400，體魄300，資質250 | 敬畏、主動結交、成為地方傳聞 |
| 一代宗師 | 3501 - 5000+ | 武力800，內力700，體魄500，資質400 | 傳說級、開宗立派資格、朝廷注意 |

**範例計算**：
- 角色A：武力100，內力50，體魄80，輕功60，資質70，悟性40，名聲20
  `評分 = 100 + 60 + 64 + 54 + 105 + 44 + 10 = 437` → **江湖新丁**
- 角色B：武力400，內力300，體魄250，輕功200，資質180，悟性120，名聲300
  `評分 = 400 + 360 + 200 + 180 + 270 + 132 + 150 = 1692` → **武林高手**

### 3. 壽命公式

**設計思路**：武俠世界，人終有一死。體魄決定壽命浮動，強化「體魄」這個屬性的戰略意義。額外增減留給事件，讓玩家對壽命有真實感。

**基準值**：70歲
**體魄影響**（結果取整數）：
- `體魄 < 100`：壽命 = 70 - floor((100 - 體魄) × 0.08) → 最多減8年（體魄0時壽命62）
- `100 ≤ 體魄 ≤ 400`：壽命 = 70 + floor((體魄 - 100) × 0.025) → 最多加7年（體魄400時壽命77）
- `體魄 > 400`：壽命 = 77 + floor((體魄 - 400) × 0.01) → 最多加4年（體魄800時壽命81）

**浮動範圍**：62 - 81 歲（約±10年）
**中位數偏差**：±5年（體魄200-300區間，壽命73-75歲）

**額外事件減壽**（舉例，非完整清單）：
- 重傷瀕死（生命低於20%）：-1~3年
- 習練陰毒邪功/走火入魔：-2~5年
- 長期飢餓/中毒：-1年/次
- 重大打擊（摯愛逝去、門派覆滅）：-1~3年

**額外事件增壽**（極罕見）：
- 獲得傳世靈藥：+5~10年
- 完成特定「養生」奇遇：+2~3年

**範例**：
- 體魄50的江湖新手：`壽命 = 70 - floor(50×0.08) = 70 - 4 = 66歲`
- 體魄250的武林高手：`壽命 = 70 + floor(150×0.025) = 70 + 3 = 73歲`
- 體魄700的一代宗師：`壽命 = 77 + floor(300×0.01) = 77 + 3 = 80歲`
- 宗師若經歷一次重傷：`壽命 = 80 - 2 = 78歲`

### 4. 鋸齒難度曲線

**設計思路**：一局遊戲40-80小時，設置五道明確的「牆」，確保玩家在每個階段都有「爽→撞牆→尋求突破→突破→再爽」的循環體驗。

| 牆序 | 出現時機（遊戲時間）| 牆的強度 | 牆的表現 | 突破手段 | 間距（遊戲月）|
|---|---|---|---|---|---|
| **第一堵** | 第1-3個月 | ★★☆☆☆ | 打不過山寨頭目、學武功卡瓶頸 | 換裝備（綠裝）、完成新手任務、提升基礎屬性 | 1-2月 |
| **第二堵** | 第12-18個月 | ★★★☆☆ | 打不過門派護法、加入門派須名聲100 | 提升名聲、學習門派武學、湊齊藍裝套裝 | 3-4月 |
| **第三堵** | 第36-48個月 | ★★★★☆ | 打不過地方梟雄、江湖稱號卡在「小有名氣」 | 刷紫裝詞條、突破資質瓶頸、完成重要奇遇 | 6-8月 |
| **第四堵** | 第72-96個月 | ★★★★★ | 打不過魔教長老、江湖稱號卡在「武林高手」 | 集齊金裝、自創武功、結交頂尖NPC | 12-18月 |
| **第五堵** | 第120-180個月 | ★★★★★★ | 打不過傳說級反派、世界事件（如正邪大戰）| 紅裝、宗師級武學、陣營領袖支持 | 24-36月 |

**設計說明**：
- 牆的強度遞增，但間距也遞增，讓玩家在後期有更長的「爽」期，然後迎接更大挑戰。
- 突破手段多樣化，避免單一解法（如：不是只有練功才能突破，社交、探索、裝備都可以）。

### 6. 世界感知傳播數值

**設計思路**：消息傳播有距離和時間，名氣加速。讓玩家感受到「名聲」是真實有價值的資源，同時增加世界的真實感與策略性。

**傳播速率公式**：
```
傳播速度 (公里/天) = 基礎速度 × (1 + 名氣加速係數)
```
- **基礎速度**：30里/天（步行傳播速度，約等於古代信使）
- **名氣加速係數**：`名聲 / 100`（名聲100時，速度加倍為60里/天；名聲500時，速度180里/天）

**距離衰減**：
- 消息強度（NPC相信程度/細節完整度）隨距離衰減
- `消息強度 = 100 - floor(距離 × 100 / (100 + 名聲 / 2))`（結果為整數%，最低0）
- 距離超過`100 + 名聲 / 2`里時，消息強度為0（完全不被相信或遺忘）

**傳播時間範例**：
- 一個「江湖新丁」（名聲10）在城中鬥毆：
  - 傳播速度：`30 × (1 + 10/100) = 33里/天`
  - 消息強度衰減到0的距離：`100 + 5 = 105里`
  - 傳到200里外：**永遠傳不到**，消息在105里處消散
- 一個「一代宗師」（名聲800）做了同一件事：
  - 傳播速度：`30 × (1 + 800/100) = 270里/天`
  - 消息強度衰減到0的距離：`100 + 400 = 500里`
  - 傳到200里外：`時間 = ceil(200/270) = 1天`，消息強度`100 - floor(200×100/500) = 60%`

**世界感知的影響**：
- NPC會根據收到的消息調整行為（仇人追殺、仰慕者追隨、商人漲價/降價）
- 消息傳遞有延遲，讓玩家有「時間差」可以利用（如：在消息傳到之前完成某件事）
- 名聲越高，你的行為影響範圍越大，但也越容易被仇人找到
