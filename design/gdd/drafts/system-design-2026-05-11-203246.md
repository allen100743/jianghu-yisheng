# 江湖一生 — 傷勢與狀態效果系統

## 1. 概述（Overview）

傷勢與狀態效果系統是角色在江湖中受傷、中毒、受控等負面體驗的統一規則引擎。本系統將所有負面效果（傷勢、中毒、內傷、點穴、恐懼等）建模為「狀態效果」（Status Effect），並透過「武俠抗性體系」來判定效果的持續時間與強度。核心邏輯是：**角色自身的抗性決定了負面效果的影響程度，而不是由效果的「優先級」來決定誰能覆蓋誰。**

## 2. 玩家體驗（Player Fantasy）

- **真實感**：玩家會感受到「內功深厚者百毒不侵」的武俠邏輯。一個修煉《易筋經》的高僧，與一個尋常江湖客，中了同一種毒，反應截然不同。
- **策略性**：玩家需要了解自己的抗性優劣，並據此選擇戰鬥策略或裝備。例如，面對擅長毒功的對手，裝備一件「辟毒玉佩」（提升毒抗）會比單純堆疊武力更有效。
- **代價感**：重傷不僅僅是血量減少，更會帶來持續的負面影響（如「骨折」降低武力），迫使玩家必須花費時間與資源去療養，體現「江湖凶險，代價真實」的核心支柱。
- **可預期性**：玩家可以透過角色面板查看自身各項抗性，並在戰鬥中看到敵我雙方的狀態效果，從而做出有根據的判斷，而不是被隨機的負面效果搞到挫敗。

## 3. 詳細規則（Detailed Rules）

### 3.1 狀態效果（Status Effect）定義

每個狀態效果是一筆配置資料，包含以下欄位：

| 欄位 | 類型 | 說明 | MVP |
|:---|:---|:---|:---|
| `ID` | 字串 | 唯一標識，如 `poison_snake` | P0 |
| `Name` | 字串 | 顯示名稱，如「蛇毒」 | P0 |
| `Description` | 字串 | 效果描述，如「中蛇毒者，行動遲緩，氣血漸衰」 | P0 |
| `Type` | 列舉 | `傷勢`, `中毒`, `內傷`, `精神`, `控制` | P0 |
| `BaseDuration` | 浮點數 | 基礎持續時間（單位：日/時辰），抗性檢定後決定實際時間 | P0 |
| `BaseStrength` | 整數 | 基礎強度 (0-100)，抗性檢定後決定實際強度 | P0 |
| `EffectFunction` | 腳本 | 每 tick（如每時辰）執行的效果邏輯，如 `減生命，減輕功` | P0 |
| `StackRule` | 列舉 | `不可疊加`, `刷新持續時間`, `疊加層數(上限N)` | P0 |
| `CleanseCondition` | 字串 | 描述可解除此效果的條件，如「使用『清心散』或運功療傷一週」 | P0 |

### 3.2 武俠抗性體系

每個角色擁有以下五項基礎抗性，數值範圍 0-1000：

| 抗性 | 影響的狀態類型 | 說明 |
|:---|:---|:---|
| **外傷抗性** | 傷勢（骨折、流血、外傷） | 由體魄、外功修為決定 |
| **內傷抗性** | 內傷（經脈受損、氣血翻湧） | 由內力、內功修為決定 |
| **毒抗性** | 中毒（蛇毒、蠱毒、迷藥） | 由內力、體魄、特殊天賦決定 |
| **精神抗性** | 精神（恐懼、迷惑、混亂） | 由悟性、意志類天賦決定 |
| **經脈抗性** | 控制（點穴、封脈、麻痺） | 由內力、輕功、特殊武學決定 |

### 3.3 狀態效果觸發流程

1. **觸發**：攻擊、環境、事件等來源對目標施加狀態效果。
2. **抗性檢定**：系統根據狀態效果的 `Type`，對目標的對應抗性進行檢定。
    - `差值 = 效果強度(SourceStrength) - 目標對應抗性(TargetResistance)`
3. **效果分級**：根據差值，決定效果的「嚴重程度」。
    - 若差值 < 0：效果被完全抵抗，不生效。
    - 若差值 >= 0：根據差值落入的區間，決定嚴重程度（輕微/中等/嚴重）。
4. **應用效果**：根據嚴重程度，計算實際的持續時間與強度，並將效果應用於目標。
5. **Tick 執行**：效果在其持續時間內，按固定間隔（如每日/每時辰）執行其 `EffectFunction`。
6. **解除**：持續時間結束，或滿足 `CleanseCondition` 時，效果被移除。

### 3.4 疊加規則

- **不可疊加**：同一來源的同一效果，無法疊加。新效果會刷新持續時間。
- **刷新持續時間**：新效果會將舊效果的剩餘時間重置為新效果的持續時間。
- **疊加層數**：同一效果可以疊加層數，每層增加其強度。例如「蛇毒」可疊加5層，每層使減速效果+5%。

## 4. 公式（Formulas）

### 4.1 抗性檢定公式

```
差值 = SourceStrength - TargetResistance
```

- `SourceStrength`：施加效果時的強度（由技能、裝備、環境等決定）。範圍：0-1000。
- `TargetResistance`：目標的對應抗性值。範圍：0-1000。

### 4.2 效果分級區間

| 嚴重程度 | 差值區間 | 持續時間倍率 | 強度倍率 |
|:---|:---|:---:|:---:|
| 完全抵抗 | `差值 < 0` | 0 | 0 |
| 輕微 | `0 <= 差值 < 200` | 0.5 | 0.5 |
| 中等 | `200 <= 差值 < 500` | 1.0 | 1.0 |
| 嚴重 | `差值 >= 500` | 1.5 | 1.5 |

### 4.3 最終持續時間與強度計算

```
最終持續時間 = BaseDuration * 持續時間倍率
最終強度 = BaseStrength * 強度倍率
```

### 4.4 範例計算

- **情境**：玩家（毒抗性 = 300）被一條「金環蛇」咬中。蛇毒效果的 `SourceStrength` 為 400。
- **計算**：
    1. `差值 = 400 - 300 = 100`
    2. 差值 100 落入「輕微」區間。
    3. 假設 `BaseDuration` 為 5 天，`BaseStrength` 為 50。
    4. `最終持續時間 = 5 * 0.5 = 2.5 天`
    5. `最終強度 = 50 * 0.5 = 25`
- **結果**：玩家只會受到 2.5 天、強度 25 的輕微蛇毒影響，而不是原本的 5 天、強度 50。

### 4.5 數值取整規則

- `最終持續時間`：以「時辰」為最小單位，向下取整。不足 1 時辰則視為 1 時辰。
- `最終強度`：向下取整，最小值為 1。

## 5. 邊界條件（Edge Cases）

| 情境 | 處理方式 |
|:---|:---|
| 目標抗性遠大於效果強度（`差值 < 0`） | 效果被完全抵抗，不產生任何負面狀態。系統可播放一個「抵抗」的視覺/文字回饋。 |
| 目標同時受到多個同類型效果 | 依各效果的 `StackRule` 處理。若規則為「不可疊加」，則保留強度最高或剩餘時間最長的效果。 |
| 效果持續時間為 0（瞬間效果） | 視為一次性效果，直接計算 `最終強度` 並執行一次 `EffectFunction`，不進入持續 tick 流程。 |
| 角色在效果持續期間死亡 | 所有狀態效果立即清除。 |
| 角色在效果持續期間屬性發生變化（如裝備更換） | 已經生效的效果不受影響。抗性檢定只在效果施加時進行一次。 |
| 一個效果同時影響多個屬性 | `EffectFunction` 中需定義所有受影響的屬性及其計算公式。 |
| 效果的 `CleanseCondition` 與持續時間同時滿足 | 以先滿足的條件為準。例如，玩家在中毒狀態下使用了「清心散」，則立即解除，剩餘持續時間作廢。 |

## 6. 系統依賴（Dependencies）

### 6.1 本系統依賴

- **角色屬性系統**：需要讀取角色的 `體魄`、`內力`、`輕功`、`悟性` 等屬性來計算抗性。
- **武學技能系統**：武學技能可作為狀態效果的來源（如「玄冥神掌」附帶寒毒效果）。
- **裝備系統**：裝備的詞條可提供抗性加成。
- **戰鬥系統**：戰鬥中的攻擊技能會觸發狀態效果的施加。
- **時間系統**：狀態效果的持續時間需要依賴遊戲內時間的推進。
- **事件系統**：環境事件（如誤入毒瘴）或劇情事件可觸發狀態效果。

### 6.2 依賴本系統

- **NPC 行為邏輯**：NPC 的中毒、受傷狀態會影響其日程、對話內容與戰鬥行為。
- **醫療/解毒系統**：所有醫療行為（使用藥品、運功療傷）都是為了處理本系統中的狀態效果。
- **世界感知系統**：玩家或 NPC 重傷的消息，會作為江湖傳聞進行傳播。
- **壽命系統**：長期、嚴重的內傷或中毒，可能會觸發減壽事件。

## 8. 驗收標準（Acceptance Criteria）

- [ ] **AC1. 狀態配置**：至少 10 種不同類型的狀態效果（傷勢、中毒、內傷、精神、控制各 2 種）被成功配置並載入遊戲。
- [ ] **AC2. 抗性檢定**：對一個角色施加狀態效果時，系統能正確讀取其對應抗性，並計算出差值。
- [ ] **AC3. 效果分級**：根據差值，系統能準確將效果分為「完全抵抗/輕微/中等/嚴重」四個等級，並應用對應的倍率。
- [ ] **AC4. 效果應用**：效果被應用後，角色的屬性（如生命、輕功）能根據 `EffectFunction` 即時變化。
- [ ] **AC5. 持續時間**：效果在設定的持續時間內，能按 tick 間隔執行邏輯，並在時間結束後自動移除。
- [ ] **AC6. 邊界情況**：
    - 對抗性極高的角色施加效果，應顯示「抵抗」且無實際效果。
    - 對同一個角色施加兩個不可疊加的同類效果，後者應刷新持續時間。
    - 角色在效果持續期間死亡，所有效果應立即清除。
- [ ] **AC7. 解除條件**：滿足 `CleanseCondition`（如使用對應道具）時，效果能正確被移除。
- [ ] **AC8. 走火入魔**：作為系統的一筆配置資料，能獨立運行並觸發其設定的效果（如內力紊亂、屬性暫時下降）。
- [ ] **AC9. UI 顯示**：角色面板能正確顯示各項抗性數值；戰鬥中，角色頭頂或 UI 欄位能正確顯示當前生效的狀態效果圖示與剩餘時間。
