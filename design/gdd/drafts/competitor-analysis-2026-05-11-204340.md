### 2. 數值設計啟示

#### 2.1 連續嚴重度 (Severity)

**競品模式：**
- `severity` 是一個 0.0 到 1.0 的浮點數
- 不同區間觸發不同 `stage`，每個 `stage` 有不同效果
- `severity` 會隨時間自然變化（增加或減少）

**對我們數值設計的具體建議：**

**2.1.1 傷勢系統升級**

將現有的「輕傷 / 中傷 / 重傷」三段式，改為 `severity` 系統：

| Severity 區間 | 傷勢名稱 | 效果（範例） |
|---|---|---|
| 0.00 – 0.15 | 皮外傷 | 無戰鬥減益，美觀度 -5 |
| 0.16 – 0.35 | 輕傷 | 武力 -10%，體魄恢復速度 -15% |
| 0.36 – 0.60 | 中傷 | 武力 -25%，輕功 -20%，每日有10%機率觸發「傷口迸裂」（severity +0.05） |
| 0.61 – 0.85 | 重傷 | 武力 -50%，所有行動速度 -30%，無法運功 |
| 0.86 – 1.00 | 瀕死 | 武力 -80%，意識 -50%，每日有30%機率觸發「惡化事件」（severity +0.1） |
| ≥ 1.0 | 死亡 | 角色死亡。 |

**恢復機制：**
- 基礎恢復：每日 `severity -= 0.02`
- 藥物治療：使用「金瘡藥」，`severity -= 0.15`（冷卻 3 天）
- 名醫診治：找名醫 NPC，一次性 `severity -= 0.4`（消耗大量銀兩或人情）
- 特殊事件：如「奇遇溫泉」，一次性 `severity -= 0.6`

**2.1.2 走火入魔 Severity 設計**

| Severity 區間 | 狀態名稱 | 效果 |
|---|---|---|
| 0.00 – 0.19 | 氣息不穩 | 無戰鬥減益，但練功時有 5% 機率 severity +0.01 |
| 0.20 – 0.39 | 氣血翻湧 | 內力恢復速度 -20%，施展內功時有 10% 機率 severity +0.02 |
| 0.40 – 0.59 | 經脈紊亂 | 內力 -30%，施展任何武功時有 15% 機率「招式失控」（傷及自身，severity +0.03） |
| 0.60 – 0.79 | 走火入魔 | 每回合開始時，有 20% 機率攻擊隨機目標（包括友軍）。無法施展需要內力的武功。 |
| 0.80 – 0.99 | 癲狂 | 意識大幅下降，會主動攻擊視野內所有單位。每日 severity +0.05。 |
| ≥ 1.0 | 爆體而亡 | 角色死亡，並對周圍單位造成大量內傷。 |

**觸發與恢復：**
- **觸發**：強行參悟高階武學、練功時心緒不寧（心情低落）、服用劣質丹藥、被特殊武功擊中。
- **恢復**：停止練功（每日 -0.03）、服用「定心丸」（-0.2）、找內功高手運功療傷（-0.4）、完成特定心境任務（一次性 -0.6）。

#### 2.2 特質度數化

**競品模式：**
- 每個特質有 -2 到 +2 共 5 個度數
- 每個度數對應不同效果
- 正面特質必有對應的負面代價

**對我們天賦/稱號設計的具體建議：**

將「天賦」從「單一標籤」改為「可成長的度數屬性」。

**範例：天賦「天生神力」**
- **度數 -2**：體弱多病。武力 -10%，疾病感染率 +20%。
- **度數 -1**：手無縛雞之力。武力 -5%。
- **度數 0**：常人。無效果。
- **度數 +1**：力氣過人。武力 +5%，體魄 +5%。
- **度數 +2**：天生神力。武力 +15%，體魄 +10%，但內力恢復速度 -10%（代價：能耗大）。

**設計原則：**
- 初始天賦池中，度數範圍為 -1 到 +2，避免新手開局過於痛苦。
- 透過特定事件或長期訓練，可提升天賦的度數（例如：從「力氣過人」練到「天生神力」）。
- 「天生神力」的負面代價（內力恢復慢）創造了角色養成的取捨：是繼續強化武力，還是想辦法彌補內力短板？

#### 2.3 心情/想法數值化

**競品模式：**
- 即時想法：由當前環境條件觸發，條件消失則消失。
- 記憶想法：由事件觸發，有固定持續時間，severity 隨時間衰減。

**對我們「江湖氣度」系統的具體建議：**

建立一個「心境值」（0-100）作為角色內在狀態的數值。影響：練功效率、戰鬥表現、NPC互動成功率。

**即時想法觸發範例：**
- 身處繁華城鎮：「人聲鼎沸」心境 +5
- 身處荒郊野嶺：「孤身一人」心境 -10
- 身上有重金：「財不露白」心境 -15
- 剛獲得神兵：「志得意滿」心境 +20

**記憶想法觸發範例（持續時間以遊戲內「月」為單位）：**

| 觸發事件 | 記憶想法 | 持續時間 | 效果曲線 |
|---|---|---|---|
| 打敗宿敵 | 大仇得報 | 6 個月 | 第1-2月：心境+30；第3-4月：+15；第5-6月：+5 |
| 被心愛之人背叛 | 心碎 | 12 個月 | 第1-3月：心境-40，社交-20%；第4-6月：-25，社交-10%... |
| 師父被殺 | 血海深仇 | 永久（直到復仇） | 心境-20，對仇人所在陣營好感-50。復仇成功後轉為「大仇得報」。 |
| 拯救一村百姓 | 俠義之舉 | 3 個月 | 心境+15，名聲傳播速度+10% |

### 3. 技能/內容設計規律

#### 3.1 競品命名模式與分層規律

RimWorld 的技能（Skill）是純粹的數值成長，沒有命名。但其「特質」（Trait）和「健康狀態」（Hediff）的命名模式值得參考：

- **描述性**：直接描述狀態或特徵（「懦弱」、「膽小」、「勇敢」）。
- **分層**：同一概念用度數區分（-2 到 +2），名稱隨度數變化。
- **對立性**：存在直接對立的特質（「勇敢」vs「懦弱」）。

#### 3.2 對我們武學系統的具體設計建議

**3.2.1 武學熟練度命名調整**

我們現有的「入門/熟練/小成/大成/圓滿」已經很好，但可以參考 RimWorld 的度數概念，將每個階段的效果數值化，並與「心境值」掛鉤。

| 熟練度 | 效果倍率 | 額外效果 |
|---|---|---|
| 入門 | 1.0x | 無 |
| 熟練 | 1.2x | 施展時有 5% 機率進入「心流」狀態（心境+5） |
| 小成 | 1.4x | 施展時有 10% 機率進入「心流」狀態 |
| 大成 | 1.7x | 施展時有 15% 機率進入「心流」狀態，並有 5% 機率觸發「頓悟」（熟練度經驗大幅增加） |
| 圓滿 | 2.0x | 施展時有 20% 機率進入「心流」狀態，解鎖隱藏效果（如：華山劍法圓滿後，額外獲得「養吾劍氣」的被動加成） |

**3.2.2 心境值與武學的互動**

- **心境值高（>70）**：練功效率 +20%，「頓悟」觸發機率 +10%。
- **心境值低（<30）**：練功效率 -30%，「走火入魔」觸發機率 +15%。
- **特定心境**：處於「大仇得報」時，施展特定武功（如「奪命十三劍」）威力 +20%。

#### 3.3 命名風格調整（武俠化）

將 RimWorld 的通用概念轉化為武俠語言：

| RimWorld 概念 | 武俠化名稱 |
|---|---|
| 心情 (Mood) | 心境 |
| 記憶想法 (Memory Thought) | 心結 / 執念 / 夙願 |
| 即時想法 (Situation Thought) | 感觸 / 興致 |
| 特質 (Trait) | 天賦 / 本性 / 命格 |
| 健康狀態 (Hediff) | 傷勢 / 內傷 / 隱疾 |
| 精神崩潰 (Mental Break) | 心魔 / 走火入魔 |
| 疼痛 (Pain) | 傷痛 |

### 4. 我們 GDD 的設計空白

以下列出 RimWorld 有，但我們 GDD 未提及，且值得引入的機制：

| 機制 | 說明 | 是否適合武俠背景？ | 如何適配？ |
|---|---|---|---|
| **心境值系統** | 角色內在的情緒與精神狀態數值化，影響行為與效率。 | ✅ 非常適合。武俠小說中，心境是影響武功發揮和走火入魔的關鍵。 | 命名為「心境」，影響練功效率、走火入魔機率、NPC社交成功率。 |
| **記憶想法（心結）系統** | 重大事件在角色心中留下持續影響，隨時間衰減，可被其他事件覆蓋。 | ✅ 非常適合。這是「選擇有代價」在角色內心的體現。 | 命名為「心結」或「執念」。殺人、被背叛、結義、成親等重大事件都會留下心結。 |
| **對稱正負設計原則** | 每個正面增益效果必須伴隨一個明確的負面代價。 | ✅ 非常適合。增加角色養成的策略深度，避免無腦疊加。 | 成為所有天賦、稱號、裝備、武學的設計鐵律。例如：「金剛不壞體」防禦極高，但移動速度極慢。 |
| **組件化設計哲學** | 用數據驅動的組件組合來定義物品、狀態、事件的行為，而非硬編碼。 | ✅ 適合。大幅提升開發效率和後期擴展性。 | 在數值設計文件中，定義一套「效果組件」庫（如：`屬性增減`、`狀態觸發`、`事件機率`），所有裝備、武學、狀態都由這些組件組合而成。 |
| **精神崩潰/心魔爆發** | 當心境值低於某個閾值，或特定心結被觸發時，角色會失控做出非玩家意願的行為。 | ✅ 非常適合。這是武俠小說中「走火入魔」和「性情大變」的遊戲化表現。 | 觸發條件：心境 < 20，或特定心結（如「血海深仇」）被仇人觸發。行為：隨機攻擊、逃離戰場、胡言亂語洩露情報、自殘等。 |

### 5. 競品設計缺陷（我們要避免的）

1.  **心情系統的「數值化」過於機械**：RimWorld 的心情增減有時顯得很「遊戲化」（例如：吃了精緻食物+5，吃了噁心食物-5），缺乏故事性。我們應該讓心境的變化**綁定具體的事件和選擇**，而不是簡單的「吃好東西就開心」。

    - **我們的解法**：心境變化必須有「原因」。例如：「在醉仙樓宴請幫派兄弟」心境+15，而不是「吃了烤全羊」+5。前者是一個事件選擇，後者只是一個數值操作。

2.  **特質系統的「代價」有時過於抽象**：RimWorld 的「TooSmart」特質代價是「精神崩潰閾值更低」，這個關聯性對新玩家不夠直觀。

    - **我們的解法**：代價必須與武俠世界觀強相關。例如：天賦「武痴」：練武效率+30%，但「人情世故」能力-20%（送禮效果減半，社交對話成功率降低）。玩家能直觀理解「這個人武功很高，但不太會做人」。

3.  **缺乏「選擇」的儀式感**：RimWorld 的事件大多是「發生→你應對」，缺乏「你選擇讓它發生」的過程。

    - **我們的解法**：我們的核心支柱是「選擇有代價」。RimWorld 的「心結」是事件結果，我們的「心結」應該是**選擇的結果**。例如：你選擇在「救青梅竹馬」和「奪取神兵」之間選擇了後者，系統會生成一個「負心人」的心結，而不是簡單地扣一點心情。

### 6. 對現有 GDD 的具體修訂建議

#### 6.1 需要補充的 GDD 章節與內容

**新增章節：15. 心境與心結系統（角色內在狀態）**

- **15.1 心境值**：定義、範圍（0-100）、影響範圍（練功效率、戰鬥表現、社交成功率、走火入魔機率）。
- **15.2 感觸（即時想法）**：由環境和當前狀態觸發，持續時間短。列出常見範例（身處鬧市、身懷巨款、剛獲神兵等）。
- **15.3 心結（記憶想法）**：由重大事件觸發，持續時間長（數月至終身）。列出所有可能的心結類型（復仇、報恩、情傷、殺孽等），並設計其持續時間和效果曲線。
- **15.4 心魔（精神崩潰）**：觸發條件、行為列表、如何解除。這是「走火入魔」的進階版本，更具故事性。
- **15.5 心境與武學的互動**：心境如何影響練功、頓悟、走火入魔。

**新增章節：16. 設計原則：對稱正負**

- 明確定義此原則，並要求所有天賦、稱號、裝備、武學、心結的設計都必須遵循。
- 提供正面效果與負面代價的對照表範例。

#### 6.2 需要調整的數值設計

| 現有設計 | 調整建議 | 原因 |
|---|---|---|
| 傷勢：輕/中/重三段式 | 改為 Severity 0-1 連續值系統 | 更精細，能創造更多戲劇張力（如：重傷瀕死時的抉擇） |
| 走火入魔：單一事件 | 改為 Severity 0-1 連續值系統 | 讓「走火入魔」成為一個可感知的、逐步惡化的過程，而不是突然暴斃 |
| 天賦：單一標籤 | 改為度數化（-2 到 +2） | 創造更豐富的角色差異和養成路線 |
| 心境：未定義 | 新增心境值 0-100 | 填補角色內在狀態的設計空白，與武學、社交、事件深度掛鉤 |

#### 6.3 建議新增的系統或機制

1.  **心結系統**：這是最重要的新增系統。它將 RimWorld 的「記憶想法」與我們的核心支柱「選擇有代價」結合。每個重大選擇都應生成一個對應的心結，持續影響角色。
2.  **心境與武學的掛鉤機制**：心境影響練功效率、頓悟機率和走火入魔風險。這讓「心境管理」成為一種遊戲策略。
3.  **武學的「心境共鳴」效果**：某些武學在特定心境下會觸發額外效果。例如：在「大仇得報」時施展「奪命十三劍」，會觸發「劍氣縱橫」範圍傷害。

---

**品霖總結：**

製作人，RimWorld 最大的價值在於它提供了一套「將抽象概念（心情、傷勢、性格）數值化、系統化」的成熟框架。我們不需要照搬，而是要汲取其「連續數值」、「階段觸發」、「組件化」和「對稱設計」的哲學，並用武俠的語言和故事性將其重新包裝。

特別是「心結系統」，我認為這是將 RimWorld 的「記憶想法」與我們「選擇有代價」核心支柱完美結合的關鍵。它讓角色的內在世界變得有血有肉，每一個選擇都會在心中留下痕跡，這才是「江湖一生」該有的重量。

我建議將「心境與心結系統」列為 P0 優先級，與 NPC 關係系統同等重要。這兩個系統，一個對內（心境），一個對外（關係），共同構成角色「活著」的證明。
