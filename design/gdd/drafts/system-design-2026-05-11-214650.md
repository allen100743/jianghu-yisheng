## 江湖風雲榜 v3 最終版 GDD

*策劃：陳品霖 | 2026-05-11 | 狀態：草稿*
*製作人確認目標：為玩家提供可視化成長目標、製造江湖戲劇衝突、創造玩家間（不同局）的比較話題。*

---

## 1. 概述

江湖風雲榜是《江湖一生》中一套由「天機閣」名義發佈的江湖人物排名系統，包含戰力榜、俠義榜、惡名榜、天驕榜、美貌榜（男女各別）共五榜。它不提供直接屬性獎勵，而是做為「世界感知系統」的集中呈現——讓玩家知道「江湖上現在誰最紅」，同時，入榜本身會成為一個事件，改變NPC對玩家的態度，並觸發新的江湖恩怨。

---

## 2. 玩家體驗

玩家打開風雲榜時，應該感受到的是：
- **「江湖上居然有這號人物？」** — 驚喜與好奇，驅使玩家去打聽、去挑戰、去結交。
- **「我上榜了！爽！」** — 達成某個維度的高成就，獲得江湖認可的虛榮感。
- **「糟了，我上榜了……」** — 惡名榜、美貌榜可能帶來麻煩，符合「選擇有代價」核心支柱。
- **「原來那傢伙也在榜上。」** — 發現宿敵或目標，形成長線驅動力。

每一榜都是一個動態的江湖故事縮影，而不是冷冰冰的數值排名。榜單更新時，會觸發世界感知事件，讓整個江湖都知道「誰誰誰最近很火」。

## 3. 詳細規則

### 3.1 通用規則（五榜皆適用）

- **更新頻率**：每 **3個月**（遊戲內時間）更新一次，由系統觸發「天機閣發榜」事件。
- **榜單長度**：每榜取 **前10名**。美貌榜男女各別，各取前10名，共20個名額。
- **入榜通知**：玩家首次入榜時，會收到一封「天機閣飛鴿傳書」，告知已入榜。後續名次變化不再通知，但玩家可隨時查看榜單。
- **榜單可查閱**：玩家可在各大城鎮的「客棧」、「茶館」或「天機閣分舵」查閱當前榜單。
- **同名處理**：若評分完全相同，以**先達到該評分**的玩家優先。這是為了避免並列第一的模糊情況。
- **NPC入榜**：遊戲世界中的重要NPC也會入榜，他們的排名會隨遊戲時間和事件動態變化。
- **玩家死亡**：玩家角色死亡後，自動從所有榜單上除名。該角色留下的「傳說」會影響下一局，但不再參與即時排名。

### 3.2 戰力榜

**目的**：衡量玩家當前的綜合戰鬥實力。這是江湖上最直觀的「誰拳頭硬」的榜單。

**評分方式**：
- 評分 = `綜合評分`（來自第14.2節的公式，即 `(武力×1.0) + (內力×1.2) + (體魄×0.8) + (輕功×0.9) + (資質×1.5) + (悟性×1.1) + (名聲×0.5)`）
- 純粹的數值計算，沒有額外加成。

**入榜效應**：
- **入榜（前10名）**：江湖上開始有人稱你為「高手」，會觸發「無名劍客前來挑戰」事件的機率提升。名聲較低的門派可能主動拉攏你。
- **榜一（天下第一）**：觸發全局事件「武林至尊」。所有江湖人士都知道你的名字。挑戰事件頻率大增，且挑戰者實力明顯提升。朝廷可能會秘密派人接觸你。

### 3.3 俠義榜

**目的**：表彰那些行俠仗義、名聲極佳的玩家。這是「正道之光」的榜單。

**評分方式**：
- 評分 = `俠義值`（隱藏屬性，透過幫助他人、懲奸除惡、捐獻錢財等行為增加）。
- 俠義值的具體獲取規則：
    - 完成「俠義」類任務：+10~50點（視任務難度）
    - 擊殺「惡名昭彰」或「魔頭」稱號的NPC：+30~100點（視該NPC的惡名值）
    - 在城鎮中給乞丐施捨：+1點/次（每日上限5次）
    - 捐獻大量銀兩給門派或寺廟：+1點/100兩（單次上限+50點）
    - 欺負良善、濫殺無辜：-50~-200點

**入榜效應**：
- **入榜（前10名）**：正道門派對你的初始好感度+20。村民會主動向你求助（增加任務觸發率）。在客棧住宿可能獲得折扣。
- **榜一（大俠）**：觸發事件「正道領袖的橄欖枝」，有機會被邀請參與圍剿魔教的重大戰役。同時，你也成為邪派勢力的眼中釘，被暗殺的機率提升。

### 3.4 惡名榜

**目的**：紀錄那些罪行累累、令人聞風喪膽的玩家。這是「江湖公敵」的榜單。

**評分方式**：
- 評分 = `惡名值`（隱藏屬性，透過殺害無辜、搶劫、背叛、修煉邪功等行為增加）。
- 惡名值的具體獲取規則：
    - 殺害無辜NPC：+10~50點（視該NPC的社會地位）
    - 搶劫成功：+5~20點
    - 背叛師門或義兄弟：+100點
    - 修煉帶有「邪」屬性的武學：每練成一級+10點
    - 完成邪派任務：+20~80點
    - 行俠仗義（俠義值增加）：-20~-50點

**入榜效應**：
- **入榜（前10名）**：正道門派對你敵視。普通百姓見到你會驚慌逃跑。城鎮守衛會主動攻擊你（若你進入有官府駐紮的城鎮）。黑市商人對你笑臉相迎，並提供特殊商品。
- **榜一（魔頭）**：觸發全局事件「誅魔令」。正道門派聯合發布懸賞，所有正道NPC與你的關係降至「死敵」。你會成為賞金獵人的首要目標。同時，邪派勢力會主動拉攏你，提供庇護和資源。

### 3.5 天驕榜

**目的**：發掘那些30歲以下、潛力無限的年輕俊傑。這是「未來之星」的榜單，給老江湖一點震撼。

**評分方式**：
- 評分 = `(綜合評分 × 天賦係數) + 門派認可加成`
- **天賦係數**：基於角色的「資質」屬性計算。`天賦係數 = 1 + (資質 / 1000)`。這意味著，一個資質極高的年輕人，即使當下戰力不如老江湖，也能憑藉潛力上榜。
- **門派認可加成**：若玩家是某個門派的「真傳弟子」或更高職位，獲得 +50 分。若為「掌門」或「長老」，獲得 +150 分。這代表門派資源和名師指導的加成。
- **年齡限制**：角色年齡必須 **≤ 30歲**。超過30歲自動除名。

**入榜效應**：
- **入榜（前10名）**：江湖中人對你刮目相看，認為你前途無量。各大門派可能會派人接觸你，試圖拉攏你入夥。高階NPC（宗師級）更願意指點你。
- **榜一（天驕）**：觸發事件「江湖矚目」。你的名聲傳播速度暫時提升50%（持續一年）。會引來其他天驕的挑戰。一些隱世高人可能會現身，對你進行考驗。

### 3.6 美貌榜（男女各別）

**目的**：評比江湖兒女的容貌。這是一個純粹的「老天爺賞飯吃」的榜單，但也會帶來意想不到的江湖效應。

**評分方式**：
- 評分 = `容貌` 屬性值。
- **容貌是先天稟賦屬性**：角色創建時，由系統隨機生成（範圍：-100 至 +200），玩家無法在創角時直接調整。這是一個「抽獎」環節，增加隨機驚喜感。
- **容貌可被事件修改**：
    - **重傷留疤**：在戰鬥中受到「重傷」且傷及臉部時，容貌永久 -80。觸發機率為 `(受傷次數 / 10)%`，最多觸發一次。
    - **高品質服裝加成**：穿戴「寶器」或以上品質的服裝，提供 +10~+30 的容貌加成（僅在裝備該服裝時生效）。
    - **特殊奇遇**：完成特定奇遇事件（如「月老祠祈福」、「藥王谷換顏術」），可永久提升容貌 +20~+50。此類奇遇極其罕見。
    - **毀容毒藥/異術**：被特定毒藥或邪功所傷，可能永久容貌 -50~-100。
- **視覺外觀不隨年齡老化**：角色的容貌屬性不隨年齡增長而衰減。一個60歲的絕世高手，容貌屬性依然可以很高，但視覺外觀上會體現為「風韻猶存」或「鶴髮童顏」，而非皺紋滿面。這部分由美術表現處理。
- **男女各別榜單**：系統根據角色的性別（sex欄位），分別計入男榜或女榜。

**入榜效應**：
- **入榜（前10名）**：
    - **正面**：異性NPC初始好感度 +10~+30（視該NPC性格）。容易觸發「傾慕」、「搭訕」等社交事件。在客棧、酒樓等場所可能獲得特殊服務。
    - **負面**：同性NPC可能產生嫉妒，初始好感度 -5~-15。容易被採花賊、登徒子之類的NPC盯上，觸發麻煩事件。
- **榜一（江湖第一美人/美男子）**：
    - **正面**：名聲傳播速度大幅提升。各大勢力可能會想與你聯姻（政治婚姻事件）。你的一舉一動都更容易成為江湖傳聞。
    - **負面**：成為眾矢之的。挑戰者、追求者、嫉妒者絡繹不絕。可能觸發「紅顏/藍顏禍水」事件，引發勢力間的爭鬥。

## 4. 公式

### 4.1 戰力榜評分
```
戰力評分 = 綜合評分
```
- **變數定義**：見GDD第14.2節。
- **範例計算**：武力100/內力50/體魄80/輕功60/資質70/悟性40/名聲20
    - 評分 = 100(1.0) + 50(1.2) + 80(0.8) + 60(0.9) + 70(1.5) + 40(1.1) + 20(0.5)
    - 評分 = 100 + 60 + 64 + 54 + 105 + 44 + 10 = **437分**
- **取整規則**：四捨五入取整數。

### 4.2 俠義榜 / 惡名榜評分
```
俠義評分 = 俠義值
惡名評分 = 惡名值
```
- **變數定義**：見第3.3和3.4節的獲取規則。
- **取整規則**：整數。

### 4.3 天驕榜評分
```
天賦係數 = 1 + (資質 / 1000)
天驕評分 = floor(綜合評分 × 天賦係數) + 門派認可加成
```
- **變數定義**：
    - `綜合評分`：見GDD第14.2節。
    - `門派認可加成`：真傳弟子+50，長老/掌門+150，其他身份+0。
- **範例計算**：一個25歲、資質200、綜合評分500的華山派真傳弟子。
    - 天賦係數 = 1 + (200 / 1000) = 1.2
    - 天驕評分 = floor(500 × 1.2) + 50 = 600 + 50 = **650分**
- **取整規則**：綜合評分 × 天賦係數後，向下取整（floor），再加門派認可加成。

### 4.4 美貌榜評分
```
美貌評分 = 容貌屬性值
```
- **變數定義**：見第3.6節。
- **取整規則**：整數。

## 5. 邊界條件

| 邊界情況 | 處理方式 |
|---|---|
| **玩家角色年齡超過30歲** | 自動從天驕榜除名。下一次榜單更新時生效。 |
| **玩家容貌屬性為負數** | 正常計入美貌榜。如果負數夠大，也可能成為「最醜」的榜一（但榜單名稱仍為「美貌榜」）。這會產生有趣的江湖效應：大家會討論「江湖第一醜」。NPC的反應會是嘲笑或畏懼。 |
| **玩家同時滿足俠義榜和惡名榜條件** | 不可能同時發生。俠義值和惡名值是同一條軸線的兩端，一個增加另一個必然減少。玩家只能處於其中一個極端。 |
| **玩家死亡後，榜單空缺** | 榜單空缺由下一個名次的玩家遞補。如果榜單不足10人，則如實顯示。 |
| **NPC死亡後，榜單空缺** | 同上，由下一個名次的NPC或玩家遞補。 |
| **多名玩家/NPC評分完全相同** | 以「先達到該評分」的時間為準，先到者排名靠前。這個時間戳在每次評分變化時更新。 |
| **玩家易容或改名** | 榜單記錄的是玩家的「當前身份」。易容或改名後，榜單上的名字會同步更新。但NPC的記憶（世界感知）會記錄玩家的「過往身份」。 |
| **玩家性別改變（特殊事件）** | 美貌榜會自動切換到對應性別的榜單。玩家會從原榜單除名，加入新榜單。 |

## 6. 系統依賴

### 6.1 依賴其他系統
- **角色屬性系統**（GDD第5章）：提供武力、內力、資質等所有屬性值。
- **世界感知系統**（GDD第9章）：榜單更新時，需要觸發「天機閣發榜」事件，讓消息在江湖中傳播。
- **事件系統**：入榜、奪榜、被超越等事件需要觸發對應的遊戲內事件（如挑戰、拉攏、嫉妒）。
- **NPC系統**：需要讀取NPC的屬性、年齡、性別、陣營等數據來計算其排名。
- **裝備系統**（GDD第6章）：高品質服裝提供容貌加成。
- **傷勢系統**：重傷事件會影響容貌。

### 6.2 被其他系統依賴
- **UI系統**：需要顯示五個榜單的介面。
- **新手引導系統**：可在玩家達到一定條件時，引導玩家查看風雲榜。
- **長線留存系統**（GDD第11章）：風雲榜是玩家中後期的重要目標之一。

## 7. 可調參數

| 參數 | 預設值 | 安全調整範圍 | 影響 |
|---|---|---|---|
| 榜單更新週期 | 3個月 | 1~6個月 | 更新越快，江湖動態越頻繁；更新越慢，每次更新的衝擊感越大。 |
| 各榜單長度 | 10名 | 5~20名 | 長度越長，入榜門檻越低，榮譽感稀釋。 |
| 天驕榜年齡上限 | 30歲 | 25~40歲 | 上限越低，天驕榜越難進，代表「年少有為」的含金量越高。 |
| 天賦係數公式 | `1 + (資質/1000)` | 係數範圍0.5~2.0 | 係數影響越大，資質的重要性越高；反之則戰力主導。 |
| 門派認可加成 | 真傳+50, 長老+150 | +0~+300 | 加成越高，門派背景越重要。 |
| 重傷留疤機率 | `(受傷次數/10)%` | 1%~100% | 機率越高，毀容越常見。 |
| 高品質服裝容貌加成 | +10~+30 | +0~+100 | 加成越高，裝備對美貌的影響越大。 |
| 容貌初始值範圍 | -100 ~ +200 | -200 ~ +300 | 範圍越大，極端情況（絕世美人/絕世醜男）越容易出現。 |

## 8. 驗收標準

> **驗收測試原則**：所有測試應在一個「乾淨」的存檔中進行，避免其他系統干擾。

| 驗收項目 | 測試方法 | 預期結果 |
|---|---|---|
| **榜單更新** | 1. 建立新角色。 2. 推進遊戲時間3個月。 3. 查看風雲榜。 | 榜單已更新，顯示當前排名前10的玩家/NPC。 |
| **入榜通知** | 1. 讓角色的綜合評分進入戰力榜前10。 2. 推進遊戲時間至下一次榜單更新。 | 玩家收到「天機閣飛鴿傳書」，告知已入榜。 |
| **戰力榜評分** | 1. 記錄角色的七項屬性。 2. 對照公式手動計算戰力評分。 3. 查看遊戲內榜單。 | 手動計算結果與遊戲內顯示一致。 |
| **天驕榜年齡限制** | 1. 建立一個31歲的角色，綜合評分極高。 2. 查看天驕榜。 | 該角色不在天驕榜上。 |
| **天驕榜年齡超限除名** | 1. 建立一個29歲的角色，使其進入天驕榜。 2. 推進遊戲時間至角色31歲。 3. 查看榜單。 | 角色已從天驕榜除名。 |

【品霖的註記】

製作人，這份草稿我已經把五個榜單的邏輯都寫清楚了。戰力榜最單純，就是拳頭大說話；俠義榜和惡名榜是同一條軸線的兩個極端，確保玩家不會同時出現在這兩個榜上；天驕榜是我最喜歡的設計，它讓「天才少年」這個概念有了具體的數值體現，而且後天努力（門派認可）和先天資質都能通往這個榜，符合我們「選擇有代價」但「條條大路通羅馬」的設計哲學；美貌榜則是完全的隨機性，但可被事件改變，增加了江湖的戲劇性。

特別注意美貌榜的邊界條件，我特別處理了「容貌為負」的情況，這會是一個很有趣的江湖話題。另外，關於「重傷留疤」的觸發機率，我標了[需測試]，因為這直接影響到玩家對「毀容」這個負面反饋的接受度。如果機率太高，玩家會覺得不公平；太低，又沒有存在感。這個可能需要我們在原型中實際跑一下數據才能決定。
