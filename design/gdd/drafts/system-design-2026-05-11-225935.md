# 江湖一生 — 角色創建系統 GDD v2

*策劃：陳品霖 | 審核：製作人 | 2026-05-12*

## 1. 概述（Overview）

角色創建系統是玩家進入《江湖一生》世界的第一道門，負責在5分鐘內生成一個獨一無二、將陪伴玩家渡過完整一生的角色。本系統透過出身背景、隨機天賦、外觀自定義與角色命名四個步驟，快速建立玩家的角色認同，並透過隨機性確保每一次新遊戲的開局都充滿新鮮感與可能性。系統的核心設計目標是：**讓玩家在最短時間內，對這個「他」產生歸屬感，並對即將展開的江湖人生充滿期待。**

## 2. 玩家體驗（Player Fantasy）

-   **「這是我，不是別人」**：玩家在幾分鐘內，透過選擇出身和天賦，回答了「我是誰」這個核心問題。出身決定你的起點與社會標籤，天賦決定你的潛力與獨特之處。這個角色不是一個隨機生成的數據集合，而是玩家親手塑造的、有故事的人。
-   **「每一局都是新的冒險」**：隨機天賦池與重骰機制，確保每次創角都有驚喜。即使玩過十次、二十次，每次開局都因天賦組合的不同而充滿新的可能性。玩家會期待「這次我會抽到什麼？」。
-   **「這就是我心中的大俠」**：外觀自定義讓角色有了具體的形象，不再是數據面板上的一個名字。玩家會為這個角色賦予情感，他的成功與失敗，都與玩家產生連結。
-   **「別廢話，讓我進江湖」**：流程簡潔明快，不讓玩家在創角階段就感到選擇困難或疲勞。目標是5分鐘內，讓玩家親手打造的這個「他」，踏入那個充滿恩怨情仇的江湖。

## 3. 詳細規則（Detailed Rules）

### 3.1 創角流程（P0）

1.  **出身背景選擇（P0）**
    -   玩家從預設的出身背景清單中選擇1個。MVP版本提供3個選項。
    -   選擇後，系統會根據出身生成一個簡短的開場文本（約50-100字），說明角色的來歷。玩家可選擇跳過此文本。
    -   **MVP出身清單**：
        | 出身 | 初始效果 | 玩家幻想 | 開場文本範例 |
        |---|---|---|---|
        | **孤兒** | 無初始金錢，無親屬，初始名聲+10 | 白手起家，無所畏懼，江湖就是我的家。 | 「你記事起就在破廟裡討生活，沒有人知道你的父母是誰。你學會的第一件事，不是寫字，是看人臉色。你唯一擁有的，就是這條命。」 |
        | **商賈之子** | 初始金錢+200兩，初始交易價格-10%，初始名聲-5 | 財力雄厚，以錢鋪路，但江湖人看不起你的出身。 | 「你是蘇州府最大綢緞莊的少東家，從小錦衣玉食。你聽膩了帳房先生的算盤聲，總想著外面的江湖是什麼樣子。父親給了你一筆盤纏，讓你『出去見見世面』。」 |
        | **武官世家** | 初始武力+10，初始體魄+5，朝廷NPC初始好感+20 | 家學淵源，體制內起點高，但枷鎖也多。 | 「你的父親是應天府衙門的總捕頭，你從小在練武場長大。他教你的第一套拳法叫『忠君報國』。你身上背負的，不只是自己的未來，還有陳家的門楣。」 |
    -   **V2追加**：增加「書香門第」（悟性+10）、「江湖浪子」（輕功+5、名聲+5）、「隱世高人之後」（資質+15）等出身。

2.  **初始天賦選擇（P0）**
    -   **核心機制**：系統從預設的天賦池中，隨機生成4個天賦。玩家從這4個中選擇1個作為初始天賦。
    -   **天賦分級**：天賦分為「凡品」、「精良」、「絕品」三級，其稀有度與效果強度遞增。
    -   **生成權重**：
        -   凡品：60%
        -   精良：30%
        -   絕品：10%
    -   **重骰機制**：玩家若不滿意當前4個天賦，可消耗一次「重骰機會」刷新。初始給予2次重骰機會。重骰時，系統重新生成4個全新天賦。若2次重骰後仍不滿意，玩家必須從當前的4個天賦中選擇一個。
    -   **天賦池設計原則**：天賦不應是單純的數值增減，而是能改變玩家玩法風格或觸發特殊事件的「種子」。例如，一個「絕品」天賦不應該只是「武力+50」，而應該是「你天生神力，但這也讓你的內力修行格外困難」這種有代價的選擇。
    -   **MVP天賦池樣例（擴展版）**：
        | 天賦名稱 | 品質 | 效果 |
        |---|---|---|
        | 天生神力 | 凡品 | 初始武力+15 |
        | 根骨清奇 | 凡品 | 初始體魄+15 |
        | 過目不忘 | 凡品 | 初始悟性+10 |
        | 八面玲瓏 | 凡品 | 初始名聲+20 |
        | 家學淵源 | 凡品 | 初始資質+10 |
        | 身手矯健 | 凡品 | 初始輕功+10 |
        | 福星高照 | 精良 | 所有「機率觸發」類事件成功率+10% |
        | 武學奇才 | 精良 | 學習武學所需時間-20% |
        | 天生領袖 | 精良 | 招募NPC隊友時好感度門檻-10% |
        | 鐵胃 | 精良 | 食物與飲水消耗速度降低30%，食物中毒機率降低50% |
        | 天選之人 | 絕品 | 可從4個天賦中選擇2個（此天賦本身不佔用名額） |
        | 死裡逃生 | 絕品 | 首次受到致命傷害時，強制保留1點生命，且3天內全屬性+30% |
        | **天煞孤星** | **絕品** | 所有親近你的NPC更容易遭遇不幸（死亡、重傷），但你自身在逆境中成長速度+50%。（**這是高風險高回報的玩法種子**）|
        | **醫者仁心** | **絕品** | 你醫治NPC的成功率+30%，被醫治的NPC對你好感度額外+20。但你的雙手不適合殺戮，造成的所有傷害-10%。（**這定義了非戰鬥玩法**）|
    -   **V2追加**：增加更多特殊天賦，如「斷袖之癖」（影響特定NPC關係）、「天生毒體」（毒抗性極高，但與正道門派初始好感降低）、「賭徒」（所有機率事件，成功與失敗的效果都放大50%）。

3.  **外觀自定義（P0）**
    -   **MVP**：提供4個可自定義圖層，每個圖層提供3-5個選項。
        -   臉型：國字臉、瓜子臉、圓臉
        -   髮型：束髮、披肩髮、光頭、馬尾、道髻
        -   上衣：粗布衣、錦衣、勁裝
        -   下裝：長褲、長裙、綁腿褲
    -   所有外觀選擇僅為視覺效果，不影響任何數值。
    -   **V2追加**：增加五官細節（眼、鼻、口、眉）、膚色、鬍鬚、飾品等7個圖層。

4.  **角色命名（P0）**
    -   玩家輸入角色名稱，字數限制2-6個中文字或4-12個英文字母。
    -   提供「隨機生成」按鈕，從預設名稱庫（男/女通用）中隨機生成一個名字。名稱庫應包含常見姓氏與具有江湖氣息的單名或雙名。

5.  **確認與進入遊戲（P0）**
    -   玩家確認所有選擇後，點擊「踏入江湖」按鈕，正式進入遊戲。
    -   此時，玩家的初始屬性、金錢、物品、關係等根據其選擇的出身和天賦被初始化。

### 3.2 角色初始化（P0）

-   玩家確認創角後，系統根據以下規則初始化角色：
    1.  **基礎屬性**：所有7項核心屬性設定為初始基礎值（見第14章數值設計）。
    2.  **出身加成**：根據選擇的出身，疊加對應的屬性、金錢、名聲等。
    3.  **天賦加成**：根據選擇的天賦，疊加對應的屬性、特殊效果。
    4.  **初始物品**：根據出身，給予初始物品（如孤兒：破舊的布衣；商賈之子：200兩銀票；武官世家：一把鐵劍）。
    5.  **初始關係**：根據出身，生成初始的NPC關係（如武官世家：父親為朝廷武官，初始好感+50）。

## 4. 公式（Formulas）

### 4.1 天賦生成公式

-   **變數定義**：
    -   `N` = 每次生成的天賦數量（固定為4）
    -   `Rarity` = 天賦品質（0: 凡品, 1: 精良, 2: 絕品）
    -   `Weight`：`Weight(凡品) = 60`, `Weight(精良) = 30`, `Weight(絕品) = 10`
-   **公式**：
    -   系統從天賦池中隨機抽取N個天賦，每個天賦的品質由其對應的權重決定。
    -   抽取方式：生成一個1-100的隨機數`R`，若`R ≤ 10`則為絕品，若`10 < R ≤ 40`則為精良，否則為凡品。
-   **範例計算**：
    -   生成4個天賦，隨機數R分別為：5, 30, 70, 88。
    -   對應品質：絕品, 精良, 凡品, 凡品。
    -   從對應品質的天賦池中隨機抽取一個天賦。
-   **取整規則**：無。

### 4.2 初始金錢公式

-   **變數定義**：
    -   `Gold_Base` = 基礎金錢（固定為50兩）
    -   `Gold_Bonus` = 出身帶來的金錢加成（孤兒：0兩，商賈之子：200兩，武官世家：50兩）
-   **公式**：`初始金錢 = Gold_Base + Gold_Bonus`
-   **範例計算**：選擇「商賈之子」，初始金錢 = 50 + 200 = 250兩。
-   **取整規則**：結果取整數。

### 4.3 初始名聲公式

-   **變數定義**：
    -   `Fame_Base` = 基礎名聲（固定為0）
    -   `Fame_Bonus` = 出身帶來的名聲加成（孤兒：+10，商賈之子：-5，武官世家：+0）
-   **公式**：`初始名聲 = Fame_Base + Fame_Bonus`
-   **範例計算**：選擇「孤兒」，初始名聲 = 0 + 10 = 10。
-   **取整規則**：結果取整數。

## 5. 邊界條件（Edge Cases）

-   **玩家跳過所有開場文本**：允許。跳過後，玩家直接進入角色創建介面。
-   **玩家對所有隨機天賦都不滿意**：玩家可使用「重骰機會」刷新。若2次重骰後仍不滿意，玩家必須從當前的4個天賦中選擇一個。系統不會強制鎖定一個「最差」的天賦，也不會無限制讓玩家重骰。
-   **玩家輸入的角色名稱為空**：系統不允許提交，並提示「角色名稱不能為空」。
-   **玩家輸入的角色名稱過長**：系統限制字數，超過部分自動截斷或提示「名稱過長」。
-   **玩家輸入的角色名稱與其他已存檔角色重複**：允許。遊戲世界中的NPC不會因為名稱相同而產生混淆，每個角色都有唯一的後台ID。
-   **玩家選擇「武官世家」出身，但隨機生成的父親NPC已在另一局遊戲中死亡**：不影響。每一局遊戲是一個獨立的世界線，NPC狀態不繼承。
-   **玩家選擇「天選之人」天賦，並選擇了2個天賦，其中一個也是「天選之人」**：不允許。天賦池設計時，不會同時出現兩個「天選之人」。系統應避免此情況。
-   **玩家選擇「天煞孤星」天賦，並在遊戲初期就導致重要NPC死亡**：這是該天賦的核心機制，屬於預期內的玩法。系統不應干預，但應在NPC死亡時給予明確的訊息提示，讓玩家知道這是天賦導致的後果。
-   **玩家選擇「醫者仁心」天賦，但在戰鬥中被迫殺人**：天賦效果「造成的所有傷害-10%」會正常生效。系統不會因為玩家殺人而剝奪其天賦，但玩家的行為會影響其善惡名聲，與天賦形成角色扮演上的張力。

## 6. 系統依賴（Dependencies）

-   **依賴的系統**：
    -   **核心屬性系統（第14章）**：角色創建時需要初始化所有核心屬性，並根據出身和天賦進行調整。
    -   **NPC人際關係系統（第7章）**：出身背景需要生成初始的NPC關係（如武官世家的父親）。
    -   **經濟系統（第12章）**：出身背景需要初始化角色的金錢和初始物品。
    -   **世界感知系統（第9章）**：出身背景影響初始名聲值，進而影響世界感知的起點。
-   **被依賴的系統**：
    -   **所有後續系統**：角色創建完成後，玩家的屬性、天賦、關係等數據將被所有後續系統（戰鬥、社交、事件等）讀取和使用。

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 類型 | 當前值 | 安全調整範圍 | 影響 |
|---|---|---|---|---|
| `N`（生成天賦數量）| 整數 | 4 | 3-6 | 值越大，玩家選擇越多，但決策時間越長。 |
| `Weight(凡品)` | 整數 | 60 | 50-70 | 影響玩家開局強度。權重越高，強力開局越少。 |
| `Weight(精良)` | 整數 | 30 | 20-40 | 同上。 |
| `Weight(絕品)` | 整數 | 10 | 5-15 | 同上。 |
| `重骰機會` | 整數 | 2 | 0-3 | 影響玩家對天賦的滿意度。機會越多，玩家越可能刷到理想天賦。 |
| `Gold_Base` | 整數 | 50 | 20-100 | 影響初期經濟壓力。 |
| `Gold_Bonus`（各出身）| 整數 | 0/200/50 | 可自由調整 | 影響不同出身玩家的初期財富差異。 |
| `Fame_Bonus`（各出身）| 整數 | 10/-5/0 | 可自由調整 | 影響不同出身玩家的初期社會關注度。 |
| `臉型`、`髮型`等圖層選項數量 | 整數 | 3/5/3/3 | 可自由增加 | 影響角色多樣性，不影響數值。 |

**品霖註記**：v2版本重點深化了天賦池的設計，加入了「天煞孤星」與「醫者仁心」這類能定義玩法的「種子型」天賦，讓隨機性不再是單純的數值加減，而是能創造不同故事線的起點。邊界條件也針對這些新天賦進行了補完。接下來，我建議可以開始規劃「早期遊戲體驗」的具體事件腳本，讓角色創建的結果，在進入遊戲的前兩個小時內就能產生具體影響。
