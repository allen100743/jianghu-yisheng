# 《江湖一生》庫存管理系統 GDD 草稿

*策劃：陳品霖 | 日期：2026-05-12 | 狀態：初稿*

## 1. 概述（Overview）

本系統管理玩家角色一生中所有隨身物品的持有、儲存、分類與使用。包括隨身行囊、家中箱籠、以及與 NPC 進行的所有物品交換行為。系統設計核心是：**行囊的重量是你的江湖負擔，箱籠裡的東西是你這輩子的累積。**

## 2. 玩家體驗（Player Fantasy）

- **新手期**：包袱裡只有幾兩碎銀、一把粗鐵劍、三張乾烙餅。感覺自己是個窮酸江湖人，什麼都缺，什麼都想撿。
- **成長期**：包袱裡開始有幾瓶好藥、一本搶來的秘笈、一把備用的匕首。開始需要思考「要帶哪把劍出門」。
- **成名期**：家裡的箱籠鎖著江湖上人人覬覦的神兵與秘笈。出門前要精打細算，帶什麼東西去辦什麼事。行囊的重量，就是你的選擇。

核心感受：**「這件東西，我該不該帶？」** 每一個物品的取捨，都是一個微型的故事選擇。

## 3. 詳細規則（Detailed Rules）

### 3.1 物品分類與屬性

所有物品分為以下四大類：

| 類別 | 說明 | 範例 |
|---|---|---|
| **裝備** | 可穿戴在身上的物品，佔用裝備欄位 | 武器、防具、飾品、暗器 |
| **消耗品** | 使用後消失或減少數量的物品 | 金瘡藥、乾糧、解毒丹、迷煙 |
| **材料** | 用於合成、鍛造、交易的原料 | 鐵礦、獸皮、藥草、木材 |
| **貴重品/任務品** | 不可堆疊的獨特物品，通常有故事背景 | 門派掌門信物、仇人的玉佩、藏寶圖碎片 |

**物品屬性結構（所有物品皆具備）：**

| 屬性 | 類型 | 說明 |
|---|---|---|
| `ID` | 整數 | 唯一識別碼 |
| `名稱` | 字串 | 物品的江湖稱呼 |
| `類別` | 列舉 | 裝備/消耗品/材料/貴重品 |
| `品質` | 整數(1-7) | 對應凡品至天工 |
| `重量` | 整數 | 單位：兩。影響角色負重 |
| `堆疊上限` | 整數 | 同ID物品可疊加的最大數量。0表示不可堆疊 |
| `耐久度` | 整數 | 僅裝備類有。0時裝備損壞消失 |
| `數值` | 浮點數 | 物品的基礎數值（治療量、傷害加成等） |
| `詞條列表` | 陣列 | 隨機詞條的ID列表，僅裝備類有 |
| `描述` | 字串 | 江湖風格的物品描述文字 |

### 3.2 負重系統

- 角色基礎負重 = `體魄 × 2`（單位：兩）
- 額外負重：可裝備「負重腰帶」、「大背包」等特殊裝備增加上限
- 當前負重 = 隨身行囊中所有物品的 `重量` 總和

**負重狀態效果：**

| 負重比例 | 狀態 | 效果 |
|---|---|---|
| 0% - 60% | 輕裝 | 無減益 |
| 61% - 80% | 略重 | 移動速度 -10%，戰鬥耐力消耗 +15% |
| 81% - 95% | 沉重 | 移動速度 -25%，戰鬥耐力消耗 +30%，閃避率 -10% |
| 96% - 100% | 超載 | 移動速度 -50%，無法奔跑，戰鬥耐力消耗 +50%，閃避率 -30% |
| >100% | 寸步難行 | 無法移動，無法進入戰鬥。必須丟棄物品至100%以下 |

### 3.3 存取機制

**隨身行囊（隨身攜帶）：**
- 初始欄位：20格
- 可透過特殊裝備（「百寶囊」）或天賦（「行商本色」）增加欄位上限
- 存取：隨時隨地可以打開，但只能在非戰鬥狀態下進行物品整理

**家中箱籠（長期儲存）：**
- 每個城鎮的住所（客棧長租房、自購房產）都配有一個箱籠
- 箱籠容量：初始30格，可花費銀兩升級（上限80格）
- 存取：必須在該住所內才能打開箱籠
- 箱籠裡的物品視為安全存放，不會在戰鬥中遺失或被偷
- 不同城鎮的箱籠**不互通**（你在開封存的劍，在蘇州拿不到）

### 3.4 交易規則

**購買：**
- 從 NPC 商店購買物品，消耗銀兩
- 部分稀有物品有「身份權限」要求（例：錦衣衛千戶才能買到軍用弓弩）
- 部分物品有「關係門檻」（例：和鐵匠好感度達到「至交」才能買到寶器級武器）

**販賣：**
- 物品賣給商店，獲得銀兩（通常為物品價值的 30%-50%）
- 貴重品/任務品通常不可販賣（或只能在黑市以極低價格脫手）
- 贓物（偷來的、搶來的）在正規商店無法販賣，需找黑市商人（價格更低，且有被官府查獲風險）

**交換（以物易物）：**
- 與特定 NPC 進行，不涉及銀兩
- 觸發條件：NPC 有需求，且玩家持有該物品
- 例：藥農需要「十年人參」來換「解毒丹配方」

### 3.5 物品損壞與丟失

- **戰鬥損壞**：戰鬥中，裝備有機率受到損壞（耐久度下降）。耐久度歸0時，該裝備損壞消失。損壞機率 = `(1 - 裝備品質/10) × 基礎損壞率` [需測試]
- **特殊事件丟失**：在特定事件中（如被偷、落水、被捕入獄），玩家可能隨機丟失部分物品
- **死亡掉落**：角色死亡時，隨身行囊中 **20%-50%** 的物品會隨機遺失在死亡地點（可回去撿，但有一定時間限制）。家中箱籠物品安全。

## 4. 公式（Formulas）

### 4.1 負重計算

```
變數定義：
- 當前負重(CurrentLoad) = 隨身行囊中所有物品的重量總和
- 最大負重(MaxLoad) = 體魄 × 2 + 裝備加成 + 天賦加成
- 負重比例(LoadRatio) = CurrentLoad / MaxLoad
```

**範例：**
角色體魄 = 80，裝備「牛皮腰帶」（+20負重）。
MaxLoad = `80 × 2 + 20 = 180` 兩。
行囊中有：鐵劍(10兩) + 金瘡藥x5(1兩/個) + 乾糧x10(0.5兩/個) + 秘笈(5兩) = `10 + 5 + 5 + 5 = 25` 兩。
LoadRatio = `25 / 180 ≈ 13.9%` → 輕裝狀態。

### 4.2 物品損壞機率

```
變數定義：
- 裝備品質階級(EquipTier)：1-7 的整數
- 基礎損壞率(BaseDamageChance)：0.05（每場戰鬥，每次被擊中）
- 最終損壞率(FinalDamageChance) = BaseDamageChance × (1 - (EquipTier / 10))
```

**範例：**
一把「利器（綠）」品質的劍，EquipTier = 3。
FinalDamageChance = `0.05 × (1 - 3/10) = 0.05 × 0.7 = 0.035` → 每次被擊中，有 3.5% 機率損壞。

### 4.3 死亡掉落物品數量

```
變數定義：
- 隨身行囊物品總數(TotalItems)
- 掉落比例(DropRatio)：0.2 ~ 0.5（隨機浮動）
- 掉落物品數量(DropCount) = floor(TotalItems × DropRatio)
```

**範例：**
角色死亡時，行囊有 27 件物品。
DropRatio 隨機為 0.35。
DropCount = `floor(27 × 0.35) = floor(9.45) = 9` 件物品遺失。

## 5. 邊界條件（Edge Cases）

| 情境 | 處理方式 |
|---|---|
| 玩家嘗試拾取物品，但行囊已滿且超載 | 系統提示「行囊已滿，無法拾取」。玩家必須先丟棄或整理物品。 |
| 玩家嘗試將不可堆疊的物品（如任務品）放入已滿的堆疊格 | 系統提示「此物品不可堆疊」，並拒絕操作。 |
| 玩家將某物品賣給商店後，想買回 | 商店會保留該物品至下次「商店刷新」（遊戲內每7天刷新一次庫存）。刷新後物品消失。 |
| 玩家在家中箱籠存滿，且所有箱籠都滿了 | 無法再存放物品。系統提示「家中無處可放」。玩家需升級箱籠或丟棄物品。 |
| 玩家嘗試裝備已損壞（耐久度=0）的裝備 | 系統提示「此裝備已損壞，無法裝備」。 |
| 玩家死亡後回去撿屍，但屍體已被刷新 | 屍體在死亡地點保留 **3天（遊戲內時間）**。3天後物品永久消失。 |
| 玩家與 NPC 交換物品時，對方提出的物品玩家已有且已滿堆疊 | 交換失敗，系統提示「你已經有足夠的此物品了」。 |
| 玩家身上有贓物，被官府 NPC 盤查 | 觸發特殊事件。玩家可選擇賄賂（花錢）、戰鬥（高風險）、或交出贓物（物品消失，名聲微降）。 |
| 玩家在超載狀態下進入戰鬥 | 戰鬥開始時，系統強制玩家丟棄隨機物品直到負重降至 100% 以下。 |

## 6. 系統依賴（Dependencies）

### 此系統依賴：
- **角色屬性系統**：讀取 `體魄` 屬性計算負重上限
- **NPC 人際關係系統**：讀取 NPC 好感度，決定交易權限與價格
- **稱號系統**：讀取玩家稱號，決定物品購買權限
- **天賦系統**：讀取玩家天賦，影響負重上限與欄位數量
- **世界感知系統**：商店刷新週期、屍體刷新時間等受遊戲內時間影響

### 依賴此系統的系統：
- **裝備系統**：裝備的穿戴、卸下、損壞管理
- **經濟系統**：所有買賣行為的底層邏輯
- **任務系統**：任務物品的獲取、交付、消耗
- **戰鬥系統**：戰鬥中消耗品的使用、裝備損壞
- **鍛造/合成系統**：材料的存放與取出
- **傳代系統**：傳代時，哪些物品可以繼承給後代

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 預設值 | 安全調整範圍 | 調整影響 |
|---|---|---|---|
| `基礎負重係數` | 2 | 1.5 - 3.0 | 影響所有角色的攜帶能力。調高 → 玩家更輕鬆，調低 → 抉擇更痛苦 |
| `負重門檻比例` | 60%/80%/95%/100% | 可調整各階段門檻 | 影響玩家在不同負重下的體驗壓力 |
| `輕裝/略重/沉重/超載減益` | 10%/25%/50% | 5% - 80% | 調整負重對戰鬥的影響程度 |
| `商店收購價比例` | 40% | 20% - 60% | 影響物品回收的經濟價值。調低 → 玩家更窮，調高 → 經濟系統更寬鬆 |
| `戰鬥損壞基礎機率` | 0.05 | 0.01 - 0.15 | 影響裝備消耗速度。調高 → 裝備更易損壞，需頻繁更換 |
| `死亡掉落比例範圍` | 0.2 - 0.5 | 0.1 - 0.8 | 影響死亡懲罰的嚴重程度。調高 → 死亡代價更大，調低 → 更寬容 |
| `屍體保留時間` | 3天 | 1天 - 7天 | 影響玩家回去撿屍的壓力。時間越短，越需立即行動 |
| `箱籠初始格數` | 30 | 20 - 50 | 影響玩家初期儲存壓力 |
| `箱籠升級最大格數` | 80 | 60 - 120 | 影響後期物品收藏的空間上限 |

## 8. 驗收標準（Acceptance Criteria）

| 編號 | 驗收項目 | 測試方法 | 預期結果 |
|---|---|---|---|
| INV-01 | 物品可正確分類 | 創建各類別物品並檢查其屬性 | 物品顯示正確的類別、品質、重量、堆疊上限 |
| INV-02 | 負重系統正確運作 | 將物品放入行囊，觀察負重狀態變化 | 負重比例即時更新，角色狀態按門檻切換 |
| INV-03 | 超載無法移動 | 將負重推至 >100% | 角色無法移動，無法進入戰鬥 |
| INV-04 | 行囊欄位上限 | 嘗試放入第21件物品至20格行囊 | 系統提示「行囊已滿」 |
| INV-05 | 箱籠跨城不互通 | 在開封存物，前往蘇州打開箱籠 | 蘇州箱籠為空，開封箱籠物品仍在 |
| INV-06 | 物品堆疊 | 將10瓶金瘡藥放入同一格 | 顯示為「金瘡藥 x10」，重量為10倍單個重量 |
| INV-07 | 交易價格 | 將價值100兩的物品賣給商店 | 獲得40兩（按40%收購價） |
| INV-08 | 戰鬥損壞 | 在戰鬥中讓角色被擊中100次 | 統計損壞次數，應接近預期機率（約3.5次） |
| INV-09 | 死亡掉落 | 讓角色死亡，檢查行囊 | 行囊中約20%-50%的物品消失 |
| INV-10 | 屍體刷新 | 角色死亡後，等待4天遊戲內時間 | 屍體消失，無法撿回遺失物品 |
| INV-11 | 贓物交易限制 | 嘗試將贓物賣給正規商店 | 商店拒絕收購 |
| INV-12 | 權限物品購買 | 非錦衣衛千戶嘗試購買軍用弓弩 | 商店不顯示該物品，或提示無權購買 |
