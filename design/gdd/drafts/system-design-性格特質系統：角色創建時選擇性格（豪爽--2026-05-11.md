# 江湖一生 性格特質系統 GDD 草稿

**策劃：陳品霖 | 狀態：草稿 | 日期：2026-05-12**

## 1. 概述（Overview）

性格特質系統是角色創建時的核心選擇之一，它定義了角色「是什麼樣的人」，而非「會什麼武功」。性格會影響初始屬性配點、與不同類型NPC的初始好感、對話選項的觸發與效果，以及特定事件的觸發條件。它是一張看不見的「社交名片」，決定了世界以何種姿態迎接你。

## 2. 玩家體驗（Player Fantasy）

玩家在創建角色時，選擇性格的瞬間，應該感受到：「我決定了這個角色在江湖上的『人設』。」這個選擇不是單純的數值加減，而是對後續數十小時遊戲體驗的風格宣言。

- **豪爽**：玩家感覺自己是大口喝酒、快意恩仇的俠客，走到哪都有人願意跟你稱兄道弟，但也容易被人算計。
- **陰沉**：玩家感覺自己是一匹獨狼，別人對你敬而遠之，但你更容易洞察陰謀、發現秘密。
- **莽撞**：玩家感覺自己像個愣頭青，常常惹禍，但也因此獲得許多意想不到的機遇。
- **謹慎**：玩家感覺自己是個老江湖，步步為營，不容易吃虧，但也錯失一些衝動帶來的驚喜。

**核心體驗**：這個系統不是用來「最優化」的，而是用來「角色扮演」的。玩家不會因為選了「莽撞」就玩不下去，而是會玩到一個與「謹慎」完全不同的故事。

## 3. 詳細規則（Detailed Rules）

### 3.1 性格清單與初始效果（MVP版本：6種）

| 性格 | 核心描述 | 初始屬性修正 | 初始好感修正（與NPC類型） | 專屬對話/事件 |
|---|---|---|---|---|
| **豪爽** | 重義氣，不拘小節，易交朋友 | 武力+5，悟性-5 | **俠義/中立NPC**：+10<br>**陰險/邪惡NPC**：-10 | 更容易觸發「結拜」、「宴請」事件；更容易被騙 |
| **陰沉** | 心思縝密，不形於色，善於算計 | 悟性+5，體魄-5 | **所有NPC**：初始好感-5（難以接近）<br>**陰險/邪惡NPC**：+5（同類相吸） | 更容易發現隱藏對話、陰謀線索；不易被情感勒索 |
| **莽撞** | 衝動行事，不計後果，敢作敢當 | 體魄+5，輕功-5 | **俠義/中立NPC**：-5（覺得你不可靠）<br>**邪惡NPC**：+5（覺得你好利用） | 戰鬥中更容易觸發「暴怒」狀態（傷害+20%，防禦-10%）；探索時更容易觸發「意外」事件（好壞皆有） |
| **謹慎** | 深思熟慮，謀定而後動，穩紮穩打 | 輕功+5，武力-5 | **所有NPC**：初始好感+5（覺得你穩重）<br>**莽撞NPC**：-5（覺得你膽小） | 戰鬥中更容易觸發「警戒」狀態（閃避+15%，傷害-5%）；陷阱、埋伏的發現率+20% |
| **正直** | 堅守原則，嫉惡如仇，光明磊落 | 名聲+5，內力-5 | **俠義NPC**：+15<br>**邪惡NPC**：-20（視為死敵） | 無法進行「偷竊」、「下毒」等卑劣行為；更容易獲得正道門派信任 |
| **狡猾** | 靈活變通，不擇手段，利益至上 | 內力+5，名聲-5 | **邪惡/中立NPC**：+10<br>**俠義NPC**：-15（視為小人） | 可進行「偷竊」、「下毒」、「說謊」等行為；更容易在黑市、邪派中獲得機會 |

**設計意圖**：每個性格都有明確的「優勢」與「劣勢」，沒有絕對的強弱。玩家選擇性格，就是在選擇一種「代價」與「收益」的偏好。

### 3.2 性格與對話選項（V2追加）

- 對話選項會根據玩家性格動態生成「專屬選項」。
- **範例**：
  - 遇到一個乞丐向你乞討：
    - **豪爽**：「拿去，買點酒喝！」（花費10兩，好感+15）
    - **謹慎**：「你是真乞丐還是騙子？」（觸發鑑定事件）
    - **狡猾**：「我可以給你錢，但你得幫我做件事。」（觸發任務）
    - **正直**：「你為何淪落至此？我帶你去見官。」（觸發救助事件）
  - 選擇非專屬選項（如直接拒絕）總是可用，但會錯失性格帶來的獨特機會。

### 3.3 性格與NPC關係演化（V2追加）

- NPC會「記住」玩家的性格行為。一個「豪爽」的玩家如果連續拒絕三次酒宴邀請，NPC可能會嘀咕：「這傢伙以前不是這樣的，是不是遇到什麼事了？」（關係可能出現裂痕或觸發關心事件）
- 這與NPC記憶系統（GDD第7章）連動，讓性格成為一個動態標籤，而非靜態數值。

### 3.4 性格改變（極罕見，V2追加）

- 角色經歷極端事件（如摯愛被殺、被最信任的人背叛）後，可能觸發「性格轉變」事件。
- 例如：一個「正直」的人在經歷不公後，可能轉變為「陰沉」或「狡猾」。
- 這是一個重大的角色發展事件，會伴隨明確的劇情演出和數值變動，不應頻繁發生。一生中觸發次數不超過1-2次。

## 4. 公式（Formulas）

### 4.1 初始屬性修正（已於規則3.1定義）

無複雜公式，直接為數值加減。

### 4.2 初始好感修正（已於規則3.1定義）

```
NPC初始好感 = NPC基礎好感 + 性格修正值
```

- `NPC基礎好感`：由NPC自身的性格、陣營、與玩家的關係類型決定（由NPC系統定義）。
- `性格修正值`：來自規則3.1表格。

**範例計算**：
- 玩家性格：豪爽
- 遇到一個俠義屬性的NPC，其基礎好感為50。
- 計算：`50 + 10 = 60`。該NPC對玩家的初始好感為60（友好）。

### 4.3 專屬狀態觸發機率（[需測試]）

- **莽撞 - 暴怒狀態**：觸發機率 = `(100 - 玩家當前血量百分比%) / 2`
  - **範例**：玩家血量30%，觸發機率 = `(100 - 30) / 2 = 35%`。每次受擊有35%機率進入暴怒。
- **謹慎 - 警戒狀態**：觸發機率 = `(100 - 玩家當前精力百分比%) / 2`
  - **範例**：玩家精力60%，觸發機率 = `(100 - 60) / 2 = 20%`。每次戰鬥開始時有20%機率進入警戒。

**測試方向**：測試這兩個狀態的觸發頻率是否過高或過低，確保它們是「戰術選項」而非「常駐Buff」。

## 5. 邊界條件（Edge Cases）

| 邊界情況 | 處理方式 |
|---|---|
| 玩家選擇「正直」性格後，試圖進行偷竊 | 系統阻止該行為，並顯示提示：「你的正直品格讓你無法做出此等宵小之舉。」 |
| 玩家選擇「狡猾」性格後，在正道門派掌門面前說謊 | 觸發「說謊」判定，成功率與玩家的「狡猾」性格相關（基礎成功率較高）。若失敗，好感大幅下降。 |
| NPC的「基礎好感」加上「性格修正值」後超過100或低於0 | 數值被強制鎖定在0-100範圍內。例如：`NPC基礎好感(90) + 正直對邪惡修正(-20) = 70`。 |
| 玩家在遊戲中後期觸發「性格轉變」事件 | 1. 所有基於舊性格的專屬對話選項被替換為新性格的選項。<br>2. 基於舊性格的NPC好感修正值被新性格的修正值覆蓋，但NPC對玩家的「記憶好感」不受影響（他們記得你以前是什麼樣的人）。<br>3. 觸發一個全局事件，讓所有與玩家有重要關係的NPC知曉這個改變，並產生不同反應。 |
| 玩家同時觸發多個性格相關事件（例如：同時遇到一個可以「結拜」的豪爽事件和一個可以「發現陰謀」的陰沉事件） | 事件不衝突，玩家可以自由選擇觸發哪一個，或先後觸發。性格系統是「影響」，不是「鎖死」。 |

## 6. 系統依賴（Dependencies）

### 6.1 依賴其他系統

- **角色創建系統（GDD第3章）**：性格是角色創建的一部分，需要與外觀、天賦等流程整合。
- **NPC人際關係系統（GDD第7章）**：性格修正值直接影響NPC的初始好感計算。
- **對話系統（待設計）**：需要對話系統支援「基於性格生成動態選項」的功能。
- **事件系統（待設計）**：需要事件系統支援「基於性格觸發特殊事件（如暴怒、警戒、性格轉變）」。

### 6.2 被其他系統依賴

- **陣營系統（GDD第8章）**：陣營在評估是否接納玩家時，可將玩家性格作為一個參考因子（例如，邪派更歡迎「狡猾」的玩家）。
- **世界感知系統（GDD第9章）**：玩家的性格行為（如「豪爽」地當眾請客）會影響名聲傳播的內容和速度。
- **任務系統（待設計）**：任務NPC可能會根據玩家性格，提供不同的任務解法或獎勵。

## 7. 可調參數（Tuning Knobs）

| 參數 | 安全調整範圍 | 影響 | MVP/V2 |
|---|---|---|---|
| 每種性格的初始屬性修正值 | ±0 到 ±10 | 影響角色初期戰鬥力與成長方向 | MVP |
| 每種性格的初始好感修正值 | ±0 到 ±30 | 影響角色初期社交難度 | MVP |
| 「暴怒」狀態的觸發機率係數 | 0.1 到 0.5 | 影響莽撞性格的戰鬥強度與風險 | MVP |
| 「警戒」狀態的觸發機率係數 | 0.1 到 0.5 | 影響謹慎性格的戰鬥風格 | MVP |
| 專屬對話選項的出現頻率 | 每N次對話出現1次 (N=3~10) | 影響性格在遊戲中的存在感 | V2 |
| 性格轉變事件的觸發閾值 | 極端事件觸發，可調整所需事件的「衝擊強度」 | 影響角色發展的動態性與稀有度 | V2 |

## 8. 驗收標準（Acceptance Criteria）

- [ ] **MVP-1**：角色創建時，可從6種性格（豪爽、陰沉、莽撞、謹慎、正直、狡猾）中選擇一種。
- [ ] **MVP-2**：選擇性格後，角色的初始屬性（武力、內力、體魄、輕功、悟性、名聲）會根據規則3.1的表格進行增減。
- [ ] **MVP-3**：選擇性格後，首次遇到NPC時，其初始好感會根據規則3.1的表格進行增減。
- [ ] **MVP-4**：選擇「正直」性格的玩家，在試圖執行偷竊、下毒等行為時，會被系統阻止並顯示提示。
- [ ] **V2-1**：對話系統可根據玩家性格，動態生成至少1個專屬對話選項。
- [ ] **V2-2**：選擇「莽撞」性格的玩家，在戰鬥中血量低於30%時，有機率觸發「暴怒」狀態（傷害+20%，防禦-10%）。
- [ ] **V2-3**：選擇「謹慎」性格的玩家，在戰鬥開始時有機率觸發「警戒」狀態（閃避+15%，傷害-5%）。
- [ ] **V2-4**：角色在經歷極端事件後，可觸發「性格轉變」事件，並正確更新所有相關系統的數值。
- [ ] **V2-5**：所有數值計算結果（初始好感、狀態觸發機率）均與設計文件中的公式一致。
