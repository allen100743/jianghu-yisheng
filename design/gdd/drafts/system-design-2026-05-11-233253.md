# 江湖一生 — 戰鬥系統設計文件

*策劃：陳品霖 | 2026-05-12*

## 1. 概述（Overview）

戰鬥系統是《江湖一生》中，玩家驗證自身成長、解決衝突與推動江湖事件的核心機制。它不是遊戲的唯一重心，而是江湖生活的一部分。

戰鬥的結果（輸贏、傷亡、使用的武學）會直接影響NPC關係、名聲傳播與世界狀態。系統採用**橫版側視即時戰鬥**，並支援**手動操作**與**可切換模板的自動戰鬥**，以服務不同類型的玩家。戰鬥的核心樂趣在於「操作驗證養成成果」，而非純粹的數值碾壓。

---

## 2. 玩家體驗（Player Fantasy）

### 核心體驗目標
- **新手期（前10小時）**：戰鬥是生存壓力。每一場戰鬥都關係到角色能否活下來，操作失誤會帶來真實後果（受傷、耗損資源）。玩家專注於學習基本操作與生存技巧。
- **成長期（10-50小時）**：戰鬥是驗證成長的舞台。玩家能明顯感受到「之前打不過的敵人，現在可以輕鬆取勝」。學習新武學、更換新裝備後的戰鬥體驗有立即的回饋。
- **高手期（50小時+）**：戰鬥是風格的展現。玩家不再需要為了生存而戰，轉而追求「如何打得漂亮」。使用自創武學、組合技、以寡敵眾成為樂趣來源。戰鬥成為一種表演，影響江湖傳聞。

### 具體感受目標
- **操作有意義**：手動操作能打贏自動戰鬥過不了的關卡。
- **成長看得見**：同樣的敵人，隨著角色成長，戰鬥時間與難度直觀下降。
- **風格有區別**：使用劍法 vs 拳法 vs 暗器的戰鬥節奏與視覺表現完全不同。
- **後果有重量**：打贏或打輸，殺死或放過，都會影響後續的江湖際遇。

## 3. 詳細規則（Detailed Rules）

### 3.1 基本戰鬥流程

1. **戰鬥觸發**：當玩家或NPC對另一方發動攻擊指令，或特定事件（如遭遇戰、劇情戰）觸發時，進入戰鬥狀態。
2. **場景切換**：從大地圖/區域地圖無縫過渡到戰鬥場景。戰鬥場景為預設的2D橫版地圖，根據觸發地點（野外、城鎮、門派）有不同的背景。
3. **戰鬥開始**：所有參戰單位根據「輕功」屬性決定出手順序（先手值）。戰鬥開始時，所有單位處於「待命」狀態。
4. **時間流動**：戰鬥為即時制，但玩家可隨時暫停（`Space`鍵）進行指令下達。暫停時，遊戲時間完全停止。
5. **勝利條件**：消滅所有敵方單位，或敵方單位投降/逃離。
6. **失敗條件**：玩家角色生命值歸零，或所有隊友生命值歸零。
7. **戰鬥結束**：結算經驗、戰利品、傷勢狀態。若角色或重要NPC死亡，觸發對應的江湖事件。

### 3.2 單位屬性與狀態

- **生命值 (HP)**：歸零則單位死亡。基礎值由體魄決定：`HP = 體魄 × 5 + 50`。
- **內力值 (MP)**：施展武學技能消耗的資源。基礎值由內力決定：`MP = 內力 × 3 + 20`。內力值會隨時間緩慢恢復（每秒恢復 `內力 / 100` 點）。
- **體力值 (SP)**：進行普通攻擊、閃避、格擋消耗的資源。基礎值由體魄與輕功共同決定：`SP = 體魄 × 2 + 輕功`。體力值在停止消耗後快速恢復（每秒恢復 `體魄 / 50` 點）。
- **狀態效果**：角色可被附加多種狀態，如「中毒」、「灼燒」、「冰凍」、「眩暈」、「恐懼」、「破甲」等。每種狀態有獨立的持續時間與效果。

### 3.3 操作與指令

| 操作 | 按鍵 | 功能 |
|---|---|---|
| 移動 | WASD | 控制角色在橫版場景中移動 |
| 普通攻擊 | 滑鼠左鍵 | 對鎖定目標進行一次基礎攻擊，消耗少量SP，造成基礎物理傷害 |
| 武學技能 | 數字鍵 1-6 | 釋放已裝備的武學技能，消耗MP與SP |
| 閃避 | `Shift` | 朝指定方向快速位移，消耗大量SP，短時間內無敵 |
| 格擋 | `Q` | 進入防禦姿態，減少受到的傷害，消耗SP。成功格擋可觸發「反擊」 |
| 切換目標 | `Tab` | 在可攻擊的敵人之間切換鎖定 |
| 暫停/指令 | `Space` | 暫停遊戲，下達移動、技能等指令，解除暫停後角色執行指令 |
| 自動戰鬥切換 | `F` | 在當前自動戰鬥模板與手動模式之間切換 |

### 3.4 自動戰鬥系統

- **觸發方式**：玩家按下`F`鍵，角色進入自動戰鬥模式。
- **行為模板**：玩家可在戰鬥外或暫停時，從以下模板中選擇：
    - **激進**：優先使用高傷害技能，傾向於近身攻擊，不保留資源。適合碾壓戰。
    - **穩健**：保持中距離，交替使用普攻與技能，保留部分MP與SP以備不時之需。適合強度相當的戰鬥。
    - **保守**：優先保證生存，頻繁閃避與格擋，只在安全時輸出。適合挑戰高難度敵人。
    - **輔助**：優先使用增益、治療技能，保持與敵人的距離。適合有隊友的場合。
- **切換邏輯**：玩家可在自動戰鬥中隨時按下`F`鍵或任何手動操作指令（移動、攻擊、技能），立即切換回手動模式。
- **AI行為**：自動戰鬥AI會根據當前模板、角色狀態（HP/MP/SP）、敵我距離、技能冷卻等因素做出決策。具體決策樹見[待補充：AI行為樹設計文件]。

### 3.5 傷害計算流程

```
攻擊方發動技能 → 判定命中 → 判定閃避 → 判定格擋 → 計算基礎傷害 → 計算傷害加成/減免 → 應用最終傷害
```

1. **命中判定**：技能基礎命中率為100%。若目標處於「閃避」狀態，則命中率降低。
2. **閃避判定**：目標有機率閃避攻擊。基礎閃避率 = `輕功 / (輕功 + 500) × 100%`。若成功閃避，則傷害為0。
3. **格擋判定**：若目標處於格擋狀態，則觸發格擋。格擋減免 = `50% + (體魄 / 1000) × 30%`。格擋成功時，消耗目標SP。
4. **基礎傷害計算**：`基礎傷害 = 技能威力 × (1 + 武力 / 500)`。
5. **最終傷害**：`最終傷害 = 基礎傷害 × (1 - 目標減傷%) × (1 + 易傷加成%)`。減傷與易傷來自裝備詞條、狀態效果等。

### 3.6 死亡與重傷

- **玩家角色死亡**：
    - **MVP規則**：角色死亡即為遊戲結束（GAME OVER），載入最近的自動存檔或手動存檔。
    - **V2規則**：引入「重傷」狀態。角色HP歸零時，不立即死亡，而是進入「重傷瀕死」狀態。在此狀態下，若玩家有「續命丹」等道具或隊友前來救治，則可復活並保留部分屬性懲罰（如HP上限暫時降低）。若無人救治且持續時間結束，則角色正式死亡。
- **重要NPC死亡**：會觸發對應的世界事件，影響相關陣營、任務與關係網。此部分由「世界感知系統」與「事件系統」處理。
- **雜兵/野怪死亡**：正常消失，掉落戰利品。

### 3.7 戰利品與結算

- **掉落機制**：敵人死亡時，根據其「難度等級」與「類型」，有機率掉落金錢、材料、裝備或武學殘篇。
- **結算畫面**：戰鬥結束後，顯示簡潔的結算面板，包含：獲得的經驗值（若有）、擊殺數、獲得的戰利品列表、戰鬥用時。此面板可在3秒後或玩家點擊後關閉。

## 4. 公式（Formulas）

### 4.1 基礎屬性公式

| 屬性 | 公式 | 說明 |
|---|---|---|
| 生命值 (HP) | `HP = 體魄 × 5 + 50` | 取整數 |
| 內力值 (MP) | `MP = 內力 × 3 + 20` | 取整數 |
| 體力值 (SP) | `SP = 體魄 × 2 + 輕功` | 取整數 |
| 基礎閃避率 | `閃避率% = 輕功 / (輕功 + 500) × 100` | 結果保留小數點後一位 |
| 基礎物理傷害 | `基礎傷害 = 武力 × (1 + 武學熟練度加成%)` | 武學熟練度加成見武學系統 |
| 內力恢復速度 | `MP恢復/秒 = 內力 / 100` | 取整數，最小為1 |
| 體力恢復速度 | `SP恢復/秒 = 體魄 / 50` | 取整數，最小為1 |

### 4.2 戰鬥傷害公式

- **變數定義**：
    - `Skill_Power`：技能威力（固定值，由武學決定）
    - `ATK`：攻擊方武力
    - `DEF`：防禦方體魄
    - `Mastery_Bonus`：武學熟練度加成（入門0%，熟練20%，小成40%，大成70%，圓滿100%）
    - `Target_Damage_Reduction`：目標總傷害減免（來自裝備、狀態等，以百分比表示）
    - `Attacker_Damage_Bonus`：攻擊方總傷害加成（來自裝備、狀態等，以百分比表示）

- **公式**：
    ```
    基礎傷害 = Skill_Power × (1 + ATK / 500) × (1 + Mastery_Bonus)
    最終傷害 = floor(基礎傷害 × (1 - Target_Damage_Reduction) × (1 + Attacker_Damage_Bonus))
    ```

- **範例計算**：
    - 玩家武力 `ATK = 200`，使用「華山劍法」（`Skill_Power = 50`），熟練度為「小成」（`Mastery_Bonus = 40%`）。
    - 目標總減傷 `Target_Damage_Reduction = 10%`，玩家總增傷 `Attacker_Damage_Bonus = 5%`。
    - `基礎傷害 = 50 × (1 + 200/500) × (1 + 0.4) = 50 × 1.4 × 1.4 = 98`
    - `最終傷害 = floor(98 × (1 - 0.1) × (1 + 0.05)) = floor(98 × 0.9 × 1.05) = floor(92.61) = 92`
    - **結果：玩家對目標造成 92 點傷害。**

- **取整規則**：所有傷害、治療、屬性增減的最終結果，均向下取整（`floor`）。

## 5. 邊界條件（Edge Cases）

| 邊界情況 | 處理方式 |
|---|---|
| **玩家與友方NPC同時攻擊敵人，最後一擊歸誰？** | 歸屬於造成最後一擊的單位。擊殺榮譽與部分特殊戰利品（如任務物品）歸屬擊殺者。 |
| **敵人在戰鬥中逃跑，如何處理？** | 戰鬥勝利條件改為「敵方全員逃離戰場」。逃跑的敵人會保留其戰鬥狀態（如殘血），並可能觸發後續事件（如回去通風報信）。 |
| **玩家在戰鬥中使用恢復道具，如何處理？** | 在戰鬥中，玩家可以打開背包使用道具。使用道具會消耗一次「行動機會」，在即時戰鬥中表現為一個短暫的施法動作，期間無法移動或攻擊。 |
| **多個單位同時攻擊一個目標，傷害如何疊加？** | 各自獨立計算傷害，然後依次應用。沒有「傷害合併」或「傷害加成」的設定。 |
| **玩家與NPC隊友的戰鬥AI衝突怎麼辦？** | 玩家手動操作的角色擁有最高指令優先級。NPC隊友會遵循其AI模板，但會避免與玩家搶奪同一目標的「最後一擊」[需測試]。 |
| **戰鬥中網路斷線（單機遊戲不適用）** | 不適用。 |
| **玩家在戰鬥中存檔** | 戰鬥中禁止存檔。存檔只能在非戰鬥狀態下進行。 |
| **角色SP或MP不足，無法施展技能** | 按鍵會顯示為灰色或發出錯誤提示音，技能無法釋放。角色會自動進行普通攻擊（若在自動戰鬥模式下）或原地待命（若在手動模式下）。 |

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 當前值 | 安全調整範圍 | 調整影響 |
|---|---|---|---|
| **基礎生命係數** | `體魄 × 5` | `[3, 7]` | 影響所有角色的總生存能力。調高延長戰鬥時間，調低使戰鬥更致命。 |
| **基礎內力係數** | `內力 × 3` | `[2, 5]` | 影響技能釋放頻率。調高使得玩家能更頻繁使用技能，戰鬥節奏加快。 |
| **基礎閃避公式分母** | `500` | `[300, 800]` | 影響閃避率的成長曲線。分母越小，輕功帶來的閃避收益越高。 |
| **武力對傷害的加成係數** | `1 / 500` | `[1/800, 1/300]` | 影響武力屬性的價值。係數越高，武力對傷害的提升越顯著。 |
| **格擋基礎減傷** | `50%` | `[30%, 70%]` | 影響格擋的戰術價值。調高使「坦克」流派更強勢。 |
| **內力恢復速度係數** | `內力 / 100` | `[內力/150, 內力/50]` | 影響戰鬥續航能力。調快使玩家更少因MP耗盡而陷入被動。 |
| **體力恢復速度係數** | `體魄 / 50` | `[體魄/80, 體魄/30]` | 影響閃避與格擋的使用頻率。調快使操作型玩家有更多操作空間。 |
| **自動戰鬥切換冷卻** | `0` 秒 | `[0, 3]` 秒 | 防止玩家在自動與手動之間頻繁切換來「作弊」。建議保持0秒，以保證操作流暢性。[需測試] |
| **戰鬥中暫停次數限制** | 無限制 | `[無限制, 每場戰鬥3次]` | 影響戰鬥難度。限制暫停次數會增加即時操作的壓力，適合硬核玩家。建議MVP階段無限制，V2再考慮加入限制模式。 |

## 8. 驗收標準（Acceptance Criteria）

| 編號 | 驗收項目 | 預期結果 | 測試方法 |
|---|---|---|---|
| AC-01 | 戰鬥觸發 | 玩家攻擊NPC或被NPC攻擊時，成功切換至戰鬥場景 | 手動觸發戰鬥10次，確認每次都能正常進入 |
| AC-02 | 基本操作 | WASD移動、滑鼠左鍵普攻、數字鍵釋放技能均能正常響應 | 逐一測試所有按鍵功能，確認無衝突或無響應 |
| AC-03 | 傷害計算 | 對同一目標造成傷害，其數值與公式計算結果一致（浮動範圍±1） | 使用固定屬性的角色攻擊防禦為0的目標，記錄10次傷害並比對公式 |
| AC-04 | 閃避與格擋 | 角色成功閃避時，傷害為0；成功格擋時，傷害減免符合公式 | 手動觸發閃避與格擋，觀察傷害數值變化 |
