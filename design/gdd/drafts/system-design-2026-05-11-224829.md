# 江湖一生 — 角色創建系統 GDD

*策劃：陳品霖 | 審核：製作人 | 2026-05-12*

## 1. 概述（Overview）

角色創建系統是玩家進入《江湖一生》世界的第一步，負責生成玩家將操作一生的角色。本系統在5分鐘內完成，提供出身背景選擇、初始天賦獲取、以及基本外觀自定義，快速將玩家送入沙盒世界。系統的核心設計目標是：**快速建立角色認同，並埋下影響一生的隨機變數。**

## 2. 玩家體驗（Player Fantasy）

- **「我是誰？」**：玩家在幾分鐘內，透過選擇出身和天賦，回答這個問題。出身決定你的起點，天賦決定你的潛力。
- **「這局不一樣」**：隨機天賦池確保每次創角都有驚喜，即使玩過10次，每次開局都有新的可能性。
- **「這是我」**：外觀自訂義讓角色有歸屬感，不是隨機生成的無名氏。
- **「快速開始」**：流程簡潔，不讓玩家在創角階段就感到疲勞或選擇困難，5分鐘內進入江湖。

## 3. 詳細規則（Detailed Rules）

### 3.1 創角流程

1.  **出身背景選擇（P0）**
    -   玩家從預設的3個出身背景中選擇1個。
    -   **備選清單（MVP）**：
        | 出身 | 初始效果 | 玩家幻想 |
        |---|---|---|
        | **孤兒** | 無初始金錢，無親屬，初始名聲+10（江湖傳言「這小子無牽無掛，是個狠角色」） | 白手起家，無所畏懼。 |
        | **商賈之子** | 初始金錢+200兩，初始交易價格-10%（商人好感），初始名聲-5（「紈褲子弟」） | 財力雄厚，以錢鋪路。 |
        | **武官世家** | 初始武力+10，初始體魄+5，朝廷NPC初始好感+20 | 家學淵源，體制內起點高。 |
    -   選擇後，系統根據出身生成一個簡短的開場文本（可跳過）。
    -   **V2追加**：增加「書香門第」（悟性+10）、「江湖浪子」（輕功+5、名聲+5）、「隱世高人之後」（資質+15）等出身。

2.  **初始天賦選擇（P0）**
    -   系統從預設的天賦池中隨機生成4個天賦。
    -   玩家從這4個中選擇1個作為初始天賦。
    -   天賦池設計：
        -   **天賦分級**：分為「凡品」、「精良」、「絕品」三級。
        -   **生成權重**：凡品60%、精良30%、絕品10%。
        -   **重骰機制**：玩家若不滿意當前4個天賦，可消耗一次「重骰機會」刷新。初始給予2次重骰機會。重骰時，系統重新生成4個全新天賦。
    -   **MVP天賦池樣例**：
        | 天賦名稱 | 品質 | 效果 |
        |---|---|---|
        | 天生神力 | 凡品 | 初始武力+15 |
        | 根骨清奇 | 凡品 | 初始體魄+15 |
        | 過目不忘 | 凡品 | 初始悟性+10 |
        | 八面玲瓏 | 凡品 | 初始名聲+20 |
        | 福星高照 | 精良 | 所有「機率觸發」類事件成功率+10% |
        | 武學奇才 | 精良 | 學習武學所需時間-20% |
        | 天生領袖 | 精良 | 招募NPC隊友時好感度門檻-10% |
        | 天選之人 | 絕品 | 可從4個天賦中選擇2個（此天賦本身不佔用名額）|
        | 死裡逃生 | 絕品 | 首次受到致命傷害時，強制保留1點生命，且3天內全屬性+30% |
    -   **V2追加**：增加更多特殊天賦，如「斷袖之癖」（影響特定NPC關係）或「天生毒體」（毒抗性極高，但與正道門派初始好感降低）。

3.  **外觀自定義（P0）**
    -   **MVP**：提供4個可自定義圖層。
        -   臉型：3種（國字臉、瓜子臉、圓臉）
        -   髮型：5種（束髮、披肩髮、光頭、馬尾、道髻）
        -   上衣：3套（粗布衣、錦衣、勁裝）
        -   下裝：3套（長褲、長裙、綁腿褲）
    -   所有外觀選擇僅為視覺效果，不影響任何數值。
    -   **V2追加**：增加五官細節（眼、鼻、口、眉）、膚色、鬍鬚、飾品（頭冠、耳環、玉佩）等7個圖層。

4.  **角色命名（P0）**
    -   玩家輸入角色名稱，字數限制2-6個中文字或4-12個英文字母。
    -   提供「隨機生成」按鈕，從預設名稱庫（男/女通用）中隨機生成一個。

5.  **確認與進入遊戲（P0）**
    -   玩家確認所有選擇後，進入遊戲。
    -   此時，玩家的初始屬性、金錢、物品、關係等根據其選擇的出身和天賦被初始化。

### 3.2 角色初始化

-   玩家確認創角後，系統根據以下規則初始化角色：
    1.  **基礎屬性**：所有7項核心屬性設定為初始基礎值（見第14章）。
    2.  **出身加成**：根據選擇的出身，疊加對應的屬性、金錢、名聲等。
    3.  **天賦加成**：根據選擇的天賦，疊加對應的屬性、特殊效果。
    4.  **初始物品**：根據出身，給予初始物品（如孤兒：破舊的布衣；商賈之子：200兩銀票；武官世家：一把鐵劍）。
    5.  **初始關係**：根據出身，生成初始的NPC關係（如武官世家：父親為朝廷武官，初始好感+50）。

## 4. 公式（Formulas）

### 4.1 天賦生成公式

-   **變數定義**：
    -   `N` = 每次生成的天賦數量（固定為4）
    -   `Rarity` = 天賦品質（0: 凡品, 1: 精良, 2: 絕品）
    -   `Weight`：`Weight(凡品) = 60`, `Weight(精良) = 30`, `Weight(絕品) = 10`
-   **公式**：
    -   系統從天賦池中隨機抽取N個天賦，每個天賦的品質由其對應的權重決定。
    -   抽取方式：生成一個1-100的隨機數`R`，若`R ≤ 10`則為絕品，若`10 < R ≤ 40`則為精良，否則為凡品。
-   **範例計算**：
    -   生成4個天賦，隨機數R分別為：5, 30, 70, 88。
    -   對應品質：絕品, 精良, 凡品, 凡品。
    -   從對應品質的天賦池中隨機抽取一個天賦。
-   **取整規則**：無。

### 4.2 初始金錢公式

-   **變數定義**：
    -   `Gold_Base` = 基礎金錢（固定為50兩）
    -   `Gold_Bonus` = 出身帶來的金錢加成（孤兒：0兩，商賈之子：200兩，武官世家：50兩）
-   **公式**：`初始金錢 = Gold_Base + Gold_Bonus`
-   **範例計算**：選擇「商賈之子」，初始金錢 = 50 + 200 = 250兩。
-   **取整規則**：結果取整數。

## 5. 邊界條件（Edge Cases）

-   **玩家跳過所有開場文本**：允許。跳過後，玩家直接進入角色創建介面。
-   **玩家對所有隨機天賦都不滿意**：玩家可使用「重骰機會」刷新。若2次重骰後仍不滿意，玩家必須從當前的4個天賦中選擇一個。系統不會強制鎖定一個「最差」的天賦。
-   **玩家輸入的角色名稱為空**：系統不允許提交，並提示「角色名稱不能為空」。
-   **玩家輸入的角色名稱過長**：系統限制字數，超過部分自動截斷或提示「名稱過長」。
-   **玩家輸入的角色名稱與其他已存檔角色重複**：允許。遊戲世界中的NPC不會因為名稱相同而產生混淆，每個角色都有唯一的後台ID。
-   **玩家選擇「武官世家」出身，但隨機生成的父親NPC已在另一局遊戲中死亡**：不影響。每一局遊戲是一個獨立的世界線，NPC狀態不繼承。
-   **玩家選擇「天選之人」天賦，並選擇了2個天賦，其中一個也是「天選之人」**：不允許。天賦池設計時，不會同時出現兩個「天選之人」。系統應避免此情況。

## 6. 系統依賴（Dependencies）

-   **依賴的系統**：
    -   **核心屬性系統（第14章）**：角色創建時需要初始化所有核心屬性，並根據出身和天賦進行調整。
    -   **NPC人際關係系統（第7章）**：出身背景需要生成初始的NPC關係（如武官世家的父親）。
    -   **經濟系統（第12章）**：出身背景需要初始化角色的金錢和初始物品。
    -   **世界感知系統（第9章）**：出身背景影響初始名聲值，進而影響世界感知的起點。
-   **被依賴的系統**：
    -   **所有後續系統**：角色創建完成後，玩家的屬性、天賦、關係等數據將被所有後續系統（戰鬥、社交、事件等）讀取和使用。

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 類型 | 當前值 | 安全調整範圍 | 影響 |
|---|---|---|---|---|
| `N`（生成天賦數量）| 整數 | 4 | 3-6 | 值越大，玩家選擇越多，但決策時間越長。 |
| `Weight(凡品)` | 整數 | 60 | 50-70 | 影響玩家開局強度。權重越高，強力開局越少。 |
| `Weight(精良)` | 整數 | 30 | 20-40 | 同上。 |
| `Weight(絕品)` | 整數 | 10 | 5-15 | 同上。 |
| `重骰機會` | 整數 | 2 | 0-3 | 影響玩家對天賦的滿意度。機會越多，玩家越可能刷到理想天賦。 |
| `Gold_Base` | 整數 | 50 | 20-100 | 影響初期經濟壓力。 |
| `Gold_Bonus`（各出身）| 整數 | 0/200/50 | 可自由調整 | 影響不同出身玩家的初期財富差異。 |
| `臉型`、`髮型`等圖層選項數量 | 整數 | 3/5/3/3 | 可自由增加 | 影響角色多樣性，不影響數值。 |

## 8. 驗收標準（Acceptance Criteria）

| 序號 | 驗收項目 | 預期結果 | 通過/失敗 |
|---|---|---|---|
| 1 | 玩家可從3個出身背景中選擇1個 | 選擇後，介面顯示對應的簡短描述和初始效果。 | |
| 2 | 系統生成4個隨機天賦供玩家選擇 | 4個天賦的品質分佈符合權重設定，且不重複。 | |
| 3 | 玩家可使用重骰功能刷新天賦 | 初始2次機會，使用後生成全新的4個天賦。 | |
| 4 | 玩家可從4個圖層自訂角色外觀 | 每個圖層有預設選項，且選擇後即時顯示。 | |
| 5 | 玩家可輸入2-6個中文字的角色名稱 | 系統接受合法名稱，拒絕空值或過長名稱。 | |
| 6 | 玩家可跳過所有開場文本 | 跳過後直接進入創角介面。 | |
| 7 | 確認創角後，角色初始化正確 | 屬性、金錢、物品、關係與出身和天賦選擇一致。 | |
| 8 | 角色創建總流程可在5分鐘內完成 | 對熟悉操作的玩家，從開始到進入遊戲不超過5分鐘。 | |
| 9 | 所有UI按鈕（選擇、確認、跳過）功能正常 | 點擊後觸發對應行為，無報錯。 | |
| 10 | 所有外觀選項無數值影響 | 選擇不同外觀，角色屬性與初始狀態不變。 | |
