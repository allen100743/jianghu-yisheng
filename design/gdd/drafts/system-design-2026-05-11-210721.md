## 1. 概述（Overview）

江湖風雲榜是天機閣每年發布一次的江湖人物排名系統，分為「戰力榜」、「俠義榜」、「惡名榜」、「財富榜」四個榜單。上榜者獲得特殊稱號，同時觸發一系列連鎖事件——挑戰者上門、仇家暗殺、勢力拉攏等。玩家可主動挑戰榜上人物，也可因上榜而成為他人目標。榜單本身是動態的，每年度根據江湖上實際發生的事件重新排名。

本系統的核心目的是：**讓玩家的成就被江湖看見，並為此付出代價**——上榜是榮耀，也是麻煩的開始。

---

## 2. 玩家體驗（Player Fantasy）

### 核心體驗

- **榮耀感**：第一次上榜時，天機閣使者在公開場合宣讀你的名字，全江湖都知道你是誰了
- **壓力感**：上榜後，挑戰者絡繹不絕，暗殺事件頻率上升，你不再是無名之輩
- **策略選擇**：可以選擇低調（不上榜）、高調（追求排名）、或刻意操控排名（壓低/抬高）
- **江湖地位**：排名高低直接影響NPC對你的態度，高排名者會收到門派邀請、朝廷拉攏
- **復仇快感**：去年打敗你的人，今年你可以挑戰他，當眾把他踩下去

### 不該有的體驗

- **純數值比拼**：排名不是只看戰鬥力，江湖地位、名聲、財富都是變數
- **上榜後無事發生**：上榜一定有後果，好壞都有
- **強迫上榜**：玩家可以選擇避開天機閣的評定，代價是失去江湖影響力

## 3. 詳細規則（Detailed Rules）

### 3.1 榜單結構

天機閣每年發布四份榜單，每份榜單取前100名：

| 榜單名稱 | 評分依據 | 上榜獎勵 | 上榜風險 |
|---------|---------|---------|---------|
| **戰力榜** | 綜合戰力評分（見公式4.1） | 稱號「天機戰力榜·第N名」 | 挑戰者數量×3，暗殺事件×2 |
| **俠義榜** | 俠義值（見公式4.2） | 稱號「天機俠義榜·第N名」 | 邪派仇視，惡名NPC主動攻擊 |
| **惡名榜** | 惡名值（見公式4.3） | 稱號「天機惡名榜·第N名」 | 正道追殺，賞金獵人出現 |
| **財富榜** | 個人財富總值（見公式4.4） | 稱號「天機財富榜·第N名」 | 綁架事件×3，盜竊事件×2 |

**MVP必做**：四份榜單各取前20名（簡化）
**V2追加**：擴充至前100名，增加「潛力榜」（30歲以下新秀）

### 3.2 榜單發布機制

**發布時間**：每年農曆正月初一（遊戲時間）

**發布流程**：
1. 天機閣使者（專屬NPC）在各大城市公告板張貼榜單
2. 榜單內容同步進入世界感知系統，以「江湖傳聞」形式傳播
3. 上榜者會收到天機閣使者親自送達的「風雲帖」（道具）
4. 未上榜者可以到天機閣分舵查詢自己的排名（需花費銀兩）

**排名更新規則**：
- 一年內有重大事蹟者（擊敗高手、完成大事、積累巨富）排名上升
- 一年內無重大事蹟者，排名自然下降（被新人超越）
- 死亡者自動除名
- 隱居者（連續三年無江湖活動）自動除名

**MVP必做**：每年固定時間觸發發布事件
**V2追加**：天機閣可因特殊事件（如武林大會）發布「緊急榜單」

### 3.3 上榜稱號系統

每個榜單前10名獲得對應稱號：

| 排名區間 | 稱號格式 | 持續時間 |
|---------|---------|---------|
| 第1名 | 「天機【榜單名】·天下第一」 | 一年（下次發布後更新） |
| 第2-3名 | 「天機【榜單名】·絕頂高手」 | 一年 |
| 第4-10名 | 「天機【榜單名】·一方之雄」 | 一年 |
| 第11-50名 | 「天機【榜單名】·江湖新秀」 | 一年 |
| 第51-100名 | 「天機【榜單名】·榜上有名」 | 一年 |

**稱號效果**：
- 主要稱號欄位顯示該稱號時，NPC對應態度變化（見第3.5節）
- 稱號本身不提供屬性加成，但會影響事件觸發機率

**MVP必做**：前10名稱號
**V2追加**：前100名稱號，稱號可累積（去年第5名今年第3名，保留去年稱號作為歷史記錄）

### 3.4 挑戰系統（HOI4決策系統設計）

#### 3.4.1 挑戰發起

玩家可主動挑戰榜上人物，條件如下：

| 條件 | 說明 |
|-----|------|
| 目標必須在榜上 | 玩家必須知道目標的排名（可透過天機閣查詢） |
| 玩家必須在榜上 | 未上榜者不可挑戰（「無名之輩沒有資格」） |
| 目標與玩家在同一區域 | 必須在同一城市或相鄰野外區域 |
| 冷卻時間 | 同一目標每年只能挑戰一次 |
| 成本 | 花費100銀兩（發布戰書費用） |

**挑戰流程**：
1. 玩家選擇「挑戰」選項
2. 系統發送「戰書」事件給目標NPC
3. 目標NPC根據自身性格決定回應：
   - 接受挑戰 → 約定時間地點決鬥
   - 拒絕挑戰 → 名聲下降，玩家自動獲得該排名（爭議）
   - 無視挑戰 → 視為拒絕
4. 決鬥結果影響排名變動

**MVP必做**：挑戰系統基本流程（接受/拒絕）
**V2追加**：目標NPC可反挑戰、可約定賭注、可設陷阱

#### 3.4.2 排名變動規則

| 情況 | 排名變動 |
|-----|---------|
| 挑戰成功（擊敗目標） | 玩家與目標排名互換 |
| 挑戰失敗（被擊敗） | 玩家排名下降1-3名（視差距而定）|
| 目標拒絕挑戰 | 玩家自動獲得目標排名，目標下降1名 |
| 目標死亡（非挑戰） | 榜單自動遞補 |

**挑戰限制**：
- 不可挑戰排名差距超過50名的對手（「差距太大，天機閣不認可」）
- 不可同時挑戰多人
- 挑戰失敗後有30天冷卻期

**MVP必做**：排名互換和下降規則
**V2追加**：賭注系統、約戰系統（約定三個月後決鬥）

## 4. 公式（Formulas）

### 4.1 戰力評分

**變數定義**：
- `武力`：玩家武力屬性值（0-1000）
- `內力`：玩家內力屬性值（0-1000）
- `輕功`：玩家輕功屬性值（0-1000）
- `體魄`：玩家體魄屬性值（0-1000）
- `武學熟練度總和`：玩家所有武學熟練度加權總和（每種武學熟練度×該武學品質係數）
- `裝備評分`：裝備品質係數總和（凡品1，精良3，利器8，寶器20，神兵50，絕世120，天工300）

**公式**：
```
戰力評分 = floor(
    (武力 × 2.5) +
    (內力 × 2.0) +
    (輕功 × 1.5) +
    (體魄 × 1.0) +
    (武學熟練度總和 × 0.1) +
    (裝備評分 × 5.0)
)
```

**範例計算**：
- 武力200，內力150，輕功120，體魄180
- 武學熟練度總和：華山劍法熟練度80（品質3）+ 養吾劍氣熟練度50（品質3）= 130×3=390
- 裝備評分：寶器劍（20）+ 精良護甲（3）= 23
- 戰力評分 = floor(200×2.5 + 150×2.0 + 120×1.5 + 180×1.0 + 390×0.1 + 23×5.0)
- = floor(500 + 300 + 180 + 180 + 39 + 115)
- = floor(1314) = 1314

**數值範圍**：0 - 10000（理論上限）

**MVP必做**：使用此公式計算戰力評分
**V2追加**：加入「實戰經驗」係數（擊敗高手數量影響）

### 4.2 俠義值

**變數定義**：
- `俠義行為次數`：完成俠義事件的次數（救助平民、對抗邪派等）
- `俠義事件評分`：每次俠義事件的評分加總（小事件+10，中事件+50，大事件+200）
- `名聲`：玩家名聲屬性值（0-1000）
- `正道門派好感度`：所有正道門派好感度平均值（0-100）

**公式**：
```
俠義值 = floor(
    (俠義行為次數 × 10) +
    (俠義事件評分 × 0.5) +
    (名聲 × 0.3) +
    (正道門派好感度 × 2.0)
)
```

**範例計算**：
- 俠義行為次數：15次
- 俠義事件評分：小事件5次(50) + 中事件2次(100) + 大事件1次(200) = 350
- 名聲：400
- 正道門派好感度：天樞劍派70 + 金剛寺60 = 65（平均）
- 俠義值 = floor(15×10 + 350×0.5 + 400×0.3 + 65×2.0)
- = floor(150 + 175 + 120 + 130)
- = floor(575) = 575

**數值範圍**：0 - 5000（理論上限）

**MVP必做**：使用此公式計算俠義值
**V2追加**：加入「犧牲」係數（為俠義付出代價的行為加成）

### 4.3 惡名值

**變數定義**：
- `惡行次數`：完成惡行事件的次數（殺害無辜、掠奪村莊等）
- `惡行事件評分`：每次惡行事件的評分加總（小惡行+10，中惡行+50，大惡行+200）
- `名聲`：玩家名聲屬性值（0-1000）
- `邪派門派好感度`：所有邪派門派好感度平均值（0-100）

**公式**：
```
惡名值 = floor(
    (惡行次數 × 10) +
    (惡行事件評分 × 0.5) +
    (名聲 × 0.3) +
    (邪派門派好感度 × 2.0)
)
```

**範例計算**：
- 惡行次數：8次
- 惡行事件評分：小惡行3次(30) + 中惡行2次(100) + 大惡行1次(200) = 330
- 名聲：300
- 邪派門派好感度：修羅門80 + 魅影樓50 = 65（平均）
- 惡名值 = floor(8×10 + 330×0.5 + 300×0.3 + 65×2.0)
- = floor(80 + 165 + 90 + 130)
- = floor(465) = 465

**數值範圍**：0 - 5000（理論上限）

**MVP必做**：使用此公式計算惡名值
**V2追加**：加入「殘忍」係數（殺害方式影響）

### 4.4 財富值

**變數定義**：
- `銀兩`：玩家持有的銀兩數量
- `房產價值`：所有房產的總價值
- `裝備價值`：所有裝備的總價值（凡品10，精良50，利器200，寶器1000，神兵5000，絕世20000，天工100000）
- `庫存價值`：所有庫存道具的總價值（按市價計算）

**公式**：
```
財富值 = floor(
    (銀兩 × 1.0) +
    (房產價值 × 1.0) +
    (裝備價值 × 0.5) +
    (庫存價值 × 0.3)
)
```

**範例計算**：
- 銀兩：5000
- 房產價值：城中小宅（3000）
- 裝備價值：寶器劍(1000) + 精良護甲(50) + 利器暗器(200) = 1250
- 庫存價值：藥材(500) + 秘笈(2000) = 2500
- 財富值 = floor(5000×1.0 + 3000×1.0 + 1250×0.5 + 2500×0.3)
- = floor(5000 + 3000 + 625 + 750)
- = floor(9375) = 9375

**數值範圍**：0 - 1000000（理論上限）

**MVP必做**：使用此公式計算財富值
**V2追加**：加入「現金流」係數（被動收入影響）

### 4.5 排名計算

**變數定義**：
- `玩家評分`：根據榜單類型使用對應公式計算的評分
- `所有上榜者評分`：所有符合上榜條件的NPC評分

**公式**：
```
玩家排名 = 1 + COUNT(所有上榜者評分 > 玩家評分)
```

**並列處理**：
- 評分相同時，先上榜者排名在前
- 同一年度評分相同者，按上次排名決定（上次排名高者在前）

**MVP必做**：基本排名計算
**V2追加**：並列排名處理，歷史排名比較

## 5. 邊界條件（Edge Cases）

### 5.1 榜單相關

| 邊界情況 | 處理方式 |
|---------|---------|
| 玩家死亡 | 自動從所有榜單除名，稱號消失 |
| 玩家隱居（連續三年無江湖活動）| 自動從所有榜單除名，稱號消失；復出後重新計算 |
| 榜單人數不足100人 | 按實際人數排名，不足部分留空 |
| 玩家同時符合多個榜單 | 可同時上榜，每個榜單獨立計算 |
| 玩家排名相同 | 按先上榜者優先，同年度按上次排名 |
| 榜單發布時玩家在偏遠地區 | 消息透過世界感知系統延遲傳播 |
| 玩家拒絕上榜 | 天機閣不允許拒絕上榜（「江湖風雲榜，不由你決定」），但玩家可選擇不使用稱號 |

### 5.2 挑戰相關

| 邊界情況 | 處理方式 |
|---------|---------|
| 目標NPC死亡 | 挑戰自動取消，排名遞補 |
| 目標NPC離開當前區域 | 挑戰自動取消，可重新發起（需再次花費銀兩）|
| 玩家在挑戰冷卻期內 | 系統提示「你剛挑戰過，休息幾天再來」|
| 玩家挑戰自己 | 不可挑戰自己，系統提示「你不能挑戰自己」|
| 目標NPC是好友/伴侶 | 可挑戰，但關係會受影響（好感度-20）|
| 目標NPC是師長 | 可挑戰，但被視為「欺師滅祖」，門派關係大幅下降 |
| 挑戰時第三方介入 | 視為挑戰失敗，第三方與玩家關係降至敵對 |

### 5.3 事件相關

| 邊界情況 | 處理方式 |
|---------|---------|
| 玩家在事件觸發時正在戰鬥 | 事件延後至戰鬥結束後觸發 |
| 玩家在事件觸發時在特殊地點（地牢、秘境）| 事件延後至離開特殊地點後觸發 |
| 事件NPC死亡 | 事件自動取消 |
| 事件選項導致矛盾（如同時接受兩個門派邀請）| 系統提示衝突，要求玩家選擇一個 |
| 玩家多次上榜（每年）| 每年重新觸發事件鏈，但可跳過重複內容 |
| 玩家從未上榜 | 不會觸發任何上榜事件 |

### 5.4 數值邊界

| 邊界情況 | 處理方式 |
|---------|---------|
| 戰力評分超過10000 | 理論上限10000，超過按10000計算 |
| 俠義值/惡名值同時為正 | 取絕對值較大者決定榜單歸屬；相等時取俠義值 |
| 財富值為負（負債）| 不計入財富榜，但會觸發「負債累累」事件 |
| 所有評分為0 | 不上榜，系統提示「你的江湖事蹟不足」|
