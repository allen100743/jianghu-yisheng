# 江湖一生 — 傷勢與狀態效果系統 GDD v2

*策劃：陳品霖 | 審核：待審核 | 狀態：初稿 | 2026-05-12*

## 1. 概述

本系統定義角色在江湖中可能遭遇的所有身體異常狀態——外傷、內傷、中毒、疾病、飢餓、疲勞、以及特殊武學造成的經脈損傷或精神創傷。採用連續 severity 模型（0.0–1.0），取代傳統三段式（輕/中/重），讓狀態惡化與恢復呈現漸進且符合直覺的曲線。所有狀態對角色屬性的影響，統一透過修飾詞疊加系統實現，確保數值架構的整潔與可擴展性。

## 2. 玩家體驗

### 2.1 預期體驗

當玩家角色受傷時，他希望感受到的是：
- **「這一刀砍得很深，我必須趕快止血，不然會越來越糟。」** — severity 持續上升的壓力感。
- **「我現在內傷很重，運功會加劇傷勢，但不用內功又打不過眼前的敵人。」** — 戰術取捨的真實感。
- **「我中了唐門的毒，得趕快找解藥，不然撐不過三天。」** — 時間壓力和明確目標感。
- **「這幾天一直在趕路，又沒吃東西，身子虛得很，連個小賊都打不過。」** — 多重狀態疊加的疲憊感。

### 2.2 不該出現的體驗

- **「我頭上有個debuff圖標，但完全感覺不到差別。」** — 數值變化必須有可感知的遊戲內回饋（動作變慢、對話選項受限、NPC態度改變）。
- **「我明明重傷，但喝一瓶藥就全好了。」** — 恢復必須有漸進過程，符合武俠世界的真實感。
- **「我同時中了五種毒，但每種毒各自計算，完全不知道哪個在影響我。」** — UI必須清晰呈現疊加狀態的總體影響。

### 2.3 MVP 與 V2 邊界

- **MVP 必須實裝**：外傷、內傷、中毒、疲勞、飢餓、疾病（每種至少3個stage效果）。
- **V2 追加**：經脈損傷、精神創傷、蠱毒、詛咒、特殊武學造成的獨特狀態（如「七傷拳」的經脈逆流）。

## 3. 詳細規則

### 3.1 Severity 模型核心規則

每個狀態效果（Buff/Debuff）都有一個連續的 severity 值，範圍 `0.0`（完全健康）到 `1.0`（瀕死/極致）。severity 的變化是連續的，受時間、行動、藥物、環境等因素影響。

**Severity 閾值觸發規則：**

| Severity 範圍 | Stage 名稱 | 觸發效果 |
|---|---|---|
| 0.0 – 0.3 | 無恙 / 輕微 | 基礎效果（若有） |
| 0.3 – 0.6 | 顯著 | 觸發 Stage 2 效果 |
| 0.6 – 0.9 | 嚴重 | 觸發 Stage 3 效果 |
| 0.9 – 1.0 | 危急 | 觸發 Stage 4 效果，並開始觸發「瀕死檢查」 |

**Severity 變化規則：**
- 每個狀態有基礎的「自然惡化速率」（單位：severity/天）和「自然恢復速率」（單位：severity/天）。
- 自然恢復僅在「不滿足惡化條件」時發生（例如：外傷不上藥會惡化，上藥後才會恢復）。
- 玩家行動、藥物、環境事件可加速或逆轉 severity 變化。
- severity 值每幀（或每日結算時）更新一次，變化量 = 當前速率 × 時間單位。

### 3.2 修飾詞疊加架構

所有狀態對角色屬性的影響，都以「修飾詞（Modifier）」的形式存在，透過疊加系統作用於角色基礎屬性。

**修飾詞類型：**
- **加法修飾詞**：`+X` 或 `-X`（直接加減數值）
- **乘法修飾詞**：`+X%` 或 `-X%`（百分比增減）
- **覆蓋修飾詞**：直接取代基礎值（用於特殊情況，如「經脈盡斷」輕功歸零）

**疊加規則（HOI4 風格）：**
1. 所有同類型的加法修飾詞直接相加。
2. 所有同類型的乘法修飾詞先各自計算，再相乘（乘法疊加）。
3. 最終屬性值 = `(基礎值 + 加法修飾詞總和) × (1 + 乘法修飾詞總乘積)`
4. 覆蓋修飾詞優先級最高，一旦生效，直接取代基礎值，忽略其他所有修飾詞。

**範例：**
角色基礎武力 100。
- 狀態A：武力 -20（加法）
- 狀態B：武力 -30%（乘法）
- 狀態C：武力 -10%（乘法）
最終武力 = `(100 - 20) × (1 - 0.30) × (1 - 0.10)` = `80 × 0.7 × 0.9` = `50.4` → 取整 `50`

### 3.4 狀態疊加與衝突

#### 3.4.1 疊加規則
- 所有狀態的修飾詞獨立計算，然後依疊加規則合併。
- 同一類型的狀態（如「外傷」）只能有一個 severity 值。新的外傷會與舊的外傷合併計算（取 severity 較高者，或根據新傷口 severity 疊加）。
- 不同類型的狀態（外傷 + 中毒）完全獨立，各自有 severity 值，各自觸發效果。

#### 3.4.2 衝突規則
- **外傷 + 內傷**：無直接衝突，但疊加 debuff 會讓角色極度虛弱。
- **中毒 + 疾病**：severity 惡化速率疊加（`疾病惡化速率 × 1.5`），因為身體虛弱更容易被毒素侵蝕。
- **疲勞 + 飢餓**：severity 惡化速率疊加（`疲勞惡化速率 × 1.3`），因為沒吃東西更容易累。
- **內傷 + 運功逼毒**：運功逼毒會加劇內傷 severity。

### 3.5 狀態 UI 表示

- 每個狀態在 HUD 上以圖標顯示，severity 值以顏色漸變表示（綠 → 黃 → 橙 → 紅）。
- 滑鼠懸停圖標時，顯示：狀態名稱、目前 severity 值、目前 stage、主要修飾詞效果、自然變化趨勢（↑惡化 / ↓恢復 / →穩定）。
- 角色血條下方，顯示一個「綜合狀態條」，反映所有狀態疊加後的「總體身體狀況」（一個合成的 severity 值，用於快速判斷角色是否健康）。

## 4. 公式

### 4.1 Severity 每日變化公式

```
Δseverity = (自然變化速率 + 環境修正 + 行動修正) × 時間單位
```

- **Δseverity**：severity 變化量（可正可負）
- **自然變化速率**：每個狀態基礎的惡化或恢復速率（severity/天）
- **環境修正**：天氣、溫度、衛生條件等（例：潮濕環境使外傷惡化速率 +0.02/天）
- **行動修正**：玩家行動帶來的修正（例：使用金瘡藥使外傷恢復速率 +0.05/天）
- **時間單位**：遊戲內時間單位（預設為 1 天）

**範例：**
角色有外傷（severity 0.5），未包紮，身處潮濕山洞。
- 自然變化速率：+0.05/天（未包紮惡化）
- 環境修正：+0.02/天（潮濕）
- 行動修正：0（無行動）
- Δseverity = (0.05 + 0.02 + 0) × 1 = +0.07
- 一天後，severity 變為 0.57。

### 4.2 最終屬性計算公式

```
最終屬性值 = clamp( (基礎值 + Σ加法修飾詞) × Π(1 + 乘法修飾詞_i), 最小值, 最大值 )
```

- **clamp**：限制結果在 `[最小值, 最大值]` 範圍內，防止負數或超過上限。
- **Σ加法修飾詞**：所有加法修飾詞的總和。
- **Π(1 + 乘法修飾詞_i)**：所有乘法修飾詞的乘積（例如：-10% 和 -20% 的乘積是 `(1 - 0.1) × (1 - 0.2) = 0.9 × 0.8 = 0.72`）。
- **最小值**：0（屬性不能為負數）。
- **最大值**：屬性上限（如 1000）。

### 4.3 生命值損失計算

```
生命值損失 = 基礎損失 × (1 + 所有 severity 相關的乘法修飾詞)
```

- **基礎損失**：由狀態 stage 決定的固定值（如「毒發」每小時 -0.5%）。
- **乘法修飾詞**：來自其他狀態的疊加（如「重病」讓生命值損失 +20%）。

### 4.4 取整規則

- 所有最終顯示給玩家的數值（屬性、生命值、severity 百分比）都取整數。
- 內部計算使用浮點數，僅在顯示時取整。
- severity 值在 UI 上顯示為百分比（0% – 100%）。

## 5. 邊界條件

### 5.1 多重狀態同時觸發瀕死檢查

- **規則**：只要有一個狀態的 severity ≥ 0.9，就觸發「瀕死檢查」。
- **檢查頻率**：每小時一次。
- **檢查結果**：
  - 若 `severity ≥ 0.95`，且有兩個以上狀態 severity ≥ 0.9：角色直接進入「昏迷」狀態，並開始「死亡倒數」（例如：10 小時內若未救治則死亡）。
  - 若 `severity ≥ 0.9` 但低於 0.95：角色進入「重傷」狀態，移動速度 -80%，無法戰鬥，可以對話和使用道具。

### 5.2 狀態 severity 歸零

- 當 severity 降至 0.0 時，該狀態圖標從 HUD 上移除。
- 若該狀態有「後遺症」（如「重傷」康復後體魄永久 -5），則在狀態移除時觸發後遺症事件。

### 5.3 狀態 severity 達到 1.0

- **外傷**：角色失血過多死亡。
- **內傷**：角色心脈斷裂死亡。
- **中毒**：角色毒發身亡。
- **疾病**：角色病逝。
- **疲勞**：角色過勞猝死（極罕見，通常會先昏迷）。
- **飢餓**：角色餓死。

### 5.4 特殊狀態無法自然恢復

- **經脈損傷**（V2）：severity 不會自然下降，必須透過特殊事件或天材地寶才能恢復。
- **蠱毒**（V2）：severity 會週期性暴漲（如每月一次），需要定期服用抑制藥物。

### 5.5 玩家死亡時的狀態處理

- 角色死亡時，所有狀態 severity 鎖定在當前值，用於「死亡報告」顯示死因。
- 若開啟「傳代系統」，死亡角色的狀態會影響下一代角色的初始狀態（如「父輩中毒而死，子輩體魄初始 -5」）。

## 6. 系統依賴

### 6.1 本系統依賴的其他系統

| 依賴系統 | 依賴原因 | 備註 |
|---|---|---|
| **核心屬性系統** | 修飾詞需要作用於具體屬性（武力、內力、體魄等） | MVP 必須 |
| **時間系統** | severity 變化以「天」和「小時」為單位 | MVP 必須 |
| **戰鬥系統** | 戰鬥中造成外傷、內傷、中毒 | MVP 必須 |
| **物品系統** | 藥物、食物、包紮工具等影響 severity 變化 | MVP 必須 |
| **環境系統** | 天氣、地域影響 severity 變化速率 | V2 追加 |

1. 一般受傷（severity 0.3-0.6）可以在 3-5 天內自然恢復。

**品霖註記**：
這個系統的設計目標是「讓受傷變成一個有敘事潛力的遊戲事件，而不是一個需要快速跳過的 debuff」。severity 的連續變化讓玩家能感受到「傷勢在好轉」或「傷勢在惡化」的細微差別，而修飾詞疊加則確保了多重狀態下的真實脆弱感。

關於數值部分，我已經盡量給出具體數字，但所有數值都需要在原型中測試調整。特別是「自然惡化速率」和「藥物恢復速率」的平衡，會直接影響玩家對治療系統的依賴程度和遊戲難度。

請製作人審閱，有需要調整的地方隨時跟我說。
