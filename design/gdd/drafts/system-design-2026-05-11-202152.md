## 性格特質系統：武俠人格設計

### 1. 概述（Overview）

**性格特質系統**是角色創建的核心環節之一，定義了角色與生俱來的「心性」。
它是一個多維度的標籤系統，玩家從預設的武俠人格中選擇一個，該選擇將帶來明確的數值權衡（Trade-off），影響角色的初始屬性分佈、與特定類型NPC的初始好感度，並解鎖專屬的對話選項與事件觸發條件。
性格不是善惡值，而是一個行為傾向的基礎設定，它會與玩家後續的選擇產生互動，決定江湖如何看待你這個人。

### 2. 玩家體驗（Player Fantasy）

- **我是誰？** 在踏入江湖前，玩家先定義自己的「人設」。選擇「豪爽」的玩家，感覺自己像個大口吃肉、大秤分金的江湖好漢；選擇「陰沉」的玩家，則像個背負秘密、獨行於暗巷的復仇者。
- **我的選擇有意義。** 玩家會立刻感受到性格帶來的影響：一個「莽撞」的角色可能更容易與人發生衝突，但也更容易在危機中抓住一線生機；一個「謹慎」的角色則能在險境中全身而退，但可能錯失良機。
- **世界對我的反應是真實的。** NPC會根據你的性格來判斷你的為人。一個「正直」的俠客更容易獲得名門正派的信任，而一個「狡猾」的商人則更能在黑市中左右逢源。
- **我的性格會成長。** 隨著遊戲進程，玩家的關鍵行為會固化或改變其性格，讓角色的「人設」隨著一生經歷而動態演化。

### 3. 詳細規則（Detailed Rules）

#### 3.1 性格維度

性格由 **三個維度** 構成，每個維度有兩個極端。角色創建時選擇的「主要性格」將決定他在這三個維度上的初始偏向。

| 維度 | 左極端 | 右極端 | 核心衝突 |
|---|---|---|---|
| **處事風格** | 剛直 (Blunt) | 圓滑 (Sly) | 直接面對問題 vs 迂迴解決問題 |
| **行動傾向** | 衝動 (Impulsive) | 謹慎 (Cautious) | 先做了再說 vs 謀定而後動 |
| **道德標尺** | 仁義 (Righteous) | 利己 (Selfish) | 以天下為己任 vs 以自身利益為優先 |

#### 3.2 主要性格清單（MVP：8種）

玩家從以下8種預設的「武俠人格」中選擇一種。每種人格對應一組三維偏向，並有數值Trade-off。

| 性格名稱 | 處事風格 | 行動傾向 | 道德標尺 | 數值 Trade-off | 角色原型 |
|---|---|---|---|---|---|
| **豪爽** | 剛直+2 | 衝動+1 | 仁義+1 | 武力+5，體魄+5，悟性-5 | 蕭峰、令狐沖 |
| **陰沉** | 圓滑+1 | 謹慎+2 | 利己+1 | 內力+5，悟性+5，武力-5 | 楊過（早期）、傅紅雪 |
| **莽撞** | 剛直+1 | 衝動+3 | 仁義+0 | 武力+8，體魄+3，悟性-10 | 郭靖（早期）、牛金牛 |
| **謹慎** | 圓滑+2 | 謹慎+2 | 利己+0 | 輕功+5，悟性+5，武力-5，體魄-5 | 張無忌（早期決策）、韋小寶（保命時） |
| **正直** | 剛直+3 | 謹慎+0 | 仁義+2 | 名聲+10，武力+3，輕功-5 | 郭靖、陳近南 |
| **狡猾** | 圓滑+3 | 衝動+0 | 利己+2 | 悟性+8，輕功+3，名聲-5 | 韋小寶 |
| **俠義** | 剛直+2 | 衝動+0 | 仁義+3 | 名聲+15，武力+5，悟性-8 | 胡斐、李尋歡 |
| **孤僻** | 圓滑+0 | 謹慎+1 | 利己+2 | 內力+8，悟性+3，名聲-10 | 阿飛、獨孤求敗 |

**（V2追加）** 更多性格如：**霸氣**、**懦弱**、**狂放**、**隱忍**，總計12-16種。

#### 3.3 性格對初始屬性的影響

- **加法原則**：選擇性格後，在基礎屬性上加上對應的數值修正。
- **初始屬性範圍**：創角時，基礎屬性在一個範圍內隨機生成（見GDD 14.1），性格修正疊加於此之上。
- **下限保護**：任何屬性經性格修正後，不得低於5。若修正後低於5，則強制鎖定為5，並在UI上提示玩家。

#### 3.4 性格對NPC初始好感的影響

每個NPC都有一個隱藏的「性格偏好」標籤，例如：
- 一個「豪爽」的丐幫長老，會對同樣「豪爽」或「俠義」的玩家初始好感+15。
- 一個「陰沉」的魅影樓殺手，會對「狡猾」或「孤僻」的玩家初始好感+10。
- 一個「正直」的天樞劍派掌門，會對「狡猾」或「莽撞」的玩家初始好感-10。

**計算公式**：
```
NPC初始好感 = 基礎好感 + Σ(玩家性格維度值 × NPC對應維度權重)
```
- 此為隱藏數值，玩家不可見，但可透過對話選項的暗示來推測。
- **（MVP）** 僅對主要NPC和陣營領袖實現此規則。普通NPC僅根據玩家當前「主要性格」名稱進行簡單的+5/-5修正。

#### 3.5 性格對對話選項的影響

- **解鎖獨特對話**：某些對話選項只有在玩家特定性格維度達到門檻時才會出現。例如：
    - 【剛直≥3】「呔！你這奸賊，納命來！」（直接開戰）
    - 【圓滑≥3】「這位大人，小的看此事另有隱情，不如我們借一步說話？」（開啟說服/賄賂路線）
    - 【仁義≥3】「這位大嫂，你放心，這事我管定了！」（觸發後續任務）
    - 【利己≥2】「幫你可以，但我有什麼好處？」（開啟交易視窗）
- **性格衝突選項**：當玩家的行為與其「主要性格」極端不符時（例如，一個「俠義」性格的玩家選擇了屠殺無辜），系統會跳出警告：「此舉與你的『俠義』本性相悖，將可能動搖你的心性。確定嗎？」
- **（V2追加）** 長期做出與性格相悖的行為，可能觸發「心魔」事件，導致性格維度永久偏移，甚至改變「主要性格」名稱。

#### 3.6 性格對事件觸發的影響

- **被動事件**：世界會根據你的性格，向你推送不同的事件。例如：
    - 高「仁義」的玩家，更容易遇到「路見不平」的事件。
    - 高「利己」的玩家，更容易遇到「黑市交易」或「暗殺委託」。
    - 高「莽撞」的玩家，更容易在野外觸發「遭遇戰」。
- **主動事件**：某些特殊事件或奇遇，有性格門檻。例如：
    - 只有「剛直≥4」的玩家，才能從某位烈士遺孀手中接過傳承。
    - 只有「圓滑≥3」的玩家，才能識破某個精心設計的騙局。

### 4. 公式（Formulas）

#### 4.1 性格維度值計算

- **定義**：
    - `Blunt`：剛直值 (0-5)
    - `Sly`：圓滑值 (0-5)
    - `Impulsive`：衝動值 (0-5)
    - `Cautious`：謹慎值 (0-5)
    - `Righteous`：仁義值 (0-5)
    - `Selfish`：利己值 (0-5)
- **規則**：每個維度的兩個極端值之和不得超過5。`Blunt + Sly ≤ 5`，依此類推。
- **初始值**：由選擇的「主要性格」決定（見3.2節表格）。
- **範例**：選擇「豪爽」：
    - `Blunt = 2`，`Sly = 0` (2+0 ≤ 5)
    - `Impulsive = 1`，`Cautious = 0` (1+0 ≤ 5)
    - `Righteous = 1`，`Selfish = 0` (1+0 ≤ 5)

#### 4.2 NPC初始好感修正公式

- **定義**：
    - `BaseFavor`：NPC對玩家的基礎好感 (0-100)
    - `FinalFavor`：最終初始好感
    - `Weight_Blunt`：NPC對「剛直」屬性的看重程度 (-5 到 5)
    - `Player_Blunt`：玩家的剛直值 (0-5)
- **公式**：
    `FinalFavor = BaseFavor + (Player_Blunt * Weight_Blunt) + (Player_Sly * Weight_Sly) + (Player_Impulsive * Weight_Impulsive) + (Player_Cautious * Weight_Cautious) + (Player_Righteous * Weight_Righteous) + (Player_Selfish * Weight_Selfish)`
- **範例**：
    - 天樞劍派掌門的`Weight_Righteous = 5`，`Weight_Selfish = -3`。
    - 一個「俠義」玩家 (`Righteous=3, Selfish=0`) 拜訪掌門。
    - `FinalFavor = 50 + (0) + (0) + (0) + (0) + (3 * 5) + (0 * -3) = 65`。
    - 一個「狡猾」玩家 (`Righteous=0, Selfish=2`) 拜訪掌門。
    - `FinalFavor = 50 + (0) + (0) + (0) + (0) + (0 * 5) + (2 * -3) = 44`。
- **取整規則**：最終結果直接取整，無小數。

### 5. 邊界條件（Edge Cases）

1.  **所有維度值為0**：玩家創角時是否可能出現全0？目前設計中，所有主要性格至少會有一個維度為1，因此不會發生。若未來允許自定義，需設定最低總和為2，防止「無性格」角色。
2.  **性格修正導致屬性溢出**：若某屬性基礎值為998，性格修正+5後變為1003，超過上限1000。**處理方式**：強制鎖定在1000，超出的部分不計算。UI上顯示為1000 (Max)。
3.  **性格修正導致屬性低於下限**：同3.3節，強制鎖定為5，並在角色創建介面顯示警告：「你的選擇使『悟性』降至極低，這將嚴重影響你學習高深武學的能力。」
4.  **NPC性格偏好衝突**：一個NPC同時對「剛直」和「圓滑」都有高權重？**處理方式**：在NPC數據設計時，避免此情況。每個NPC的性格偏好應有其邏輯一致性，例如一個「豪爽」的NPC偏好「剛直」和「衝動」，厭惡「圓滑」和「謹慎」。
5.  **玩家後續行為改變性格維度**：當一個維度改變時，其對立維度會如何？**處理方式**：遵循 `Blunt + Sly ≤ 5` 規則。若玩家通過行為將 `Blunt` 從2提升到3，而 `Sly` 當前為2 (總和=5)，則 `Sly` 會自動下降為2。若 `Sly` 已經是3，則無法繼續提升 `Blunt`，除非先降低 `Sly`。
6.  **主要性格名稱的變更**：當玩家的三維偏向發生大幅改變時，主要性格名稱何時變更？**處理方式**：當核心維度（如處事風格）的偏向發生逆轉時（例如 `Sly > Blunt`），系統觸發一個「心性轉變」事件，並在事件結束後，根據當前最新的三維偏向，重新匹配一個最接近的主要性格名稱，並在UI上通知玩家。

### 6. 系統依賴（Dependencies）

| 依賴方向 | 依賴的系統 | 說明 |
|---|---|---|
| **本系統依賴** | **角色創建系統** | 性格選擇是角色創建流程的一部分。 |
| | **NPC人際關係系統** | NPC需要定義「性格偏好」數據，並在好感度計算時調用。 |
| | **對話系統** | 對話選項需要根據性格維度值進行條件判斷與顯示。 |
| | **事件系統** | 事件觸發條件需要能讀取玩家的性格維度值。 |
| **依賴本系統** | **世界感知系統** | 性格可能影響名聲傳播的內容（例如「一個豪爽的俠客在XX地做了XX事」）。 **(V2)** |
| | **門派政治系統** | 某些派系可能更歡迎特定性格的成員。 **(V2)** |

### 7. 可調參數（Tuning Knobs）

| 參數名稱 | 安全調整範圍 | 預設值 | 影響說明 |
|---|---|---|---|
| 性格對屬性的修正值 | 0 到 ±15 | ±3 ~ ±10 (依性格而異) | 調高會讓性格的「職業」導向更強，但可能導致角色Build單一化。調低則讓性格更像一種 flavor。 |
| NPC性格偏好權重 | -5 到 5 | -3 ~ 5 | 調高權重會讓NPC對玩家性格的反應更極端，強化「江湖有人」的感受。調低則讓NPC更中立。 |
| 對話選項性格門檻 | 1 到 5 | 2 ~ 4 | 門檻設低，所有玩家都能看到更多選項；設高，則讓性格的差異化更明顯，但可能導致某些玩家錯過內容。 |
| 事件觸發性格門檻 | 1 到 5 | 2 ~ 3 | 同上，影響內容的可及性與角色的獨特性。 |
| 性格維度總和上限 | 3 到 6 | 5 | 此值決定角色性格的「鮮明程度」。數值越高，角色可以同時具備更多元的性格特質；數值越低，角色性格越極端。 |

### 8. 驗收標準（Acceptance Criteria）

1.  **角色創建**：玩家可以從8種預設性格中選擇一種，並在UI上看到對應的數值Trade-off和角色描述。
2.  **屬性修正**：驗證選擇「莽撞」的角色，其初始武力確實比選擇「謹慎」的角色高8點，悟性低10點。
3.  **NPC好感**：一個「正直」的角色拜訪天樞劍派掌門時，初始好感高於一個「狡猾」的角色。 **[需測試]** 測試方向：調整NPC偏好權重，觀察好感度變化是否符合公式。
4.  **對話解鎖**：一個「剛直≥3」的角色，在與一個惡霸對話時，能看到「直接開戰」的選項；一個「圓滑≥3」的角色則看不到此選項，但能看到「嘗試說服」的選項。
5.  **事件觸發**：一個「仁義≥2」的角色在進入某村莊時，觸發「村民求助」事件的機率，顯著高於一個「利己≥2」的角色。 **[需測試]** 測試方向：用不同性格的角色反覆進出村莊，統計事件觸發頻率。
6.  **邊界處理**：創建一個角色，使其某項屬性因性格修正而低於5，驗證系統是否強制鎖定為5並顯示提示。
7.  **邊界處理**：創建一個角色，設法使其維度值達到上限，驗證無法繼續提升對立維度。
8.  **（V2）** 一個「俠義」角色做出大奸大惡之事，驗證系統是否跳出「心性動搖」警告，並在多次發生後，其「主要性格」名稱發生改變。
