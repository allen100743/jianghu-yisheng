# 江湖一生 時間與老化系統設計文件

*策劃：陳品霖 | 2026-05-12 | 狀態：初稿*

---

## 1. 概述（Overview）

本系統定義了《江湖一生》世界的時間流動規則，以及角色隨著時間流逝在生理、社會、心理三個層面的變化機制。時間是遊戲中最根本的資源，它推動一切——角色的成長、衰老、死亡，以及世界的變遷。本系統的核心目標是讓玩家真實感受到「這是我的一生」，而非一個永無止境的練功循環。

---

## 2. 玩家體驗（Player Fantasy）

玩家在使用這個系統時，應該感受到以下體驗：

- **時間的份量**：每一次移動、每一次修煉、每一次社交，都在消耗「生命」這個最寶貴的資源。玩家會慎重選擇要做什麼，因為知道時間有限。
- **成長的代價**：玩家會親眼看到角色從少年英姿蛻變為白髮蒼蒼的江湖傳說。這種變化不是純粹的數值增減，而是伴隨著外貌、能力、社會地位的整體轉變。
- **選擇的沉重**：玩家會做出取捨——是要趁年輕力壯時闖蕩江湖累積名聲，還是先閉關修煉提升實力？每一種選擇都有明確的機會成本。
- **生命的終點**：玩家會理解死亡不是失敗，而是角色故事的必然終章。當角色老去，玩家會開始思考「這一生做過什麼」、「還有什麼沒完成」，並在最後做出選擇——是平靜離世，還是轟轟烈烈地戰死。

## 3. 詳細規則（Detailed Rules）

### 3.1 時間單位與推進

| 時間單位 | 定義 | 遊戲內推進方式 | 玩家感知 |
|---------|------|--------------|---------|
| **刻** | 最小行動單位，約等於現實中的「一刻鐘」（15分鐘） | 玩家執行單次行動（如戰鬥中的一個回合、與NPC對話一次） | 幾乎無感知，連續動作間的微小間隔 |
| **時辰** | 遊戲內約2小時，一日12個時辰 | 玩家完成一組連續行動（如修煉一個時辰、探索一個區域） | 感覺到時間在流逝，行動有節奏感 |
| **日** | 遊戲內24小時，為核心結算單位 | 玩家完成每日行動後，進入「日結算」階段 | 最常感知的時間單位，決定作息、事件觸發、NPC日程 |
| **月** | 遊戲內30日 | 被動結算，主要用於長期事件（如門派俸祿、農作物收成） | 感覺到季節變化，長期規劃的參考單位 |
| **年** | 遊戲內360日（12個月） | 被動結算，觸發**年度體魄損耗結算**與**壽命減少** | 最強的「時光飛逝」感，生日事件、年度回顧 |

**時間推進規則（MVP必做）：**
1. 玩家執行任何行動，系統自動扣除對應的遊戲內時間。
2. 時間推進是**不可逆**的。沒有「讀檔回到昨天」的設計。
3. 時間推進時，世界同步推進：NPC執行日程、事件冷卻倒數、資源刷新。
4. 玩家無法「跳過」時間（如直接跳到三個月後），所有時間流逝必須有對應的行動或事件。

**時間加速（V2追加）：**
- 當玩家執行重複性行動（如長途趕路、長時間修煉）時，提供1x / 2x / 4x 加速選項。
- 加速期間，世界事件（如隨機遭遇、NPC互動）的觸發頻率按比例降低，避免玩家錯過重要內容。

### 3.2 年齡階段與生理變化

角色一生劃分為六個年齡階段，每個階段對應不同的生理狀態和能力曲線。

| 年齡階段 | 年齡區間 | 生理狀態 | 核心變化 |
|---------|---------|---------|---------|
| **少年** | 16–20歲 | 成長期，體質快速增強 | 體魄、輕功成長速度+50%；武力、內力成長速度-20% |
| **青年** | 21–30歲 | 巔峰期，全屬性成長最快 | 全屬性成長速度+20%；體魄達自然增長上限 |
| **壯年** | 31–45歲 | 穩定期，屬性維持高檔 | 屬性成長速度歸零；屬性不會自然衰減 |
| **中年** | 46–55歲 | 衰退前期，部分屬性開始下滑 | 體魄、輕功每年衰減1%；武力、內力維持不變 |
| **初老** | 56–65歲 | 衰退中期，戰鬥能力明顯下降 | 體魄、輕功每年衰減2%；武力、內力每年衰減1% |
| **暮年** | 66歲至壽命上限 | 衰退晚期，生存成為挑戰 | 全屬性每年衰減3%；觸發「風中殘燭」狀態，戰鬥力大幅下滑 |

**年齡階段觸發規則（MVP必做）：**
1. 角色年齡達到階段門檻時，自動觸發「生日事件」，系統提示玩家進入新階段。
2. 階段切換時，所有基於「自然增長」的屬性成長立即切換為新階段的成長/衰減速率。
3. 屬性衰減是**線性**的，每年結算一次，不會突然暴跌。

**外貌變化（V2追加）：**
- 每個年齡階段對應一套角色立繪（少年/青年/壯年/中年/初老/暮年），共6套。
- 階段切換時，立繪自動更換，玩家無法回到年輕時的外貌。
- 特殊情況（如重傷、中毒）可能提前觸發外貌老化（如白髮、皺紋），但屬性衰減仍按年齡計算。

### 3.3 壽命系統

壽命是角色的硬性終點，由體魄屬性決定基礎值，並受事件影響浮動。

**基礎壽命計算（詳見第4章公式）：**
- 基礎壽命範圍：62–81歲（體魄0–1000區間）
- 體魄是唯一影響基礎壽命的屬性，符合「體魄決定壽命」的武俠邏輯。

**壽命消耗規則（MVP必做）：**
1. 遊戲內每過一年，角色壽命減少1年。
2. 壽命減少至0時，角色自然死亡，遊戲結束。
3. 角色死亡時，觸發「江湖一生」結算畫面，統計角色一生事蹟。

**事件影響壽命（V2追加，但需預留配置空間）：**

| 事件類型 | 壽命影響 | 觸發條件 |
|---------|---------|---------|
| 重傷瀕死 | -1~3年 | 戰鬥中生命值歸零，被救回 |
| 習練陰毒邪功 | -2~5年 | 學習特定品質的邪派武學（如「奪命十三劍」） |
| 長期飢餓/中毒 | -1年/次 | 連續5日未進食，或中毒持續超過10日 |
| 重大打擊（摯友/愛侶身亡） | -1~3年 | 關係值達「刎頸之交」或「神仙眷侶」的NPC死亡 |
| 服用傳世靈藥 | +5~10年 | 極罕見，完成特定奇遇任務 |
| 養生奇遇 | +2~3年 | 完成特定養生任務（如找到「龜息功」秘笈） |

**壽命感知機制（MVP必做）：**
1. 角色面板永久顯示「剩餘壽命（估算）」欄位，格式為「約X年」。
2. 進入暮年階段後，每年生日事件會更新「剩餘壽命」估算值。
3. 玩家無法透過任何方式（除極罕見奇遇外）大幅延長壽命，強化「人生有限」的體驗。

### 3.4 時間壓力與機會成本

**時間壓力的設計目標：**
- 玩家無法「什麼都練滿」。有限的壽命迫使玩家做出取捨。
- 玩家無法「等事件發生」。錯過的機會可能永遠不會再來。
- 玩家無法「逃避後果」。選擇的代價會跟隨角色一生。

**具體機制（MVP必做）：**

1. **行動時間消耗表**（範例，完整清單待後續補完）：

| 行動類型 | 時間消耗 | 備註 |
|---------|---------|------|
| 城鎮內移動（到某個店鋪） | 1刻 | 無 |
| 與NPC單次對話 | 1刻 | 深談或交易可能更久 |
| 短途趕路（城鎮到城鎮） | 1~3日 | 依距離浮動 |
| 長途趕路（跨省） | 7~15日 | 依距離浮動 |
| 修煉（一次） | 1~3時辰 | 依修煉類型浮動 |
| 戰鬥（一場） | 1~5刻 | 依戰鬥規模浮動 |
| 睡覺（恢復體力） | 6~8時辰 | 強制每日執行 |

2. **機會成本提示**：當玩家選擇一個行動時，系統不主動提示「你將錯過什麼」，但玩家可以透過NPC對話、世界感知系統（公告板）來推斷「現在江湖上正在發生什麼事」。

3. **錯過的事件**：特定事件（如武林大會、門派政變）有觸發時間窗口，錯過即無法參與。但事件結果會繼續影響世界（如新的武林盟主上任），玩家必須面對這個結果。

### 3.5 終局條件

遊戲結束的觸發條件（MVP必做）：

| 終局條件 | 觸發方式 | 結算內容 |
|---------|---------|---------|
| **自然死亡** | 壽命歸零 | 完整的一生回顧，統計所有成就、關係、仇人、財富 |
| **戰死** | 戰鬥中生命值歸零，且無隊友/藥物可救治 | 戰鬥回顧，統計「戰死時」的成就 |
| **主動歸隱** | 玩家選擇「金盆洗手」事件 | 提前結算，角色從江湖消失，後代繼承部分遺產 |
| **意外身亡** | 特定事件（如走火入魔、中毒、墜崖）觸發死亡 | 事件回顧，統計「意外身亡」的成就 |

**關於「遊戲結束後的傳承」（與第13章傳代系統連動，V2追加）：**
- 角色死亡後，玩家可選擇「開啟新的一生」，繼承部分遺產。
- 舊角色成為世界中的NPC，活在NPC的記憶中。
- 詳細規則見第13章傳代系統設計文件。

## 4. 公式（Formulas）

### 4.1 基礎壽命公式

**變數定義：**
- `BASE_LIFESPAN`：基礎壽命（年），計算結果取整數
- `BODY`：體魄屬性值（0–1000）

**公式：**
```
if BODY < 100:
    BASE_LIFESPAN = 70 - floor((100 - BODY) × 0.08)
elif 100 ≤ BODY ≤ 400:
    BASE_LIFESPAN = 70 + floor((BODY - 100) × 0.025)
else:  // BODY > 400
    BASE_LIFESPAN = 77 + floor((BODY - 400) × 0.01)
```

**範例計算：**
- 體魄=50：`70 - floor((100-50)×0.08) = 70 - 4 = 66歲`
- 體魄=100：`70 + floor((100-100)×0.025) = 70 + 0 = 70歲`
- 體魄=250：`70 + floor((250-100)×0.025) = 70 + 3 = 73歲`
- 體魄=400：`70 + floor((400-100)×0.025) = 70 + 7 = 77歲`
- 體魄=800：`77 + floor((800-400)×0.01) = 77 + 4 = 81歲`

**數值範圍：** 62–81歲

### 4.2 年齡屬性衰減公式

**變數定義：**
- `STAT`：任意屬性值（武力、內力、體魄、輕功）
- `AGE`：角色當前年齡（歲）
- `STAGE`：角色當前年齡階段（以數字1-6表示，少年=1，暮年=6）
- `DECAY_RATE`：每年衰減百分比（少年=0%，青年=0%，壯年=0%，中年=1%，初老=2%，暮年=3%）

**公式：**
```
每年衰減值 = floor(STAT × DECAY_RATE / 100)
```

**範例計算：**
- 中年角色（DECAY_RATE=1%），武力=500：`floor(500 × 1 / 100) = 5` → 每年武力-5
- 暮年角色（DECAY_RATE=3%），體魄=200：`floor(200 × 3 / 100) = 6` → 每年體魄-6

**規則：**
- 衰減在每年生日事件時結算一次。
- 衰減後的屬性值不可低於該年齡階段的「最低生存值」（中年=10，初老=5，暮年=1）。
- 屬性衰減至最低生存值後，不再繼續衰減，但角色進入「脆弱」狀態，更容易因疾病或重傷死亡。

### 4.3 時間消耗計算

**變數定義：**
- `BASE_TIME`：行動基礎時間消耗（單位：刻或日）
- `DISTANCE`：移動距離（單位：里）
- `SPEED`：角色移動速度（單位：里/日），由輕功屬性決定
- `SKILL_MOD`：技能熟練度帶來的時間縮減倍率（如輕功熟練度影響移動時間）

**移動時間公式：**
```
移動時間（日）= DISTANCE / (SPEED × SKILL_MOD)
```

**範例計算：**
- 距離=300里，輕功=200（對應SPEED=30里/日），SKILL_MOD=1.0：`300 / 30 = 10日`
- 距離=300里，輕功=500（對應SPEED=50里/日），SKILL_MOD=1.2：`300 / (50 × 1.2) = 5日`

**修煉時間公式（範例，完整公式待數值章節定義）：**
```
修煉時間（時辰）= BASE_TIME / (1 + (悟性 / 100))
```

**範例計算：**
- BASE_TIME=3時辰，悟性=50：`3 / (1 + 0.5) = 2時辰`
- BASE_TIME=3時辰，悟性=200：`3 / (1 + 2.0) = 1時辰`

### 4.4 事件觸發機率（時間相關）

**變數定義：**
- `BASE_PROB`：事件基礎觸發機率（0–1）
- `TIME_MOD`：時間修正係數（某些事件只在特定時間段觸發，如夜晚事件機率提升）
- `AGE_MOD`：年齡修正係數（某些事件只會發生在特定年齡階段，如「晚年收徒」事件）
- `FINAL_PROB`：最終觸發機率（0–1）

**公式：**
```
FINAL_PROB = BASE_PROB × TIME_MOD × AGE_MOD
```

**規則：**
- 最終機率超過1時，視為1（必定觸發）。
- 最終機率低於0時，視為0（永不觸發）。
- [需測試] 事件觸發的隨機種子應與角色ID綁定，避免SL大法重複刷事件。

## 5. 邊界條件（Edge Cases）

| 編號 | 情境 | 處理方式 |
|-----|------|---------|
| E1 | 角色在少年階段（16-20歲）體魄就達到1000（滿值） | 體魄成長速度+50%的增益仍然存在，但屬性無法超過1000。超出的部分轉化為「體魄潛能」，在進入青年階段時一次性釋放（轉化為其他屬性，如武力或內力）。 |
| E2 | 角色在暮年階段，全屬性衰減至最低生存值 | 角色進入「風中殘燭」狀態：無法進行戰鬥、無法長途移動、無法修煉。只能進行社交、交易等低強度活動。此狀態持續至角色死亡。 |
| E3 | 角色因事件減壽，剩餘壽命小於0 | 觸發「油盡燈枯」事件：角色在7日內必定死亡，無法透過任何方式延緩。7日內玩家可以安排後事（分配遺產、寫遺書、與重要NPC告別）。 |
| E4 | 玩家在角色少年階段就完成所有目標，選擇主動歸隱 | 歸隱結算時，角色年齡仍為少年。後代繼承時，角色的「傳說值」較低（因為江湖經歷短），但「天賦潛能」較高（因為年輕）。 |
| E5 | 玩家在角色暮年階段才開始練武 | 學習速度降低（因為悟性和資質因年齡衰減），但可觸發「大器晚成」特殊事件，獲得額外屬性成長。 |
| E6 | 角色在戰鬥中生命值歸零，但隊友/藥物將其救回 | 觸發「重傷瀕死」事件，壽命-1~3年（隨機）。角色進入「養傷」狀態，期間無法進行高強度活動。 |
| E7 | 角色壽命剩餘1年時，完成「逆天改命者」任務 | 觸發「延壽」事件，壽命+10年。角色外貌維持在當前年齡階段，但屬性衰減速率暫停5年。 |
| E8 | 同一個存檔中，玩家進行了多次傳代（玩了好幾代） | 每一代的時間線是連續的。第一代角色出生於洪武年間，第二代角色出生於第一代角色死亡後的某一年。世界時間會持續推進，歷史事件會發生。 |

## 6. 系統依賴（Dependencies）

### 6.1 這個系統依賴哪些系統？

| 依賴系統 | 依賴原因 | 備註 |
|---------|---------|------|
| **角色創建系統** | 提供初始年齡（16-20歲）和初始體魄屬性，是壽命計算的起點 | 必備（MVP） |
| **成長系統（屬性）** | 提供體魄屬性的即時數值，是壽命公式的輸入變數 | 必備（MVP） |
| **戰鬥系統** | 提供「重傷瀕死」事件的觸發條件，影響壽命 | 必備（MVP） |
| **裝備與武學系統** | 提供「陰毒邪功」的判定條件，影響壽命 | V2追加 |
| **NPC人際關係系統** | 提供「重大打擊」事件的觸發條件（摯友/愛侶死亡），影響壽命 | V2追加 |
| **世界感知系統** | 提供時間流逝對世界事件的影響（如事件錯過後無法重來） | V2追加 |

**品霖的補充備註：**

製作人，這份設計文件我盡量保持「需求先行」的原則，沒有因為擔心技術難度而自我審查。時間與老化系統是《江湖一生》核心支柱「這是我的一生」和「時間可見」的直接體現，我認為它是整個遊戲體驗的基石，值得投入心力。

幾個我認為需要特別注意的地方：

1. **MVP vs V2的切割**：我把「事件影響壽命」和「外貌變化」放在V2，因為它們雖然能大幅增強沉浸感，但不是「時間流逝」這個核心機制運作的必要條件。MVP階段只要做到「年齡增長、屬性衰減、壽命歸零死亡」這條主線就夠了。

2. **「壽命感知」的設計**：我故意不讓玩家看到精確的剩餘壽命（如「還有12年3個月7天」），而是用「約X年」的估算值。這是為了保留一點模糊感——人生本來就充滿不確定性，精確到天的倒數計時反而會破壞沉浸感。

3. **邊界條件E3（油盡燈枯）**：這是我特別設計的「最後7天」機制。目的是讓玩家在角色臨終前有機會「安排後事」，而不是突然死亡什麼都來不及做。這對後續的傳代系統設計很重要。

4. **數值平衡**：目前所有數值都是基於我對武俠遊戲的理解和直覺設定的，標注了「[需測試]」的地方需要原型驗證。特別是「體魄對壽命的影響係數」，這個直接決定了遊戲的整體節奏。
