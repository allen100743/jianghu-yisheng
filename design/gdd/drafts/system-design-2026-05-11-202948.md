## 系統設計文件：武俠抗性體系

**策劃：陳品霖**
**日期：2026-05-12**
**狀態：初稿**

### 1. 概述

武俠抗性體系是角色對抗江湖中各種非直接物理傷害（如毒藥、極端環境、內傷、精神衝擊等）的防禦機制。它不是一個單一的「抗性」數值，而是一套由角色核心屬性（體魄、內力、輕功）衍生出的多維度防禦網路。玩家透過練武、裝備、江湖歷練來提升抗性，這影響了角色在特定環境下的生存能力、戰鬥效率以及壽命損耗。

### 2. 玩家體驗

- **「我練成了金剛不壞神功，區區蛇毒能奈我何？」**：當玩家投入資源提升體魄或內力後，能直觀感受到對應抗性的提升，從被動挨打到從容應對，獲得成長的成就感。
- **「這座雪山寒冷刺骨，沒有準備硬闖就是找死。」**：在探索特定區域前，玩家需要思考自己的抗性是否足夠，或需要準備特殊的藥物、裝備，這增加了探索的策略深度和真實感。
- **「這老魔頭的掌力陰毒無比，不但傷我經脈，還讓我內力運轉不暢！」**：戰鬥中，高階敵人的攻擊會附加多種抗性檢定，失敗則觸發負面狀態（如中毒、內傷、眩暈），讓戰鬥不只是血量對轟，更有戰術博弈。
- **「我這一生縱橫江湖，但暗傷積累，晚年怕是難熬了。」**：某些抗性（特別是內傷抗性）與角色的長期健康掛鉤，影響壽命，呼應「時間可見」與「選擇有代價」的核心支柱。

### 3. 詳細規則

#### 3.1 抗性類型與衍生來源

| 抗性名稱 | 武俠描述 | 衍生來源（主要/次要） | 影響的負面狀態/情況 |
|---|---|---|---|
| **毒抗** | 百毒不侵之體 | 體魄（主要），內力（次要） | 中毒（持續扣血、屬性下降）、麻痹（行動遲緩） |
| **寒抗** | 不畏嚴寒 | 體魄（主要），內力（次要） | 凍傷（移動速度下降、生命恢復停止）、寒毒（內力消耗加倍） |
| **火抗** | 不懼烈火 | 體魄（主要），輕功（次要） | 灼燒（持續扣血）、焚身（裝備耐久下降） |
| **內傷抗** | 經脈穩固，氣血充盈 | 內力（主要），體魄（次要） | 內傷（生命上限暫時下降、武力/內力屬性下降）、經脈受損（無法運功） |
| **眩暈抗** | 心神堅定，下盤穩健 | 內力（主要），輕功（次要） | 眩暈（無法行動）、混亂（攻擊目標隨機） |
| **點穴抗** | 氣門閉塞，難以被封 | 內力（主要），悟性（次要） | 點穴（無法使用輕功、部分技能被封鎖） |

#### 3.2 抗性值的計算與提升

- **基礎抗性值**：由衍生來源的屬性決定。例如，毒抗 = 體魄 × 0.5 + 內力 × 0.3。
- **裝備加成**：裝備詞條可以提供直接的抗性數值加成（如：「這件金絲軟甲能抵禦尋常刀劍，更可隔絕蛇蟲鼠蟻之毒」→ 毒抗 +20）。
- **武學加成**：特定內功或外功心法可以提供百分比抗性加成或被動觸發抗性檢定優勢（如：「修習《寒冰真氣》後，對嚴寒的抵禦力大幅提升」→ 寒抗 +30%）。
- **藥物/食物加成**：消耗品可以提供暫時的抗性提升（如：「喝下一碗薑湯，驅散體內寒意」→ 寒抗 +50，持續1天）。
- **永久提升**：透過特定奇遇、完成艱難任務或服用天材地寶（如「朱果」），可永久提升某一項抗性的上限。

#### 3.3 抗性檢定機制

當玩家或NPC受到帶有特殊屬性的攻擊或身處惡劣環境時，系統會進行一次「抗性檢定」。

1.  **觸發**：攻擊或環境效果附帶「抗性檢定難度」。
2.  **計算**：`檢定結果 = 角色對應抗性值 + 亂數(0, 20)`
3.  **判定**：
    - 若 `檢定結果 >= 抗性檢定難度`：完全抵抗負面效果。
    - 若 `檢定結果 < 抗性檢定難度`：觸發負面效果，效果強度由 `(抗性檢定難度 - 檢定結果)` 的差值決定。

#### 3.4 負面效果強度分級

| 差值範圍 | 效果強度 | 示例（中毒） |
|---|---|---|
| 1–20 | 輕微 | 每回合損失5點生命，持續3回合 |
| 21–50 | 中等 | 每回合損失15點生命，持續5回合，並降低10%武力 |
| 51+ | 嚴重 | 每回合損失30點生命，持續8回合，並降低20%武力與內力 |

### 4. 公式

#### 4.1 基礎抗性值計算

```
變數定義：
- BOD: 體魄 (Body)
- NRI: 內力 (Internal)
- AGL: 輕功 (Agility)
- WIS: 悟性 (Wisdom)

公式（結果取整數）：
- 毒抗 = floor( BOD × 0.5 + NRI × 0.3 )
- 寒抗 = floor( BOD × 0.6 + NRI × 0.2 )
- 火抗 = floor( BOD × 0.4 + AGL × 0.4 )
- 內傷抗 = floor( NRI × 0.6 + BOD × 0.3 )
- 眩暈抗 = floor( NRI × 0.5 + AGL × 0.3 )
- 點穴抗 = floor( NRI × 0.7 + WIS × 0.2 )
```

**範例計算**：
一個角色屬性為：BOD=80, NRI=60, AGL=50, WIS=40。
- 毒抗 = floor(80 × 0.5 + 60 × 0.3) = floor(40 + 18) = 58
- 內傷抗 = floor(60 × 0.6 + 80 × 0.3) = floor(36 + 24) = 60

#### 4.2 抗性檢定公式

```
變數定義：
- RES: 角色對應抗性值 (Resistance)
- DC: 抗性檢定難度 (Difficulty Class)
- ROLL: 亂數(0, 20)，整數

公式：
- 檢定結果 = RES + ROLL
- 若 檢定結果 >= DC: 完全抵抗
- 若 檢定結果 < DC: 觸發負面效果，效果強度 = DC - 檢定結果
```

**範例計算**：
角色毒抗=58，被一條毒蛇咬到，毒蛇攻擊附帶毒抗檢定 DC=70。
- 若 ROLL = 15: 檢定結果 = 58 + 15 = 73 >= 70 → **完全抵抗，無中毒。**
- 若 ROLL = 5: 檢定結果 = 58 + 5 = 63 < 70 → **中毒！** 效果強度 = 70 - 63 = 7。根據分級表，屬於「輕微中毒」。

### 5. 邊界條件

- **抗性值為負數**：當角色因特殊詛咒或重傷導致核心屬性極低時，抗性值可能為負。負的抗性值將使檢定更容易失敗，且失敗時的效果強度會更高（`DC - (負數)` 會使差值變大）。
- **多種抗性同時檢定**：一個攻擊可能同時附帶多種效果（如「寒冰毒掌」同時檢定寒抗與毒抗）。兩種檢定獨立進行，玩家可能只抵抗其中一種。
- **抗性值溢出**：當抗性值遠高於遊戲中可能出現的最高DC時，檢定永遠成功。這是遊戲後期角色「百毒不侵」的表現，合理。
- **免疫狀態**：某些特殊武學或稱號（如「藥王谷傳人」）可賦予對特定負面狀態的「免疫」。免疫狀態會直接跳過抗性檢定，是比高抗性更強力的效果，需謹慎設計。
- **環境抗性檢定**：身處環境（如火山口、萬年冰洞）會持續進行抗性檢定，週期為每「1天」或每「1個時辰」檢定一次。若連續失敗，累積效果會快速惡化。

### 6. 系統依賴

- **依賴其他系統**：
    - **角色屬性系統**：抗性值直接從核心屬性衍生。
    - **裝備與武學系統**：提供抗性值的加成來源。
- **被其他系統依賴**：
    - **戰鬥系統**：攻擊效果需要定義「抗性檢定難度（DC）」和「負面效果」。
    - **世界與地圖系統**：特定區域需要定義「環境抗性檢定」。
    - **經濟系統**：藥物、特殊裝備的價值與抗性掛鉤。
    - **壽命系統**：長期處於低抗性狀態或反覆受到重傷，會觸發減壽事件。
    - **NPC人際關係系統**：NPC對玩家的抗性有認知（如：知道你是用毒高手，會更謹慎）。

### 7. 可調參數

| 參數名稱 | 說明 | 安全調整範圍 | 影響 |
|---|---|---|---|
| 基礎抗性係數 | 公式中核心屬性的權重（如體魄×0.5） | 0.1 ~ 1.0 | 決定屬性對抗性的貢獻度。係數越高，屬性成長帶來的抗性收益越大。 |
| 檢定亂數範圍 | `ROLL` 的範圍 | 0~10 至 0~30 | 範圍越小，結果越穩定，高抗性的優勢越明顯；範圍越大，運氣成分越重。 |
| 負面效果強度斜率 | 效果強度差值與實際效果的線性關係 | 每1點差值對應0.5~2點傷害/效果 | 決定抗性檢定失敗的懲罰力度。斜率越高，失敗越致命。 |
| 環境檢定週期 | 環境傷害的檢定頻率 | 每1時辰至每3天 | 頻率越高，對抗性的要求越苛刻，探索特定區域的門檻越高。 |
| 暫時抗性增益持續時間 | 藥物/食物的增益持續時間 | 1小時至7天 | 影響戰術準備的節奏。時間太短會讓玩家頻繁使用，太長則失去準備的意義。 |
