## 1. 概述（Overview）

戰鬥系統v2在v1的基礎上，深化了戰鬥與江湖世界的連結。它不再是一個獨立的「打架小遊戲」，而是玩家與世界互動、驗證自身傳奇、並創造江湖傳聞的核心舞台。v2版本引入了「戰鬥記憶」、「環境互動」、「聲望戰鬥」與「武學相生相剋」四大模塊，讓每一場戰鬥的過程與結果，都擁有超越數值增減的意義，直接影響角色的江湖地位、人際關係與後續際遇。

---

## 2. 玩家體驗（Player Fantasy）

v2的目標是讓玩家在戰鬥中感受到「這是我在江湖中的一場傳奇」，而非僅僅是「我打贏了一場架」。

- **戰鬥是故事的載體**：在酒樓與人一言不合的鬥毆，可能引來對方門派的報復；在眾目睽睽之下用一招失傳劍法擊敗強敵，你的名聲會像野火般傳開。
- **戰鬥是風格的畫筆**：一個以輕功和暗器聞名的俠客，與一個以硬氣功和拳法著稱的莽漢，他們的戰鬥方式、視覺表現和江湖評價截然不同。v2的相生相剋系統讓這種差異化更加明顯。
- **戰鬥是世界的回聲**：在懸崖邊戰鬥，你的一招「力劈華山」可能將敵人擊落深淵；在城鎮中心戰鬥，你的誤傷可能引來官差。環境不再只是背景，而是戰鬥的一部分。
- **戰鬥是記憶的烙印**：你放過的一個手下敗將，可能在多年後成為你的救命恩人；你殺死的一個無名小卒，可能是某個大俠的獨子。v2的戰鬥記憶系統讓每一次揮劍都有其後續重量。

**一句話總結v2的體驗目標**：讓玩家覺得「我剛才那一戰，可以寫進說書人的話本裡」。

## 3. 詳細規則（Detailed Rules）

### 3.1 戰鬥事件輸出（系統邊界定義）

**設計原則：戰鬥系統只負責解決戰鬥，不負責戰鬥的後果。**

戰鬥結束時，系統透過**事件總線（#35）**廣播以下事件，由其他系統各自處理：

| 事件 | 接收系統 | 處理內容 |
|------|---------|---------|
| `combat_npc_killed(attacker, victim, method)` | NPC人際關係系統（#15）| 觸發殺親之仇、仇恨值 |
| `combat_npc_defeated(attacker, victim)` | NPC行為系統（#14）| 手下敗將的畏懼/懷恨/敬服 |
| `combat_player_lost(enemy)` | NPC行為系統（#14）| 敵人氣焰、追擊行為 |
| `combat_witnessed(attacker, style, audience)` | 世界感知系統（#16）| 江湖傳說、名聲傳播 |

**戰鬥系統的職責止於此。** NPC 如何反應、仇恨如何演變、傳說如何傳播，由對應系統設計，不在本文件範疇。

### 3.2 環境互動系統 [V2追加]

**設計原則：視覺即規則，不需要說明書。**
看起來能打壞的東西就能打壞，沒有隱藏邏輯，不讓玩家被不知道的規則懲罰。

**可互動元素（僅這三類，保持簡單）：**

| 元素 | 觸發方式 | 效果 | 設計意圖 |
|------|---------|------|---------|
| **木箱/貨物** | 任何攻擊命中 | 爆開掉落物品（材料/金錢） | 破壞有獎勵，鼓勵主動打環境 |
| **石柱/懸崖邊緣** | 敵人被擊退至邊緣 | 墜落造成傷害，視高度而定 | 利用地形的成就感 |
| **火盆/油桶** | 任何攻擊命中 | 範圍火焰傷害，持續2-3秒 | 視覺爽感，風險/機會並存 |

**刻意移除的機制（靜怡 UX 審查後刪除）：**
- ~~水中雷電加成/火焰減益~~ — 需記規則，自動戰鬥時玩家不知道
- ~~木橋承重倒塌~~ — 500傷害閾值玩家無從感知
- ~~誤傷平民/野獸加入~~ — 移至 NPC 行為系統處理，不在戰鬥場景製造意外懲罰
- ~~SP消耗觸發~~ — 增加認知負擔，自動戰鬥時尤其混亂

**自動戰鬥相容性：** 環境互動不需要玩家主動觸發，普通攻擊命中環境物件即觸發效果，自動戰鬥下自然發生，不造成意外負面後果。

### 3.3 戰鬥前後的聲望邏輯（系統邊界說明）

**製作人確認：聲望是戰鬥前後的事，不是戰鬥本身的事。**

- **戰鬥前**：玩家的名聲影響NPC是否主動挑戰、旁觀者數量、大地圖上的態度 → 由 **NPC行為系統（#14）** 和 **世界感知系統（#16）** 管理
- **戰鬥後**：戰鬥風格（光明正大/心狠手辣）影響名聲變化 → 由 `combat_witnessed` 事件傳遞給世界感知系統處理

戰鬥系統唯一需要做的是在 `combat_witnessed` 事件中帶上**戰鬥風格標籤**：

```
combat_witnessed(
  attacker,
  style: "honorable" | "ruthless" | "spectacular",
  audience_count,
  location_type
)
```

其他所有聲望計算（俠義值+、惡名值+、挑戰者觸發、賭盤）由接收端系統處理，**不在戰鬥系統內實作**。

### 3.4 武學屬性與效果風格系統 [V2追加]

**設計原則：屬性標籤描述武學的風格，決定 Buff/Debuff 傾向，TIPS 視窗直接呈現，玩家不需要背表。**

#### 四種屬性標籤

| 屬性 | 風格 | 傾向效果 |
|------|------|---------|
| **陽** | 剛烈爆發 | 灼燒、擊退、破甲、短時高傷 |
| **陰** | 滲透持久 | 中毒、減速、暗傷、持續消耗 |
| **剛** | 正面壓制 | 硬直、恐嚇、大傷、防禦破壞 |
| **柔** | 借力化勁 | 反彈、回血、卸力、控制解除 |

每個武學秘笈和技能，在道具說明/武學 TIPS 視窗中**直觀展示**其屬性標籤及對應效果傾向。玩家選武學時就能讀懂，不依賴隱藏機制。

#### 相生加成（內功+外功同屬性）

內功屬性決定角色的「內力風格」。當外功屬性與內功屬性相符時，該外功的**傾向效果更強**：

| 相生組合 | 增強效果 |
|---------|---------|
| 陽內功 + 陽外功 | 灼燒持續時間+50%，擊退距離+30% |
| 陰內功 + 陰外功 | 中毒層數+1，減速效果+25% |
| 剛內功 + 剛外功 | 硬直時間+30%，傷害+15% |
| 柔內功 + 柔外功 | 反彈傷害+50%，回血量+20% |

**這不是傷害加成黑箱，而是效果品質的提升，玩家能直接感受到差異。**

#### UI 設計要求（給靜怡）
- 武學道具 TIPS 視窗必須顯示：屬性標籤、傾向效果列表
- 角色面板顯示當前內功屬性
- 屬性相符時，技能圖示有輕微光暈提示（不強制，玩家可忽略）

## 4. 公式（Formulas）

### 4.1 環境墜落傷害公式 [V2追加]

- **變數定義**：
    - `Fall_Height`：墜落高度（遊戲單位，1單位約等於1米）
    - `Target_Body`：被擊落目標的體魄屬性

- **公式**：
    ```
    墜落基礎傷害 = Fall_Height × 10
    最終墜落傷害 = floor(墜落基礎傷害 × (1 - Target_Body / 2000))
    墜落暈眩時間 = min(3, floor(Fall_Height / 5)) 秒
    ```

- **範例計算**：
    - 目標體魄 `Target_Body = 100`，從高度 `Fall_Height = 15` 的懸崖墜落。
    - `墜落基礎傷害 = 15 × 10 = 150`
    - `最終墜落傷害 = floor(150 × (1 - 100/2000)) = floor(150 × 0.95) = floor(142.5) = 142`
    - `墜落暈眩時間 = min(3, floor(15/5)) = 3` 秒
    - **結果：目標受到142點傷害，並暈眩3秒。**

### 4.2 武學相生相剋加成公式 [V2追加]

- **變數定義**：
    - `Attack_Attr`：攻擊武學屬性（陰/陽/剛/柔）
    - `Defense_Attr`：防禦方當前運功的內功屬性（陰/陽/剛/柔）
    - `Player_Internal_Attr`：玩家自身內功屬性

- **判定邏輯**：
    ```
    if (Attack_Attr 剋制 Defense_Attr):
        傷害加成 = +25%
    if (Attack_Attr 與 Player_Internal_Attr 相生):
        消耗減免 = 15%
        效果加成 = 10%
    ```

- **範例計算**：
    - 玩家使用「陽」屬性的「大開碑手」（消耗MP 30，造成100點基礎傷害）。
    - 目標內功為「陰」屬性（被陽剋制）。
    - 玩家自身內功為「陽」屬性（與武學相生）。
    - `最終傷害 = 100 × (1 + 0.25) = 125`
    - `最終MP消耗 = 30 × (1 - 0.15) = 25.5`，取整為25。
    - **結果：玩家消耗25點MP，對目標造成125點傷害。**

## 5. 邊界條件（Edge Cases）

| 邊界情況 | 處理方式 |
|---|---|
| **戰鬥記憶中，玩家殺死NPC後，該NPC的親友前來尋仇，但尋仇時又被玩家殺死，仇恨鏈如何處理？** | 仇恨鏈會繼續向下傳遞至該NPC的親友。若該NPC已無任何親友，則仇恨鏈終結。系統會記錄玩家滅門的「事蹟」，極大影響名聲（惡名大幅增加）。 |
| **環境互動中，玩家將最後一個敵人打下懸崖，但無法下去拾取戰利品。** | 若敵人因環境死亡，其戰利品會自動結算至玩家背包，並在戰鬥結算畫面中顯示。無需手動拾取。 |
| **聲望戰鬥中，玩家在無人目睹的野外殺死敵人，是否會觸發旁觀者效應？** | 不會。聲望戰鬥系統只在有「旁觀者」生成的公共場所觸發。在無人地區的戰鬥，其對名聲的影響主要透過「世界感知系統」中的「消息傳播」來體現（例如屍體被發現後）。 |
| **武學相生相剋中，若敵我雙方武學屬性相同，如何處理？** | 無加成，也無減免。視為「屬性對等」，傷害計算回歸基礎公式。 |
| **玩家同時裝備了多種屬性的武學，如何決定當前戰鬥的「基礎屬性」？** | 玩家當前的「基礎屬性」由其裝備的「內功」決定。切換內功會改變基礎屬性，並影響所有外功的相生判定。外功自身的屬性則影響相剋判定。 |
| **戰鬥記憶中的「手下敗將」若在逃跑後，又加入了一個更強的門派，其AI行為是否會改變？** | 會。NPC的「畏懼」狀態會根據其自身實力的成長而動態調整。若該NPC後來練成絕世武功，其「畏懼」狀態可能消失，轉為「雪恥」狀態，並主動向玩家發起挑戰。 |
| **玩家在戰鬥中利用環境殺死一個重要劇情NPC，是否會導致劇情斷裂？** | 會。此為「選擇有代價」原則的體現。系統會檢測該NPC是否為關鍵任務觸發者，若是，則相關任務鏈會永久關閉，或由其他NPC觸發替代的、更困難的任務鏈。遊戲不會崩潰，但世界會以另一種方式回應。 |

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 當前值 | 安全調整範圍 | 調整影響 |
|---|---|---|---|
| **墜落傷害係數** | `高度 × 10` | `[高度 × 5, 高度 × 20]` | 影響環境殺傷的強度。調高使懸崖等地形成為致命陷阱，調低使其成為一個戰術選項而非終結手段。 |
| **墜落暈眩時間公式** | `min(3, floor(高度/5))` | `[min(1, floor(高度/5)), min(5, floor(高度/2))]` | 影響環境互動後的控制效果長度。調高使擊落敵人能帶來巨大的戰術優勢。 |
| **武學相剋傷害加成** | `+25%` | `[+10%, +40%]` | 影響屬性剋制的策略價值。調高會強烈鼓勵玩家針對敵人弱點配裝，調低則讓萬金油流派更可行。 |
| **武學相生消耗減免** | `-15%` | `[-5%, -25%]` | 影響屬性相生的資源續航價值。調高使專精一系內功的流派更具持續作戰能力。 |
| **手下敗將畏懼機率** | `敗績次數 × 10%` | `[敗績次數 × 5%, 敗績次數 × 20%]` | 影響戰鬥記憶對AI行為的影響程度。調高會讓戰鬥記憶系統非常顯著，可能導致部分NPC過於膽小。 |
| **聲望戰鬥旁觀者生成數量** | `場所繁華度 × 名聲/100` | `[場所繁華度, 場所繁華度 × 名聲/50]` | 影響聲望戰鬥的影響範圍。調高會讓名聲高的玩家在城鎮中每戰必成焦點。 |
| **賭盤賠率範圍** | `1.1 ~ 3.0` | `[1.01, 5.0]` | 影響賭盤系統的風險與回報。賠率範圍越大，賭博的刺激性越高，但也可能破壞經濟平衡。[需測試] |

## 8. 驗收標準（Acceptance Criteria）

| 編號 | 驗收項目 | 預期結果 | 測試方法 |
|---|---|---|---|
| AC-v2-01 | 戰鬥記憶：手下敗將 | 擊敗NPC「張三」後，再次遇見時，張三有一定機率逃跑或投降 | 擊敗張三5次，記錄其後續行為。 |
| AC-v2-02 | 戰鬥記憶：殺親之仇 | 殺死NPC「李四」，其子「李五」會自動與玩家成為仇人，並在數日後前來尋仇 | 殺死李四，觀察李五的行為與觸發的事件。 |
| AC-v2-03 | 環境互動：墜落 | 將敵人從懸崖邊擊落，敵人受到墜落傷害並暈眩 | 在懸崖場景戰鬥，使用「推掌」將敵人擊落。 |
| AC-v2-04 | 環境互動：點燃 | 使用火屬性武學攻擊火盆，火盆爆炸對範圍內單位造成傷害 | 在火盆附近戰鬥，使用「烈焰掌」攻擊火盆。 |
| AC-v2-05 | 聲望戰鬥：旁觀者生成 | 在城鎮中心戰鬥時，場景中出現多名旁觀者NPC | 在應天府中心廣場觸發戰鬥。 |
| AC-v2-06 | 聲望戰鬥：風格評價 | 使用光明正大的方式取勝，戰後「俠義值」增加 | 在旁觀者面前，不使用暗器、不攻擊倒地敵人取勝。 |
| AC-v2-07 | 武學相生相剋：相剋傷害 | 使用「陽」屬性武學攻擊「陰」屬性內功的敵人，傷害增加25% | 記錄基礎傷害，再記錄相剋時的傷害，比對是否增加25%。 |
