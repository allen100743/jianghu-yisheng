# 江湖一生 — 角色創建系統 GDD v3

*策劃：陳品霖 | 審核：製作人 | 2026-05-12*

## 1. 概述（Overview）

角色創建系統是《江湖一生》的入口，負責在5分鐘內，透過「出身背景選擇」、「初始天賦選擇」、「外觀自定義」與「角色命名」四個步驟，生成一個獨一無二的角色。本系統的核心任務不僅是建立角色的初始狀態，更是為玩家即將展開的江湖人生，埋下第一顆屬於「他」的故事種子。每一次創角，都是為一段獨特的江湖傳奇寫下開篇。

## 2. 玩家體驗（Player Fantasy）

- **「我的出身，決定了我的江湖起點」**：選擇「孤兒」或「商賈之子」不只是獲得不同的初始金錢，而是踏入江湖時，第一個遇到的人、第一句聽到的話、第一個可以接到的任務，都會因此不同。玩家能明確感受到「我的選擇塑造了我的世界」。
- **「我的天賦，是獨一無二的命運種子」**：隨機天賦不只是數值加減，而是定義了角色潛在的命運走向。抽到「天煞孤星」的玩家，會帶著一絲不安與期待踏入江湖，因為他知道，自己的選擇將帶來與眾不同的故事。抽到「醫者仁心」的玩家，則會思考如何在不殺戮的情況下生存與成長。
- **「這就是我，我準備好了」**：外觀自定義與命名儀式，完成了角色認同的最後一塊拼圖。當玩家點下「踏入江湖」的瞬間，他已經準備好，以這個角色的身份，去經歷所有的一切。

## 3. 詳細規則（Detailed Rules）

### 3.1 創角流程（P0）

1.  **出身背景選擇（P0）**
    -   玩家從預設的出身背景清單中選擇1個。MVP版本提供3個選項。
    -   選擇後，系統會根據出身生成一個約50-100字的開場文本，說明角色的來歷。玩家可選擇跳過。
    -   **MVP出身清單**：
        | 出身 | 初始效果 | 玩家幻想 | 開場文本範例 | **早期事件影響（P0）** |
        |---|---|---|---|---|
        | **孤兒** | 無初始金錢，無親屬，初始名聲+10 | 白手起家，無所畏懼，江湖就是我的家。 | 「你記事起就在破廟裡討生活，沒有人知道你的父母是誰。你學會的第一件事，不是寫字，是看人臉色。你唯一擁有的，就是這條命。」 | 進入第一個城鎮時，觸發事件「城門口的乞丐」：一名老乞丐認出你身上的破廟印記，告訴你一些關於你身世的模糊線索（需後續驗證），並給你一個低階任務。 |
        | **商賈之子** | 初始金錢+200兩，初始交易價格-10%，初始名聲-5 | 財力雄厚，以錢鋪路，但江湖人看不起你的出身。 | 「你是蘇州府最大綢緞莊的少東家，從小錦衣玉食。你聽膩了帳房先生的算盤聲，總想著外面的江湖是什麼樣子。父親給了你一筆盤纏，讓你『出去見見世面』。」 | 進入第一個城鎮時，觸發事件「錢莊的麻煩」：一名錢莊掌櫃認出你是蘇州陳家的公子，請你幫忙護送一批重要帳本到隔壁城鎮，報酬豐厚。 |
        | **武官世家** | 初始武力+10，初始體魄+5，朝廷NPC初始好感+20 | 家學淵源，體制內起點高，但枷鎖也多。 | 「你的父親是應天府衙門的總捕頭，你從小在練武場長大。他教你的第一套拳法叫『忠君報國』。你身上背負的，不只是自己的未來，還有陳家的門楣。」 | 進入第一個城鎮時，觸發事件「衙門的考驗」：當地衙門的捕頭認出你的家傳令牌，請你協助調查一起失竊案，作為你加入「六扇門」的敲門磚。 |
    -   **V2追加**：增加「書香門第」（悟性+10）、「江湖浪子」（輕功+5、名聲+5）、「隱世高人之後」（資質+15）等出身，並為每個出身設計對應的早期事件。

2.  **初始天賦選擇（P0）**
    -   **核心機制**：系統從預設的天賦池中，隨機生成4個天賦。玩家從這4個中選擇1個作為初始天賦。
    -   **天賦分級**：天賦分為「凡品」、「精良」、「絕品」三級，其稀有度與效果強度遞增。
    -   **生成權重**：
        -   凡品：60%
        -   精良：30%
        -   絕品：10%
    -   **重骰機制**：玩家若不滿意當前4個天賦，可消耗一次「重骰機會」刷新。初始給予2次重骰機會。重骰時，系統重新生成4個全新天賦。若2次重骰後仍不滿意，玩家必須從當前的4個天賦中選擇一個。
    -   **天賦池設計原則**：天賦是能改變玩家玩法風格或觸發特殊事件的「種子」。每個天賦都應有明確的「正面效果」與「潛在代價或限制」，以創造角色扮演上的張力。
    -   **MVP天賦池樣例（擴展版，加入早期事件影響）**：
        | 天賦名稱 | 品質 | 效果 | **早期事件影響（P0）** |
        |---|---|---|---|
        | 天生神力 | 凡品 | 初始武力+15 | 無特殊事件，但初期戰鬥中更容易觸發「擊退」效果。 |
        | 根骨清奇 | 凡品 | 初始體魄+15 | 無特殊事件，但初期受傷後恢復速度更快。 |
        | 過目不忘 | 凡品 | 初始悟性+10 | 在首次閱讀任何書籍或秘笈時，觸發「頓悟」事件，額外獲得少量悟性經驗。 |
        | 八面玲瓏 | 凡品 | 初始名聲+20 | 進入第一個城鎮時，所有NPC初始好感度+5。 |
        | 家學淵源 | 凡品 | 初始資質+10 | 無特殊事件，但學習第一個武學時，所需時間-10%。 |
        | 身手矯健 | 凡品 | 初始輕功+10 | 在首次逃離戰鬥或追逐事件中，成功率+10%。 |
        | 福星高照 | 精良 | 所有「機率觸發」類事件成功率+10% | 在第一次進行任何「機率性」行動（如賭博、探索廢墟）時，系統會提示「你感覺今天運氣不錯」。 |
        | 武學奇才 | 精良 | 學習武學所需時間-20% | 在遇到第一個武學師父時，師父會多看你兩眼，說「你這小子，骨骼精奇啊」。 |
        | 天生領袖 | 精良 | 招募NPC隊友時好感度門檻-10% | 在第一次與可招募NPC對話時，會觸發一個額外的「意氣相投」對話選項。 |
        | 鐵胃 | 精良 | 食物與飲水消耗速度降低30%，食物中毒機率降低50% | 在第一次食用「可疑」食物時，系統會提示「你的胃告訴你，這東西沒問題」。 |
        | 天選之人 | 絕品 | 可從4個天賦中選擇2個（此天賦本身不佔用名額） | 無特殊事件，但其本身的效果即為最強的開局優勢。 |
        | 死裡逃生 | 絕品 | 首次受到致命傷害時，強制保留1點生命，且3天內全屬性+30% | 無特殊事件，但會在玩家真正面臨死亡威脅時，觸發一次史詩級的逆轉。 |
        | **天煞孤星** | **絕品** | 所有親近你的NPC更容易遭遇不幸（死亡、重傷），但你自身在逆境中成長速度+50%。 | 玩家完成第一個與NPC的友好互動後，該NPC在3天內會遭遇一次「不幸事件」（如被小偷光顧、走路摔傷）。系統會提示「一股無形的晦氣似乎纏上了你身邊的人」。 |
        | **醫者仁心** | **絕品** | 你醫治NPC的成功率+30%，被醫治的NPC對你好感度額外+20。但你的雙手不適合殺戮，造成的所有傷害-10%。 | 玩家第一次目睹有人受傷時，會觸發一個「救治」選項。成功救治後，該NPC會感激涕零，並提供一個獨特的情報。 |
    -   **V2追加**：增加更多特殊天賦，如「斷袖之癖」、「天生毒體」、「賭徒」等，並為每個天賦設計對應的早期事件或對話。

3.  **外觀自定義（P0）**
    -   **MVP**：提供4個可自定義圖層，每個圖層提供3-5個選項。
        -   臉型：國字臉、瓜子臉、圓臉
        -   髮型：束髮、披肩髮、光頭、馬尾、道髻
        -   上衣：粗布衣、錦衣、勁裝
        -   下裝：長褲、長裙、綁腿褲
    -   所有外觀選擇僅為視覺效果，不影響任何數值。
    -   **V2追加**：增加五官細節（眼、鼻、口、眉）、膚色、鬍鬚、飾品等7個圖層。

4.  **角色命名（P0）**
    -   玩家輸入角色名稱，字數限制2-6個中文字或4-12個英文字母。
    -   提供「隨機生成」按鈕，從預設名稱庫（男/女通用）中隨機生成一個名字。名稱庫應包含常見姓氏與具有江湖氣息的單名或雙名。

5.  **確認與進入遊戲（P0）**
    -   玩家確認所有選擇後，點擊「踏入江湖」按鈕，正式進入遊戲。
    -   此時，玩家的初始屬性、金錢、物品、關係等根據其選擇的出身和天賦被初始化。

### 3.2 角色初始化（P0）

-   玩家確認創角後，系統根據以下規則初始化角色：
    1.  **基礎屬性**：所有7項核心屬性設定為初始基礎值（見第14章數值設計）。
    2.  **出身加成**：根據選擇的出身，疊加對應的屬性、金錢、名聲等。
    3.  **天賦加成**：根據選擇的天賦，疊加對應的屬性、特殊效果。
    4.  **初始物品**：根據出身，給予初始物品（如孤兒：破舊的布衣；商賈之子：200兩銀票；武官世家：一把鐵劍）。
    5.  **初始關係**：根據出身，生成初始的NPC關係（如武官世家：父親為朝廷武官，初始好感+50）。
    6.  **早期事件佇列（P0）**：根據玩家的出身與天賦選擇，系統生成一個「早期事件佇列」，確保玩家在踏入江湖的第一個小時內，能體驗到與其選擇相關的獨特事件。

## 4. 公式（Formulas）

### 4.1 天賦生成公式

-   **變數定義**：
    -   `N` = 每次生成的天賦數量（固定為4）
    -   `Rarity` = 天賦品質（0: 凡品, 1: 精良, 2: 絕品）
    -   `Weight`：`Weight(凡品) = 60`, `Weight(精良) = 30`, `Weight(絕品) = 10`
-   **公式**：
    -   系統從天賦池中隨機抽取N個天賦，每個天賦的品質由其對應的權重決定。
    -   抽取方式：生成一個1-100的隨機數`R`，若`R ≤ 10`則為絕品，若`10 < R ≤ 40`則為精良，否則為凡品。
-   **範例計算**：
    -   生成4個天賦，隨機數R分別為：5, 30, 70, 88。
    -   對應品質：絕品, 精良, 凡品, 凡品。
    -   從對應品質的天賦池中隨機抽取一個天賦。
-   **取整規則**：無。

### 4.2 初始金錢公式

-   **變數定義**：
    -   `Gold_Base` = 基礎金錢（固定為50兩）
    -   `Gold_Bonus` = 出身帶來的金錢加成（孤兒：0兩，商賈之子：200兩，武官世家：50兩）
-   **公式**：`初始金錢 = Gold_Base + Gold_Bonus`
-   **範例計算**：選擇「商賈之子」，初始金錢 = 50 + 200 = 250兩。
-   **取整規則**：結果取整數。

### 4.3 初始名聲公式

-   **變數定義**：
    -   `Fame_Base` = 基礎名聲（固定為0）
    -   `Fame_Bonus` = 出身帶來的名聲加成（孤兒：+10，商賈之子：-5，武官世家：+0）
-   **公式**：`初始名聲 = Fame_Base + Fame_Bonus`
-   **範例計算**：選擇「孤兒」，初始名聲 = 0 + 10 = 10。
-   **取整規則**：結果取整數。

## 5. 邊界條件（Edge Cases）

-   **玩家跳過所有開場文本**：允許。跳過後，玩家直接進入角色創建介面。
-   **玩家對所有隨機天賦都不滿意**：玩家可使用「重骰機會」刷新。若2次重骰後仍不滿意，玩家必須從當前的4個天賦中選擇一個。系統不會強制鎖定一個「最差」的天賦，也不會無限制讓玩家重骰。
-   **玩家輸入的角色名稱為空**：系統不允許提交，並提示「角色名稱不能為空」。
-   **玩家輸入的角色名稱過長**：系統限制字數，超過部分自動截斷或提示「名稱過長」。
-   **玩家輸入的角色名稱與其他已存檔角色重複**：允許。遊戲世界中的NPC不會因為名稱相同而產生混淆，每個角色都有唯一的後台ID。
-   **玩家選擇「武官世家」出身，但隨機生成的父親NPC已在另一局遊戲中死亡**：不影響。每一局遊戲是一個獨立的世界線，NPC狀態不繼承。
-   **玩家選擇「天選之人」天賦，並選擇了2個天賦，其中一個也是「天選之人」**：不允許。天賦池設計時，不會同時出現兩個「天選之人」。系統應避免此情況。
-   **玩家選擇「天煞孤星」天賦，並在遊戲初期就導致重要NPC死亡**：這是該天賦的核心機制，屬於預期內的玩法。系統不應干預，但應在NPC死亡時給予明確的訊息提示，讓玩家知道這是天賦導致的後果。
-   **玩家選擇「醫者仁心」天賦，但在戰鬥中被迫殺人**：天賦效果「造成的所有傷害-10%」會正常生效。系統不會因為玩家殺人而剝奪其天賦，但玩家的行為會影響其善惡名聲，與天賦形成角色扮演上的張力。
-   **玩家選擇「孤兒」出身，並在早期事件中遇到了「城門口的乞丐」**：該事件只會觸發一次。若玩家錯過或拒絕，將不會再次觸發。但身世線索會以其他形式（如一張舊地圖）在後續遊戲中出現。
-   **玩家的出身與天賦組合導致其早期事件佇列為空**：不可能發生。每個出身至少綁定一個早期事件，每個天賦也至少綁定一個早期事件或對話。系統會確保佇列中至少有1-2個事件。

## 6. 系統依賴（Dependencies）

-   **依賴的系統**：
    -   **核心屬性系統（第14章）**：角色創建時需要初始化所有核心屬性，並根據出身和天賦進行調整。
    -   **NPC人際關係系統（第7章）**：出身背景需要生成初始的NPC關係（如武官世家的父親）。
    -   **經濟系統（第12章）**：出身背景需要初始化角色的金錢和初始物品。
    -   **世界感知系統（第9章）**：出身背景影響初始名聲值，進而影響世界感知的起點。
    -   **事件系統（待設計）**：角色創建時生成的「早期事件佇列」需要依賴事件系統來觸發和執行。
-   **被依賴的系統**：
    -   **所有後續系統**：角色創建完成後，玩家的屬性、天賦、關係等數據將被所有後續系統（戰鬥、社交、事件等）讀取和使用。

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 類型 | 當前值 | 安全調整範圍 | 影響 |
|---|---|---|---|---|
| `N`（生成天賦數量）| 整數 | 4 | 3-6 | 值越大，玩家選擇越多，但決策時間越長。 |
| `Weight(凡品)` | 整數 | 60 | 50-70 | 影響玩家開局強度。權重越高，強力開局越少。 |
| `Weight(精良)` | 整數 | 30 | 20-40 | 同上。 |
| `Weight(絕品)` | 整數 | 10 | 5-15 | 同上。 |
| `重骰機會` | 整數 | 2 | 0-3 | 影響玩家對天賦的滿意度。機會越多，玩家越可能刷到理想天賦。 |
| `Gold_Base` | 整數 | 50 | 20-100 | 影響初期經濟壓力。 |
| `Gold_Bonus`（各出身）| 整數 | 0/200/50 | 可自由調整 | 影響不同出身玩家的初期財富差異。 |
| `Fame_Bonus`（各出身）| 整數 | 10/-5/0 | 可自由調整 | 影響不同出身玩家的初期社會關注度。 |

**品霖註記**：v3版本最重要的迭代，是為每個出身和天賦都綁定了具體的「早期事件影響」。這讓角色創建不再是一個孤立的環節，而是與遊戲世界深度連結的起點。玩家在創角時做的每個決定，都會在踏入江湖的第一個小時內得到具體回應，這正是「選擇有代價」與「沙盒世界運轉」這兩個核心目標在遊戲最前端的體現。接下來，我建議可以開始為「早期遊戲體驗」設計具體的事件腳本，讓這些種子真正發芽。
