## 1. 概述

局末人生回顧系統在玩家角色死亡後，自動生成一段約 2–3 分鐘的被動回顧旅程。這不是任務清單，而是一面情感的鏡子，映照出玩家在遊戲世界中的存在痕跡。它旨在回答「我是誰？」而非「我做了什麼？」——讓玩家感覺到「我就是這麼活過了」，引發內省與情感共鳴，而非成就滿足感。

系統從全域玩家行為標籤（Severity 連續值）動態組合情境腳本。每個情境都是一個微型場景，著重於關係、遺憾與平靜瞬間，而非任務完成度。

---

## 2. 玩家體驗

1. **死亡瞬間** — 畫面淡出，沒有失敗音樂，只有環境音（風聲、雨聲或心跳逐漸停止）
2. **開啟回顧** — 畫面從全黑中浮現抽象空間（星空、水面、無盡的書架）；無 UI，無任何互動提示
3. **情境流轉** — 系統播放 5–8 個情境，以視覺隱喻（翻頁、漣漪、流星劃過）自然過渡
4. **情感堆疊** — 開頭是溫柔或中性的記憶，中段浮現遺憾，最後以開放式疑問或平靜收尾
5. **結語** — 最後一個情境結束後，出現一行小字：「你被記住了，以你未曾想過的方式。」

**禁止事項：** 全程無評分、無統計數字、無「完成度百分比」、無「稀有成就解鎖」提示。

## 3. 詳細規則

### 3.1 行為標籤體系（MVP）

玩家的每個行為記錄在以下標籤中，每個標籤為 0.0–1.0 的 Severity 連續值：

| 標籤類別 | 標籤名 | 說明 |
|---------|--------|------|
| 關係類 | `AltruismLevel` | 主動幫助他人的累計傾向 |
| 關係類 | `BondsFormed` | 建立過深厚關係的 NPC 數量（標準化）|
| 關係類 | `BondsBroken` | 主動背叛或傷害過的關係數量（標準化）|
| 遺憾類 | `UnopenedLetters` | 未開啟的重要信件數量 |
| 遺憾類 | `UnspokenWords` | 放棄說出的重要對話選項次數 |
| 遺憾類 | `UnfulfilledDreams` | 遊戲內角色從未追求的潛在目標數 |
| 遺憾類 | `UnchosenPaths` | 在重大分岐點選擇數量 |
| 影響類 | `WorldAlterationDegree` | 對世界永久改變的正面程度 |
| 平靜類 | `IdleStargazingTime` | 玩家在遊戲中「無所事事」凝視場景的時間 |

### 3.2 情境觸發條件（MVP）

| 情境組 | 觸發標籤條件 | 情境類型 |
|--------|------------|---------|
| 正向關係 | `BondsFormed > 0.3` AND `NPCsSaved > 0` | 你幫助過的 NPC，在你死後的世界裡⋯⋯ |
| 漣漪效應 | `WorldAlterationDegree > 0.2` AND 「隨手贈禮」事件存在 | 某次隨手的善意，成為某人一生的珍藏 |
| 岐路感 | `UnchosenPaths > 3` | 你沒走的那條路，剪影一閃而過 |
| 個人遺憾 | `UnopenedLetters > 0` OR `UnspokenWords > 0` | 那封信，在死後自動展開了 |
| 宿敵反轉 | `CrueltyLevel > 0.4` AND `WorldAlterationDegree > 0.5` | 你以為恨你的宿敵，在你的墓前站了很久 |
| 存在主義 | 無條件觸發（固定）| 一生中最平靜的瞬間、「你被記住了」|

### 3.3 三幕強制結構（MVP）

系統將選出的情境分配為三幕，確保敘事節奏：

| 幕次 | 主題 | 情境數 | 情感基調 |
|------|------|--------|---------|
| 第一幕：此曾在 | 關係與影響 | 1–2 個 | 溫柔、中性 |
| 第二幕：未竟之事 | 遺憾與轉折 | 2–3 個 | 低沉、複雜 |
| 第三幕：餘音 | 平靜與開放 | 2–3 個 | 平靜、問句 |

若某幕無足夠情境，以抽象過場（長時間星空、空椅子特寫）填補。

### 3.4 任務遺憾呈現（V2，接收 #19 任務系統資料）

結算畫面呈現「失諾/無緣/辜負」三區塊（task-system.md 3.8.2 節），但不使用文字列表：

- **失諾**（FAILED）：凋零的樹葉，石碑上的任務名一秒後風化消失
- **無緣**（INVALIDATED）：往未選擇方向瘋狂生長的樹枝
- **辜負**（ABANDONED）：纏繞著你傷害過的 NPC 幻影的樹根

**核心原則：沒有譴責，只有呈現。**

## 4. 公式

### 4.1 情境優先級計算（MVP）

```
S_bond   = BondsFormed / (BondsFormed + BondsBroken + 1)
S_regret = min(1.0, UnopenedLetters×0.2 + UnspokenWords×0.3 + UnfulfilledDreams×0.5)
S_complexity = CrueltyLevel × WorldAlterationDegree

情境優先級 = w1×(1 - S_bond) + w2×S_regret + w3×S_complexity
```

**變數定義：**

| 變數 | 說明 | 範圍 |
|------|------|------|
| w1, w2, w3 | 各情感維度的加權係數（策劃配置）| 0.0–1.0，加總=1.0 |
| S_bond | 關係淨正面程度 | 0.0–1.0 |
| S_regret | 遺憾積累程度 | 0.0–1.0 |
| S_complexity | 矛盾複雜程度（做了善事但也傷害過人）| 0.0–1.0 |

**範例：** `UnopenedLetters=2, UnspokenWords=1, BondsFormed=0.6, BondsBroken=0.1`
→ S_regret = min(1.0, 0.4+0.3) = 0.7，S_bond = 0.6/0.7 = 0.857
→ 遺憾情境組優先觸發

## 5. 邊界條件

| 情境 | 處理方式 |
|------|---------|
| 速通/無互動（所有標籤為 0）| 播放預設回顧（星空情境 + 結語），螢幕浮現：「你像一陣風，來過，然後離開。」|
| 死亡過於頻繁（距上次完整觀看 < 5 分鐘且無新進展）| 提供「跳過回顧」選項 |
| 特定 NPC 已被刪除或資源無法載入 | 降級為該 NPC 的剪影或一封信 |
| 玩家強制關閉遊戲 | 進度自動存檔，下次啟動不再播放已看過的同一局回顧 |

## 7. 可調參數

**外部化至：`assets/data/life-retrospect/config.json`**

| 參數 | 預設值 | 安全範圍 | 影響 |
|-----|--------|---------|------|
| `max_retrospect_scenes` | **7** | 5–8 | 最多播放的情境數 |
| `abstract_filler_duration_s` | **20** | 15–30 | 抽象過場填充持續秒數 |
| `w1_bond_weight` | **0.3** | 0.0–1.0 | 關係維度加權 |
| `w2_regret_weight` | **0.4** | 0.0–1.0 | 遺憾維度加權 |
| `w3_complexity_weight` | **0.3** | 0.0–1.0 | 矛盾維度加權（w1+w2+w3=1.0）|
| `skip_cooldown_minutes` | **5** | 1–30 | 允許跳過回顧的最短間隔（現實分鐘）|

## 8. 驗收標準

| 編號 | 驗收項目 | 預期結果 | 阻斷 |
|-----|---------|---------|-----|
| AC1 | 速通死亡 | 所有標籤為 0 → 播放預設回顧（星空+「像一陣風」），無報錯 | 是 |
| AC2 | 有正向關係的死亡 | BondsFormed > 0 → 第一幕出現相關 NPC 情境 | 是 |
| AC3 | 三幕結構完整 | 任何回顧必定包含三幕，且第一幕先播、餘音最後播 | 是 |
| AC4 | 全程無 UI | 回顧期間無任何 HUD、評分、任務標記出現 | 是 |
| AC5 | 跳過機制 | 頻繁死亡時出現「跳過回顧」選項，確認後直接進主選單 | 是 |
| AC6 | NPC 資源缺失降級 | 死亡前 NPC 被刪除 → 回顧中顯示剪影代替，無崩潰 | 是 |
| AC7 | 遺憾情境觸發 | UnopenedLetters > 0 → 第二幕出現「那封信自動展開」情境 | 否（V2）|
| AC8 | 任務三幕呈現 | FAILED/INVALIDATED/ABANDONED 各自對應正確的視覺呈現樹 | 否（V2）|
