## 1. 概述

武俠抗性體系是角色對抗江湖中各種非直接物理傷害（毒藥、極端環境、內傷、精神衝擊等）的防禦機制。抗性不是單一數值，而是由核心屬性（體魄、內力、輕功、悟性）衍生的六種獨立抗性值，形成多維度防禦網路。玩家透過練武、裝備、江湖歷練提升抗性，直接影響生存能力、戰鬥效率與壽命損耗。

## 2. 玩家體驗

- **「練成金剛不壞之體，蛇毒奈我何？」** — 體魄提升帶來的毒抗成就感
- **「這座雪山寒冷刺骨，沒準備好就是送死。」** — 探索前的策略準備
- **「老魔頭陰毒掌力，不但傷我，還讓我內力不暢！」** — 戰術博弈的多維度抗性
- **「縱橫江湖，暗傷積累，晚年怕是難熬了。」** — 長期選擇的代價感

## 3. 詳細規則

### 3.1 六種抗性類型

| 抗性 | 武俠描述 | 主要屬性 | 次要屬性 | 抵抗狀態 | 版本 |
|-----|---------|---------|---------|---------|------|
| 毒抗 | 百毒不侵之體 | 體魄 ×0.5 | 內力 ×0.3 | 中毒、麻痺 | MVP |
| 寒抗 | 不畏嚴寒 | 體魄 ×0.6 | 內力 ×0.2 | 凍傷、寒毒 | **V2**（MVP 階段暫無對應的凍傷狀態，推遲至 V2 實作）|
| 火抗 | 不懼烈火 | 體魄 ×0.4 | 輕功 ×0.4 | 灼燒、焚身 | **V2**（MVP 階段暫無對應的灼燒狀態，推遲至 V2 實作）|
| 內傷抗 | 經脈穩固氣血充盈 | 內力 ×0.6 | 體魄 ×0.3 | 內傷、經脈受損 | MVP |
| 眩暈抗 | 心神堅定下盤穩健 | 內力 ×0.5 | 輕功 ×0.3 | 眩暈、混亂 | MVP |
| 點穴抗 | 氣門閉塞難以被封 | 內力 ×0.7 | 悟性 ×0.2 | 點穴、技能封鎖 | MVP |

**注意**：名聲（社交屬性）不參與抗性計算。

### 3.2 抗性值提升方式

1. **基礎值**：由屬性公式自動計算（見第4節）
2. **裝備詞條**：如「金絲軟甲：毒抗 +20」
3. **武學加成**：如「習寒冰真氣：寒抗 +30%」
4. **藥物/食物**：暫時提升（如薑湯：寒抗 +50，持續 1 天）
5. **永久奇遇**：特定事件或天材地寶可永久提升抗性上限

### 3.3 抗性檢定機制

受到特殊攻擊或身處惡劣環境時觸發抗性檢定：

1. **觸發**：攻擊/環境效果帶有「抗性檢定難度（DC）」
2. **計算**：`檢定結果 = 對應抗性值 + 亂數(0, 20)`
3. **判定**：
   - `檢定結果 ≥ DC` → 完全抵抗，無負面效果
   - `檢定結果 < DC` → 觸發負面效果，效果強度 = `DC - 檢定結果`

### 3.4 負面效果強度分級

| 差值範圍 | 強度 | 初始 severity 注入量 | 中毒範例（進入 #43 傷勢系統）|
|---------|-----|-------------------|--------------------------|
| 1–20 | 輕微 | +0.1 severity | 中毒輕微，生命每小時 -0.5% |
| 21–50 | 中等 | +0.3 severity | 中毒明顯，武力 -10%，生命每小時 -1.5% |
| 51+ | 嚴重 | +0.6 severity | 中毒嚴重，武力 -20%，內力 -20%，生命每小時 -3% |

觸發的負面效果直接注入對應狀態的 severity 值，後續由傷勢系統（#43）接管計算。（已移除「回合」概念，遊戲為即時制，統一使用時間單位。）

## 4. 公式

### 4.1 基礎抗性值計算

```
毒抗   = floor( BOD × 0.5 + NRI × 0.3 )          # MVP
寒抗   = floor( BOD × 0.6 + NRI × 0.2 )          # V2（MVP 暫無凍傷/寒毒狀態，公式預留）
火抗   = floor( BOD × 0.4 + AGL × 0.4 )          # V2（MVP 暫無灼燒/焚身狀態，公式預留）
內傷抗 = floor( NRI × 0.6 + BOD × 0.3 )          # MVP
眩暈抗 = floor( NRI × 0.5 + AGL × 0.3 )          # MVP
點穴抗 = floor( NRI × 0.7 + WIS × 0.2 )          # MVP

BOD=體魄, NRI=內力, AGL=輕功, WIS=悟性
```

範例（BOD=80, NRI=60, AGL=50, WIS=40）：
- 毒抗 = floor(80×0.5 + 60×0.3) = floor(40+18) = 58
- 內傷抗 = floor(60×0.6 + 80×0.3) = floor(36+24) = 60

### 4.2 抗性檢定公式

```
檢定結果 = 對應抗性值 + ROLL(0, 20)
if 檢定結果 ≥ DC: 完全抵抗
else: 效果強度 = DC - 檢定結果
```

範例：毒抗 58，毒蛇 DC=70
- ROLL=15 → 73 ≥ 70 → 完全抵抗
- ROLL=5  → 63 < 70 → 差值=7，輕微中毒

## 5. 邊界條件

| 情況 | 處理方式 |
|------|---------|
| 抗性值為負數 | 允許（因重傷/詛咒導致屬性極低），差值更大效果更強 |
| 多種抗性同時檢定 | 各自獨立進行，玩家可能只抵抗部分 |
| 抗性值遠超最高 DC | 永遠成功，即武俠世界「百毒不侵」的正常表現 |
| 特殊免疫狀態 | 直接跳過抗性檢定（比高抗性更強，需謹慎設計） |
| 環境持續檢定 | 每 1 天或 1 個時辰一次，連續失敗累積惡化 |

## 6. 系統依賴

**本系統依賴：**
- 核心屬性系統（抗性值衍生來源）
- 裝備與武學系統（提供抗性加成）

**依賴本系統：**
- 傷勢與狀態效果系統（抗性檢定失敗觸發 severity 增加）
- 戰鬥系統（攻擊定義 DC 和附帶狀態類型）
- 世界地圖系統（特定區域定義環境檢定 DC）
- 壽命系統（長期低抗性 + 反覆受傷觸發減壽事件，V2）
- NPC 關係系統（NPC 感知玩家是用毒高手，V2）
