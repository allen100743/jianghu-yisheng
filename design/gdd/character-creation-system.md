## 1. 概述（Overview）

角色創建系統是《江湖一生》的入口，負責在5分鐘內，透過「出身背景選擇」、「外觀自定義」、「角色命名」、「性格選擇」、「初始天賦開獎」五個步驟，生成一個獨一無二的角色。系統設計一個包含10個出身背景、30個天賦的資料池，每次遊玩從池中隨機抽取展示。核心任務不只是建立角色的初始狀態，更是為玩家即將展開的江湖人生埋下第一顆故事種子。

---

## 2. 玩家體驗（Player Fantasy）

- **「我的出身，決定了我的江湖起點」**：出身不只是初始數值，而是玩家踏入江湖時，第一個遇到的人、第一句聽到的話、第一個任務，都因此不同。
- **「我的天賦，是命運的第一顆骰子」**：隨機天賦不只是數值加減，而是定義角色命運走向的種子。抽到「天煞孤星」的玩家，知道自己身邊的人會遭殃；抽到「醫者仁心」的玩家，則思考如何不殺戮地走完這一生。
- **「這就是我，我準備好了」**：外觀自定義與命名讓角色有了具體形象。點下「踏入江湖」的瞬間，玩家已準備好以這個角色的身份經歷一切。
- **「快速開始」**：5分鐘內完成，不讓玩家在創角就疲勞。

## 3. 詳細規則（Detailed Rules）

### 3.1 創角流程（P0）—— 靜怡核准版

> 流程順序：出身 → 外觀 → 命名 → **性格選擇** → 天賦開獎 → 確認
>
> 性格在命名之後、天賦之前。命名讓玩家先對角色產生情感依附，此時再選擇「我這個人是什麼性格」，順序上更像「認識自己」的過程；天賦開獎則是命運的最後一張牌。

**步驟一：出身背景選擇**
- 玩家從10個出身中選擇1個
- 選擇後系統顯示約50-100字開場文本（可跳過）

**步驟二：外觀自定義**
- MVP：4個圖層（見3.3節）

**步驟三：角色命名**
- 玩家輸入名稱，或點「隨機生成」

**步驟四：性格選擇**
- 玩家從**八種性格**中選擇1種，每種性格再選擇**三個度數（-1 / 0 / +1）**之一，代表該性格的純粹程度
- 八種性格：豪爽、陰沉、莽撞、謹慎、正直、狡猾、冷酷、俠義
- 每個性格的三個度數皆有簡短說明（口頭禪/行為風格），幫助玩家理解選擇意義
- 選擇後，介面顯示該性格對屬性和NPC好感度的加減影響預覽
- **此選擇在確認後永久鎖定，影響整個角色一生。** 遊戲中不提供重新選擇的機會。
- 性格的完整效果定義（屬性修飾詞、NPC好感修正、對話觸發規則）見 `personality-system.md`

**步驟五：天賦開獎**
- 系統從30個天賦池隨機抽出4個，玩家選1個
- 可重骰2次

**步驟六：確認踏入江湖**

## 4. 公式（Formulas）

### 4.1 天賦生成公式

**變數定義：**
- `N` = 每次展示天賦數量（固定為4）
- `Weight(凡品) = 60`, `Weight(精良) = 30`, `Weight(絕品) = 10`

**公式：** 生成一個1-100的隨機數 `R`：
- `R ≤ 10` → 絕品
- `10 < R ≤ 40` → 精良
- `R > 40` → 凡品

**範例計算：** 生成4個天賦，R分別為5, 30, 70, 88 → 絕品, 精良, 凡品, 凡品

### 4.2 初始金錢公式

```
初始金錢 = Gold_Base(50兩) + Gold_Bonus(出身)
```

| 出身 | Gold_Bonus |
|------|-----------|
| 孤兒 | +0兩 |
| 商賈之子 | +200兩 |
| 武官世家 | +50兩 |
| 書香門第 | +50兩 |
| 江湖浪子 | -20兩 |
| 隱世高人之後 | +30兩 |
| 農家子弟 | +20兩 |
| 醫者之後 | +80兩 |
| 落魄貴族 | +100兩 |
| 寺廟孤兒 | +10兩 |

### 4.3 初始名聲公式

```
初始名聲 = Fame_Base(0) + Fame_Bonus(出身)
```

範例：孤兒初始名聲 = 0 + 10 = 10

## 5. 邊界條件（Edge Cases）

| 情境 | 處理方式 |
|------|---------|
| 玩家跳過開場文本 | 允許，直接進入下一步 |
| 重骰2次後仍不滿意 | 必須從當前4個選1，不能無限骰 |
| 角色名稱為空 | 不允許提交，提示「名稱不能為空」 |
| 角色名稱過長 | 超過字數上限自動截斷或提示 |
| 名稱與已存檔角色重複 | 允許，後台ID唯一，NPC不會混淆 |
| 「天選之人」天賦：4個中出現兩個天選之人 | 天賦池設計時禁止同時出現兩張，系統層面阻止 |
| 「天煞孤星」導致重要NPC在遊戲初期死亡 | 預期內玩法，不干預，但觸發明確提示 |
| 「醫者仁心」玩家被迫在戰鬥中殺人 | 傷害-10%效果照常生效，不剝奪天賦，但影響善惡名聲 |
| 「落魄貴族」玩家無法負擔每月10兩維護費 | 無法維持「體面」時，特定貴族/官宦NPC好感逐漸下滑，系統提示 |
| 出身+天賦組合導致早期事件佇列為空 | 不可能：每個出身綁定至少1個早期事件，系統確保佇列非空 |

## 6. 系統依賴（Dependencies）

**依賴的系統：**
- 核心屬性系統（#2）：初始化7項核心屬性
- 性格特質系統（`personality-system.md`）：性格選擇步驟從此系統讀取選項、修飾詞規則，初始化 severity 值
- NPC人際關係系統（#15）：出身生成初始NPC關係
- 經濟系統（#12）：初始化金錢與物品
- 世界感知系統（#16）：出身影響初始名聲起點
- 事件系統（#20/#21）：觸發「早期事件佇列」

**被依賴的系統：**
- 所有後續系統均讀取角色創建產出的屬性、天賦、關係數據

> **與天賦系統（#6）的邊界說明：**
> 本系統負責「初始天賦的抽取流程與展示」（從30個池子中抽4個、玩家選1個、重骰規則）。
> 天賦的效果計算規則、疊加規則、衝突對規則、附加天賦獲取機制，由 **talent-system.md** 定義。
> 程序員實作時：創角模組調用天賦系統的「初始化天賦」接口，不自行計算效果。

## 7. 可調參數（Tuning Knobs）

| 參數 | 當前值 | 安全範圍 | 影響 |
|------|-------|---------|------|
| N（展示天賦數量）| 4 | 3–6 | 越多選擇越豐富，但決策時間越長 |
| Weight(凡品) | 60 | 50–70 | 越高則強力開局越少 |
| Weight(精良) | 30 | 20–40 | |
| Weight(絕品) | 10 | 5–15 | |
| 重骰機會 | 2 | 0–3 | 越多玩家越能刷到滿意天賦 |
| Gold_Base | 50兩 | 20–100兩 | 影響初期經濟壓力 |
| 早期事件佇列大小 | 2 | 1–3 | 影響初期獨特內容量 |
| 天煞孤星不幸觸發率 | 100% | 50–100% | 控制負面效果強度 [需測試] |
| 醫者仁心傷害減免 | -10% | -5%至-20% | 平衡正負效果 [需測試] |
| 落魄貴族月維護費 | 10兩/月 | 5–20兩/月 | 影響出身的長期壓力 |
