## 1. 概述（Overview）

程序化世界生成系統是《江湖一生》世界的骨架生成器。它負責在每一次新遊戲開始時，根據一套固定的地理邏輯與可配置的隨機種子，動態生成一個完整、合理、可探索的明朝江湖世界地圖。這個系統確保了「地圖框架固定（門派位置固定），但各地點的細節與連接方式有變化」的設計原則，為每次遊玩提供新鮮感，同時保證核心體驗的一致性。

---

## 2. 玩家體驗（Player Fantasy）

- **每次開局都是一個新的江湖**：玩家不會每次都在同一個新手村醒來，也不會每次都看到完全相同的城鎮佈局。這強化了「這是我的一生」的獨特性。
- **世界是真實的、有距離感的**：從地圖上就能感受到，去北平府需要跋山涉水，而去蘇州則依水網密佈。移動的選擇本身就是一種策略。
- **探索的樂趣**：地圖上會標出已知的主要城鎮與門派，但野外區域、秘境、隱藏地點的位置是未知的。玩家會因為「前方有條小路」而產生探索慾望，而不是看著一張全亮的地圖。

## 3. 詳細規則（Detailed Rules）

### 3.1 生成流程（MVP）

1.  **種子初始化**：新遊戲開始時，系統生成一個隨機種子（Seed）。
2.  **錨點放置（固定）**：基於種子，在固定坐標放置「不可移動的錨點」：
    *   **主要城鎮（12個）**：應天府、北平府、開封府等，位置固定（對應真實地理）。
    *   **主要門派（8個）**：天罡劍派（華山）、金剛寺（嵩山）等，位置固定。
    *   **特殊地點（6個）**：龍門石窟、毒龍潭等，位置固定。
3.  **次要地點生成（動態）**：
    *   在主要城鎮之間的交通路線（官道、水路）上，以一定間距生成「驛站」與「渡口」。
    *   在主要城鎮周邊，生成「衛星村莊」（新手村、礦村、漁村等）。
    *   在門派附近，生成「關聯聚落」（如天罡劍派山腳下的「劍廬鎮」）。
4.  **野外區域填充（動態）**：
    *   將地圖上未被錨點佔據的區域劃分為「野外區塊」。
    *   每個野外區塊被賦予一個地形類型（森林、山地、平原、沼澤、水域）。
    *   在野外區塊內，隨機生成「興趣點」：廢棄神祠、強盜營寨、獵人小屋、藥草叢等。
    *   興趣點之間由「隨機小徑」連接，形成非主幹道的探索網絡。
5.  **路網生成**：
    *   **主幹道**：連接所有主要城鎮與門派，路況最好，安全性最高，但路線固定。
    *   **次級道**：連接衛星村莊與主幹道，路況普通。
    *   **小徑**：連接野外興趣點，路況差，易遇襲，但可能發現捷徑或寶物。

### 3.2 生成規則（MVP）

*   **距離規則**：任何兩個主要城鎮之間的距離必須在 `[X, Y]` 天（遊戲內時間）的範圍內，以保證地圖的「可玩性」與「真實感」。
*   **地形邏輯**：
    *   水域（長江、黃河、洞庭湖、鄱陽湖）的位置是固定的。
    *   山地（華山、嵩山、點蒼山）圍繞對應門派生成。
    *   森林、平原圍繞城鎮與河流生成，提供補給與平坦行軍路線。
    *   沼澤、荒漠等地形分佈在邊緣地帶。
*   **可探索性規則**：每個野外區塊至少包含 `[N]` 個興趣點，避免地圖空洞。
*   **新手保護規則**：初始城鎮（玩家出生點）周圍 `[Z]` 天路程內的野外區塊，生成的敵人強度上限為「普通」，確保玩家初期不會誤入高難度區域。

### 3.3 特殊地點的「可變性」（V2 追加）

*   **非固定位置的特殊地點**：如「龍泉寶藏」的入口不再固定在浙江龍泉，而是根據種子隨機分佈在一個或多個可能的「寶藏圖碎片」所指的位置。玩家需要收集線索才能找到。
*   **動態秘境**：某些秘境（如「懸空寺」）的進入方式（需要特定物品、特定天氣、特定時間）可以隨種子變化，增加重玩性。

## 4. 公式（Formulas）

### 4.1 野外區塊興趣點數量公式

`興趣點數量 = 基礎數量 + floor(區塊面積 / 面積係數) + 隨機偏移`

*   **變數定義**：
    *   `基礎數量`：`3`（確保最低可玩性）
    *   `區塊面積`：以「格」為單位的地圖區塊大小。
    *   `面積係數`：`100`（每100格增加一個基礎興趣點）
    *   `隨機偏移`：`randint(-1, 2)`，增加隨機性。
*   **範例計算**：
    *   一個面積為 `250` 格的野外區塊。
    *   `興趣點數量 = 3 + floor(250 / 100) + randint(-1, 2)` = `3 + 2 + randint(-1, 2)` = `4` 到 `7` 個興趣點。
*   **數值取整規則**：`floor()` 向下取整。

### 4.2 主幹道距離範圍公式

`距離（天） = 地理距離（里） / 每日行軍里程`

*   **變數定義**：
    *   `地理距離（里）`：兩個錨點在生成時計算出的歐幾里得距離，乘以一個「距離係數」轉換為「里」。
    *   `每日行軍里程`：`60` 里/天（參考古代步兵行軍速度）。
*   **範例計算**：
    *   應天府與開封府的 `地理距離` 計算後為 `450` 里。
    *   `距離（天） = 450 / 60 = 7.5` 天。
*   **數值取整規則**：`ceil()` 向上取整，顯示為 `8` 天。

### 4.3 敵人強度區域等級公式

`區域等級 = 基礎等級 + floor(距離初始城鎮天數 / 難度增長間隔)`

*   **變數定義**：
    *   `基礎等級`：`1`（初始城鎮周邊）。
    *   `距離初始城鎮天數`：玩家從初始城鎮出發，沿最短路徑到達該區域所需的遊戲內天數。
    *   `難度增長間隔`：`15` 天（每遠離初始城鎮15天路程，區域等級+1）。
*   **範例計算**：
    *   一個距離初始城鎮 `40` 天路程的野外區塊。
    *   `區域等級 = 1 + floor(40 / 15) = 1 + 2 = 3`。
*   **數值取整規則**：`floor()` 向下取整。

## 5. 邊界條件（Edge Cases）

*   **地圖過大/過小**：
    *   **情況**：種子生成的參數導致地圖上的城鎮之間距離過遠或過近。
    *   **處理**：生成完成後進行一次「合理性校驗」。若任意兩個主要城鎮的距離超出 `[X, Y]` 天範圍，則自動調整「距離係數」並重新生成，直到所有距離符合要求。
*   **興趣點生成在無法到達的位置**：
    *   **情況**：興趣點生成在湖泊中央、懸崖峭壁等無法步行到達的位置。
    *   **處理**：興趣點生成後進行一次「可達性校驗」。若發現無法到達，則在該興趣點與最近的可行走路徑之間，自動生成一條「隱藏小徑」或「獨木橋」。
*   **衛星村莊與門派聚落重疊**：
    *   **情況**：生成的衛星村莊與門派關聯聚落在位置上發生重疊。
    *   **處理**：觸發「合併」邏輯。將兩個聚落合併為一個更大的、功能更豐富的城鎮，並同時擁有「補給」與「門派相關」的功能屬性。
*   **玩家出生在邊緣地帶**：
    *   **情況**：玩家初始城鎮生成在地圖邊緣，導致一側是「世界邊界」，探索方向受限。
    *   **處理**：這是一個可接受的邊界情況。遊戲不會強制玩家出生在地圖中央。邊緣出生會引導玩家向內陸探索，這本身就是一種遊戲體驗。世界邊界用「連綿不絕的凶險群山」或「無邊無際的汪洋大海」來合理化。
*   **種子導致地圖過於單調**：
    *   **情況**：種子生成的隨機偏移導致所有野外區塊的地形都是「平原」。
    *   **處理**：在生成邏輯中加入「地形多樣性強制規則」。確保每個主要區域（如華北、江南、巴蜀）內，至少包含 `[3]` 種不同的地形類型。

## 6. 系統依賴（Dependencies）

### 依賴其他系統：
*   **無**。世界生成系統是遊戲啟動時第一個運行的系統，它不依賴其他任何遊戲系統。

### 被其他系統依賴：
*   **地圖與移動系統**：依賴此系統生成的地圖數據來顯示地圖、計算移動路徑與時間。
*   **NPC生成與日程系統**：依賴此系統生成的城鎮、門派、野外興趣點來決定NPC的初始位置與活動範圍。
*   **事件觸發系統**：依賴此系統生成的興趣點與路網來決定隨機事件的發生地點。
*   **經濟系統**：依賴此系統生成的城鎮、村莊、驛站來決定交易市場的位置。
*   **戰鬥系統**：依賴此系統生成的「區域等級」來決定遭遇敵人的強度。

## 7. 可調參數（Tuning Knobs）

| 參數名稱 | 預設值 | 安全調整範圍 | 影響 |
|---|---|---|---|
| `每日行軍里程` | `60` 里/天 | `[40, 80]` | 影響地圖感知大小。值越小，地圖感覺越大，移動越耗時。 |
| `難度增長間隔` | `15` 天 | `[10, 25]` | 影響遊戲難度曲線。值越小，離開新手區後敵人變強的速度越快。 |
| `基礎興趣點數量` | `3` | `[1, 5]` | 影響地圖的「內容密度」。值越大，探索時發現東西的頻率越高。 |
| `面積係數` | `100` | `[50, 200]` | 影響地圖的「可玩性」。值越小，大地圖上的興趣點越多。 |
| `最小城鎮距離` | `5` 天 | `[3, 8]` | 影響世界「空曠感」。值越大，城鎮之間越空曠，長途旅行更常見。 |
| `最大城鎮距離` | `15` 天 | `[10, 20]` | 影響世界「緊湊感」。值越大，地圖範圍越大。 |
| `新手保護半徑` | `3` 天 | `[2, 5]` | 影響新手體驗的「安全區」大小。 |

## 8. 驗收標準（Acceptance Criteria）

*QA人員可以逐條驗證以下項目：*

1.  [P0] 新遊戲開始時，能成功生成一個包含12個主要城鎮、8個主要門派、6個特殊地點的世界地圖，且無報錯。
2.  [P0] 所有生成的城鎮、門派、特殊地點均位於其固定坐標，與設計文件一致。
3.  [P0] 所有生成的次要地點（驛站、村莊）均位於主/次級道路沿線，無孤立於路網之外的情況。
4.  [P0] 使用不同的隨機種子開始遊戲10次，每次生成的地圖在次要地點、野外興趣點的位置與類型上均有顯著差異。
5.  [P0] 地圖上任意兩個主要城鎮之間的遊戲內移動時間，均在 `[5, 15]` 天的範圍內。
6.  [P0] 初始城鎮周圍 `3` 天路程內的野外區塊，其生成的敵人強度等級均為 `1`（普通）。
7.  [P0] 地圖上不存在無法通過步行到達的野外興趣點（已生成隱藏路徑或獨木橋）。
8.  [P1] 連續生成50張地圖，無任何因種子導致的崩潰或生成失敗。
9.  [P1] 地圖上每個主要地理區域（華北、江南、巴蜀等）內，至少包含3種不同的地形類型。
10. [P2] V2追加功能：非固定位置的特殊地點入口，能根據種子正確隨機分佈。
