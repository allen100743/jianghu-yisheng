## 核心系統架構原則

整個遊戲世界的運作邏輯可以用一個公式描述：

```
玩家變量 → NPC 反應引擎 → 世界回應
```

**玩家變量**包含：屬性、稱號、陣營、關係、名聲、行為記錄……
**NPC 反應引擎**：讀取變量，觸發對應反應
**世界回應**：對話改變、事件觸發、機會開啟或關閉

這意味著系統天然可擴展——
增加新稱號 = 增加新的變量值
增加新陣營 = 增加新的反應集合
增加新關係類型 = 增加新的觸發條件

**GDD 中列出的稱號、陣營、關係都只是初始實例，不是完整清單。**
沙盒模擬的是社會與人際關係，變量永遠可以增加。

## 1. 遊戲概覽

### 核心定位
**武俠沙盒生涯RPG。**
玩家扮演明朝初年一個普通江湖人，在有限的一生中做出選擇，選擇留下痕跡，痕跡構成這一生的故事。

### 四個核心支柱
1. **這是我的一生** — 一局遊戲代表角色完整的一生，有生老病死
2. **選擇有代價** — 每個決定都有真實後果，無法撤回
3. **江湖有人** — NPC是活的，有自己的生命、恩怨、記憶
4. **時間可見** — 角色的身體和世界隨著時間真實變化

### 競品定位
- **基礎框架**：站在龍胤立志傳肩膀上（世界觀、沙盒深度）
- **個人戲劇**：學習鬼谷八荒（仇人、情人、義兄弟的戲劇性）
- **核心創新**：世界感知系統（距離＋時間維度的名聲傳播）

### 時代背景
明朝洪武年間（朱元璋執政早期），元朝餘部仍在北方。江湖秩序初建，正邪未定，是最適合一個普通人改寫命運的時代。

## 2. 早期遊戲體驗

### 設計目標
Steam兩小時退款窗口是生死線。前兩小時必須讓玩家感受到：「這個選擇是我做的，後果是真實的。」

### 第一次遊玩流程

**第一幕（0-20分鐘）：我是誰**
- 角色創建：外觀自定義（紙娃娃分層）
- 初始天賦選擇：系統隨機生成天賦池，玩家選一個
- 開場劇情：玩家角色的出身故事（短，可跳過）
- 第一個選擇：在15分鐘內出現，有明確的兩條路

**第二幕（20-60分鐘）：江湖是什麼**
- 第一場戰鬥：有清楚的操作回饋
- 第一個記得住的NPC：有個性、有後續出現
- 第一個選擇的後果：在同一個小時內讓玩家看到

**第三幕（60-120分鐘）：我要做什麼**
- 世界開放：玩家開始自己決定去哪、做什麼
- 第一次境界突破：選天賦（隨機池選擇）
- 玩家心裡有了一個目標（不是系統逼的，是自己想的）

### 再次遊玩
- 可完整跳過新手劇情
- 直接進入角色創建→開放世界
- 熟悉流程的玩家10分鐘內進入沙盒

## 3. 角色創建系統

### 外觀自定義（紙娃娃系統）
共11個圖層，詳見美術規格文件。
玩家可自定義：臉型、五官、髮型、服裝、膚色等。

### 初始天賦系統

**設計原則：隨機池讓玩家選**
- 系統隨機生成N個天賦（具體數量待測試調整）
- 玩家從中選擇一個作為初始天賦
- 保留鬼谷八荒的隨機驚喜感 + 龍胤立志傳的主導感
- 避免鬼谷的「完全廢號」問題（玩家有選擇權）

**天賦出現時機**
1. 角色創建時：初始天賦
2. 江湖稱號提升時（屬性自動達到門檻）：附加天賦

## 4. 核心玩法循環

### 時間單位
以「日」和「月」為基本單位。玩家行動消耗時間，時間推進世界。

### 每日循環（短期）
1. 選擇今日行動（探索/練武/社交/任務/其他）
2. 執行行動，遭遇事件
3. 世界回應（NPC反應、消息傳播、關係變化）
4. 日結算（資源、狀態、關係更新）

### 生涯循環（長期）
1. 成長（武學精進、屬性提升、關係深化）
2. 選擇（加入哪個陣營、跟誰結盟、做什麼事）
3. 後果累積（名聲傳播、仇人增加、身份確立）
4. 生命終點（角色老死或在某個關鍵事件中結束）

## 5. 成長系統：屬性與境界標籤

### 核心邏輯

**境界不是目標，是結果。**

玩家真正在培養的是**屬性**。屬性累積到一定程度，系統自動給予對應的「境界標籤」。這個標籤是對外的社會認可，不是玩家需要主動追求的東西。

```
裝備詞條 ┐
武學技能 ├→ 累積角色屬性 → 屬性達到門檻 → 自動獲得境界標籤
天賦     │
特定成就 ┘
```

### 屬性（核心成長機制）

屬性是遊戲真正的成長維度（詳見第14章數值設計：武力/內力/體魄/輕功/資質/悟性/名聲）。
屬性影響：
- 能不能學某套武功（有屬性門檻）
- 戰鬥中的各種表現
- 能用哪些裝備
- 壽命長短

### 修煉機制（雙軌制）

**演習修煉**：玩家主動選擇「練武」行動，消耗遊戲內時間，對應屬性穩定成長。玩家自己決定何時修煉、練哪個屬性。

**實戰修煉**：實際戰鬥帶來屬性成長，以戰養戰。打得越多、越難的對手，成長越顯著。

兩條路徑可並行：專心練功的隱士型 vs 闖蕩江湖的實戰型，玩法風格自然分化。

### 江湖稱號（成就系統）

稱號不是單一等級線，而是**多維度成就標籤系統**。

- 不同屬性維度各有對應的稱號（武力極高 → 武學稱號；名聲極高 → 江湖地位稱號；特定事件 → 特殊稱號）
- 稱號決定 NPC 對玩家的態度、可觸發的對話與機會
- 玩家可同時持有多個來自不同維度的稱號

### 成就系統：多維度稱號樹

**設計核心原則：稱號 = 世界給你的社會標籤，不是戰鬥力數值。**
稱號改變世界對你的看法，而非直接提升屬性。稱號帶來的屬性加成是「因為達到了某個境界，系統自動獎勵」，不是「為了拿稱號去衝數值」的邏輯。

#### 多稱號並存機制

玩家可同時持有來自不同維度的多個稱號。UI提供一個「稱號欄位」，玩家選擇一個**主要稱號**（對外展示），其他稱號作為**隱藏標籤**，影響NPC的深層判斷。

- **主要稱號**：決定NPC的第一印象和主要態度。同一個人亮出「武當七俠」或「朝廷密探」，會收到截然不同的反應。
- **隱藏標籤**：當NPC與玩家互動深入（長時間相處、特定事件觸發），系統根據隱藏標籤調整反應，創造「知人知面不知心」的戲劇張力。
- **主要稱號切換**：無冷卻時間，可隨時更換，但會即時影響當前區域NPC態度。

#### 稱號六大維度

##### 維度一：武學境界（結果論）
基於綜合評分自動賦予（公式見14.2節）。此維度**只保留一個**，新稱號覆蓋舊稱號。

| 稱號 | 觸發評分 | NPC反應 |
|---|---|---|
| 江湖新丁 | 0–500 | 漠視，交易價格偏高，小嘍囉會主動挑釁 |
| 小有名氣 | 501–1500 | 尊重，門派守門弟子會通報，開始有無名劍客前來挑戰 |
| 武林高手 | 1501–3500 | 敬畏，地方豪強設宴款待，官府列為「危險人物」監控 |
| 一代宗師 | 3501+ | 傳說，朝廷秘密拉攏或戒備，後輩見你自動讓路 |

##### 維度二：善惡名聲（行為論）
基於「俠義值」與「惡名值」兩個隱藏數值計算：善惡值 = 俠義值 - 惡名值。此維度稱號**累進式**，只能處於當前善惡值對應的一個稱號。

| 稱號 | 善惡值區間 | NPC反應 |
|---|---|---|
| 俠義之士 | 200+ | 正道NPC好感提升，村民主動提供情報，客棧老闆可能免單 |
| 江湖豪俠 | 500+ | 名門正派爭相結交，有機會被推舉為武林盟主候選人 |
| 惡名昭彰 | -200 ~ -500 | 正道封鎖山門，百姓繞道，黑市商人笑臉迎，邪派主動拉攏 |
| 魔頭 | -500以下 | 正道發布「誅魔令」，賞金獵人主動攻擊，無法進入有官府駐紮的城鎮 |

**特殊觸發**：「一代宗師」+ 「魔頭」同時持有，觸發「正邪大戰」全局事件。

##### 維度三：江湖地位（身份論）
基於陣營職位觸發，**可同時持有多個**（如「武當長老」與「六扇門總捕頭」），但須遵守陣營衝突規則。

| 稱號 | 所屬陣營 | 觸發條件（示例） | NPC反應 |
|---|---|---|---|
| 武當掌門 | 武當派 | 前任掌門傳位或擊敗所有競爭者 | 武當弟子服從，其他門派掌門以禮相待，朝廷視其為一方諸侯 |
| 丐幫九袋長老 | 丐幫 | 完成幫主交付的三大艱鉅任務 | 天下乞丐皆為眼線，情報獲取速度大幅提升 |
| 錦衣衛千戶 | 朝廷 | 破獲重大謀反案，獲指揮使賞識 | 可調動地方衛所兵力，隨意進入官府檔案庫 |
| 青龍會舵主 | 青龍會（邪派） | 暗殺前任舵主並通過內部試煉 | 獲得組織資源，可派遣殺手，正道門派對你懸賞 |

##### 維度四：人際關係（緣分論）
基於與特定重要NPC的極致關係狀態觸發，帶有強烈故事性與情感色彩。

| 稱號 | 觸發條件（示例） | NPC反應 |
|---|---|---|
| 神仙眷侶 | 與NPC結婚，雙方好感度與名聲均達極高值 | 江湖傳為佳話，單身NPC可能對你產生愛慕 |
| 刎頸之交 | 與NPC義結金蘭，並共同經歷生死考驗 | 義兄弟危急時無條件前來，其仇人視你為仇人 |
| 關門弟子 | 成為宗師級NPC的最後一位弟子 | 師父傳授畢生絕學，江湖皆知你是XX的傳人 |
| 不共戴天 | 與NPC仇恨值達極限且雙方均存活 | 該NPC不惜一切追殺你，並動用所有人脈對付你 |

##### 維度五：特殊成就（事蹟論）
完成極具挑戰性或獨特性的行為，通常帶有炫耀性質。

| 稱號 | 觸發條件（示例） | NPC反應 |

| 獨孤求敗 | 公平對決中擊敗10位不同門派的掌門級高手 | 江湖後輩視你為傳說，頂尖高手視你為必須挑戰的目標 |

#### 特殊事件稱號（非屬性觸發）

這些稱號無法透過練功或累積獲得，需在特定時機、特定地點做出特定選擇：

1. **試劍山莊之主**：在十年一度的武林大會上連敗七位頂尖高手。獲山莊令牌，可繼承財富與藏劍。
2. **屠龍者**：協助朝廷對抗元朝殘餘，親手擊殺元朝大將。朝廷賜予「忠勇伯」爵位，引來元朝餘孽報復。
3. **藥王谷傳人**：瘟疫時留下救助病患，意外獲得谷主遺書與《藥王神篇》。
4. **畫眉郎/畫眉妻**：與伴侶在月老祠共同許願，並在一年內為對方親手畫眉/梳頭一百次。觸發隱藏結局與特殊飾品「同心結」。
5. **盜聖**：不殺任何守衛、不觸發任何警報，盜取皇宮大內指定三件寶物。
6. **俠之大者**：襄陽城被圍時留下共存亡，並率江湖義士突襲成功解圍。名字刻於城頭英雄碑。
7. **塞外孤狼**：與中原門派決裂後遠走西域，殺出一條血路成為西域地下勢力無冕之王。
8. **天機老人**：破解「天機閣」失傳謎題，成為江湖最大情報販子（高風險）。
9. **無名**：達「一代宗師」後選擇隱居山林，徹底銷聲匿跡十年。十年後重出，江湖無人識你，一出手天下皆驚。
10. **逆天改命者**：壽命不足一年時完成幾乎不可能的任務（如取得「龍鳳還魂草」），從而延壽十年。

#### 稱號衝突規則

| 衝突類型 | 衝突的稱號對 | 衝突結果 |
|---|---|---|
| 陣營對立 | 「武當掌門」vs「魔教教主」 | 不可能同時獲得；先成為掌門後加入魔教，自動失去掌門稱號 |
| 行為矛盾 | 「俠義之士」vs「魔頭」 | 善惡值是線性數值，無法同時處於兩個極端 |
| 身份互斥 | 「錦衣衛千戶」vs「江洋大盜」 | 獲得一個導致另一個被剝奪 |
| 關係獨佔 | 「神仙眷侶」vs「採花大盜」 | 持有「採花大盜」時，所有異性NPC初始好感極低，不可能達成真愛結局 |
| 路線選擇 | 「少林棄徒」vs「少林方丈」 | 被逐出師門者不可再當掌門；主動還俗者有機會多年後回歸 |

**設計要求**：觸發衝突行為時，系統給予明確警告：「此舉將使你失去『武當掌門』稱號，並與武當派關係降至『敵對』，是否確認？」

#### MVP優先實現範圍（P0）

- 維度一：武學境界（江湖新丁、小有名氣、武林高手、一代宗師）— NPC判斷玩家實力的基礎依據
- 維度二：善惡名聲（俠義之士、惡名昭彰）— 觸發不同事件鏈的核心變數

### 壽命（武俠邏輯，非修仙）

人就是會老，這是武俠，不是修仙。

- 角色有自然壽命（約60-80歲，依體魄屬性有浮動）
- 體魄高：老得慢、健朗得久
- 重傷、積勞、過度消耗：可能減壽
- **沒有「修煉越高壽命越長」這種事**

時間壓力來自：**人生就這幾十年，有些事錯過了就錯過了。**
這比修仙的「修不夠快就死」更貼近「這是我的一生」這個核心支柱。

**標籤的作用：**
- NPC 看到標籤做出反應
- 決定能否加入某些門派或接觸某些人
- 影響世界感知系統的傳播速度（名氣越大消息傳越快）

### 屬性來源

| 來源 | 說明 |
|---|---|
| 武學技能 | 學習和精進武功帶來屬性成長 |
| 裝備詞條 | 武俠語言包裝的暗黑式詞條加成 |

## 6. 裝備與武學系統

### 設計原則：暗黑式詞條 × 武俠語言包裝

**不是這樣：**「+5%爆擊率的青銅劍」

**是這樣：**「以玄鐵鑄就的殘刀，傳說沾過仇人鮮血，持者見敵生寒」
→ 效果：攻擊時有機率使敵人心神大亂（恐懼狀態）

### 品質層級（與第14章數值設計對齊）

凡品（灰）→ 精良（白）→ 利器（綠）→ 寶器（藍）→ 神兵（紫）→ 絕世（金）→ 天工（紅）

武俠語言對應：每個品質有對應的描述風格與詞條數量（詳見第14章）

### 詞條結構
每件裝備/武學有：
- **固定效果**（品質決定，穩定可預期）
- **隨機素質**（品質決定數量，凡品0條，絕世3條，天工4條）
- **隨機效果**（從詞條池抽取，武俠語言描述）

### 初期稀少原則
- 初期詞條出現機率低，普通裝備為主
- 後期成為可追求的深度玩法
- 避免破壞早期世界觀沉浸感

> **品霖 2026-05-11 補充完成**

### 武學技能系統

**設計核心原則：** 武學不只是戰鬥工具，更是玩家的社交名片與故事觸發器。玩家學了華山劍法，江湖上就會有人因此尊重他，也有人因此想挑戰他。

#### 武學五大類

| 大類 | 核心屬性 | 戰鬥定位 | 風格描述 |
|---|---|---|---|
| **外功** | 武力 | 主要傷害輸出 | 刀、劍、拳、掌、棍等直接打擊技。講究招式凌厲，一力降十會。 |
| **內功** | 內力 | 核心能力、續航、特殊效果 | 心法、吐納、運功。決定內力總量、恢復速度及驅動高階招式的能力。 |
| **輕功** | 輕功 | 機動、先手、規避 | 身法、步法、提縱術。影響閃避、先手順序及地圖探索效率。 |
| **奇術** | 悟性 | 控制、輔助、環境互動 | 暗器、點穴、毒術、機關術、醫術。非正面戰鬥，但能創造戰機。 |
| **絕學** | 多項高門檻 | 終極招式、逆轉戰局 | 門派鎮派之寶、失傳秘典。學習條件極苛刻，威力巨大，使用有高代價。 |

**屬性成長對應：**

| 練武行動 | 主要成長屬性 | 次要成長屬性 |
|---|---|---|
| 練習外功 | 武力 | 體魄 |
| 修習內功 | 內力 | 體魄 |
| 鍛鍊輕功 | 輕功 | 體魄 |
| 鑽研奇術 | 悟性 | 資質 |
| 參悟絕學 | 資質、悟性 | 對應絕學所需屬性 |

#### 武學學習機制

**獲取途徑：**

| 途徑 | 說明 | 風險/代價 |
|---|---|---|
| 師父傳授 | 加入門派或拜師後，消耗時間和門派貢獻學習 | 需忠於門派，叛門可能廢武功 |
| 自行摸索 | 從秘笈、殘卷、壁畫中參悟 | 耗時長、可能走火入魔（減壽/扣屬性） |
| 奪取 | 擊敗或殺死特定NPC獲得 | 與該NPC及其關係網全面敵對，名聲大幅下降 |
| 購買 | 在拍賣會或黑市用銀兩交換 | 花費巨大，高階武學有「身份權限」限制 |
| 交換 | 以物易物或以「人情」交換 | 需要深厚的關係資本 |
| 自創 | 悟性和資質達極高水準，消耗大量時間自創武功 | 成功機率低，但創造出的武學完全契合自身 |

**屬性門檻：** 每門武學有最低屬性要求（如「武力≥30，內力≥20」）。屬性不足時無法學習；強行參悟（自行摸索）則觸發「走火入魔」事件，導致屬性暫時或永久受損。

**熟練度系統（五階）：**

| 階段 | 名稱 | 效果 | 提升方式 |
|---|---|---|---|
| 1 | 入門 | 發揮基礎效果，消耗精力大 | 學會即達成 |
| 2 | 熟練 | 效果+20%，消耗-10% | 戰鬥使用5次，或練習10天 |
| 3 | 小成 | 效果+40%，消耗-20% | 戰鬥使用20次，或練習30天 |
| 4 | 大成 | 效果+70%，消耗-30% | 戰鬥使用50次，或練習60天，或「頓悟」事件 |
| 5 | 圓滿 | 效果+100%，消耗-50%，解鎖隱藏效果 | 達「大成」後，在特定情境（如生死關頭）觸發「天人合一」事件 |

設計意圖：一個把「太祖長拳」練到圓滿的江湖老手，比剛學會「獨孤九劍」的新手更具威脅。

高品質武學不僅數值高，更代表「社會地位」和「故事背景」。玩家獲得一本「神功」，整個江湖都會為之震動。

#### 武學組合與流派

**同流派加成（示例：華山劍派）：**
- 核心：輕靈、迅捷、後發先至
- 組成：華山劍法（外功）+ 養吾劍氣（內功）+ 雲梯縱（輕功）
- 裝備2件：劍法招式速度+15%
- 裝備3件：施展劍法時有機率觸發「無招勝有招」，無視對手部分防禦

**跨流派組合技（待玩家探索）：**
- 狂風刀法（外功）+ 梯雲縱（輕功）→「天外飛仙」：一次高額單體傷害，無法被格擋
- 龜息功（內功）+ 點穴手（奇術）→「龜息點穴」：大幅降低存在感，點穴成功率提升

#### 武學與NPC互動

**門派歸屬識別：**
- 正面：施展某門派獨門武學時，同門或友好門派NPC增加好感，可能提供更高階武學或任務
- 負面：在敵對門派面前施展其獨門武學，被視為挑釁，好感大幅下降或直接觸發戰鬥
- 中立：施展失傳或罕見武學，引起江湖人士注意，名聲傳播速度加快，可能引來覬覦者

**特定NPC反應類型：**
- **武痴**：見到精妙武學會主動上前切磋，無論勝負都可能結為好友
- **仇家**：見到玩家使用殺害其親友的武學，觸發「血海深仇」事件
- **名門正派**：玩家使用邪派武學（如「奪命十三劍」），被列入「誅邪令」
- **朝廷鷹犬**：玩家使用驚世駭俗的武學，增加被監視或通緝的風險

**武學與世界感知連動：** 玩家在公開場合施展高品質或稀有武學時，事件成為「江湖傳聞」進入世界感知系統傳播，直接影響名聲值並吸引特定類型NPC前來拜訪或挑戰。

## 7. NPC人際關係系統

### 三層架構

**第一層：個人戲劇**（學鬼谷八荒）
每個玩家都會有：
- 仇人（主動追殺、派刺客、破壞玩家關係）
- 妻/夫、紅顏知己（可同居、生子、分離、背叛）
- 義兄弟（可召喚助戰、可背叛、可為你犧牲）
- 師父/師兄弟（傳授技能、門派衝突）
- 仇家後代（繼承上代恩怨）

**設計要求**：關係要持續演化，不能觸發一次就廢棄。

**第二層：社會身份**（學龍胤並加深）
- 門派地位（長老/掌門等）
- 朝廷官職（捕快/縣令/指揮使等，有上限）
- 江湖名聲（正道/魔道/中立）
- 各維度影響玩家能做的事和NPC的態度

**第三層：世界感知**（本作創新）
詳見第9章。

### 關係類型

| 關係類型 | 初始狀態 | 備註 |
|---------|---------|------|
| 親屬 | 血緣綁定，不可更改 | 父母、子女、兄弟姊妹 |
| 師徒 | 傳授武學後建立 | 可因背叛斷絕 |
| 同門 | 加入門派後自動建立 | 門派被滅則消失 |
| 友誼 | 從陌生人開始 | 透過社交活動提升 |
| 敵對 | 因衝突觸發 | 殺人、搶奪、背叛 |
| 愛侶 | 從傾慕或友誼演化 | 特殊事件或長期相處 |
| 仇人 | 從敵對升級，有明確仇恨值 | 殺親、奪愛、大辱 |

### NPC 記憶系統

- **短期記憶**：日常對話、交易，持續 1–3 個月（遊戲內時間），無後續觸發則淡忘
- **長期記憶**：重大恩惠、深仇大恨、親人死亡，**持續一生不遺忘**
- **記憶傳遞**：NPC 會向親友分享記憶——你在 A 地的行為，B 地的相關 NPC 可能在數天後得知

### 關係變化觸發條件

- 玩家主動：送禮、聊天、幫助、攻擊、殺害
- NPC 自主：長期目標驅動（報仇、報恩）
- 第三方事件：玩家傷害 NPC 的親友，NPC 對玩家關係直接升至仇人
- 時間流逝：友誼值緩慢衰減，仇恨值不衰減

## 9. 世界感知系統

### 設計原則：消息在江湖上流傳，有距離和時間

**三個參數：**
1. **距離**：你在哪裡做的事，附近的人先知道
2. **時間**：消息需要時間傳播，不是即時全知
3. **NPC節點**：消息從NPC傳到NPC，有社交網絡邏輯

### 技術實現（參考鬼谷八荒並改進）

**基礎層（全局數值）：**
- 全局名聲值（-1000到+1000）
- 陣營歸屬旗標
- 主要事件旗標（重大事件永久記錄）

**區域層（傳播機制）：**
- 行為在發生地點生成「事件」
- 事件以距離衰減：越遠知道的越少、越晚知道
- 時間推移：每過N天，消息傳播到下一個「節點」
- NPC與NPC之間有社交連接，消息沿連接擴散

**玩家可感知的效果：**
- 在A地做的事，B地三天後才有NPC聽說
- 消息傳播中可能失真（以訛傳訛）
- 名氣大的人消息傳得更快（高知名度加速傳播）
- 偏遠地區消息慢，讓玩家有「躲避」的策略空間

## 10. 戰鬥系統

### 核心設計原則
戰鬥是江湖生活的一部分，不是遊戲的唯一重心。
打贏之後發生的事，和怎麼打贏一樣重要。

### 基本規格

| 項目 | 決定 | 備注 |
|---|---|---|
| 戰鬥視角 | 橫版側視 | 動作感強，招式清晰可見 |
| 特效原則 | 收束在角色周圍，不蓋過走位 | 參考美術聖經戰鬥規格 |
| 隊伍規模 | 玩家＋N個NPC隊友 | N為變量，測試後決定（預估2-5人）|
| 自動戰鬥 | 支援，可選模板 | 對沙盒玩家友好 |
| 速度控制 | 1x / 1.5x / 2x | 自動戰鬥時可加速 |

### 手動 / 自動 切換機制

**自動戰鬥模板（初步）：**
- 激進：主動衝鋒，最大化傷害
- 穩健：攻守平衡，保留資源
- 保守：優先生存，低風險
- 輔助：以隊友為主，玩家補位

**切換邏輯：**
- 任何時候可從自動切換到手動接管
- 自動過不了 → 手動可以過 = 玩家操作有意義
- 手動輕鬆過 → 掛機自動 = 不強迫玩家每場都親自打

### 武學在戰鬥中的表現

玩家學的武學決定戰鬥風格：
- 不同武學門派有不同的動作組合（劍法、拳法、輕功、暗器等）
- 屬性決定這些動作的威力與效果
- 高手和新手的差距，看得出來在動作上

*具體技能設計待補充*

### 數值設計原則：鋸齒狀體驗曲線

**不做線性難度，不做永久碾壓，做鋸齒。**

```
爽（輕鬆期）→ 遇牆（挑戰）→ 追求成長 → 突破 → 嚐到甜頭 → 爽 → 更高的牆 → ……
```

**關鍵設計要求：**
1. **牆要可見** — 玩家輸了要清楚知道為什麼輸（不是隨機的，是差距）
2. **缺口要可填** — 玩家知道去哪成長（找更好的武學、更好的裝備、更好的隊友）
3. **填缺口的過程要有趣** — 追求裝備/武學本身就是內容，不是純粹的數字刷取
4. **突破要有爽感** — 之前打不過的，現在輕鬆解決 = 成長感的最強體現

**缺口的填補方式（玩家動力來源）：**
- 尋找更高品質的詞條裝備
- 學習更適合當前敵人的武學
- 提升關鍵屬性
- 招募更強或更合適的隊友

*具體數值曲線設計待數值章節定義*

### 世界內容分類原則：固定錨點 vs 程序生成

遊戲世界中的陣營、人物、地點分為兩類，開發時處理方式完全不同。

#### 固定錨點

有歷史、野史、或武俠小說依據，玩家耳熟能詳的內容。固定錨點承載世界觀的可信度與文化厚度，**需要認真設計，跨文件保持一致**。

| 類型 | 已確定的固定錨點 |
|------|----------------|
| **城市** | 應天府（南京）、北平府、開封府（汴梁）、蘇州府、武昌府（江夏）、成都府、大理府、太原府、泉州府、揚州府、洛陽府、南昌府（見本章清單）|
| **歷史機構** | 錦衣衛、應天府衙門（明朝官方機構）|
| **宗教地點** | 龍門石窟（洛陽）、懸空寺（山西大同）、龍泉寶藏（浙江龍泉）|
| **門派/組織** | 金剛寺（嵩山，與少林有淵源）、武當派（武當山，已在稱號系統中出現）、丐幫（武俠小說常設門派）、錦衣衛（歷史機構）|
| **武學** | 太祖長拳（趙匡胤）、太祖長拳相關典故 |

> **說明：** 固定錨點的名稱、根據地、歷史背景在所有 GDD 中必須一致。修改固定錨點設計時，需同步更新所有引用該錨點的文件。

#### 程序生成

由系統規則和模板創造，每局遊戲可以不同，不需要跨文件或跨局保持一致性。

**已確認為程序生成的內容：**
- **隨機江湖門派**：如「天罡劍派」、「雲夢澤」、「幽冥教」、「飛鷹幫」、「點蒼派」、「血刀門」——這些門派雖在本局清單中有具體設定，但其名稱、武學風格、根據地均可在不同局中重新生成，不要求歷史依據
- **隨機江湖人士**：無名NPC、散兵、普通商人、隨機對手
- **隨機任務與傳聞**：事件佇列內的動態內容
- **隨機陣營政治事件**：門派政變、幫派火拼等動態事件的具體參與者

> **說明：** 程序生成內容只需要遵守「生成規則和模板」，名字、數量、具體設定可以每局不同。設計文件只需記錄模板格式，不需要鎖定具體實例。

#### 開發時的區別對待

| | 固定錨點 | 程序生成 |
|---|---------|---------|
| **一致性要求** | 跨所有GDD必須一致 | 只需符合模板規則 |
| **修改成本** | 高（需同步多份文件）| 低（只改規則和模板）|
| **設計深度** | 需要認真設計背景、關係、事件鏈 | 需要設計生成規則與模板 |
| **玩家預期** | 玩家可能帶著既有認知進來 | 玩家每局都當新內容看待 |
| **程序員實作** | 靜態資料，硬編碼允許 | 資料驅動，外部化到 `assets/data/` |

## 11. 中後期深度系統

### 設計目標

解決武俠生涯遊戲最常見死症：**30小時後沒事做**。
本章四個子系統互相交織，確保玩家進入「名震江湖」階段後，選擇難度不降反升。

---

### 11.1 門派政治深度

**核心體驗**：你不只是門派成員，你是門派權力格局的一個變數。

**機制層：**
- 每個門派有 3–5 個內部派系（保守/激進/中立等），各有領袖 NPC
- 玩家行動（任務選擇、武學傳授、站隊）影響各派系對玩家的「信任值」
- 信任值達到門檻可觸發：掌門提名、長老席位、秘典開放
- 門派可發生「政變」事件——若玩家介入決定走向，影響後續 20+ 小時

**差異化（vs 龍胤）**：龍胤門派是資源提供者，本作門派是政治棋盤，玩家可以是棋手也可以是棋子。

---

### 11.2 朝廷官場玩法

**核心體驗**：用劍的人與用印的人的博弈。

**機制層：**
- 官職系統：縣尉 → 知縣 → 知府 → 督撫 → 閣臣（5 級）
- 晉升靠：任務功績、賄賂、後台 NPC 關係、剿匪/治水等政績事件
- 官場有「清濁值」：清流路線慢但安全，濁流路線快但有抄家風險
- 江湖身份 vs 官場身份衝突——某些武林任務會讓官場信譽損失，玩家必須選邊

**壓力來源**：每隔 3 遊戲年，會有「考核」事件，不達標降職或罷黜。

---

### 11.3 身份世界反應（名聲深度效果）

**核心體驗**：活得夠久、名聲夠響，江湖開始圍繞你轉。

> 以下為觸發閾值示意，非硬性 NPC 行為規則。
> 各 NPC 的具體互動條件由其自身狀態決定，名聲值是其中一個輸入變數。

| 名聲值 | 世界反應（示意） |
|--------|----------------|
| 0–200 | 無名之輩，無人因名氣特別對待 |
| 201–400 | 地方有名，商販主動讓利、小嘍囉見面逃跑 |
| 401–600 | 聲名遠播，各方勢力主動派人接觸、拉攏 |
| 601–800 | 一代宗師，門派主動邀請，官府既忌憚又利用 |
| 801–1000 | 江湖傳說，後輩主動挑戰，仇家傾巢而出，保護者變成目標 |

**高名聲代價（避免「無敵」感）**：
- 刺客出現頻率隨名聲上升
- 高名聲角色死亡後，後代起點更高但仇家更多

---

### 11.4 長線留存機制

**遺產系統**（與第 13 章傳代系統連動）：
- 本局角色建立的據點、關係、名聲，部分以「傳說」形式影響下一局
- 例：父輩是某派掌門，子輩進入該派初始好感 +100

**成就式壓力事件**（防止後期空洞）：
- 境界達化神後，觸發「武林盟主之爭」全局事件
- 官至閣臣後，觸發「奪嫡之爭」危機
- 這些事件強迫玩家做終極選擇，而非繼續「掛機」

## 12. 經濟系統

### 資源層級

經濟系統不只是銀兩，而是**多層資源**：

| 資源類型 | 說明 | 如何取得 |
|---|---|---|
| **個人財富**（銀兩/銅錢）| 自由支配，可花在任何地方 | 賺錢方式所得 |
| **陣營資源**（門派/朝廷庫房）| 因身份可調用，不屬於個人 | 身份地位給予使用權 |
| **身份權限** | 決定能買什麼、能用什麼 | 江湖稱號、陣營地位 |
| **關係資本** | 某些東西只能透過特定NPC取得 | 人際關係深度 |

**有錢不一定買得到：**
- 名劍只賣給有聲望的人
- 秘笈只傳給特定門派弟子
- 官府資源因職位可調用，但不能入私囊
- 高人指點靠關係，不靠銀兩

這解決「後期錢太多」的問題——錢是多種資源之一，有些東西花錢買不到。

### 貨幣
- **銀兩**：主要貨幣，大額交易
- **銅錢**：零散消費，日常買賣

### 賺錢方式

**核心收入（初期實装）：**
- 鏢局護鏢：穩定但有風險的護送任務
- 江湖懸賞：追捕目標，有故事背景
- 城市間貿易：低買高賣，利用各地價差
- 門派任務：陣營帶來的穩定來源
- 武林比武：擂台賽獎金，高風險高回報
- 採集製作：藥草、鍛造、釀造等出售
- 置產收租：置產後的被動收入（中後期）

**創意收入（逐步實裝，以事件/任務模板形式）：**
- 說書人/話本：將親身江湖經歷寫成故事販售
- 江湖郎中：獨門藥方高價兜售
- 情報販賣：蒐集門派秘密出售
- 贋品匠人：仿造古董，高風險高回報
- 狀師代筆：幫NPC打官司、寫狀紙

### 花費方向

**裝備與成長：**
- 購買武學秘笈、裝備、珍稀材料

**社交投資：**
- 送禮、請客、打點關係——影響NPC關係和陣營聲望

**移動費用：**
- 租馬、坐船、住客棧——每種都消耗時間和金錢

**食水消耗（強制生存機制）：**
- 角色必須定期吃喝，飢餓/缺水帶來負面效果
- 不是計時扣錢，是消耗庫存道具（每隔一段遊戲時間需補充）
- 特殊環境（沙漠、雪山、地牢）加快消耗速度
- 特殊食物可抵抗環境消耗（雪地的薑茶、沙漠的特製乾糧）
- 食物可在客棧買、野外採集、或自己烹飪
- 特殊食物提供短暫屬性加成（吃好的打得更猛）

**置產與發展：**
- 購地置業，前期投入，中後期收益

**江湖債（強制性不規則大額支出）：**
- 重傷找名醫：戰鬥或意外重傷，需要大筆醫費
- 被掛暗花：仇家懸賞你的人頭，需花錢解除或逃避
- 你也可以掛別人的暗花：雇人對付仇家
- 師父/義兄弟有難：掏錢救人
- 朝廷要求孝敬/捐獻：選擇有代價的延伸
- 這些支出不是系統扣的，是**選擇帶來的後果**，符合「選擇有代價」核心支柱

### 市場資訊通知機制

玩家如何感知市場變動：

| 場景 | 通知方式 |
|---|---|
| 進入城鎮/店鋪 | NPC 開口提及，或買賣面板顯示價格變動 |
| 大地圖移動中 | 每7天或每月一次**區域廣播**（當地重大事件）|
| 世界級大事 | **全域廣播**（戰爭、天災、江湖大事）|

---

### 防止「打工感」的設計原則

**市場動態原則：局部，不是全局**

市場價格的變動是局部的，作用範圍是：
- 特定 NPC 或店鋪（他自己的庫存和定價）
- 當地公告板（反映本地供需與緊急需求）

**公告板（告示板）：**
- 每個城鎮/地點都有公告板
- 張貼：懸賞、求助、交易機會、緊急物資需求
- 天災人禍影響公告板內容 → 影響當地價格
- 公告板內容與世界感知系統連動：消息傳到才更新（有傳播延遲）

**實際效果：**
- 某城發生瘟疫 → 當地公告板出現「急需藥材」→ 當地藥材商漲價
- 遠地玩家幾天後才從公告板得知 → 帶藥材趕去可賺暴利
- 玩家大量購買某商人的鐵礦 → 該商人漲價，但不影響其他城市

賺錢方式本身要有事件性和江湖感：
- 護鏢途中遭遇劫鏢不只是「扣血」，而是觸發完整的衝突事件
- 收租時佃農哭窮或地方惡霸橫插，不只是「等錢到帳」
- 食衣住行的消費要「活」：住客棧遇高手、吃飯聽到消息

## 13. 傳代系統

**這是《江湖一生》最重要的差異化特色之一。**

### 核心邏輯

```
玩家操控角色A（這一生）
    ↓ 玩家選擇傳代（或角色自然老死）
角色A → 繼續活在江湖，成為 NPC
角色A的孩子 → 玩家開始操控（下一生）
```

### 傳代時機

- **玩家主動選擇**：角色還活著，玩家認為時機到了，主動傳代
- **角色自然死亡**：壽命耗盡，自動進入傳代流程

### 傳承清單（玩家自行選擇）

玩家可選擇性地把以下傳給孩子：
- 財產（銀兩、房產、土地）
- 裝備與秘笈
- 人脈（部分NPC關係繼承）
- 仇怨（未了結的恩怨跟著傳下去）
- 名聲（父輩的江湖稱號帶來初始聲望加成或負擔）

### 舊角色成為 NPC 的意義

角色A傳代後，**繼續作為 NPC 活在江湖**：
- 玩家可以去拜訪自己的父母/祖父母
- 世界上的 NPC 記得他們的過去
- 可能成為新角色的師父、盟友，或因舊有恩怨成為障礙
- 舊角色的故事和選擇，在世界上留下了痕跡

**這是「江湖有記憶」原則的最強體現。**

### 設計邊界

- 傳代次數沒有上限（可以玩很多代）
- 每一代都是獨立的一生，但世界是連續的
- 前幾代的選擇可能影響後代的處境（仇家的後代、舊日盟友的後代）

### 14.1.2 屬性成長機制

#### 練武提升

每次完成「練武」行動（每日可執行1次），依修煉武學等級決定屬性增益：

| 武學等級 | 練武屬性增益/次 |
|---|---|
| 入門（1–3級）| +1–2點（主屬性）|
| 小成（4–6級）| +2–4點（主屬性）|
| 大成（7–9級）| +3–6點（主屬性），副屬性+1 |
| 圓滿（10級）| +4–8點（主屬性），副屬性+2 |

#### 老化降低

| 年齡階段 | 屬性年衰減率 | 受影響屬性 |
|---|---|---|
| 青壯（20–40歲）| 0% | — |
| 中年（41–55歲）| 1%/年 | ATK、AGL |
| 初老（56–65歲）| 2%/年 | ATK、AGL、NRI |
| 老年（66歲以上）| 3%/年 | 所有戰鬥屬性 |

- BOD、REP、APT 不受老化衰減
- WIS 老年反而 +1%/年（越老越有悟性）
- 老化衰減採修飾詞疊加：`最終屬性 = 基礎屬性 × Π(1 - 年衰減率)`

#### 修飾詞疊加順序

`aged衰減 → flat加法 → percentage乘法 → setMax上限`

### 14.1.3 典型第30天玩家完整屬性範例

24歲，加入門派，主修外功劍法（小成），兼練輕功（入門），三件綠品裝備。

| 屬性 | 基礎值 | 裝備加成 | 最終值 |
|---|---|---|---|
| ATK | 145 | +20 | **165** |
| NRI | 90 | +10 | **100** |
| BOD | 170 | +15 | **185** |
| AGL | 110 | +10 | **120** |
| APT | 100 | 0 | **100** |
| WIS | 70 | 0 | **70** |
| REP | 55 | 0 | **55** |

衍生數值（UI顯示均為整數）：
- HP = 185 × 5 + 50 = **975**
- MP = 100 × 3 + 20 = **320**
- SP = 185 × 2 + 120 = **490**
- 閃避率 = floor(120 / 620 × 100) = **19%**
- 毒抗 = floor(185 × 0.5 + 100 × 0.3) = **122**
- 內傷抗 = floor(100 × 0.6 + 185 × 0.3) = **115**

綜合評分（整數）：
= floor(165×1.0 + 100×1.2 + 185×0.8 + 120×0.9 + 100×1.5 + 70×1.1 + 55×0.5)
= floor(165 + 120 + 148 + 108 + 150 + 77 + 27)
= **795分** → 「小有名氣（501–1500）」✓

### 14.3 壽命公式

基準值70歲，體魄影響浮動，結果取整數：

- `體魄 < 100`：壽命 = 70 - floor((100 - 體魄) × 0.08)
- `100 ≤ 體魄 ≤ 400`：壽命 = 70 + floor((體魄 - 100) × 0.025)
- `體魄 > 400`：壽命 = 77 + floor((體魄 - 400) × 0.01)

**範圍：** 62–81 歲（±10年）

**事件減壽：** 重傷-1~3年、習練陰毒邪功-2~5年、長期飢餓/中毒-1年/次、重大打擊-1~3年
**事件增壽（極罕見）：** 傳世靈藥+5~10年、養生奇遇+2~3年
