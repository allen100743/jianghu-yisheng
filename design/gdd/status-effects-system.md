## 1. 概述

本系統定義角色在江湖中可能遭遇的所有身體異常狀態——外傷、內傷、中毒、疾病、飢餓、疲勞、以及特殊武學造成的經脈損傷或精神創傷。採用連續 severity 模型（0.0–1.0），取代傳統三段式（輕/中/重），讓狀態惡化與恢復呈現漸進且符合直覺的曲線。所有狀態對角色屬性的影響，統一透過修飾詞疊加系統實現，確保數值架構的整潔與可擴展性。

## 2. 玩家體驗

### 2.1 預期體驗

- **「這一刀砍得很深，我必須趕快止血，不然會越來越糟。」** — severity 持續上升的壓力感。
- **「我現在內傷很重，運功會加劇傷勢，但不用內功又打不過眼前的敵人。」** — 戰術取捨的真實感。
- **「我中了唐門的毒，得趕快找解藥，不然撐不過三天。」** — 時間壓力和明確目標感。
- **「這幾天一直在趕路，又沒吃東西，身子虛得很，連個小賊都打不過。」** — 多重狀態疊加的疲憊感。

### 2.2 不該出現的體驗

- 狀態圖標存在但感覺不到差異（數值變化必須有可感知的遊戲內回饋）
- 重傷喝一瓶藥就全好（恢復必須有漸進過程）
- 多種毒疊加但 UI 不清晰（疊加狀態的總體影響必須可讀）

### 2.3 MVP 與 V2 邊界

- **MVP 必須實裝**：外傷、內傷、中毒、疲勞、飢餓、疾病（每種至少 3 個 stage 效果）
- **V2 追加**：經脈損傷、精神創傷、蠱毒、詛咒、特殊武學獨特狀態（如七傷拳經脈逆流）

## 3. 詳細規則

### 3.1 Severity 模型核心規則

每個狀態都有連續 severity 值，範圍 `0.0`（無影響）到 `1.0`（瀕死/極致）。

| Severity 範圍 | Stage | 觸發效果 |
|-------------|-------|---------|
| 0.0 – 0.3 | 輕微 | 基礎效果（若有）|
| 0.3 – 0.6 | 顯著 | Stage 2 效果 |
| 0.6 – 0.9 | 嚴重 | Stage 3 效果 |
| 0.9 – 1.0 | 危急 | Stage 4 效果 + 觸發瀕死檢查 |

**Severity 變化規則：**
- 每個狀態有基礎的「自然惡化速率」和「自然恢復速率」（單位：severity/天）
- 自然恢復僅在「不滿足惡化條件」時發生
- 玩家行動、藥物、環境事件可加速或逆轉變化

### 3.2 修飾詞疊加架構

所有狀態對角色屬性的影響以「修飾詞」形式存在，透過疊加系統作用於基礎屬性。

**修飾詞類型：**
- **加法修飾詞**：`+X` 或 `-X`（直接加減）
- **乘法修飾詞**：`+X%` 或 `-X%`（百分比增減）
- **覆蓋修飾詞**：直接取代基礎值（最高優先級，用於極端情況如「經脈盡斷」）

**疊加計算：**
```
最終屬性 = clamp( (基礎值 + Σ加法修飾詞) × Π(1 + 乘法修飾詞_i), 0, 上限 )
```
範例：基礎武力100，外傷-20（加法），中毒-30%（乘法），疾病-10%（乘法）
→ `(100 - 20) × (1 - 0.30) × (1 - 0.10) = 80 × 0.7 × 0.9 = 50.4 → 50`

| 0.6–0.9 | 飢火中燒 | 體魄 -10 | 武力 -15%，輕功 -10% | 每小時頭暈：命中率 -10% |
| 0.9–1.0 | 餓殍之相 | 體魄 -30 | 武力 -30%，輕功 -20% | 5% 機率昏迷；**生命扣除及昏迷機制由 4.3 管理** |

自然惡化：+0.08/天 | 恢復：進食立即降至 0.0

#### 疾病（Disease）

> **MVP 必裝** — 2.3節有列入但此前規格缺失，本次補齊。

疾病由外部感染（惡劣環境、接觸病患、免疫力下降）觸發，不同於外傷/內傷的即時受損，疾病有**潛伏期**（severity 緩慢上升）和**爆發期**（快速惡化）。

| Severity | Stage | 加法修飾詞 | 乘法修飾詞 | 特殊效果 |
|---------|-------|----------|----------|---------|
| 0.0–0.3 | 初染微恙 | 無 | 無 | 偶爾咳嗽/頭痛提示，無影響 |
| 0.3–0.6 | 病勢漸重 | 體魄 -10 | 武力 -10%，輕功 -5% | 疲勞惡化速率 ×1.5；睡眠恢復效率 -30% |
| 0.6–0.9 | 高燒不退 | 體魄 -25 | 武力 -20%，輕功 -15%，悟性 -10% | 每小時：生命 -0.5%；神志不清：NPC 對話選項減少 |
| 0.9–1.0 | 病入膏肓 | 體魄 -50 | 武力 -40%，輕功 -30%，悟性 -20% | severity +0.01；無法修煉/練武；**生命扣除由 4.3 管理** |

自然惡化：+0.03/天（未就醫）| 恢復：+0.05/天（臥床休息），+0.10/天（大夫診治+藥方），+0.20/天（名醫）

**觸發條件（MVP）：**
- 在惡劣天氣（大雨/嚴冬）中連續趕路 3 天以上，且飢餓 severity > 0.5
- 進入疫區地點（地點標籤：疫區）
- 疲勞 severity ≥ 0.8 且飢餓 severity ≥ 0.6 同時觸發

**與其他狀態的關係：**
- 中毒 + 疾病：疾病惡化速率 ×1.5（已在 3.4 特殊疊加中定義）
- 疾病 + 外傷：外傷恢復速率 -50%（病中難以癒合）

### 3.4 狀態疊加規則

- **同類型狀態疊加公式（遞減累加）：**
  `new_severity = clamp(current + incoming × (1.0 - current × 0.5), 0.0, 1.0)`
  說明：現有傷越重，新增同類傷的有效量越低（最低為新傷害量的50%）。確保每次受傷都有效果，但避免輕微攻擊造成過快死亡。
- 不同類型狀態完全獨立，各自計算，修飾詞疊加
- **特殊疊加關係：**
  - 中毒 + 疾病：疾病惡化速率 ×1.5（體虛易被毒侵）
  - 疲勞 + 飢餓：疲勞惡化速率 ×1.3
  - 內傷 + 運功逼毒：觸發內傷 severity +0.02

### 3.5 狀態效果視覺化規範

**設計原則：玩家不應該需要打開 UI 才知道自己有什麼狀態。**

視覺回饋分三層，各層職責不重疊：

#### 第一層：角色本體視覺（沉浸感）

| 狀態 | 視覺效果 |
|------|---------|
| 外傷（severity ≥ 0.3）| 角色身上出現傷口粒子（血跡飛濺、傷口光效）；嚴重時角色動作輕微踉蹌 |
| 內傷（severity ≥ 0.3）| 角色輪廓偶爾閃爍紅光（氣血紊亂視覺）；嚴重時伴隨咳血粒子 |
| 中毒（severity ≥ 0.3）| 角色皮膚出現綠/紫色漸層粒子；嚴重時角色動作變慢可見 |
| 疲勞（severity ≥ 0.6）| 角色動作稍慢，呼吸加重音效（配合音效團隊）|
| 飢餓（severity ≥ 0.6）| 角色移動速度輕微下降，可見的蹣跚感 |
| 疾病（severity ≥ 0.3）| 角色偶爾咳嗽動作（無攻擊時觸發）|

**原則：** severity < 0.3 不顯示任何角色視覺效果（微弱狀態不打擾玩家）。

#### 第二層：HUD 圖示（可讀性）

- 每個激活的狀態顯示一個圖示 + 數字（severity 百分比）
- 圖示顏色對應 Stage：灰（輕微）→ 黃（顯著）→ 橙（嚴重）→ 紅（危急）
- 超過 3 個狀態時，圖示收縮為緊湊模式（小圖示排列），保留顏色信號
- **不顯示的條件：** severity = 0.0，圖示從 HUD 淡出消失

#### 第三層：行動封鎖提示（功能性）

玩家嘗試執行某個行動但因狀態效果被封鎖時，立即顯示：
- 按鈕/快捷鍵閃爍變灰 + 原因說明（如「內傷過重，無法運功」）
- **不用文字說明**只用視覺：無法行動的原因已由第一、二層傳遞，第三層只需告知「這個操作現在不可用」

**多狀態疊加可讀性規則：**
- 圖示疊加時，以 severity 最高的狀態圖示最突出（尺寸最大）
- 角色本體粒子效果若超過3種狀態，以最危急的2種顯示粒子，其餘僅保留 HUD 圖示

### 3.6 玩家自行選擇解除方式

不設系統自動優先級。玩家可見當前所有狀態，自行決定：
- 使用道具（立即效果，消耗物品）
- 使用武學技能（有成功率，消耗內力）
- 選擇休息（緩慢恢復，需要安全地點）
- 等待時間自然恢復（最慢，無消耗）

### 3.7 MVP 最小世界感知鉤子

以下三個低成本鉤子是 MVP 必裝。它們把「數值狀態」轉化為「江湖生活體驗」，是狀態效果系統對沙盒核心幻想的最低履行。

**鉤子一：NPC 對話前綴（極低成本）**

任何 NPC 開口前，系統檢查玩家當前最嚴重的可見狀態（severity ≥ 0.6）：

- 外傷 0.6+：「兄台，你這傷……要不要先去醫館？」
- 內傷 0.6+：「閣下臉色不太好，是不是傷到了內息？」
- 中毒 0.6+：「你眼下發黑，莫非是中毒了？」
- 疲勞 0.8+：「你這副模樣，怕是已經很久沒好好歇息了。」
- 疾病 0.6+：「你臉色蒼白，看著像是染了病，快去找大夫吧。」

觸發前綴不影響對話選項內容，只是第一行台詞。全部 NPC 共用此模板，不需要為每個 NPC 單獨設計。

**鉤子二：特定 NPC 拒絕服務（極低成本）**

當玩家有任何狀態 severity ≥ 0.85（接近瀕死）時，非必要 NPC（娛樂場所、武學教習、技藝學習）顯示拒絕交互：

- 「你這樣子，先去找大夫吧，其他的事等你好了再說。」

醫館/藥鋪/大夫 NPC 不受此限制（反而優先接觸）。

**鉤子三：傷勢移動飄字（零成本）**

玩家在以下條件下移動時，每 10 秒觸發一條敘事飄字（不影響遊戲流程）：

- 外傷 0.5+：「你按住傷口，一步步艱難前行。」
- 疲勞 0.7+：「腿腳虛沉，每一步都比平時多費兩分氣力。」
- 中毒 0.4+：「體內如有火在燒，氣血翻湧。」

這是純文字事件，渲染開銷為零，但把「屬性數值」翻譯成「武俠身體感受」。

## 4. 公式

### 4.1 Severity 每日變化

> **時間單位聲明：** 本系統所有 severity 變化速率**統一使用「每遊戲天」（/天）為基本單位**。涉及較快速率時，在各 Stage 效果欄位中用「/小時」或「/秒」標示，並在該欄位內說明與「/天」的換算。1 遊戲天 = 24 遊戲小時 = 86400 遊戲秒。

```
Δseverity = (自然變化速率 + 環境修正 + 行動修正) × 時間單位
```

範例：外傷 severity 0.5，未包紮，潮濕山洞（+0.02/天）
→ Δseverity = (0.05 + 0.02) × 1 = +0.07，一天後 = 0.57

> **每日單一來源護欄：** 任何單一來源（自然惡化/環境修正/行動修正）每天對同一狀態的 severity 貢獻上限為 **+0.15/天**。多來源疊加無上限，但每個來源各自受此限制。此護欄防止極端環境配置造成角色在單日內死亡。

### 4.2 最終屬性計算

```
最終屬性 = clamp( (基礎值 + Σ加法修飾詞) × Π(1 + 乘法修飾詞_i), 0, 屬性上限 )
```

所有計算使用浮點數，顯示時取整數。severity 在 UI 顯示為百分比（0%–100%）。

### 4.3 各狀態獨立致命倒數（取代連續生命扣除）

當 severity 達到瀕死閾值（≥ 0.9）時，各狀態啟動獨立的致命倒數，而非連續扣除生命值。

| 狀態 | 觸發條件 | 致命倒數機制 |
|------|---------|------------|
| 外傷 | severity ≥ 0.9 | 每秒失血：生命值 -0.5%（玩家可見「傷口大量失血」HUD 警告）|
| 內傷 | severity ≥ 0.9 | 10 遊戲小時死亡倒數（玩家可見倒數計時，可中途搶救）|
| 中毒 | severity ≥ 0.9 | 每遊戲小時毒素攻心：生命值 -3%（依毒種類可能更快）|
| 疾病 | severity ≥ 0.9 | 每遊戲小時病情惡化：生命值 -1.5%，且所有屬性修飾詞加重 |
| 疲勞 | severity ≥ 0.9 | 5% 機率每次行動昏厥（不扣生命，但進入強制暫停 30 秒）|
| 飢餓 | severity ≥ 0.9 | 每遊戲小時：生命值 -1%，5% 機率暈倒（同疲勞昏厥機制）|

**多個倒數同時存在：** 各自獨立計時，最先達到生命值歸零者優先觸發死亡事件，其他倒數同時取消。

**搶救條件（全狀態通用）：** 讓該狀態 severity 降低至 0.85 以下即可取消對應倒數。

### 4.4 同類型新傷疊加公式

```
new_severity = clamp(current + incoming × (1.0 - current × 0.5), 0.0, 1.0)
```

**變數定義：**
- `current`：受傷前的 severity（0.0–1.0）
- `incoming`：新傷害對應的 severity 量（0.0–1.0）
- 遞減因子 = `(1.0 - current × 0.5)`，current=0 時為 1.0，current=1 時為 0.5

**範例計算：**

| current | incoming | 計算過程 | new_severity |
|---------|---------|---------|-------------|
| 0.0 | 0.4 | 0.0 + 0.4 × (1.0 - 0.0×0.5) = 0.0 + 0.4×1.0 | **0.4** |
| 0.5 | 0.4 | 0.5 + 0.4 × (1.0 - 0.5×0.5) = 0.5 + 0.4×0.75 | **0.8** |
| 0.8 | 0.4 | 0.8 + 0.4 × (1.0 - 0.8×0.5) = 0.8 + 0.4×0.6 = 1.04 → clamp | **1.0** |

## 5. 邊界條件

| 情況 | 處理方式 |
|------|---------|
| severity ≥ 0.9 | 每小時觸發瀕死檢查 |
| 兩個以上狀態 severity ≥ 0.9 | 角色昏迷，10 小時死亡倒數 |
| severity 歸零 | 狀態移除；若有後遺症（如重傷後體魄永久 -5）則觸發後遺症事件 |
| severity ≥ 1.0 | 對應致死事件（外傷失血、中毒毒發、飢餓餓斃等）|
| 角色死亡 | 所有 severity 鎖定用於死亡報告；若啟用傳代，影響下一代初始狀態 |
| 「運功逼毒」 | 中毒恢復 +0.10/天，同時觸發內傷 severity +0.02 |

- 一般受傷（0.3–0.6）可在 3–5 天自然恢復
