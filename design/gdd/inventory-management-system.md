*策劃：陳品霖（v2草稿）| 整合修訂：怡嘉 | 製作人拍板：2026-05-12 | 狀態：✅ 已核准*

---

## 1. 概述（Overview）

庫存管理系統管理玩家角色持有、存放、取用所有物件的規則。它定義五個存儲層的結構與限制、物品的分類與屬性、以及核心操作（拾取/存放/取出/丟棄/使用）的規則。

**系統邊界：** 本系統只定義物品的「在哪裡」和「怎麼操作」。物品的效果（如藥的治療量）、物品的來源（如戰鬥掉寶）、物品引發的世界反應（如NPC看到你的武器），均由各自對應的系統負責。

---

## 2. 玩家體驗（Player Fantasy）

- **初期（0-20h）**：家當就背在身上，什麼都缺，什麼都想撿，出門前要精打細算帶什麼
- **中期（20-100h）**：有了落腳處，開始懂得「狡兔三窟」，身上只帶必需品，珍貴的東西存在安全地方
- **後期（100h+）**：武學藏書閣裡存著一生習得的秘笈，思考哪些要傳給下一代

## 3. 詳細規則（Detailed Rules）

### 3.1 五個存儲層

| 層 | 名稱 | 存什麼 | 存取條件 | 容量 |
|---|------|-------|---------|------|
| 1 | **隨身行囊** | 消耗品、材料、備用裝備、秘笈、信物 | 隨時 | 20格，可擴充 |
| 2 | **裝備欄** | 穿戴中的武器/防具/飾品 | 隨時 | 固定欄位（依部位）|
| 3 | **箱籠（住所）** | 長期存放物品 | 需在對應住所 | 依房產等級 |
| 4 | **武學藏書閣** | 武學秘笈專用 | 需在藏書閣所在地 | 初始50本，可擴充 |
| 5 | **角色屬性** | 銀兩（顯示為數值）| 非物件，無需操作 | 無上限 |

> **銀兩不佔格子。** 銀兩是角色屬性欄的獨立數值，不是物件。

---

### 3.2 武學藏書閣（詳細規則）

武學秘笈是武俠RPG的特殊物件，需要獨立的存儲空間——鬼谷八荒、龍胤立志傳、群俠傳皆有此設計。

**功能：**
- 存放習得或待學的武學秘笈
- 秘笈學完後**不消失**，仍可傳授他人
- 收徒後，師父可從藏書閣選擇秘笈傳給弟子
- 加入門派後，門派藏書閣向弟子開放部分秘笈（依身份等級）

**存取規則：**
- 個人藏書閣：在自宅或所住客棧存取
- 門派藏書閣：在門派據點存取，存取權限見 3.3

### 3.3 箱籠與門派倉庫

**個人住所箱籠：**

| 住所類型 | 箱籠格數 |
|---------|---------|
| 客棧（短租）| 50格 |
| 茅草屋 | 100格 |
| 磚瓦房 | 200格 |

**門派倉庫（依身份開放）：**

| 身份 | 倉庫存取格數 |
|------|-----------|

### 3.4 物品分類

| 類別 | 可疊加 | 代表物品 | 備註 |
|------|--------|---------|------|
| 消耗品 | ✅ 上限99 | 金瘡藥、乾糧、迷煙 | 用完消失 |
| 材料 | ✅ 上限99 | 鐵礦、藥草、獸皮 | 供製作使用 |
| 裝備 | ❌ | 武器、防具、飾品 | 持久存在，有耐久度 |
| 秘笈 | ❌ | 武學書、殘卷 | 學完不消失，可傳授 |
| 信物/任務道具 | ❌ | 門派令牌、藏寶圖 | 不可丟棄，任務完成後系統處理 |
| 財物 | ❌ | 珠寶、古董 | 主要供交易 |

### 3.5 負重系統

**最大負重 = `50 + floor(體魄 × 0.5)` 斤**

範例：體魄60 → 最大負重 = `50 + 30 = 80斤`

**移動速度影響：**
```
速度倍率 = max(0.1, 1 - (當前負重 / 最大負重) × 0.6)
```
- 負重0%：速度100%
- 負重100%：速度40%
- 負重>100%：無法移動，必須丟棄物品

**超載與戰鬥：**
- 超載狀態可進行戰鬥（可攻擊/使用物品），但無法移動
- 戰鬥系統讀取「無法移動」狀態，不額外懲罰

---

### 3.6 基本操作

| 操作 | 觸發方式 | 規則 |
|------|---------|------|
| 拾取 | 靠近物品按鍵 | 格位滿時提示無法拾取；任務道具強制拾取進「臨時欄（5格）」|
| 使用 | 右鍵點擊消耗品 | 觸發效果，數量-1；效果由對應系統（醫療/飲食）處理 |
| 丟棄 | 拖拽至外或右鍵選擇 | 物品落地形成包裹，3天（遊戲內）後消失 |
| 存放 | 在存取點打開對應介面 | 按層操作（行囊↔箱籠↔藏書閣） |
| 拆分 | 右鍵堆疊物品 | 輸入數量拆分 |

---

### 3.7 裝備耐久度

- 耐久度範圍：50–200
- 每場戰鬥後依受擊次數下降
- 耐久效果：

| 耐久比例 | 效果 |
|---------|------|
| >50% | 正常 |
| 20%–50% | 詞條效果 -50% |
| <20% | 詞條效果無效，戰鬥中有機率損壞 |
| 0% | 裝備損壞消失，穿戴中的自動卸下 |

- 修理費 = `(最大耐久 - 當前耐久) × 品質單價`

| 品質 | 單價（銀兩/點）|
|------|------------|
| 凡品 | 1 |
| 精良 | 2 |
| 利器 | 5 |
| 寶器 | 15 |
| 神兵 | 50 |
| 絕世 | 200 |
| 天工 | 1000 |

## 4. 公式（Formulas）

```
最大負重 = 50 + floor(體魄 × 0.5)  單位：斤
速度倍率 = max(0.1, 1 - (當前負重/最大負重) × 0.6)
修理費   = (最大耐久 - 當前耐久) × 品質單價
```

**物品重量參考值（設計基準）：**

| 物品類型 | 重量 |
|---------|------|
| 輕型裝備（匕首/布衣）| 2斤 |
| 中型裝備（單手劍/皮甲）| 5斤 |
| 重型裝備（長柄/鐵甲）| 15斤 |
| 藥材/食物 | 0.2斤/個 |
| 暗器 | 0.1斤/個 |
| 礦石 | 2斤/個 |
| 武學秘笈 | 0.5斤/本 |

## 5. 邊界條件（Edge Cases）

| 情境 | 處理方式 |
|------|---------|
| 格位滿時拾取普通物品 | 拒絕，提示「行囊已滿」 |
| 格位滿時拾取任務道具 | 強制進入臨時欄（5格）；臨時欄不可交易/丟棄 |
| 超載進入戰鬥 | 可攻擊/使用物品，無法移動；戰鬥結束後仍提示超載 |
| 裝備耐久歸零在穿戴狀態 | 自動卸下，從行囊消失 |
| 拆分堆疊時數量超過上限 | 拒絕，提示「超過堆疊上限」 |
| 離開門派時門派倉庫物品 | 廣播事件，由門派系統決定物品歸屬（庫存系統不處理） |

## 6. 系統依賴（Dependencies）

**依賴的系統：**
- 角色屬性系統（#2）：讀取體魄計算最大負重
- 時間系統（#1）：丟棄物品的3天消失計時
- 武學技能系統（#8）：秘笈傳授的學習邏輯
- 事件總線（#35）：廣播 `player_left_faction` 等事件

**被依賴的系統：**
- 裝備系統（#9）：裝備欄的穿戴/卸下/詞條生效
- 經濟系統（#12）：買賣時讀/寫行囊
- 任務系統（#19）：任務道具的給予與回收
- 戰鬥系統（#11）：戰鬥中的道具使用、裝備耐久扣減
- 傳代系統（#32）：傳代時哪些物品可繼承

## 7. 可調參數（Tuning Knobs）

| 參數 | 當前值 | 安全範圍 | 影響 |
|------|-------|---------|------|
| 行囊初始格數 | 20格 | 15–30格 | 越少越有選擇壓力 |
| 負重基礎值 | 50斤 | 30–80斤 | 新手攜帶能力 |
| 體魄負重係數 | 0.5 | 0.3–0.8 | 體魄對負重的貢獻 |
| 速度懲罰係數 | 0.6 | 0.4–0.8 | 負重對移動的影響強度 |
| 藏書閣初始容量 | 50本 | 30–100本 | 武學收集空間 |
| 耐久損壞閾值 | 20% | 10–30% | 裝備耐用程度 |
| 丟棄物品消失時間 | 3天 | 1–7天 | 撿回遺棄物的時間窗口 |

## 8. 驗收標準（Acceptance Criteria）

| # | 驗收項目 | 預期結果 |
|---|---------|---------|
| AC1 | 行囊20格滿時拒絕拾取普通物品 | 提示「行囊已滿」，物品留在地上 |
| AC2 | 銀兩不佔用行囊格位 | 獲得銀兩後格位不變，屬性欄數值增加 |
| AC3 | 消耗品可堆疊至99，第100個新建格 | 數量正確，超過99自動新格 |
| AC4 | 裝備/秘笈不可堆疊 | 各佔一格 |
| AC5 | 負重100%時無法移動 | 角色無法在地圖上移動 |
| AC6 | 武學秘笈學完後不消失 | 學完後秘笈仍在行囊/藏書閣 |
| AC7 | 藏書閣只接受秘笈類物品 | 嘗試存入其他類型物品被拒絕 |
| AC8 | 箱籠跨住所不互通 | 在甲城存的物品，在乙城箱籠看不到 |
| AC9 | 門派倉庫按身份開放對應格數 | 入門弟子10格，長老100格 |
| AC10 | 裝備耐久<20%詞條效果無效 | 裝備同一件，耐久不同時屬性加成有差異 |
| AC11 | 鐵匠修理費用公式正確 | 利器劍耐久100/150 → 修理費=250銀兩 |
| AC12 | 任務道具格位滿時進臨時欄 | 臨時欄最多5件，不可交易/丟棄 |
