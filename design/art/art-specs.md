## 三、動畫系統 ✅

| 階段 | 工具 | 說明 |
|---|---|---|
| MVP | Godot Skeleton2D | 免費，夠用 |
| 正式版 | Spine 2D（$69 買斷）| 升級時遷移 |
| 現在起 | 統一使用 Spine 骨骼命名規範 | 降低未來遷移成本 |

**Spine 標準骨骼命名（現在就照這個建）：**
```
root → hip → spine → chest → neck → head
                           → upper_arm_l / upper_arm_r → forearm_l/r → hand_l/r
              hip → thigh_l / thigh_r → shin_l/r → foot_l/r
```
