# UX Spec：死亡結算畫面

*建立：2026-05-13 | 版本：MVP v0.9 | 狀態：待審核*

---

## 1. 目的與觸發時機

### 觸發情境
角色因任何原因死亡（戰鬥敗亡、傷重不治、壽終正寢、疾病、中毒、走火入魔）後，遊戲世界暫停，畫面漸暗，進入此結算畫面。

### 玩家心理狀態
玩家剛經歷「角色死亡」這個不可逆事件，處於**失落、回顧、總結**的情緒點。
- **目標**：理解「我這一生是怎麼過的」，不是看失敗懲罰
- **情緒需求**：被接住、被尊重、感受到「這一生有意義」
- **設計關鍵**：這是**情感設計的最高優先級畫面**，不是冰冷數據報表

### 與遊戲結束的區別
本遊戲沒有「Game Over」——只有「壽終正寢」或「命殞江湖」。
死亡結算是**一生的句點**，不是「你輸了」。

## 2. 資訊架構（優先層次）

### P1 — 必須立即可見（畫面核心，不需任何操作）

| 資訊要素 | 說明 |
|----------|------|
| **角色名號** | 玩家命名的角色名（大字） |
| **享壽年數** | 「享壽 XX 年」（壽終正寢）/「年僅 XX 歲」（非壽終） |
| **江湖評斷** | 1-2 句武俠語境總結，基於核心選擇（見下方生成邏輯） |
| **死亡方式敘述** | 1 句武俠語境描述（「刀傷過重，血盡而亡」/「年邁體衰，壽終正寢」等） |
| **墓碑/遺物圖示** | MVP：靜態背景圖（營造氛圍）；V2：角色剪影與生平符號 |

**江湖評斷生成邏輯（MVP 規則）**：
```
若 壽終正寢 → 「一生行事，無愧於心」 
若 死於戰鬥 + 正派行為多 → 「俠義之士，刀下留名」
若 死於戰鬥 + 負面行為多 → 「恩怨糾纏，終至如此」
若 死於疾病/中毒 → 「天不假年，世事無常」
若 死於走火入魔 → 「習武過急，反噬其身」
（MVP 最多 8 種，V2 根據更多累積行為擴充）
```

### P2 — 按需展開（玩家點擊/按鍵後展開）

| 資訊要素 | 說明 |
|----------|------|
| **使命回顧** | 三類任務結算區塊（見下方） |
| **重要關係** | 顯示 3-5 位關鍵 NPC 的關係終態（一句化） |
| **武學巔峰** | 顯示最高熟練度武學 1-2 項 |
| **生涯數字** | MVP：擊敗敵手數、完成承諾數、結交好友數（精簡，非清單） |

**使命回顧三區塊**（嚴格遵循 GDD 規格）：

| 區塊 | 標題 | 顏色 | 說明 |
|------|------|------|------|
| 失諾之事 | 「失諾之事」 | 暗紅 (#CC3333) | 失敗的任務 |
| 無緣之事 | 「無緣之事」 | 灰 (#888888) | 失效（INVALIDATED）的任務 |
| 辜負之事 | 「辜負之事」 | 深紫 (#663388) | 玩家主動放棄的任務 |

每個區塊內顯示任務名（若無任務則顯示「無」），最多列出 5 項，超過顯示「另有 N 事未盡」。

### P3 — 進階（玩家可選擇是否觀看）

| 資訊要素 | 說明 |
|----------|------|
| **完整傳記** | 時間軸形式，主要事件節點（V2） |
| **世界墓誌銘** | 不同 NPC 對死訊的反應摘要（V2） |

## 3. 互動流程

### 操作清單

| # | 操作 | 觸發方式 | 結果 | 狀態變化 |
|---|------|---------|------|---------|
| 1 | **展開/折疊「使命回顧」** | 點擊區塊標題 / Y鍵 | 展開顯示該區塊任務列表，再次點擊/按鍵折疊 | 僅視覺展開，不改變畫面結構 |
| 2 | **捲動任務列表** | 滾輪 / D-pad 上下 | 當任務超過 5 項時可捲動查看 | 焦點高亮移動 |
| 3 | **回到開場選單** | 點擊「重返江湖」（按鈕在畫面底部）/ Start鍵 | 返回遊戲主選單（開場畫面） | 結算畫面關閉，主選單浮現 |
| 4 | **直接回到主選單** | ESC / B鍵（長按1秒，防誤觸） | 同上 | 需要長按確認，避免誤終結 |
| 5 | **截圖儲存** | F12 / Share鍵 | 擷取當前畫面（不顯示UI按鈕的純畫面） | 短暫閃屏 + 提示「傳記已存」 |

**關鍵設計**：
- 「重返江湖」按鈕**不在 P1 立即顯示**——畫面淡入後，先讓玩家閱讀核心資訊（靜置 2 秒），按鈕再浮現
- 按鈕文案：「重返江湖」（回到主選單，開始新的旅程），不使用「離開」「退出」等冷漠詞
- 按鈕下方副文案：「江湖仍在，另一個故事等待著」

## 4. 狀態定義

| 狀態 | 觸發條件 | 視覺表現 | 行為差異 |
|------|---------|---------|---------|
| **淡入** | 角色死亡後 1.5 秒 | 畫面從全黑緩慢淡入（2 秒），核心資訊先出現，背景後浮現 | 禁止操作（防止玩家誤跳過結算） |
| **靜置** | 淡入完成後 2 秒 | 完整 P1 資訊顯示，按鈕尚未出現 | 僅可截圖操作 |
| **可互動** | 靜置結束 | 「重返江湖」按鈕從畫面底部浮入（0.5 秒動畫） | 所有操作開放 |
| **展開區塊** | 玩家展開任一回顧區塊 | 任務列表從區塊標題下方向下滑出（0.3 秒） | 區塊標題箭頭旋轉 90° |
| **壽終正寢特殊色調** | 死亡原因為 age | 背景色調偏暖金（夕陽感），墓碑圖示有松鶴元素 | 與非壽終的冷色調區別 |
| **非壽終的冷色調** | 死亡原因非 age | 背景色調偏暗青（月夜感），墓碑圖示為刀劍相關 | 與壽終正寢區別 |

## 5. 輸入映射

| 操作 | 鍵鼠 | 手把 |
|------|------|------|
| 展開/折疊「失諾之事」 | 點擊區塊標題 | A鍵（區塊有焦點時） |
| 展開/折疊「無緣之事」 | 點擊區塊標題 | A鍵（區塊有焦點時） |
| 展開/折疊「辜負之事」 | 點擊區塊標題 | A鍵（區塊有焦點時） |
| 切換焦點（區塊間移動） | 點擊目標區塊 / Tab鍵 | D-pad 上下 |
| 區塊內任務列表捲動 | 滾輪 | D-pad 上下 |
| 回到開場選單 | 點擊「重返江湖」按鈕 | Start鍵 |
| 安全退出（防誤觸） | 長按 ESC 1秒 | 長按 B鍵 1秒 |
| 截圖儲存 | F12 | Share鍵 |

**手把焦點順序**（D-pad 路徑）：
```
[角色名號/年數（不可選）]
        ↓
[江湖評斷（不可選）]
        ↓
[失諾之事 ▸]  ← 初始焦點
        ↓
[無緣之事 ▸]
        ↓
[辜負之事 ▸]
        ↓
[生涯數字（不可選，但可讀取）]
        ↓
[重返江湖 按鈕]
```

## 6. 無障礙要求

| # | 要求 | 規格 |
|---|------|------|
| 1 | **色彩區分不唯一** | 三個任務區塊除了顏色（暗紅/灰/深紫），必須有獨立圖示輔助：失諾=✗、無緣=◷、辜負=⟳ |
| 2 | **文字可讀性** | 所有文字在 720p 解析度下最小字級 ≥ 16px；江湖評斷大字 ≥ 24px |
| 3 | **色盲模式** | 失諾區塊增加左側豎線標記（3px）；無緣區塊增加虛線邊框；辜負區塊增加斜線底紋 |
| 4 | **螢幕閱讀器** | 依序讀取：角色名號 → 享壽年數 → 死亡方式 → 江湖評斷 → 區塊標題+數量 → 按鈕；讀取任務列表時先報總數再報項目 |
| 5 | **按鍵導航** | 完全支援鍵盤 Tab 導航（區塊標題→任務項→按鈕），焦點框對比度 ≥ 3:1 |
| 6 | **延遲螢幕** | 畫面靜置時間可延長至 5 秒（無障礙設定開啟時），確保閱讀障礙者有足夠時間 |

## 8. MVP / V2 邊界

### MVP 必做
- [x] 核心資訊顯示：角色名號、享壽年數、死亡方式、江湖評斷
- [x] 三區塊任務結算（失諾/無緣/辜負），可展開折疊
- [x] 背景色調區分壽終 vs 非壽終（暖金 vs 暗青）
- [x] 「重返江湖」按鈕（延遲浮入）
- [x] 防誤觸 ESC/B 長按
- [x] 色盲模式標記（豎線/虛線/斜線）
- [x] 基本手把導航（D-pad 焦點移動 + A鍵選擇）
- [x] 8種江湖評斷文案

### V2 追加
- [ ] 角色剪影 / 墓碑背景美術資源（目前 MVP 用色調+圖示區分）
- [ ] 生涯數字區塊（擊敗敵手數、完成承諾數等統計）
- [ ] 重要NPC關係終態顯示（3-5位關鍵人物的一句化總結）
- [ ] 武學巔峰顯示
- [ ] 完整傳記時間軸（P3層，主要事件節點）
- [ ] 死亡瞬間的短動畫（0.5秒閃回畫面）
- [ ] 區塊展開時任務名旁顯示對應NPC名稱
- [ ] 江湖評斷文案擴充至 20+ 種（根據更多行為累積變數）

### 明確不做
- ❌ 顯示精確死亡時間（因為不顯示精確剩餘壽命，死後也不回溯精確時刻）
- ❌ 顯示「分數」或「評價等第」（S/A/B/C）—— 玩家自我評斷，不由系統打分
- ❌ 顯示可避免死亡的「攻略提示」（破壞沉浸和情感重量）
- ❌ 「再來一局」快速按鈕 —— 必須經過「重返江湖」回到主選單，節奏上尊重死亡
- ❌ 戰鬥重播 —— 本作不做戰鬥錄影回放
