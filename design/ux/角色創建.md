# UX Spec：角色創建

*建立：2026-05-12 | 狀態：MVP 定義完成*

## 1. 目的與觸發時機

**觸發時機**  
- 玩家在主選單點擊「入世」（開始新遊戲）後，立即進入角色創建流程。
- 這是玩家與江湖的第一次接觸，也是「這是我的一生」支柱的第一個落地點——從這一刻起，玩家就開始「活」這個角色。

**玩家心理狀態**
- **目標**：創造一個「屬於我的江湖人物」，期待這個人物的出身和性格會在江湖中產生不同際遇。
- **情緒**：好奇、期待、略帶謹慎（因為知道選擇有代價，但尚未體驗過代價的重量）。
- **資訊需求**：玩家需要「夠多資訊做選擇，但不需要看穿所有後續影響」。
  - 給：每個選擇的即時意義（出身決定起點、性格決定對話風格）
  - 不給：完整後果矩陣（不知道哪個出身「最強」、不知道性格會讓哪些 NPC 討厭你）

**設計意圖**  
此畫面不是「表單填寫」，而是一段「命數初定」的短暫儀式——玩家在不知不覺中，已經開始做有代價的選擇。

## 2. 資訊架構（優先層次）

### P1 — 必須立即可見（常駐）

| 元素 | 內容 | 呈現方式 |
|------|------|---------|
| 當前步驟指示器 | 六步驟標籤：出身 → 外觀 → 命名 → 性格 → 天賦 → 確認 | 頂部水平步驟條，當前步驟高亮（金色），已完成步驟顯示勾（灰色），未達步驟顯示灰底圓點 |
| 步驟說明文字 | 一句武俠語境說明當前步驟的意義 | 步驟條下方 32-48px 處，置中，字級 18pt（例：「你從何處來，便決定了你最初的目光所及」） |
| 當前步驟選擇區 | 出身：6 個選項卡片（農家/商賈/書香/武林/將門/孤兒） | 畫面中央，水平排列 3×2 網格（鍵鼠/手把皆可選取），每張卡片顯示出身名 + 一句江湖描述 |
| 角色預覽 | 當前外觀的即時畫面 | 畫面右側（或左側，取決於佈局），角色剪影/模型即時反應所有外觀變更 |
| 下一步按鈕 | 「繼行」按鈕 | 畫面右下角常駐，灰底（未選擇時無法點擊，選中後亮金） |
| 上一步按鈕 | 「回首」按鈕 | 畫面左下角常駐，從第二步開始出現（第一步無上一步） |

### P2 — 需要時展開（選中後觸發）

| 元素 | 內容 | 呈現方式 |
|------|------|---------|
| 出身詳情浮框 | 選中某出身卡片後，浮框顯示：起始門派/勢力關係、起始武學傾向、起始銀兩範圍（文字描述，不給數字）、一句人生格言 | 懸停/聚焦後 0.3s 淡入，位於所選卡片上方或側方（避免遮擋其他卡片） |
| 性格度數說明 | 選中某性格後，度數選項（-1 / 0 / +1）下方顯示簡短說明文字 | 即時文字更新，字級 14pt（例：「剛正不阿，寧折不彎」= 剛正+1；「不偏不倚」= 剛正 0） |
| 屬性修飾詞預覽 | 性格確認後，展開「此心性將影響…」說明 | 藍色底框，詞條式顯示（例：「與剛正之人往來，彼此敬重；遇奸邪之徒，水火不容」） |
| 天賦詳情 | 點擊天賦卡片後展開詳細說明 | 浮框顯示天賦效果（武俠描述 + 遊戲機制描述並存，例：「氣運加身——行走江湖時，遇險得救的機緣略增」） |

### P3 — 進階/設定（玩家主動查詢）

| 元素 | 內容 | 呈現方式 |
|------|------|---------|
| 完整屬性計算預覽 | 所有選擇的最終屬性數值 | 僅在「確認」步驟顯示，以表格形式呈現（但不下鑽到公式） |
| 跳過動畫設定 | 是否跳過天賦開獎動畫 | 設定選單中設定，不在此畫面直接呈現 |

## 3. 互動流程

### 3-1 步驟流轉（線性，不可跳步，已確認不可回頭到性格步驟）

```
出身選擇 → [繼行] → 外觀自定義 → [繼行] → 命名 → [繼行] → 性格選擇 → [繼行] → 天賦抽取 → [繼行] → 總覽確認 → [入世]
                       ↑ [回首]          ↑ [回首]      ↑ [回首]      ↑ [回首，但只能回到外觀]   ↑ [回首]
                                                                                     (性格不可回改)
```

**設計規則**：
- 第一步（出身）只有「繼行」，無「回首」。
- 性格步驟之後，不可回到性格修改——這是製作人指定的設計禁忌（GDD 明確定義）。
  - 因此從天賦步驟點「回首」只能回到外觀步驟（跳過性格和命名）。
  - **UI 處理**：性格步驟後的「回首」按鈕旁顯示提示句：「心性既定，無可回首」（灰色小字，14pt）。
- 最後一步（確認）的「繼行」改為「入世」，按下後不可逆。

### 3-2 各步驟操作細節

**步驟 1：出身選擇**
- 操作：鍵鼠點擊/手把 D-pad 移動焦點 + A 鍵選取。
- 選中後：選中卡片亮金框 + 浮框顯示出身詳情（P2），同時角色預覽區更新為該出身的預設外觀。
- 未選中時：「繼行」按鈕灰色不可點擊。
- 點擊「繼行」→ 鎖定出身，進入下一步，步驟指示器更新。

**步驟 2：外觀自定義**
- 操作：左右箭頭或下拉選項切換髮型、臉型、服色等（具體自定義項目由美術提供規格，此處定義互動邏輯）。
- **即時預覽**：每次變更直接反應在角色預覽區，無需確認。
- 外觀變更不影響屬性，純視覺選擇。
- 「繼行」始終可點擊（外觀無所謂「未選擇」狀態）。

**步驟 3：命名**
- 操作：文字輸入框，鍵盤直接輸入；手把模式下點擊輸入框後叫出系統鍵盤（Steam Input API）。
- 字數限制：2-6 字（中文/英文混合算字數）。
- 即時驗證：空白或超長時輸入框底部顯示紅字提示，且「繼行」灰色不可點擊。
- 命名完成後，「繼行」亮起。

**步驟 4：性格選擇**
- 八種性格：剛正、陰沉、豪邁、機巧、仁厚、孤傲、痴情、澹泊。
- 操作：選中性格卡片後，出現三級度數選擇（-1 / 0 / +1）。
  - 度數選擇用三段滑塊或三個按鈕，目前選中項高亮。
  - 度數下方即時顯示說明文字（P2）。
- 選中性格+度數後：「繼行」亮起。
- 點擊「繼行」→ **屬性修飾詞預覽**浮現（0.5s 淡入），顯示兩秒後自動繼續，或玩家點擊「知曉」跳過。
- 從此步驟開始，上一步只能回到外觀步驟（跳過命名）。

**步驟 5：天賦抽取（關鍵體驗點）**
- **機制**：隨機抽取 5 個天賦（可選其中 1 個；若為「天選之人」天賦則可選 2 個，需明示）。
- **視覺呈現**：
  - MVP：5 張卡片背面朝上排列，玩家依序點擊翻開，每張翻開有 0.3s 翻牌動畫（V2 加強）。
  - 翻開後顯示天賦名稱、品質顏色邊框（灰/白/綠/藍/紫/金/紅）、簡短效果描述。
  - 品質顏色規範：灰（凡）/ 白（常）/ 綠（良）/ 藍（佳）/ 紫（稀）/ 金（極）/ 紅（天選）。
- **選取規則**：
  - 玩家已選的卡片顯示金色選中框。
  - 點擊已選卡片可取消選取。
  - 選滿上限後（1 個或 2 個），其餘卡片自動灰化不可點擊。
- **「天選之人」特殊處理**：
  - 若 5 張中出現紅品「天選之人」天賦，該卡片必須清楚標示「可選二項天賦」（紅色文字提示）。
  - 選取「天選之人」後，可選取數量變為 2。
- 選滿後「繼行」亮起。

**步驟 6：總覽確認**
- 畫面顯示所有選擇的摘要（文字列表形式）：
  - 出身、外觀（小圖示）、姓名、性格（含度數）、天賦（含品質顏色邊框）。
- **屬性修飾詞總覽**：列出初始屬性走向（例：「臂力——略有根基」「機敏——天生過人」），不給數值。
- 「回首」可回到外觀步驟修改（但不能改性格、不能改天賦、不能改出身——已鎖定）。
- 「入世」按鈕：按下後 1 秒黑幕過渡，角色誕生，進入遊戲世界。

### 3-3 退出流程
- 任何步驟按下 Esc（鍵鼠）/ Start（手把）→ 彈出確認對話框：「放下筆墨，暫且離去？」（是/否）。
- 選擇「是」→ 回到主選單，所有創角進度不保留（因為選擇有代價，事前反悔也算代價）。

## 4. 狀態定義

| 狀態 | 視覺表現 | 行為差異 |
|------|---------|---------|
| **步驟未達** | 步驟指示器：灰底圓點 | 不可點擊前往 |
| **步驟當前** | 步驟指示器：金色圓點脈衝（循環 1.5s 一次） | 當前操作區 |
| **步驟已完成** | 步驟指示器：白色勾（灰色底） | 可點擊前往（但性格之後無法回到性格步驟） |
| **選項未選中** | 卡片：灰底、無邊框、文字灰色 | 不可觸發繼行 |
| **選項聚焦（hover/focus）** | 卡片：淺金邊框（#C9A96E）、微弱光暈、文字略亮 | 浮框顯示詳情（P2） |
| **選項已選中** | 卡片：金邊框（#D4AF37）、3px 邊框、底色微亮 | 可觸發繼行 |
| **選項已鎖定（不可改）** | 卡片：暗金邊框 + 右下角小鎖圖示 | 不可取消選取（總覽步驟的出身/性格/天賦） |
| **按鈕不可用** | 灰底、文字暗灰、無邊框 | 點擊無反應 |
| **按鈕可用** | 亮金底（#D4AF37）、文字墨黑、2px 邊框 | 點擊觸發行動 |
| **天賦卡片未翻開** | 背面（統一紋理，卡背設計由美術提供） | 點擊翻開 |
| **天賦卡片已翻開未選** | 正面顯示內容、品質顏色邊框 | 點擊選取 |
| **天賦卡片已選取** | 正面 + 金框 + 勾 | 點擊取消選取 |
| **天賦卡片不可選（滿額）** | 正面灰化、半透明遮罩 | 不可點擊 |

## 5. 輸入映射

| 操作 | 鍵鼠 | 手把（Xbox 配置） |
|------|------|------------------|
| 移動選擇焦點 | 滑鼠移動 / Tab 切換群組 | D-pad 上下左右 / 左搖桿 |
| 選取當前焦點 | 滑鼠左鍵點擊 | A（底部鍵） |
| 切換度數（性格步驟） | 點擊度數按鈕 / 滾輪 | D-pad 左/右 |
| 翻開天賦卡片 | 點擊卡片 | A（聚焦卡片後） |
| 下一步 | 點擊「繼行」按鈕 | Start（或 Y 快速鍵） |
| 上一步 | 點擊「回首」按鈕 | B（底部右鍵） |
| 退出創角（含確認對話框） | Esc | Start（長按 1s） |
| 跳過屬性預覽（性格後） | 點擊「知曉」 / 任意鍵 | A |
| 命名輸入 | 鍵盤直接輸入 | A 點擊輸入框 → 叫出系統鍵盤 |

**按鍵圖示規範**：
- 鍵鼠模式下，按鈕旁顯示鍵盤快捷鍵提示（例：`[Enter] 繼行`）。
- 手把模式下，按鈕旁顯示手把按鍵圖示（美術提供圖示素材）。
- 偵測到最後一次輸入來自手把 → 全部 UI 自動切換手把圖示；來自鍵鼠 → 切換鍵鼠圖示。無需玩家手動設定。

## 6. 無障礙要求

### 6-1 視覺
- **最小字級檢查**：所有文字在 720p 解析度下 ≥ 14pt（實際渲染後可讀性測試）。
- **品質顏色非唯一區分方式**：每張天賦卡片除了品質顏色邊框外，必須在卡片左上角顯示品質文字標籤（凡/常/良/佳/稀/極/天選），確保色盲玩家可辨識。
- **步驟指示器不純靠顏色**：當前步驟除了金色，還要有脈衝動畫（圓圈縮放循環），確保色盲玩家可辨識。
- **對比度**：所有文字與背景對比度 ≥ 4.5:1（WCAG AA）。

### 6-2 聽覺
- **此畫面無語音，不需字幕**。
- 天賦開獎時的音效需同時有視覺回饋（卡片翻開動畫 + 品質邊框閃現），確保聽障玩家可感知。

### 6-3 操作
- 所有功能必須用 D-pad + A/B/Start 完成，無 hover-only 互動。
- 命名輸入在手把模式下需叫出系統鍵盤（Steam Input API），不可讓玩家無法輸入。
- 天賦步驟翻牌：手把焦點移動順序為左→右、上→下（卡片排列順序），不可出現「跳躍式」焦點路徑。

### 6-4 認知
- 每步驟的說明文字（P1 步驟說明）簡短直白，武俠語境但不過度文言，避免認知負荷。
- 性格度數的說明文字需直觀（例：「剛正 -1：凡事留三分，不與人爭鋒」），不寫需要二次解讀的隱喻。

## 8. MVP / V2 邊界

### MVP 必做（Pre-production 末期交付）
- [x] 六步驟線性流程完整可走
- [x] 步驟指示器（當前/完成/未達狀態切換）
- [x] 出身選擇：6 張卡片 + 選中浮框
- [x] 外觀即時預覽（項目由美術定義，此處僅定義互動邏輯）
- [x] 命名輸入框 + 驗證
- [x] 性格 8 選 1 + 度數三段選擇
- [x] 性格確認後屬性修飾詞預覽（2 秒浮現）
- [x] 天賦 5 選 1（或天選之人 5 選 2）
- [x] 天賦卡片翻牌動畫（0.3s 過渡，MVP 可用簡單旋轉或淡入，不需精緻物理翻牌）
- [x] 天賦品質顏色邊框 + 文字標籤（無障礙）
- [x] 確認步驟總覽
- [x] 「心性既定，無可回首」提示
- [x] 退出確認對話框
- [x] 鍵鼠 + 手把完整支援
