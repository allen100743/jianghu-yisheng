# UX Spec：傷勢與狀態效果 HUD

*建立：2026-05-13 | 狀態：MVP 規格*
*設計者：李靜怡 | 版本：v1.0*
*對應 GDD：status-effects-system.md（傷勢與狀態效果）*

---

## 1. 目的與觸發時機

### 目的
讓玩家隨時感知自身角色的身體狀況，不打開任何選單就能透過 HUD 圖示掌握傷勢、中毒、疲勞等狀態的**存在、嚴重程度與變化**，並在需要時快速取得武俠語境的情境描述，以及最終數值細節。  
設計上徹底貫徹四大支柱中的「時間可見」與「選擇有代價」：傷勢惡化、飢餓加劇都必須是可察覺的，玩家不需讀數值就能感受到「這一刀砍得很深，我必須趕快止血」。

### 觸發時機
- **HUD 圖示**：任何狀態的 `severity > 0.0` 時，對應圖示即時出現（從無到有淡入 0.3 秒）。
- **圖示持續**：只要 `severity > 0.0` 就保持顯示，`severity` 歸零時圖示淡出消失（0.5 秒）。
- **危急脈衝**：任一狀態首次達到 `severity ≥ 0.9` 時，觸發一次性「心脈示警」動畫（圖示放大 + 紅色光環向外擴散），之後該圖示維持微弱脈動，直至 `severity < 0.9` 或角色死亡。
- **懸停浮框（P2）**：滑鼠游標移至圖示上停留 0.2 秒，或手把焦點選中圖示後按「確認」鍵，立即顯示武俠情境描述。
- **詳細面板（P3）**：從 HUD 可一鍵進入「江湖志 — 身上狀況」全螢幕面板（見互動流程）。

## 2. 資訊架構（漸進揭露三層）

### P1 — HUD 圖示列（即時感知層）
常駐於畫面左上角（角色血量/內力條下方），水平排列，每一狀態一個圖示。

**顯示內容（每個圖示）：**
- **圖形基底**：六角形盾框（18×18 px，可依 UI 縮放設定調整）
- **填充度**：內部由下往上填滿的色塊，高度對應 `severity × 100%`（0.0 空，1.0 全滿）
- **段位色條**：盾框底部 3px 高的 micro-bar，顏色直接反映當前段位（見下方顏色表）
- **狀態象形標誌**：盾內中央疊加簡化圖形（如血滴、毒液），即使去色也能分辨狀態種類
- **危急脈衝**：`severity ≥ 0.9` 時，盾框外緣帶有紅色微光脈衝（每 1.5 秒一次呼吸明暗）

**排序規則：**
- 強制規則：任何 `severity ≥ 0.9` 的圖示一律置頂（放在最左側），並帶脈衝
- 其餘圖示按「緊急度評分」從高到低排列（系統計算：`severity × 惡化速率係數 × 致死風險係數`，玩家不可見）
- 超過 **5 個**狀態時，只顯示前 4 個（最高緊急度），第 5 個及以後折疊為一個 `+N` 圖示（灰底白字），點擊/懸停可展開全部狀態清單

### P2 — 懸停浮框（情境理解層）
游標懸停圖示或手把選取時，在圖示上方彈出浮框（寬 220px，自適應文案長度）。

**浮框內容：**
1. **狀態名稱**（大字，顏色同狀態主色）
2. **情境句式描述句**（依 severity 階段變化，見下方文案表）
3. **主要影響提要**（一句武俠語境，如「出招稍緩，力不從心」）
4. **進度指示**：一條細長 bar（`severity` 百分比），輔助理解嚴重度
5. 若該狀態導致某項行動被封鎖（如內傷無法運功），在此顯示紅色警示句：「經脈受損，無法運功」

**格式範例（外傷，severity = 0.45）：**
```
【外傷】  
傷口見骨，血染衣襟，疼痛難當。  
身手略鈍，行動稍緩。  
[████████░░░░░░░░░░] 45%  
```

### P3 — 詳細狀態面板（數值決策層）
觸發方式：點擊任一圖示、或按快捷鍵 `C` / 手把 `View鍵`，開啟全螢幕「江湖志 — 身上狀況」面板。

**面板內容：**
- **角色全身插畫**（或剪影），以視覺標記標示各傷處（外傷於肢體、內傷於胸腹等）
- **所有當前狀態的詳細卡片**，每張包含：
  - 狀態名稱與圖示
  - severity 數值（百分比與進度條）
  - 目前段位
  - 對屬性的具體影響（寫明「武力 -15%、輕功 -10%」等，此處可用遊戲術語）
  - 惡化/恢復速率說明（如「未包紮，每日惡化 0.05」）
  - 建議處置（如「服用金創藥可加速癒合」）
- **總合影響**：列出最終屬性變化（已在底層計算完成），讓玩家一目瞭然
- **關閉**：按 `ESC` / 手把 `B` 返回遊戲，整個流程從打開面板到關閉不超過 2 次按鍵

## 3. 互動流程

### 3.1 滑鼠操作 (PC 預設)
1. **HUD 感知**：玩家眼角餘光看到圖示出現、變色、脈衝。
2. **懸停看浮框**：游標移到任一圖示，暫停 0.2 秒彈出浮框，移開即消失（無點擊）。
3. **點擊進入詳細面板**：左鍵點擊任一圖示（或按下 `C` 鍵），立即開啟 P3 面板。
4. **折疊狀態**：點擊 `+N` 圖示，浮框出現全部狀態條目；再點擊其中一個可直接跳轉對應 P3 面板。
5. **返回遊戲**：`ESC` 或再次點擊 HUD 區域外的遊戲畫面關閉面板。

### 3.2 手把操作 (支援 Steam Input)
1. **常規遊戲**：HUD 不可直接互動，避免干擾戰鬥。
2. **啟用 HUD 焦點**：按住 `LB` 鍵（或設定中的修飾鍵），狀態圖示區出現焦點框，預設選中最左側（最緊急）圖示。
3. **瀏覽**：D-pad 左右移動焦點。
4. **看浮框**：焦點停留在一圖示上 0.3 秒，自動彈出浮框。
5. **展開折疊**：焦點在 `+N` 上按下 `A`，彈出折疊狀態清單，用 D-pad 上下瀏覽。
6. **進入詳細面板**：選定圖示後按下 `A`（或長按 `A` 0.5 秒打開 P3）。
7. **退出**：按 `B` 關閉浮框或面板，回到遊戲。再按 `B` 或放開 `LB` 離開 HUD 焦點模式。

## 4. 狀態定義：六種傷勢/狀態視覺規格

### 4.1 顏色與圖示定義表

| 狀態 | 主色（HEX） | 武俠稱呼 | 圖示象形 | 微色條段位色 |
|------|------------|---------|---------|-------------|
| 外傷 | 暖紅 `#C0392B` | 傷 | 血滴 + 刀痕裂口 | 0.0–0.3 灰、0.3–0.6 黃、0.6–0.9 橙、0.9–1.0 紅 |
| 內傷 | 深紫 `#8E44AD` | 內 | 斷裂經脈（分叉線條）| 同外傷色階，但底色為深紫 |
| 中毒 | 毒綠 `#27AE60` | 毒 | 毒液滴 + 骷髏簡影 | 同上色階邏輯 |
| 疲勞 | 冷灰 `#7F8C8D` | 乏 | 彎腰垂頭小人 | 同上色階邏輯 |
| 飢餓 | 土黃 `#D4AC0D` | 飢 | 空碗 + 裂紋 | 同上色階邏輯 |
| 疾病 | 病黃藍 `#2980B9` | 病 | 藥罐 + 升騰疫氣 | 同上色階邏輯 |

**段位色階判斷**：micro-bar 與圖示填充色塊的主色為該狀態主色，但隨 severity 段位加入通用警示色調：
- `0.0 < severity ≤ 0.3`：輕微 → 主色混合 20% 灰，暗淡
- `0.3 < severity ≤ 0.6`：顯著 → 主色變為黃色調疊加（如外傷變橙黃）
- `0.6 < severity ≤ 0.9`：嚴重 → 主色變為橙色調疊加（外傷接近橙紅）
- `0.9 < severity ≤ 1.0`：危急 → 純紅色脈衝（所有狀態在此階段統一紅色警示）

### 4.2 懸停浮框文案階段映射

每種狀態針對 severity 劃分 4 句武俠情境描述，並配一句影響提要。此處提供完整六組。

#### 外傷
- 0.01–0.3：「皮肉擦傷，些許疼痛，尚無大礙。」（提要：無明顯影響）
- 0.3–0.6：「傷口見骨，血染衣襟，疼痛難當。」（提要：身手略鈍，行動稍緩）
- 0.6–0.9：「重創在身，血流不止，性命交關。」（提要：武力大減，身形踉蹌）
- 0.9–1.0：「奄奄一息，魂魄將散，速速救治！」（提要：瀕死，無法再戰）

#### 內傷
- 0.01–0.3：「氣血微有不順，稍作調息即可。」（提要：無明顯影響）
- 0.3–0.6：「經脈受損，內息紊亂，運功之時隱隱作痛。」（提要：內力運轉稍滯）
- 0.6–0.9：「臟腑震傷，真氣逆衝，強運內力恐有性命之憂。」（提要：內力大損，無法全力施為）
- 0.9–1.0：「心脈斷裂，生機如風中殘燭。」（提要：無法運功，瀕死）

#### 中毒
- 0.01–0.3：「微感不適，似有異物侵體。」（提要：無明顯影響）
- 0.3–0.6：「毒性發作，四肢痠麻，頭昏眼花。」（提要：身手略顯遲鈍）
- 0.6–0.9：「毒入臟腑，腹痛如絞，氣力飛快流逝。」（提要：武力內力俱損，性命倒數）
- 0.9–1.0：「毒入骨髓，神仙難救，意識即將遠去。」（提要：隨時可能昏迷）

#### 疲勞
- 0.01–0.3：「精神尚可，略有倦意。」（提要：無明顯影響）
- 0.3–0.6：「四肢沉重，眼皮打架，出招已見遲緩。」（提要：武力輕功稍減）
- 0.6–0.9：「氣喘如牛，步履蹣跚，幾欲倒地。」（提要：攻防大幅衰退，易出差錯）
- 0.9–1.0：「精疲力竭，隨時可能昏厥，務必歇息。」（提要：可能不支倒地）

#### 飢餓
- 0.01–0.3：「腹中略空，還能再撐一陣。」（提要：無明顯影響）
- 0.3–0.6：「飢腸轆轆，力氣有些不濟。」（提要：武力稍降）
- 0.6–0.9：「飢火中燒，頭暈眼花，持劍之手微微顫抖。」（提要：武力輕功顯降，命中失準）
- 0.9–1.0：「餓殍之相，氣若游絲，再不進食恐倒斃路旁。」（提要：隨時昏厥）

#### 疾病
- 0.01–0.3：「偶感風寒，微微咳嗽。」（提要：無明顯影響）
- 0.3–0.6：「病勢漸重，身子發沉，手腳使不上勁。」（提要：武力稍減，容易疲倦）
- 0.6–0.9：「高燒不退，神志朦朧，五內俱焚。」（提要：武力悟性皆衰，反應遲鈍）
- 0.9–1.0：「病入膏肓，藥石罔效，大限將至。」（提要：無法修練，生機漸逝）

## 5. 輸入映射

### 5.1 鍵盤／滑鼠（預設）

| 動作 | 輸入 |
|------|------|
| 查看浮框 | 滑鼠游標移至 HUD 圖示上（0.2秒延遲）|
| 開啟詳細面板（P3） | 點擊任一圖示，或按 `C` 鍵 |
| 關閉面板回遊戲 | `ESC` 或點擊面板外區域 |
| 展開折疊狀態清單 | 點擊 `+N` 圖示 |

### 5.2 手把（Xbox 佈局為例，Steam Input 可自訂）

| 動作 | 輸入 |
|------|------|
| 啟用 HUD 焦點模式 | 按住 `LB`（左肩鍵） |
| 在圖示間移動焦點 | D-pad 左右 |
| 展開折疊清單 | 焦點在 `+N` 上按 `A`；清單內用 D-pad 上下 |
| 查看浮框 | 焦點停留 0.3 秒自動顯示 |
| 進入詳細面板（P3） | 按 `A`（選定圖示） |
| 快速退出一層 | 按 `B`（關閉浮框或面板） |
| 完全退出焦點模式 | 放開 `LB` 或按兩次 `B` |

**按鍵提示切換**：當遊戲偵測到手把輸入，HUD 浮框下方會顯示 `[A] 詳情  [B] 返回`；鍵鼠則顯示 `點擊查看詳情  [ESC] 返回`。

## 6. 無障礙要求

- **色盲模式**（設定選項可啟用）：
  - 圖示盾框上疊加狀態簡稱文字（外／內／毒／乏／飢／病），字級 8px，白色描邊
  - micro-bar 改為黑白斜線密度變化，取代紅黃橙綠
- **字級大小**：支援 UI 縮放 120% / 150%，HUD 圖示按比例調整，仍須在 720p 下最小觸控區不小於 24×24 px（滑鼠操作）
- **音效回饋**（用於無障礙，V2 實作）：
  - 狀態出現/消失時播放獨特環境音（刀劍入肉悶響、內傷低頻嗡聲、中毒滴答、疲勞喘氣、飢餓腹鳴、疾病咳嗽）
  - 危急脈衝伴隨心跳音效
- **螢幕閱讀器支援**（V2）：在詳細面板中提供文字朗讀，敘述當前傷勢摘要
- **操作輔助**：HUD 焦點模式下，手把導航速度可調（三級靈敏度）

## 7. 驗收標準（QA 測試用）

### 7.1 基本顯示與消失
- [ ] Q1：角色初始無任何狀態，HUD 狀態列完全空白，無多餘圖示。
- [ ] Q2：藉由攻擊或事件使角色獲得外傷 `severity = 0.1`，外傷圖示以淡入效果出現，內部填充約 10%，micro-bar 為灰色。
- [ ] Q3：將同一外傷 severity 降至 0.0（如治癒），圖示在 0.5 秒內淡出消失。

### 7.2 段位閾值與顏色
- [ ] Q4：`severity` 從 0.25 升到 0.35，micro-bar 與填充色塊從灰切換為黃色調（帶有對應狀態主色）。
- [ ] Q5：`severity` 升到 0.65，變為橙色調。
- [ ] Q6：`severity` 達到 0.91，圖示觸發一次性「心脈示警」動畫（放大 + 光環），之後 micro-bar 變為紅色，圖示外緣開始脈衝呼吸燈效。
- [ ] Q7：`severity` 從 0.95 降回 0.85，脈衝停止，顏色回到橙色，但圖示不重播一次性動畫。

### 7.3 排序邏輯
- [ ] Q8：同時存在外傷 severity=0.2、中毒 severity=0.7，中毒圖示排在外傷左側（緊急度更高）。
- [ ] Q9：加入內傷 severity=0.92，內傷圖示強制移至最左側，並脈衝，原中毒圖示右移一位。
- [ ] Q10：同時存在 6 種狀態，畫面只顯示 4 個圖示 + 一個 `+2` 圖示；點擊 `+2` 可浮出剩餘 2 個狀態條目。

### 7.4 懸停浮框內容
- [ ] Q11：滑鼠懸停在外傷圖示（severity 0.45），浮框顯示情境描述「傷口見骨，血染衣襟…」及提要「身手略鈍，行動稍緩」。
- [ ] Q12：手把 LB+焦點選中後，浮框於 0.3 秒後出現，文案相同。
- [ ] Q13：浮框進度條長度對應 45% 左右。
- [ ] Q14：內傷 severity=0.8 且設定上「無法運功」，浮框顯示紅色警示「經脈受損，無法運功」。

### 7.5 詳細面板
- [ ] Q15：點擊任一圖示按 `C` 鍵，開啟「江湖志 — 身上狀況」面板，能看到全身剪影與所有狀態卡片。
- [ ] Q16：卡片上顯示具體屬性影響（武力 -15%、內力 -30% 等）、惡化速率、建議處置。
- [ ] Q17：按 `ESC` / 手把 `B` 返回遊戲，過程不超過兩次按鍵。

### 7.6 無障礙
- [ ] Q18：啟用色盲模式，圖示出現文字簡稱（外、內、毒等），micro-bar 轉為黑白密度線。
- [ ] Q19：UI 縮放 150% 下，圖示不小於 36×36 px，文字仍清晰。
- [ ] Q20：詳細面板內滑鼠/手把導航可達所有互動元素。

### 7.7 性能與邊界
- [ ] Q21：快速連續觸發多個狀態（例如同時中毒加內傷），圖示不出現閃爍或重疊錯誤。
- [ ] Q22：severity 恰好為 0.0 時，浮框不意外觸發。
- [ ] Q23：手把修飾鍵放開瞬間，HUD 焦點立即消失，不卡在 UI 模式。

---

*此 Spec 定義了 HUD 的核心體驗，V2 將擴充音效回饋、更多狀態視覺細節（如骨折專門圖示），以及狀態治療後的特殊消退動畫。*
