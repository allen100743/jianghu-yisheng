## 1. HUD 設計原則（本作專屬）

### 核心信念：HUD 是玩家角色身體感知的延伸

HUD 不是「遊戲狀態顯示器」，而是**角色對自身狀態的感知**。  
當玩家看到 HUD 變化，不是在「讀取數據」，而是在「感覺到自己身體的變化」。

### 1.1 常駐顯示 vs 動態顯示

**永遠可見（P1 常駐）：**
- 生命值條（角色對自身安危的直覺）
- 時間/季節指示（角色對晝夜節律的感知）
- 內力值條（習武之人對自身內息的覺察）
- 快捷欄（角色肌肉記憶的延伸）

**情境觸發（P2 動態）：**
- 狀態效果圖示（身體異常出現時才浮現）
- 目標方向指引（有明確目的地時才顯示）
- 戰鬥資訊（只有進入警戒/戰鬥才展開）

**玩家主動查詢（P3 面板）：**
- 詳細傷勢說明（按鍵開啟角色面板）
- 任務進度（按鍵開啟承諾日誌）
- 武學熟練度（按鍵開啟武學面板）

### 1.2 沉浸感平衡策略

| 設計決策 | 理由 |
|---------|------|
| HUD 元素全半透明，背景不遮擋遊戲畫面 | 強化「活在江湖裡」而非「看著 UI 玩遊戲」|
| 不顯示浮動數字（傷害/經驗/好感）| 數字破壞武俠沉浸感，用視覺回饋取代 |
| 狀態變化優先靠角色外觀、動作、音效表達 | HUD 只做為「確認」，不是「主要通知管道」|
| 戰鬥時 HUD 輕微放大、邊框變銳利 | 視覺上只強調「現在是生死關頭」，不新增資訊 |
| 非戰鬥時 HUD 邊緣淡出至 60% 透明度 | 不干擾探索和對話沉浸感 |

## 3. 狀態效果區（6 種狀態的 HUD 呈現）

*依據傷勢與狀態效果系統 GDD §3.5、競品 UX 研究結論設計*

### 3.1 顯示邏輯

**觸發條件：** 任一狀態 severity ≥ 0.1 時，對應圖示從左上角浮現（淡入 0.3s）

**消失條件：** severity 歸零後，圖示淡出 0.5s 後消失

**排序規則（自動，由系統決定）：**

圖示排列優先級 = `severity × 惡化速率係數 × 致死風險係數`

| 優先級計算參數 | 說明 |
|-------------|------|
| severity | 當前嚴重度 0.0–1.0 |
| 惡化速率係數 | 自然惡化速率 / 0.08（歸一化至 0–1）|
| 致死風險係數 | 危急階段（≥0.9）直接影響生命者 = 1.5；其他階段 = 1.0 |

**強制置頂規則：** severity ≥ 0.9 的狀態**強制排序至第一位置**，以最大尺寸顯示。

**緊湊模式：** 超過 3 個狀態時，第 4+ 圖示縮小至 60% 尺寸排列。

### 3.2 三層視覺語言規格

#### 第一層：圖示填充度
- 每個狀態圖示為**32×32px**（720p 基準），內部以填充度反映 severity 0–100%
- 填充方向：由下往上（如容器盛水，符合流失 = 生命流失隱喻）
- 顏色依狀態類型：

| 狀態 | 圖示色 | 填充色 |
|------|--------|--------|
| 外傷 | 暖紅 #CC3333 | 深紅 #881111 → 亮紅 #FF4444 |
| 內傷 | 深紫 #8844AA | 暗紫 #442255 → 亮紫 #BB66DD |
| 中毒 | 毒綠 #44AA44 | 暗綠 #225522 → 亮綠 #66DD66 |
| 疲勞 | 冷灰 #888899 | 暗灰 #444455 → 淺灰 #BBBBCC |
| 飢餓 | 土黃 #BB9944 | 暗黃 #665522 → 亮黃 #DDCC66 |
| 疾病 | 病黃藍 #7799AA | 暗藍灰 #334455 → 病黃 #AABBCC |

**色盲模式切換：** 在設定中開啟後，每種狀態圖示上疊加**不同的紋理圖案**（外傷=斜線、內傷=網格、中毒=斑點、疲勞=橫線、飢餓=波紋、疾病=十字紋），確保不靠顏色也能區分。

#### 第二層：3px micro-bar
- 每個圖示**右側**附加一條 3px 寬、與圖示等高的微型條
- 顏色對應 severity 段位（非狀態類型）：

| Severity 範圍 | Micro-bar 顏色 |
|-------------|--------------|
| 0.1 – 0.3 | 灰白 #CCCCCC |
| 0.3 – 0.6 | 淡黃 #DDDD88 |
| 0.6 – 0.9 | 橙色 #DD8844 |
| 0.9 – 1.0 | 暗紅 #CC2222 |

- Micro-bar 作用：讓玩家不用讀圖示，**光看顏色段位**就知道哪些狀態危急
- 段位顏色統一 6 種狀態共用，減少認知負擔

#### 第三層：脈衝動畫
- **觸發條件**：severity ≥ 0.9 時
- **動畫規格**：
  - 圖示邊緣發出暗紅色光暈
  - 光暈以 1.2s 週期緩慢呼吸（放大 120% → 縮回 100%）
  - **首次觸發時**播放一次性強脈衝（0.3s 快速放大至 150% + 邊緣閃白），之後進入靜態光暈模式
- **為何不用持續閃爍**：避免玩家脫敏（競品 UX 研究結論）
- **severity 降至 0.9 以下**：脈衝停止，光暈消失

### 3.3 懸停浮框內容規格

玩家將滑鼠懸停（或手把聚焦）在狀態圖示上時，顯示浮框：

**浮框位置：** 圖示右側展開，不遮擋其他狀態圖示

**浮框結構（由上到下）：**
1. **狀態名稱**（武俠語境）：如「外傷 — 見骨」
2. **情境描述句**（severity 對應的 stage 文案）：
   - 0.1–0.3：「皮肉之傷，尚可行動」
   - 0.3–0.6：「傷口見骨，血染衣襟，疼痛難當」
   - 0.6–0.9：「身負重創，每一步都如刀割」
   - 0.9–1.0：「命在旦夕，再不行動恐難回天」
3. **影響摘要**（不顯示數值，用武俠語言）：
   - 如：「行動遲緩，運功受阻」
   - 如：「內息紊亂，強行運功恐傷經脈」
4. **恢復建議**（模糊提示，不列精確時間）：
   - 如：「尋醫包紮或臥床靜養可緩」
   - 如：「此毒猛烈，速尋解藥為上」

**浮框不顯示的內容：**
- ❌ 精確 severity 數值（如「0.45」）
- ❌ 精確修飾詞百分比（如「武力 -25%」）
- ❌ 自然恢復速率（如「+0.05/天」）

## 4. 時間/年齡顯示

### 4.1 遊戲時間的呈現方式

**設計理念：** 時間不是「數字」，是角色對光陰流逝的感知。

**常駐顯示：右上角小型日晷**

| 顯示元素 | 規格 | 說明 |
|---------|------|------|
| **日晷圖示** | 圓形，24px | 底色為當下晝夜天色（白日淡金、黃昏橙、夜晚深藍、清晨灰藍）|
| **時辰文字** | 日晷右側，12px | 顯示當下時辰名（子、丑、寅、卯…），非現代的「幾點幾分」|
| **季節文字** | 日晷下方，10px | 顯示當前季節（春、夏、秋、冬），以季為單位，不顯示月份 |
| **年份文字** | 日晷下方第二行，10px | 顯示「洪武X年」，不顯示角色年齡（年齡在角色面板看）|

**動態變化：**
- 每當時辰轉換時，日晷瞬間更新天色（不漸變，模擬「忽然察覺天色已晚」的感受）
- 季節轉換時，日晷外環出現季節對應的自然元素微粒子（春=花瓣、夏=螢火、秋=落葉、冬=雪花），持續 3 秒

### 4.2 老化視覺錨點

**角色年齡不在 HUD 常駐顯示**——年齡是角色面板（P3）的資訊，不是戰鬥/探索中的即時需求。

**但在以下情境，HUD 會短暫顯示年齡相關的視覺錨點：**

| 觸發情境 | HUD 反應 | 持續時間 |
|---------|---------|---------|
| 進入新的年齡階段 | 畫面中央浮現一段短文字：「而立之年，不再年輕」| 4 秒後淡出 |
| 暮年階段進入戰鬥 | 生命條邊框從銀白變為暗淡銅色（表示體衰）| 整場戰鬥 |
| 壽命剩餘約 5 年 | 每當日晷季節轉換時，附加一行小字「時日無多」| 3 秒後淡出 |
| 壽命剩餘約 1 年 | 生命條上方出現一行淡字：「風中殘燭」| 永久，直到死亡 |

**為何不常駐顯示年齡：** 玩家在日常探索時不需要時時刻刻被提醒「你在變老」，老化感應來自**偶爾的察覺**，而非持續的數字壓力。這符合「這是我的一生」支柱——你不會在活著的每個瞬間都意識到自己在變老。

## 5. 戰鬥 HUD 狀態

### 5.1 進入戰鬥時 HUD 變化

**觸發條件：** 系統偵測到敵意（敵方進入警戒範圍、玩家發起攻擊、事件觸發戰鬥）

**變化時序（0.8 秒過渡）：**

| 時間點 | 變化 |
|--------|------|
| 0.0s | 螢幕邊緣出現微暗暈影（暗角效果），提示「進入警戒」|
| 0.2s | 生命條、內力條輕微放大至 120%，邊框從圓角變銳利 |
| 0.3s | 快捷欄技能圖示變亮，未裝備技能的空白格變暗 |
| 0.4s | 左上狀態效果區微幅下移，讓出空間給敵人鎖定指示器（若自動鎖定開啟）|
| 0.5s | 目標鎖定環出現在當前敵人身上（若有）或顯示「無鎖定」提示 |
| 0.8s | 非必要 HUD 元素（目標指引文字、迷你地圖）淡出 |

**戰鬥專屬 HUD 新增元素：**

| 元素 | 位置 | 說明 |
|------|------|------|
| 目標鎖定環 | 鎖定敵人腳下 | 圓環 + 敵人類型小圖示（人類/動物/頭目）|
| 鎖定敵人生命條 | 畫面上方中央 | 僅顯示紅條，不顯示數值；severity ≥ 0.6 時條上出現裂痕特效 |
| 自動/手動模式指示 | 快捷欄左側 | 小字「自」或「手」，按 F 切換 |
| 速度指示 | 快捷欄右側 | 「1x」「1.5x」「2x」，白色字 |

### 5.2 退出戰鬥時的過渡

**觸發條件：** 所有敵方死亡/逃跑/投降，或玩家逃離戰鬥場景

**變化時序（1.0 秒過渡）：**

| 時間點 | 變化 |
|--------|------|
| 0.0s | 暗角效果開始消退 |
| 0.2s | 生命條、內力條縮回原始尺寸，邊框恢復圓角 |
| 0.3s | 戰鬥專屬元素（鎖定環、敵人生命條）淡出 |
| 0.5s | 非必要 HUD 元素（目標指引文字、迷你地圖）淡入 |
| 0.8s | 若有新狀態效果（severity ≥ 0.1），圖示從左上浮現 |
| 1.0s | HUD 完全恢復探索模式 |

**戰後特殊處理：**
- 若角色在戰鬥中受到新狀態效果，退出戰鬥後狀態圖示以**微弱脈衝一次**提示新增
- 若角色生命值低於 30%，退出戰鬥後生命條邊緣持續微弱泛紅（直到恢復至 30% 以上）

## 6. 輸入映射

### 6.1 鍵盤/滑鼠 — HUD 相關操作

| 操作 | 鍵位 | 說明 |
|------|------|------|
| 開啟角色面板（查看詳細傷勢/年齡）| `C` | 打開含狀態效果說明的完整角色面板 |
| 開啟承諾日誌（任務）| `J` | 打開任務/承諾清單面板 |
| 開啟武學面板 | `K` | 打開武學技能和熟練度面板 |
| 開啟行囊（背包）| `B` | 打開物品清單面板 |
| 暫停 / 指令模式 | `Space` | 暫停時間，顯示完整戰鬥指令選單 |
| 自動/手動切換 | `F` | 切換自動戰鬥模板與手動操作 |
| 切換鎖定目標 | `Tab` | 循環切換場上敵人，HUD 鎖定環同步更新 |
| 速度控制 | `+` / `-` | 切換 1x / 1.5x / 2x（僅戰鬥中）|
| 快速使用道具 | `1–6` | 使用快捷欄對應格位的道具或技能 |

### 6.2 手把 — HUD 相關操作（Steam Input API）

*手把按鍵標示以 Xbox 佈局為基準，Steam Input 會自動映射至 PS/Switch 手把*

| 操作 | 手把按鍵 | 說明 |
|------|---------|------|
| 開啟角色面板 | `View 鍵 (Back)` | 打開含狀態效果說明的完整角色面板 |
| 開啟承諾日誌 | `D-pad 上` | 打開任務/承諾清單面板 |
| 開啟武學面板 | `D-pad 左` | 打開武學技能和熟練度面板 |
| 開啟行囊 | `D-pad 右` | 打開物品清單面板 |
| 暫停 / 指令模式 | `Menu 鍵 (Start)` | 暫停時間，顯示完整戰鬥指令選單 |
| 自動/手動切換 | `D-pad 下` | 切換自動戰鬥模板與手動操作 |
| 切換鎖定目標 | `RB` | 循環切換場上敵人 |
| 速度控制 | `LB + D-pad 左/右` | 切換 1x / 1.5x / 2x（僅戰鬥中）|
| 快速使用道具 1–4 | `A / B / X / Y` | 戰鬥中使用快捷欄前 4 格 |
| 快速使用道具 5–6 | `LT + A / B` | 戰鬥中使用快捷欄後 2 格 |
| HUD 元素聚焦（查看狀態說明）| `LT + D-pad 上` | 將焦點移至狀態效果區，用 D-pad 左右瀏覽，A 鍵查看浮框 |

### 6.3 手把 HUD 導航規範

- **焦點順序（D-pad 循環）：** 狀態效果區 → 目標指引 → 快捷欄 → 時間/日晷 → 回到狀態效果區
- **兩步回主：** 任何面板開啟時，按 `B` 關閉面板 → 回到遊戲主畫面（最多 2 次按鍵）
- **不允許 hover-only：** 所有需要滑鼠懸停才能觸發的浮框資訊，手把必須可以透過聚焦 + `A` 鍵查看

## 7. 驗收標準

### 7.1 一般 HUD 驗收

| 編號 | 測試項目 | 預期結果 | 優先級 |
|------|---------|---------|--------|
| HUD-01 | 遊戲啟動後，生命條、內力條（學習內功後）、日晷、快捷欄是否顯示 | 顯示於指定位置，透明度正常 | MVP |
| HUD-02 | 非戰鬥時，HUD 元素透明度是否為 60% | 半透明，不干擾遊戲畫面 | MVP |
| HUD-03 | 進入戰鬥時，HUD 是否在 0.8 秒內完成過渡變化 | 暗角→放大→戰鬥元素出現，無閃爍 | MVP |
| HUD-04 | 退出戰鬥時，HUD 是否在 1.0 秒內恢復探索模式 | 戰鬥元素消失→HUD 恢復，過渡平滑 | MVP |
| HUD-05 | 所有可互動 HUD 元素是否顯示對應按鍵提示 | 鍵鼠/手把圖示自動切換 | MVP |
| HUD-06 | 720p 解析度下，所有 HUD 文字是否可讀 | 最小字級不低於 10px | MVP |
| HUD-07 | 色盲模式下，狀態圖示是否顯示差異化紋理 | 六種狀態六種紋理，清晰可辨 | MVP |
| HUD-08 | 手把模式下，D-pad 能否循環導航至所有 HUD 元素 | 狀態→目標→快捷→日晷→回到狀態 | MVP |
| HUD-09 | 手把模式下，能否用 A 鍵查看狀態浮框 | 聚焦狀態圖示後按 A，浮框顯示 | MVP |

### 7.2 狀態效果區驗收

| 編號 | 測試項目 | 預期結果 | 優先級 |
|------|---------|---------|--------|
| STAT-01 | 任一狀態 severity ≥ 0.1，圖示是否從左上浮現（淡入 0.3s）| 圖示浮現，填充度對應 severity | MVP |
| STAT-02 | severity 歸零後，圖示是否淡出（0.5s 後消失）| 圖示完全消失，不佔位 | MVP |
| STAT-03 | 多個狀態同時存在時，排序是否正確 | 依 severity×惡化×致死 排序，危急狀態置頂 | MVP |
| STAT-04 | severity ≥ 0.9 的狀態是否出現脈衝動畫 | 光暈呼吸，首次觸發強脈衝，之後靜態 | MVP |
| STAT-05 | severity ≥ 0.9 強制置頂 | 無論排序結果如何，危急狀態在最上方 | MVP |
| STAT-06 | 超過 3 個狀態時，第 4+ 是否進入緊湊模式 | 圖示縮小至 60%，仍可辨識 | MVP |
| STAT-07 | micro-bar 顏色是否對應 severity 段位 | 灰白/淡黃/橙/暗紅 | MVP |
| STAT-08 | 滑鼠懸停是否顯示浮框 | 浮框含名稱、情境句、影響摘要、恢復建議 | MVP |
| STAT-09 | 手把聚焦 + A 鍵是否等效於滑鼠懸停 | 浮框顯示，內容相同 | MVP |
| STAT-10 | 浮框不顯示精確數值和百分比 | 文案為武俠語境，無 0.XX 或 % 符號 | MVP |
| STAT-11 | 六種狀態各有獨立顏色（正常模式）| 顏色不重複（紅/紫/綠/灰/黃/藍灰）| MVP |
| STAT-12 | 色盲模式下六種狀態是否可區分 | 疊加紋理後仍可快速辨別狀態類型 | MVP |

### 7.3 時間/年齡驗收

| 編號 | 測試項目 | 預期結果 | 優先級 |
|------|---------|---------|--------|
| TIME-01 | 日晷顯示當下時辰名和季節 | 文字正確對應遊戲內時間 | MVP |
| TIME-02 | 日晷底色是否隨晝夜變化 | 白日淡金/黃昏橙/夜晚深藍/清晨灰藍 | MVP |

| TIME-04 | 進入新年齡階段是否顯示提示 | 畫面中央浮字，4 秒後淡出 | MVP |

## 8. MVP / V2 邊界

### MVP（必做，pre-production 結束前完成 Spec 定稿）

| 功能 | 說明 |
|------|------|
| 生命條 + 內力條（探索/戰鬥雙模式）| 含透明度變化和戰鬥過渡動畫 |
| 日晷時間顯示（時辰+季節）| 含晝夜天色變化和時辰瞬間切換 |
| 快捷欄 6 格 | 鍵鼠和手把均可操作 |
| 狀態效果區（六種狀態）| 含三層視覺語言、排序規則、浮框 |
| 戰鬥 HUD 變化 | 含暗角、放大、鎖定環（最小規格）、敵人生命條（僅紅條，無數值）|
| 色盲模式切換 | 狀態圖示疊加差異化紋理 |
| 手把完整導航 | 所有 HUD 元素可用 D-pad + 4 鍵操作 |
| 按鍵圖示自動切換 | 鍵鼠/手把對應圖示 |
| 720p 最小字級可讀 | 全 HUD 文字不低於 10px |

### V2（後續迭代，不阻塞 MVP 開發）

| 功能 | 說明 |
|------|------|
| 迷你地圖/方位顯示 | 右上角圓形小地圖 |
| 暮年戰鬥生命條變色 | 邊框銀白 → 暗銅色 |
| 壽命瀕臨提示（5年/1年）| 「時日無多」「風中殘燭」動態提示 |
| 季節轉換粒子特效 | 花瓣/螢火/落葉/雪花微粒子 |
| 鎖定敵人生命條裂痕特效 | severity ≥ 0.6 時，敵人生命條上出現裂痕 |
| 戰後狀態新增微脈衝 | 退出戰鬥後，新狀態圖示閃爍一次提示 |
| 低生命值（<30%）生命條泛紅 | 戰後持續微弱紅光直到恢復 |
| 12345 快捷鍵道具/技能圖示自訂 | 玩家可拖放自訂快捷欄內容 |

### 明確不做（防範圍膨脹）

| 項目 | 原因 |
|------|------|
| 浮動戰鬥數字（傷害/治療/經驗）| 破壞武俠沉浸感，違反 UX 核心原則 |
| 精確數值顯示在 HUD 任何位置 | 違反「UI 是最後手段」哲學 |
| 角色年齡常駐顯示於 HUD | 年齡屬於角色面板（P3），非即時情境需求 |
| 狀態效果的精確 severity 百分比文字 | 浮框只給武俠描述，不給數值 |
| 全局小地圖（非迷你）| 違反「探索感」，玩家應靠環境記憶導航 |
| 任務進度條在 HUD 常駐 | 任務進度在承諾日誌（P3）查看，HUD 只顯示當前目標指引 |
