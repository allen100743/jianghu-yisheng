## 一、無障礙分類與優先級

| 類別 | MVP 必做 | V2 追加 | 說明 |
|------|---------|---------|------|
| **視覺 - 字體** | 最小字級 720p 可讀；大字模式（+20%） | 字體大小自訂滑桿（100%-200%） | MVP 確保基本可讀性；V2 給玩家精細控制 |
| **視覺 - 色彩** | 色盲模式（三種類型）；不純靠顏色傳遞資訊 | 自訂關鍵顏色（血條/狀態圖示色） | MVP 確保資訊不被顏色阻斷；V2 是個人化 |
| **視覺 - 對比** | 所有文字/圖示符合 WCAG AA（對比 ≥ 4.5:1） | 通過 WCAG AAA（對比 ≥ 7:1） | MVP 即符合 Steam 無障礙標籤要求 |
| **視覺 - UI 縮放** | 整體 UI 縮放 120% 模式 | 整體 UI 縮放 150% 模式；個別面板獨立縮放 | MVP 先做全體縮放；V2 做精細化 |
| **輸入 - 鍵鼠** | 所有功能可用鍵盤完整操作；按鍵可重映射 | 內建多組按鍵配置預設（左手/右手/單手） | MVP 確保鍵盤可達；V2 是便利性 |
| **輸入 - 手把** | D-pad + 4 鍵可操作所有功能；不可有 hover-only | 手把陀螺儀瞄準（如有需要） | MVP 已涵蓋全部手把需求 |
| **輸入 - 輔助** | 長按/連打可選（用按住替代） | 一鍵多擊自動化（如自動連擊） | MVP 處理輸入疲勞；V2 更高自動化 |
| **認知 - 字幕** | 對話字幕 + 環境音字幕（默認開啟） | 字幕背景透明化選項；說話者名稱位置選項 | MVP 確保聽障可玩 |
| **認知 - 暫停** | 所有非即時選單可暫停；即時戰鬥有暫停快捷鍵 | 自訂暫停時的時間流速（完全暫停/慢速） | MVP 確保思考時間 |
| **認知 - 確認** | 不可逆操作有雙重確認；確認框有明確後果說明 | 可自訂哪些操作需要確認 | MVP 確保不誤操作 |
| **認知 - 教學** | 首次進入系統時強制引導；武學/狀態系統有術語說明 | 術語辭典可查詢；引導可重播 | MVP 有基本引導就夠 |

## 二、視覺無障礙規格

### 2.1 字體大小規範

| 層級 | MVP 規格 | V2 追加 | 適用場景 |
|------|---------|---------|---------|
| **最小可讀** | 14px @ 720p（實際像素） | — | 所有 UI 文字的下限，不可低於此值 |
| **標準正文** | 16px @ 720p | 自訂 14-24px | 對話框、說明文字、任務描述 |
| **標題/重要資訊** | 20px @ 720p | 自訂 18-28px | 角色名稱、選單標題、關鍵狀態 |
| **大字模式** | 全 UI 字級 +20% | +50% 模式 | 設定中切換，一次放大所有文字 |
| **字體本身** | 使用無襯線/高可讀性中文字體 | 開放玩家自訂字體 | MVP 用系統預設可讀字體（如思源黑體） |

**驗收標準**：
- 720p 解析度、螢幕距離 60cm，標準正文可被正常視力玩家清晰閱讀
- 大字模式下，同樣條件下 0.3 視力（模擬）可讀

---

### 2.2 顏色對比要求

**適用標準**：WCAG 2.1 AA（MVP）/ AAA（V2）

| 元素類型 | MVP 最低對比 | 色盲模式追加 | 測試工具 |
|---------|------------|------------|---------|
| 正文文字（<18px） | 4.5:1 | 確保色盲模擬下仍 ≥ 4.5:1 | WebAIM Contrast Checker |
| 大字文字（≥18px） | 3:1 | 同上 | 同上 |
| UI 圖示（功能性） | 3:1 | 形狀區分 + 顏色 | 手動審查 |
| 血條/狀態條（填充 vs 背景） | 3:1 | 加紋理/圖案區分 | 同上 |
| 禁用/灰色元素 | 不要求（但不可為唯一區分方式） | 加文字標籤或圖示 | 同上 |

**特殊規定**：
- **武俠語境不豁免對比要求**：即使用情境句（如「命在旦夕」），文字仍須符合對比標準
- **浮框/通知文字背景**：必須為不透明或半透明 + 足夠對比（不可透明背景配淺色字）

---

### 2.3 色盲模式規格

**三種類型對應**：

| 色盲類型 | 影響 | MVP 對策 | V2 追加 |
|---------|------|---------|---------|
| **紅色盲（Protanopia）** | 紅/綠/棕 難區分 | 紅綠狀態用圖示形狀區分；血條加明度差異 | 自訂血條顏色 |
| **綠色盲（Deuteranopia）** | 紅/綠 難區分（最常見） | 同上；狀態效果圖示必有形狀差異，不可只靠顏色 | 自訂狀態圖示色盤 |
| **藍黃色盲（Tritanopia）** | 藍/黃、紫/紅 難區分 | 藍色系資訊加底線或邊框輔助（例如冰/水屬性） | 自訂屬性顏色 |

**強制規則（所有模式共用）**：
1. **不可純靠顏色傳遞資訊**：任何顏色編碼的資訊，必須有第二編碼（形狀/文字/圖案/位置）
2. **狀態效果圖示**：六種狀態各有獨立形狀 + 顏色（見 status-effects-hud spec 已定義）
3. **任務標籤**：失效 [灰色] + 時鐘圖示 vs 失敗 [暗紅] + ❌ 圖示（已雙編碼）
4. **武學品質**：顏色 + 文字標籤（灰/白/綠/藍/紫/金/紅）+ 邊框形狀差異

**色盲模式開啟方式**：
- 設定 → 無障礙 → 色盲模式（下拉：無/紅色盲/綠色盲/藍黃色盲）
- 選中後即時預覽（全 UI 色盤切換）
- MVP 使用色盤映射表（預先定義三組色盤對照）

---

### 2.4 UI 縮放支援規格

| 模式 | MVP (120%) | V2 (150%) | 技術要求 |
|------|-----------|-----------|---------|
| 基準 | 100% @ 1080p (預設解析度) | 同左 | — |
| 全 UI 縮放 | 120% 一鍵切換 | 150% 一鍵切換 | Godot Theme 或 anchor system |
| 個別面板 | — | 對話框/技能詳情/角色面板獨立縮放 | 需額外 UI 架構 |
| HUD 元素 | 跟隨全 UI 縮放 | 可獨立縮放（不跟隨全 UI） | V2 做獨立設定 |
| 最小保證 | 720p + 120% 仍不裁切 | 720p + 150% 仍不裁切 | 需測試最小視窗 |
| 字體對應 | 字級同步放大 | 同上，但可微調字級獨立於面板縮放 | 字級用倍率計算 |

**驗收標準**：
- 在各縮放倍率下，所有 UI 元素不裁切、不超出螢幕邊界
- 文字不因放大而模糊（向量字體或足夠解析度的點陣字）
- 手把焦點順序不因縮放而改變

## 三、輸入無障礙規格

### 3.1 按鍵重映射規範

**強制可重映射項目（MVP）**：

| 功能群組 | 必須可重映射的按鍵 | 說明 |
|---------|-------------------|------|
| **移動** | WASD / 方向鍵 | 基本移動，最低限度 |
| **攻擊/互動** | 滑鼠左鍵 / 主要攻擊鍵 | 最常用操作 |
| **閃避/防禦** | 次要動作鍵 | 戰鬥核心操作 |
| **選單** | ESC / 開啟選單鍵 | 兩步回主的第一步行為 |
| **確認/取消** | Enter / ESC 或在手把 A/B | 所有確認框的操作 |
| **鎖定目標** | Tab 或指定鍵 | 戰鬥常用 |
| **暫停** | Space 或指定鍵 | 即時戰鬥暫停 |

**可重映射但非強制（V2 建議）**：
- 快捷使用道具（1-9 數字鍵）
- 技能快捷鍵
- 切換武器/流派
- 地圖/角色面板等面板快捷鍵

**技術規範**：
- 重映射設定頁必須顯示當前綁定（不可空白）
- 按鍵衝突時顯示警告（不可靜默覆蓋）
- 提供「恢復預設」按鈕

---

### 3.2 單手模式建議

**適用情境**：單手鍵盤（左手或右手）、單手手把、或特殊輸入裝置

**MVP 不強制「單手模式開關」**，但以下設計使其可行：
- 所有功能可用純鍵盤完成（不需同時操作滑鼠）
- 所有功能可用純手把完成（不需鍵盤輔助）
- 長時間按住的操作可改用切換（toggle）替代（設定選項）

**V2 追加「單手模式配置預設」**：
- 左手鍵盤預設：所有常用鍵集中在鍵盤左半部（WASD + QERF + 1234 + Shift/Ctrl）
- 右手鍵盤預設：所有常用鍵集中在鍵盤右半部（方向鍵 + NumPad + 右 Shift/Ctrl）
- 單手手把模式：將常用操作映射到同一側按鍵（利用手把自訂功能）

---

### 3.3 滑鼠敏感度與無障礙輸入選項

| 選項 | MVP | V2 | 說明 |
|------|-----|----|------|
| 滑鼠敏感度 | 設定中提供滑桿 | 戰鬥/選單分開設定 | MVP 已足夠 |
| 雙擊間隔 | — | 可調整雙擊判定時間 | 對震顫玩家友善 |
| 按住替代連打 | **必做**：任何需要連打的 QTE 可用按住替代 | 自訂按住觸發速度 | MVP 處理最常見的輸入疲勞 |
| 長按判定時間 | 設定中提供滑桿（短/中/長） | — | MVP 已做 |
| 死區設定（手把） | 手把搖桿死區可調 | — | 避免手把飄移誤觸 |
| 震動開關 | 手把震動可完全關閉 | 震動強度滑桿 | MVP 關閉即可 |

## 四、認知無障礙規格

### 4.1 字幕規範

**三層字幕系統**：

| 字幕類型 | 默認狀態 | 內容 | 格式 | 顏色 |
|---------|---------|------|------|------|
| **對話字幕** | **開啟** | NPC 對話全文 + 說話者名稱 | 底部居中，最多兩行 | 白字黑底（或半透明黑底） |
| **環境音字幕** | **開啟** | 重要環境音效的文字描述 | 右上角，小字，斜體 | 灰字黑底，前面加 🔊 圖示 |
| **系統訊息字幕** | **開啟** | 系統通知（任務更新、狀態變化等）| 左上角或中央浮框 | 黃字黑底（重要訊息）|

**環境音字幕規範（這是最容易被忽略的）**：
- 格式：`🔊 [聲音描述]`（例如：`🔊 遠處馬蹄聲漸近`、`🔊 風聲呼嘯，樹葉沙沙`）
- 只顯示對玩家決策有意義的聲音（腳步聲、戰鬥聲、環境危險提示音），不顯示背景氛圍音
- 同一時間最多顯示兩條環境音字幕，超過時顯示最重要的（戰鬥相關 > 探索相關 > 氛圍）

**對話字幕額外規範**：
- 說話者名稱在字幕前，格式：`【歐陽鋒】「今日便要你命喪於此！」`
- 說話者名稱可選前置/後置（設定選項，V2）
- 字幕背景可選不透明/半透明/透明（V2，但默認必須保證可讀性）

---

### 4.2 暫停容忍設計

**核心原則**：玩家不應因為「來不及反應」而失敗，除非是即時戰鬥中的戰術失誤。

| 情境 | 暫停行為 | 說明 |
|------|---------|------|
| **所有選單/面板** | 開啟時遊戲時間暫停 | 背包、角色、任務、地圖、設定等 |
| **對話進行中** | 時間暫停，對話不自動推進 | 玩家可慢慢閱讀 |
| **確認框** | 時間暫停，直到玩家做出選擇 | 不可逆操作前的確認 |
| **即時戰鬥中** | 按暫停鍵（Space）完全暫停 | 可環顧、可下指令嗎？（V2 討論）|
| **非即時戰鬥** | 系統本身就是回合/策略制，無時間壓力 | — |
| **時間敏感事件** | 如果事件有現實時間限制，必須在觸發前有明確倒數提示 | 不讓玩家措手不及 |

**特殊規定**：
- 任何需要玩家「在 X 秒內按某鍵」的 QTE，必須提供「跳過 QTE」的輔助選項（設定中啟用）
- 劇情演出期間，即使無對話，也不自動跳過（玩家按確認鍵才繼續）

---

### 4.3 資訊重複確認機制

**目的**：確保玩家在做出不可逆決定前，充分理解後果。

| 操作類型 | 確認層級 | 確認方式 |
|---------|---------|---------|
| **刪除存檔** | 三重確認 | 「確認刪除？」→ 輸入確認文字 → 最終確認 |
| **不可逆劇情選擇** | 雙重確認 | 顯示選擇概述 → 「是否確定？」（含後果說明） |
| **拜師/結義** | 雙重確認 | 顯示 NPC 關係變化 → 確認 |
| **捨棄高品質物品** | 雙重確認 | 提示物品品質 → 確認 |
| **一般選單操作** | 即時生效，可復原 | 不需要確認，但提供復原路徑 |

**確認框規範**：
- 必須用武俠語境撰寫（例如「此舉將使歐陽鋒與你反目成仇，從此江湖相見便是刀劍，確定？」）
- 必須使用「是/否」或「確定/再想想」而非「OK/Cancel」
- 預設焦點在「否/再想想」（防止誤按 Enter 就執行）
- 不可復原的操作，必須有明確的「此操作無法復原」文字提示

### B. 輸入無障礙審查

| # | 測試項目 | 測試方法 | 通過標準 | 阻斷 |
|---|---------|---------|---------|------|
| B1 | 純鍵盤可操作 | 拔除滑鼠，只用鍵盤完成：創角→開始遊戲→戰鬥→開啟選單→關閉選單→對話→存檔→退出 | 所有功能可操作，無任何卡關 | 🔴 |
| B2 | 純手把可操作 | 拔除鍵鼠，只用手把完成 B1 流程 | 所有功能可操作（含對話選擇、選單瀏覽），無任何卡關 | 🔴 |
| B3 | 無 hover-only 功能 | 用手把瀏覽所有 UI 畫面 | 所有可互動項目可用手把焦點選中，無任何需要「滑鼠懸停」才能觸發的功能 | 🔴 |
| B4 | 按鍵重映射 - 移動 | 將移動鍵改為方向鍵，將攻擊鍵改為 K | 設定儲存後，新按鍵立即生效；重啟遊戲後仍保留 | 🔴 |
| B5 | 按鍵重映射 - 衝突警告 | 將兩個不同功能設為同一按鍵 | 系統顯示衝突警告，不靜默覆蓋 | 🔴 |
| B6 | 按鍵重映射 - 恢復預設 | 改動多個按鍵後，點擊「恢復預設」 | 所有按鍵回到預設值 | |
