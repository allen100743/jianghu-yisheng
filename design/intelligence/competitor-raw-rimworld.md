## 一、Hediff 健康狀態系統（核心啟示）

### 架構哲學：連續嚴重度，而非二元開關

RimWorld 所有負面狀態（傷口、疾病、中毒）都是 severity 0.0→1.0 的連續數值，
不同區間觸發不同 stage（輕微/中等/嚴重/致命）。

**血液流失 BloodLoss 範例：**
| severity 區間 | 效果 |
|-------------|------|
| 0.00–0.14 | 無可見影響 |
| 0.15–0.29 | 意識 -10% |
| 0.30–0.44 | 意識 -20% |
| 0.45–0.59 | 意識 -40% |
| 0.60+ | 意識 -40% + 上限 -90%（瀕死）|

### 對《江湖一生》的直接應用

**現有傷勢系統需要升級**：
- 不要用「輕傷/中傷/重傷」三段式，改用 severity 0→1 連續值
- 每個關鍵閾值觸發新的 stage 效果（0.3 / 0.6 / 0.9）
- severity 每天自然恢復 -0.01，治療加速恢復
- severity ≥ 1.0 = 瀕死狀態

**走火入魔的設計範本：**
- 初始 severity = 0.1（感覺異樣）
- 每次強行催動內力 +0.05
- stage 0.3：武力 -20%、思緒混亂
- stage 0.6：攻擊隨機、無法運功
- stage 0.9：癲狂狀態，可能傷害隊友
- severity ≥ 1.0：走火入魔爆體（觸發死亡事件）

## 二、組件化設計（comps）

一個狀態可同時具備多種行為，用組件組合：

```xml
<comps>
  <感染機率組件 機率="30%" />
  <治療持續組件 基礎時間="96小時" 每日恢復="-0.003" />
  <自然進展組件 每日增長="+0.003" 治療期="-0.002" />
</comps>
```

**《江湖一生》應用**：狀態效果用配置組合，而非硬編碼分支邏輯

## 三、特質系統的光譜設計

特質不是「有/沒有」，而是多個度數（degree -2 → +2）：

| 度數 | 名稱 | 效果 |
|-----|------|------|
| -2 | 懦弱 | 移速 -20%，戰鬥離開觸發更早 |
| -1 | 膽小 | 移速 -10% |
| 0 | 普通 | 無修改 |
| +1 | 勇敢 | 移速 +10%，疼痛承受 +15% |
| +2 | 無畏 | 移速 +20%，疼痛完全無視 |

**Trade-off 設計（每個正面必有代價）：**
- TooSmart：學習+75%，但精神崩潰閾值更低
- Brawler：近戰+4，但遠程學習反感

## 四、心情/想法系統

**兩種想法類型：**
1. **即時想法**（Situation Thought）：條件存在就存在，條件消失就消失
2. **記憶想法**（Memory Thought）：事件觸發，有固定持續時間，隨時間衰減

**對《江湖一生》的應用（江湖氣度系統）：**

```
記憶想法：「被打敗」（持續 15 天）
- 0-5天：名聲 -10，心情 -15（奇恥大辱）
- 6-10天：名聲 -5，心情 -8（逐漸平復）
- 11-15天：名聲 -2，心情 -3（已成往事）
- 如果期間擊敗對手：立即移除，觸發「復仇成功」+30心情

記憶想法：「師父陣亡」（持續 90 天）
- 0-30天：心情 -20，戰鬥傷害 -15%（悲痛）
- 31-60天：心情 -15，戰鬥傷害 -8%
- 61-90天：心情 -5（漸漸走出）
- 特殊：擊敗殺師仇人 → 移除此想法，觸發「復仇成功」
```

## 五、設計哲學總結

1. **層次漸進**：傷口→輕傷→中傷→重傷→失肢，每步有實際效果
2. **因果鏈具象化**：需求→想法→行為→故事，玩家隨時理解狀況
3. **組件化復用**：同一機制用於血量、修煉、親密度、名聲
4. **隨機性合理邊界**：不完全隨機，在設計者預期範圍內波動
5. **對稱正負設計**：每個正面特質有對應的負面代價
