## 鬼谷八荒戰鬥體驗

### 喜歡的部分
- **巨齒狀數值體驗**：屬性/裝備的大起大落，得到一件神兵或突破境界時的爽感
- **掉寶機制**：擊殺有掉落，掉落驅動繼續戰鬥的動力

### 討厭的部分
- **大地圖踩地雷**：行走時意外觸發不必要的戰鬥，打斷節奏
- 雖然有寵物協助、避戰符道具緩解，但根本問題仍在

### 設計結論
- 掉寶+數值爆發是戰鬥的核心情緒高點
- 大地圖戰鬥觸發必須可控（玩家主動進入，非被動踩到）

---

## 龍胤立志傳戰鬥體驗

### 不同點
- **回合制，非即時制** — 與鬼谷八荒完全不同的體驗
- 走格子的回合制感覺不舒服

### 做得好的部分
- **自動戰鬥 + 策略設定 + 加速** — 解決了重複戰鬥的疲勞問題

### 設計結論
- 自動戰鬥是剛需，不是選項
- 即時制比回合制更符合目標體驗

## 目標戰鬥體驗：暗黑破壞神

製作人明確說：「暗黑破壞神的打怪刷寶的戰鬥體驗！！！」

### 暗黑戰鬥的核心要素（應用到江湖一生）
1. **主動進入**：玩家選擇去哪裡打，不是被遊戲強迫
2. **即時反饋**：擊殺有即時音效+視覺爆發感
3. **掉寶即爽感**：怪死了東西就掉，撿到好東西是情緒高點
4. **越打越強**：戰鬥直接驅動成長，成長再驅動戰鬥
5. **流暢不卡**：操作響應即時，沒有回合等待感

## 對江湖一生戰鬥系統的直接設計指引

| 設計原則 | 說明 |
|---------|------|
| **戰鬥是主動行為** | 玩家走進某個區域/NPC主動選擇戰鬥，不是大地圖隨機踩到 |
| **掉寶是核心回饋** | 每場戰鬥都要有掉落，好的掉落是情緒高點 |
| **巨齒狀成長** | 戰鬥要能製造數值爆發的瞬間（突破、神兵、秘笈） |
| **自動戰鬥是標配** | 日常/簡單戰鬥可以自動，玩家保留介入權 |
| **即時制，非回合制** | 操作感比策略感更重要 |
| **可以快速結束** | 配合加速/自動，不讓重複戰鬥成為負擔 |
