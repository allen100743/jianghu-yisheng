不向玩家顯示「背後的數字」，靠世界和情境傳達資訊。

**Why:** 製作人和品霖共同確立的設計原則，貫穿所有 GDD。顯示數值公式會破壞沉浸感，讓玩家感覺在管理電子表格，而非活在江湖裡。SCUM 的 Metabolism 系統是反面教材——資訊過量「嚇跑玩家」。

**How to apply:** 設計每個 UX 元素時，問自己：「這個資訊能靠 NPC 反應、環境效果、戰鬥結果傳達嗎？」如果可以，就不要放進 UI。

具體禁忌（已在各 GDD 中確認）：
- 不顯示傷害公式、速度獎勵倍率
- 不顯示精確截止日期（只說「約N日」）
- 不顯示 severity 數值（只顯示視覺狀態）
- 不顯示 NPC 好感度精確數字
- 不提前列出「影響X的所有因素」清單
- 不提前顯示失敗後果（玩家應自行推導）
