UI 文案全程武俠語言，不用遊戲術語或修仙詞彙。

**Why:** 製作人明確要求，《江湖一生》是武俠遊戲不是修仙遊戲，語言是沉浸感的一部分。龍胤立志傳被玩家批評「UI 太像遊戲，不像江湖」，我們要做得更好。

**How to apply:** 寫任何 UI 文案或 Spec 時，逐字核對以下對照表。情境句優先用感受描述，不用功能描述。

| 禁用術語 | 使用術語 |
|---------|---------|
| HP 低 / 血量不足 | 傷重 / 體力不支 / 命在旦夕 |
| 等級提升 | 武功精進 / 頗有所悟 |
| 任務完成 | 事成 / 承諾已踐 |
| 遊戲結束 | 壽終正寢 / 這一生… |
| 背包 | 囊中之物 / 行囊 |
| 技能欄 | 武學 / 內功心法 |
| NPC 好感度 | 義氣 / 交情 / 積怨 |
| 任務失敗 | 失諾 / 負人心 |
| 任務無效 | 無緣 / 世事弄人 |
| 任務放棄 | 辜負 / 轉身而去 |
| 靈力、法力 | 內力 |
| 修煉境界 | 武功精進 |
| 丹藥 | 藥材、金瘡藥 |

**情境句格式**（浮框/通知/說明文字）：
描述感受，不描述數值。
✅ 「傷口見骨，血染衣襟，疼痛難當」
❌ 「外傷 severity = 0.45，攻擊力 -15%」
