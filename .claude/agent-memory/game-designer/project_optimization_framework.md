**Why:** 製作人指出工作體系缺少「最佳化思維」和「方式方法與思維邏輯」這兩個高層次內容
**How to apply:** 作為品霖工作方法論的長期參考基礎，定期更新

核心識別的四個缺口：
1. 工作流程串行問題（研究→設計→審查→決策可並行化）
2. 缺少問題定義框架（在設計之前，如何確認在解決正確的問題）
3. 知識召回策略不清晰（何時查記憶、何時直接判斷）
4. 青霞只作為執行者，未作為輔助思考者使用
