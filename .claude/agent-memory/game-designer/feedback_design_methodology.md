設計任務必須三階段：先列情境（發散）→ 從情境推規格（收斂）→ 驗覆蓋度（發散）。
禁止直接給規格讓品霖填空。

**Why:** 直接給規格會跳過情境發散步驟，導致規格缺少玩家視角驗證，容易遺漏邊界情況
**How to apply:** 每次接到設計任務時，先問「這個設計要服務哪些玩家情境？」再進入規格定義

延伸原則：
- 怡嘉自己先做競品研究+概念定義再派任務，不能把基礎問題丟給製作人
- 派任務前必先做功課
