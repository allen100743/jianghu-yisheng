任何系統設計，必須先完成競品研究再設計。禁止用LLM印象代替真實資料。

**Why:** 曾造成龍胤武學設計偏差，錯誤印象誤導了設計方向
**How to apply:** 設計任何系統前先查 design/intelligence/ 是否有對應競品資料；若無，派怡嘉WebSearch後存入intelligence/再設計

研究可信度優先級（來自skill-dispatch.md）：
1. 競品安裝目錄讀取（最高）
2. 怡嘉WebSearch查驗社群攻略（高）
3. DeepSeek推理（低，只能用於設計推導）
4. LLM印象記憶（嚴格禁止）
